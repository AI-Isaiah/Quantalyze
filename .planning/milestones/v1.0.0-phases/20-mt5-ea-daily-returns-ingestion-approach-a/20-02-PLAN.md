<objective>
Write the net-new MQL5 Expert Advisor under `tools/mt5/` that computes a strategy's daily total-equity return series (flow-adjusted, equity-based, DENSE calendar-daily, restart-durable) and writes it as a `date,daily_return` CSV into the MT5 `MQL5\Files` sandbox — conforming to the existing `daily_returns` ingestion contract pinned by Plan 01. Plus a README documenting the USD-only choice, deploy/run steps, the row cap, the CORRECTION caveat, and the NUMERIC manual T14/T15 acceptance gates.

The EA emits a DENSE calendar-daily series — ONE row per calendar day. Because the venues are crypto (OKX/Bybit, 24/7/365), the market trades EVERY day, so every row is a REAL equity-based return — there are NO artificial weekend/closed-day zeros to fill. (The interim "sparse @252" revision was reverted on 2026-06-14 per the user domain-correction: it had been driven by a red-team measurement that injected SYNTHETIC weekend zeros, a premise that is false for a 365-day market.) Annualization stays the existing `compute_all_metrics` path UNCHANGED (quantstats `periods=252`) so MT5's Sharpe/vol/CAGR are apples-to-apples with every crypto strategy on the ranking page; the EA does NOT need any annualization plumbing — it just emits the real daily-return series.

Purpose: This is the only client-side half of Phase 20. Its daily-return math runs under Wine with no CI harness, so its correctness is gated on a one-time manual demo-account reconcile (T14, now a concrete numeric worksheet) + restart-state test (T15) before the first live KPI is page-visible.
Output: `tools/mt5/QuantalyzeDailyReturns.mq5` + `tools/mt5/README.md`.

Equity (T6):        double AccountInfoDouble(ACCOUNT_EQUITY)   // includes floating PnL; NOT ACCOUNT_BALANCE
Deal history:       bool HistorySelect(datetime from, datetime to)
                    ulong HistoryDealGetTicket(int index)
                    long  HistoryDealGetInteger(ulong ticket, DEAL_TYPE)   // ENUM_DEAL_TYPE
                    double HistoryDealGetDouble(ulong ticket, DEAL_PROFIT) // signed cash effect
File (MQL5\Files):  int FileOpen(string, int flags, short delim)  // FILE_READ|FILE_WRITE|FILE_CSV|FILE_ANSI, ','
                    FileWrite(handle, ...); FileClose(handle); bool FileMove(src, 0, dst, FILE_REWRITE)  // for atomic temp→final rename
Server time:        datetime TimeTradeServer()                   // for date-rollover detection (server time)
Timer:              EventSetTimer(int seconds); OnTimer()        // fires even when market closed
Restart state:      file in MQL5\Files (NOT GlobalVariable — not durable across a hard kill)

Deal classification (E5 / per the test-strategy table):
  EXTERNAL FLOW — EXCLUDE from return (subtracted as net_external_flows):
    DEAL_TYPE_BALANCE (deposit/withdrawal), DEAL_TYPE_CREDIT, DEAL_TYPE_CHARGE, DEAL_TYPE_BONUS
    DEAL_TYPE_CORRECTION — DEFAULT classification is BROKER-DEPENDENT (a correction can be a balance
       correction → flow, OR a broker P&L/slippage/swap correction → a genuine COST that belongs in the
       return). Do NOT silently default to flow. Document the chosen default + its money-direction
       rationale in the EA AND the README, and make at least one CORRECTION deal a named T14 reconcile row.
  COST — INCLUDE in return (NOT netted as flow):
    DEAL_TYPE_COMMISSION[_DAILY|_MONTHLY|_AGENT_*], DEAL_TYPE_INTEREST, swap (carried in DEAL_SWAP)

Flow-adjusted return (the #1 formula, T2/T3/T10):
  net_external_flows = Σ signed cash of the day's EXTERNAL-FLOW deals (deposit>0, withdrawal<0)
  daily_return = (equity_close − net_external_flows − prior_close_equity) / prior_close_equity
  INCEPTION RULE (M2 fix): the first-ever row has no prior_close_equity → set daily_return = 0.0
    (base = initial funded equity); never divide by zero / emit ±Inf.

Output contract the EA MUST satisfy (pinned by Plan 01):
  Header `date,daily_return`; date ISO YYYY-MM-DD (NOT TimeToString's YYYY.MM.DD — replace '.' with '-');
  daily_return fractional decimal (0.0123 = 1.23%); DENSE calendar-daily (one row per calendar day —
  every day is a real trading day on a 24/7/365 crypto venue, so every row is a genuine equity-based
  return, NOT a zero-fill); full calendar-daily history from inception;
  MAX_INGEST_ROWS=5000 cap downstream (~13.7yr at one row per calendar day).
