services/csv_validator.py:
  def validate_csv(raw_bytes: bytes, fmt: str) -> dict[str, Any]
  - For fmt="daily_returns" the success envelope has:
      env["ok"]: bool
      env["errors"]: list[{"rule": str, ...}]   # e.g. {"rule": "currency_usd_or_blank"}
      env["info_flags"]: list[dict]              # ALWAYS present; [] when nothing fired; each entry has a "rule" key
      env["daily_returns_series"]: list[{"date": "YYYY-MM-DD", "daily_return": float}]
  - Header is lowercased+stripped; `date,daily_return`; optional `currency` column accepted (required=False, nullable=True).
  - currency rule: value must be "" or "USD" (case-insensitive) → else rule "currency_usd_or_blank", ok=False.
  - auto-÷100 (_maybe_auto_normalize_percent_form): fires ONLY when non-zero-value median |x| > PERCENT_FORM_AUTO_NORM_LOWER (=0.5) AND <= 100 AND max |x| <= 100. On firing it appends an info_flag with rule == "auto_normalized_percent_form". A fractional series (non-zero median |x| <= 0.5) → that flag is ABSENT.
  - dollar-form sentinel rejects series with non-zero median |x| > threshold that don't auto-normalize; daily-Sharpe sentinel rejects if daily Sharpe (mean/std, no annualization) > 10.0.
  - date must be strictly increasing AND unique; emit ISO YYYY-MM-DD.

services/metrics.py:
  def compute_all_metrics(returns: pd.Series, benchmark_returns=None) -> MetricsResult
  - VERIFIED this revision: signature has NO `periods` parameter. Called by BOTH analytics_runner.py:1584 (trades) AND :2027 (CSV/MT5) with no periods override — so periods=252 is the PRODUCT-WIDE displayed convention. Do NOT plumb periods=365.
  - Preconditions (fail loud): returns.index must be a DatetimeIndex, FLOAT dtype, MONOTONIC-increasing.
  - KPIs call qs.stats.{cagr,volatility,sharpe,sortino,calmar,max_drawdown}(returns) with NO periods argument
    → quantstats 0.0.81 DEFAULT periods=252 (verified this session):
       volatility = std(ddof=1) * sqrt(252)
       sharpe     = (mean/std(ddof=1)) * sqrt(252)
       cagr       = (1+returns).prod()**(252/len) - 1   [years = len/252]
  - total_return = (1+returns.dropna()).prod()-1
  - MetricsResult.__getitem__ proxies to .metrics_json, so result["sharpe"] works in tests.
