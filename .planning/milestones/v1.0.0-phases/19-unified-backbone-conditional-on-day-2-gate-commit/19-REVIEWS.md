## What the plan gets RIGHT (calibrates trust)

Both reviewers independently agreed on these strengths — these should NOT be changed:

1. **REUSE-NOT-RECREATE discipline** is enforced explicitly. Keeping `services/exchange.py` (629 LOC) untouched and the IngestionAdapter Protocol pattern (5 methods, `@runtime_checkable`, lazy import to avoid circular deps with EquityCurveBuilder) is the right way to extend without rewriting.
2. **Drain semantics primitive** (`compute_jobs.metadata->>'unified_backbone_at_claim'` snapshot at claim time) is the only correct way to handle long-running jobs behind a kill switch. Most teams get this wrong — but the IMPLEMENTATION has D-1 (re-claim overwrite) and D-3 (no PostgREST fallback) issues that need fixing.
3. **Supabase kill-switch row** (instead of Vercel env-var flip for auto-rollback) avoids redeploy churn and allows fast rollback.
4. **First-class `public_token`/`expires_at` columns in 103** (Pitfall 7 mitigation) rather than burying them in JSONB is senior-level.
5. **Sentinel migration 106** documenting the deferred 107 apply is a clean way to reserve a migration slot without coupling files.
6. **Wave 0 file dependencies map cleanly** — no critical REQ lacks an automated test entry, even where individual tests are weak (per §HIGH).
7. **Assumption log** (Sentry events API shape, quantstats periods) explicitly flags live-verify-before-ship.
