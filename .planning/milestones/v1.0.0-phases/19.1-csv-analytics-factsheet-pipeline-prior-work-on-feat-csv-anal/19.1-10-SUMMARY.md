## B3 parity expansion — PDF export routes (caught by /ship code review)

The /ship coverage+testing specialist (conf 8) found the **same B3 gate** in the
two PDF export routes: `src/app/api/factsheet/[id]/pdf/route.ts:218` and
`tearsheet.pdf/route.ts:185`, both `computation_status !== "complete"` → HTTP 400.

regression test (asserts the strategy passes the analytics gate / reaches the PDF

the plan author didn't know about. Files added to this PR: `pdf/route.ts`,
