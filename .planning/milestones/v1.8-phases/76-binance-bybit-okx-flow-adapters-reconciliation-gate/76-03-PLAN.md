  <behavior>
    reconcile_flow_residual(terminal_nav, reconstructed_start, daily_pnl, flows_by_day):
      - residual = terminal_nav − reconstructed_start − Σpnl − Σflows.
      - tol = max(1.00, 1e-6 * abs(terminal_nav)).
      - abs(residual) <= tol → OK (holds by construction). abs(residual) > tol →
        raise NavReconstructionError (a dropped/mis-valued flow leaked into the roll).
      - This is a construction-sanity / mutation detector: MUTATION — deleting the
        `- flows[t]` term in reconstruct_nav (or dropping a flow before the roll) →
        the residual test REDs. Called from inside reconstruct_nav_and_twr after the
        NAV is rolled (numpy-finite-checked; I/O-free).

    Terminus segmentation — a STANDALONE pure helper applied by the caller (76-04),
    NOT a kwarg threaded through transforms.py (keeps the high-blast-radius shared path
    untouched → the Phase 74 byte-identity pins stay trivially GREEN):
    `apply_flow_coverage_terminus(returns, flow_coverage_start_day) -> (returns, flags)`:
      - When flow_coverage_start_day is set and later than the first return day, the
        pre-terminus window is untrustworthy (a deposit older than retention is
        unfetchable → early reconstructed NAV goes ≤ 0). Segment at the last trustworthy
        day: NaN the returns for days BEFORE flow_coverage_start_day (refuse pre-terminus
        TWR — never a fabricated number) and set a `flow_coverage_incomplete` flag →
        complete_with_warnings. The caller merges the flag into the meta.
      - flow_coverage_start_day is None (full coverage) → returns unchanged, no flag
        (SC-4 byte-identity preserved; flow-less + fully-covered accounts do NOT move).
      - Transient vs terminal: this helper segments ONLY on a set start-day signal
        (a clean end-of-history boundary). A transient fetch error is NOT this signal —
        it bubbles at the I/O layer (76-04) and fails the job retryable; it must never
        reach here as a segment request. MUTATION — removing the segment lets a
        pre-terminus fabricated return through → the terminus test REDs.
  </behavior>
