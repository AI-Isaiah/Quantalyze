<objective>
Build the pure native-unit core (contract §1): the frozen `NativeLedger` input
dataclass (§1.2), `reconstruct_native_nav_and_twr` performing the six pure steps
of §1.3 (classify/coalesce → per-bucket native roll via the SAME
`nav_twr.reconstruct_nav` → inception gate → union-calendar valuation →
chain-link with `prev0` → meta with the §6 key), the §5 inception-reconciliation
refuse gate with its tolerance constants, and the one additive change to an
existing symbol: `chain_linked_twr(..., prev0=None)` (§1.4, App A #2 — day-0
`prev` from `daily_pnl.iloc[0]` is meaningless once pnl is per-currency native).

The USD-space identity `NAV_{t-1} = NAV_t − pnl_t − F_t` omits the translation
integral `Σ_c ∫ B_c·dP_c` (§0 — the −$480,782 LTP068 mislabeled start capital);
in native units per currency the ledger reconciles exactly, and the translation
term is carried implicitly by `B_c(t-1)·(P_c(t) − P_c(t-1))` inside the day-over-
day NAV difference. Mixed accounts are the base case (§8): a USD-native account
is zero branch-2 buckets, a pure coin account zero branch-1 — same code.

NO production wiring: nothing calls this module outside tests until Phase 80.

Purpose: SC-1 + SC-3 (density/value-gate enforcement half) + the SC-6 gate impl.
Output: `native_nav.py` core + gate; `prev0` kwarg; mutation-honest tests.
