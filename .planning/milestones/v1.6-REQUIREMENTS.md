# Requirements: Quantalyze — v1.6 Scenario Series-Space Purification (ARCHIVED)

**Shipped:** 2026-07-04, PR #572 squash `f78f036b` = v0.36.0.0, tag `v1.6`.
**Outcome:** 16/16 v1 requirements complete and validated (audit: `v1.6-MILESTONE-AUDIT.md`; live canary: `v1.6-phases/65-authed-prod-canary/65-VERIFICATION.md`). No requirement adjusted or dropped.

**Defined:** 2026-07-03. **Design source:** `.planning/v1.6-SERIES-SPACE-INPUT.md`
(prod-grounded: 0 real gate=false users; only 2 `phase10-rpc-*@test.local` residue
holders). Kickoff decisions locked 2026-07-03: **D1** gate=false → blank-mode
fallback; **D2** membership = explicit per-key id list; **D3** data-source toggles
stay ephemeral.

**The principle:** the scenario tab operates in **series space** (return streams
blended over a window), never position space (a current snapshot). Holdings are only
a derivation source for a book's series and natural weights. Both P61 bugs were
position-space machinery leaking into series space.

**Ordering lock:** MEMBER (schema) lands BEFORE ENGINE (deletion) — membership
replaces the runtime gate as the draft's source of truth, so the deletion has a
persisted selector to stand on.

## v1 Requirements

### ENGINE — holdings-snapshot fallback removal

- [x] **ENGINE-01**: The composer builds its engine set exclusively from per-key units and added-strategy units — the holdings-snapshot unit builder (`buildStrategyForBuilderSet`) and its composer call sites are removed.
- [x] **ENGINE-02**: Compare (`computeMetricsForDraft`) computes on the same series-space selection; the legacy holdings path is removed from `scenario-compare.ts`.
- [x] **ENGINE-03**: A gate=false book (transient: new key before backfill) falls back to BLANK mode — added-only composer plus the existing calm "per-source modeling needs per-key history" note; never a broken or empty book UI (D1).
- [x] **ENGINE-04**: The holding-alias collapse (`scenario-dealias.ts`, `symbolByHoldingId`, `buildHoldingRef`-as-engine-id) retires with the holdings units — ONLY after verifying per-key/added ids never alias (avg-|ρ| honesty tests stay green); executed as a reviewed re-baseline act, never a silent deletion.
- [x] **ENGINE-05**: No `holding:` scopeRef can appear as an engine unit id on any scenario surface — pinned by a grep-guard test that fails on reintroduction.

### MEMBER — explicit draft series membership (schema v4)

- [x] **MEMBER-01**: A saved draft persists its series membership as an explicit per-key id list alongside `addedStrategies` (D2); `SCENARIO_SCHEMA_VERSION` 3→4 with a NON-destructive upgrade branch (a v3 draft derives membership from today's gate rule on open — same pattern as `upgraded_v2_windowless`).
- [x] **MEMBER-02**: Compare distinguishes blank-authored drafts from book drafts by persisted membership — a blank draft NEVER has the live book merged into its column (closes red-team F5); the ephemeral `entryMode` stops being load-bearing for saved drafts.
- [x] **MEMBER-03**: The share mint gate and share-resolve read the SAME membership field — "book-only" is defined as membership containing only per-key ids, one definition across mint/resolve/compare.
- [x] **MEMBER-04**: Reopening a draft whose persisted member key is no longer eligible DISCLOSES the drop (provenance-note mechanics) — never a silent recompute over a different member set.

### PRESENT — presentation purification

- [x] **PRESENT-01**: The scenario KPI strip is return-form only — the AUM KPI is removed from the tab (matching the share page's existing "no USD, no AUM" contract).
- [x] **PRESENT-02**: Commit sizing keeps reading `scenarioAum` at the COMMIT boundary (diff modal) unchanged — weight × AUM sizing is unaffected.
- [x] **PRESENT-03**: The public share page renders a one-line caption when the shared draft's membership includes book series — "computed from this scenario's catalog strategies only" (red-team F3; no private data needed).

### GUARD — cleanup, safety nets & live verification

- [x] **GUARD-01**: The two `phase10-rpc-*@test.local` residue holders' rows are removed from prod (the last gate=false holders).
- [x] **GUARD-02**: The P61 regression suites (composer P61 block, compare per-key block, T_CP8, share T_SH13/14) survive the removal verbatim — or are re-pointed as individually reviewed acts with rationale, never blind-updated.
- [x] **GUARD-03**: The frozen engine (`src/lib/scenario.ts`, `src/lib/scenario-window.ts`) stays zero-diff through the whole milestone.
- [x] **GUARD-04**: An authed prod canary verifies the purified surfaces live — book blend, blank mode, mixed keys+added, save→reopen membership round-trip, compare columns, share mint/resolve — with 0 console errors.
