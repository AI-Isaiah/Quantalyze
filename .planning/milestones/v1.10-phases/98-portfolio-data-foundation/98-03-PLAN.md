<decisions_locked_by_planner>
These three data-shape decisions were explicitly delegated to the planner (98-VALIDATION.md "Open decisions"). They are now LOCKED — implement exactly, do not re-litigate:

- **D-P1 — Exposure taxonomy: `holding_type` is the primary "class" dimension; the read exposes the raw groupable grain.** `allocator_holdings.venue` is always a crypto exchange (allocator_positions.py:216,253), so the #597 crypto/traditional classifier is DEGENERATE per-position (one all-crypto bucket) — using it would violate no-invented-data in spirit. The only complete, honest, non-degenerate per-position class that EXISTS is `holding_type` (`spot`/`derivative`). `venue` is custody location (not an asset class); `symbol` is too granular to be a class; a symbol->asset-bucket map would be an invented taxonomy with an unbounded symbol universe. Therefore: the snapshot read returns slices at the `(holding_type, venue, symbol, side)` grain with `holding_type` designated primary — Phase 99 groups by it by default (display label, e.g. "Spot vs Derivatives", is Phase 99's call) and has venue/symbol available for secondary grouping/drill-down without a new read.
- **D-P2 — Net exposure is SIGNED.** `value_usd` is stored UNSIGNED (positions.py:63 takes abs(size); size_usd is magnitude; spot is qty*mark >= 0) and direction lives in `side` (`long`/`short`/`flat`). PI-02 says NET: `signedValueUsd = side === "short" ? -value_usd : value_usd`; `netUsd = sum(signed)`, `grossUsd = sum(value_usd)`. Summing unsigned notional and labeling it "net" would misstate any hedged book (long 300 + short 100 must read net 200, not 400). Both net and gross are returned (gross is free and Phase 99 will want it).
- **D-P3 — Allocation-over-time weights are per-VENUE.** `allocator_holdings` has NO strategy linkage (its only FK is `api_key_id` -> `api_keys`; verified database.types.ts:208-216) — "per-strategy weight" does not exist in this table, so CONTEXT's "per-strategy (or per-venue)" resolves to per-venue. `weight = venueGrossUsd / asofTotalGrossUsd` per `asof` (gross denominators — mixing signed values into a weight denominator can divide by ~0 on a hedged book). An `asof` whose total gross is 0 cannot form honest weights: SKIP that asof (it then falls into a marked gap) rather than emitting NaN/fabricated weights.
- **D-P7 — Honest-empty shapes:** `getLatestExposureSnapshot` returns `null` when the allocator has zero holdings rows (so "no data" is distinguishable from "zero exposure"); the two series functions return `{ points: [], gaps: [] }`. Never a zero-filled point, never a synthetic asof.
- **Gap convention:** `asof` is a DATE with one row per (allocator, venue, symbol, asof) day (mig 20260420073003:102,146). Expected cadence is daily; a missing calendar day strictly between the first and last observed `asof` is a gap span `{ start, end, kind: "gap", days }` (days inclusive both ends), mirroring the factsheet `missingSegments` shape (src/lib/factsheet/types.ts:472-478). Points are emitted ONLY for asof days that exist.
- **Module placement/naming:** new file `src/lib/portfolio-exposure.ts` (sibling convention: portfolio-stats.ts, portfolio-insights.ts, portfolio-math-utils.ts). Do NOT grow queries.ts (god-file; splits are opportunistic-only, additions go to new modules). Row cap: `.gte("asof", <today - 730 days>)` mirroring the 730-day BACKFILL_CAP_DAYS cap at queries.ts:2540-2542.
- **Projection allow-list (secretless):** exactly `"asof, venue, symbol, holding_type, side, value_usd"`. NOT `raw_payload` (may contain exchange payload), NOT `api_key_id` (research contract: no `api_key*` in projection), NOT quantity/mark/entry/pnl (not needed by any of the three reads; add later only with a consumer).

```typescript
export type HoldingClass = "spot" | "derivative";        // D-P1 primary class
export interface ExposureSlice {
  holdingType: HoldingClass; venue: string; symbol: string;
  side: "long" | "short" | "flat";
  valueUsd: number;          // unsigned, as stored
  signedValueUsd: number;    // D-P2: short => -valueUsd
}
export interface ExposureSnapshot {
  asof: string;              // the latest asof the slices belong to
  slices: ExposureSlice[];
  totalGrossUsd: number; totalNetUsd: number;
}
export interface AsofGap { start: string; end: string; kind: "gap"; days: number }
export interface NetExposurePoint { asof: string; netUsd: number; grossUsd: number }
export interface AllocationPoint {
  asof: string;
  venues: { venue: string; valueUsd: number; weight: number }[]; // weights sum to 1 per point
}
export async function getLatestExposureSnapshot(userId: string): Promise<ExposureSnapshot | null>;
export async function getNetExposureSeries(userId: string): Promise<{ points: NetExposurePoint[]; gaps: AsofGap[] }>;
export async function getAllocationSeries(userId: string): Promise<{ points: AllocationPoint[]; gaps: AsofGap[] }>;
export function computeAsofGaps(sortedAsofDays: string[]): AsofGap[]; // pure, exported for tests + reuse
```
