# Phase 108 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **⚠️ THIS IS A PARITY CONTRACT, NOT A REDESIGN.** Phase 108 is a backend-of-frontend
> refactor: the scenario-planner blend panels move off the bespoke `scenario-blend-panels.ts`
> "second-Sharpe" TS compute onto the canonical backbone rolling PRIMITIVES. **The rendered UI
> must look byte/pixel-identical to today.** DESIGN.md governs and is UNCHANGED this phase. No new
> panels, palettes, layouts, copy, or components. The entire contract below is a "these must NOT
> change" checklist plus the states matrix. SC-4 = "no user-visible regression."

## Scope of Change (the ONE delta)

| Aspect | Before | After | User-visible? |
|--------|--------|-------|---------------|
| Rolling vol/Sharpe/Sortino denominator | SAMPLE std (÷ n−1) | POPULATION std (÷ n) — canonical backbone | **No.** Shift is at the 3rd–4th significant figure; invisible at the 2-decimal display precision (USER DECISION, 108-CONTEXT §Parity std). |
| Derivation source | `scenario-blend-panels.ts::buildBlendPanels` (deleted) | Backbone `factsheet/rolling.ts` primitives fed by `computeScenario`'s `portfolio_daily_returns` | No — same series, same shapes, same panels. |
| Everything else (layout, copy, colors, type, whiskers, window toggle, empty states, chart props) | — | **IDENTICAL** | No. |

**Nothing else may move.** If any pixel other than the sub-display-precision rolling values changes, the refactor is wrong.

**Adapter obligations (invisible plumbing that preserves the above):**
- The backbone rolling primitives return `Array<number | null>` parallel to `dates[]`. The adapter MUST zip `dates[i] ↔ value[i]` and DROP the leading `null` warmup region to reproduce today's `{date,value}[]` shape (dated at the window's last day).
- Reshape `quantileSummary` back to the positional `{All:[min, p25, p50, p75, max]}` — take `min`/`max` for the whiskers, NOT `p05`/`p95` (USER DECISION; adopting p05/p95 would visibly tighten the box = regression).
- Re-home the `usableN` degenerate gate alongside the new derivation (Claude's Discretion, thin adapter): collapse EVERY series to `[]`/`{}` when `hasNonFinite || length < 10 (MIN_USABLE) || length < window`, and report `usableN: 0` when any non-finite value is present. The three UI keys that read `usableN` (distribution empty-branch, per-option `SegmentedControl` disable, rolling empty-branch) must render IDENTICALLY.

## States Matrix (the verification surface)

For each state, the rendered DOM/pixels must be identical before and after the refactor. Only the numeric rolling values may differ, and only below display precision.

| State | Trigger | Expected render (must match today) |
|-------|---------|-------------------------------------|
| **Normal** | usable series ≥ selected window, all finite | Both Cards render; histogram (20 bins), quantiles (min/max box), rolling Sharpe/vol/Sortino at the selected window; captions populated. Rolling values shift ≤ 3rd–4th sig fig (invisible at 2dp). |
| **Window toggle — 3M** | `rollingWindow=63` | Sharpe/vol/Sortino recompute at 63-day window via backbone primitives; caption reads `63-day rolling window`; legend label `63d`. |
| **Window toggle — 6M (default)** | `rollingWindow=126` | Default on mount; caption `126-day rolling window`; legend `126d`. |
| **Window toggle — 12M** | `rollingWindow=252` | Caption `252-day rolling window`; legend `252d`. |
| **Window disabled** | `usableN < window` for a given option | That segment is `disabled` in the `SegmentedControl`; identical disabled styling. |
| **Degenerate — below window** | `usableN < rollingWindow` (≥10 but short of the window) | Rolling Card body swaps to neutral `PartialDataBanner` (`role="status"`) with the per-window "Awaiting more data" copy. WR-02 test pins this exact behavior. |
| **Degenerate — non-finite present** | any non-finite value in the series | `usableN` reported as `0`; BOTH panels collapse to empty (histogram empty-branch + all rolling options disabled); honest "Awaiting more data" banner. No NaN/Inf ever reaches a chart (security V5 — preserve the collapse). |
| **Empty — <10 points** | `length < MIN_USABLE(10)` | Distribution Card shows "Awaiting more data / …at least 10 overlapping daily returns…"; rolling options disabled. |
