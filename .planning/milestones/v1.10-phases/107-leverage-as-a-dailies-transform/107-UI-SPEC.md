# Phase 107 — UI Design Contract

> Visual and interaction contract for the leverage-as-a-dailies-transform refactor.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note (load-bearing):** This is a **frontend REFACTOR of an existing surface**, not a
net-new UI. The factsheet leverage slider already renders; Phase 107 rewires it so that at
L≠1 the WHOLE factsheet re-derives levered (charts + right rail + honest α/β/IR) instead of
re-scaling only the 7 KpiStrip headline scalars, and DELETES the ~780 LOC MODELED /
CAVEAT / α-IR-blanking / BASE·1× disclosure apparatus. No new panels, palettes, layouts,
components, or tokens are introduced. DESIGN.md governs the existing aesthetic and is
**byte-unchanged** this phase. This spec is therefore scoped to four contracts:
(1) the slider → whole-page re-derive **interaction contract**,
(2) the **microcopy contract** for the kept-and-reworded "modeled what-if / excludes financing cost" disclosure + clamp messages,
(3) the **deletion contract** (elements removed; no orphaned states / empty eyebrows remain),
(4) the **state matrix** (L=1 byte-identical baseline; L≠1 settled; L≠1 re-deriving; clamp/error).

an *existing* token is the only color decision in this phase:

| Role | Value | Usage in this phase |
|------|-------|---------------------|
| Dominant (60%) | `--color-page` #F8F9FA / `--color-surface` #FFFFFF | factsheet background + strip surface (unchanged) |
| Secondary (30%) | `--color-border` #E2E8F0 hairlines; right-rail metrics column | unchanged |
| Accent (10%) | `--color-accent` #1B6B5A | strategy equity curve; focus ring on the leverage input (`focus-visible:outline-accent`) — **reserved for these only** |
| Positive | `--color-positive` #15803D | α / IR / Cum / CAGR positive sign-tone (now shown honestly at L≠1) |
| Negative | `--color-negative` #DC2626 | α / IR / Max DD negative sign-tone (now shown honestly at L≠1) |
| Warning | `--color-warning` #B45309 | **KEPT ONLY on the clamp/validation message** (a transient, recoverable input-validation state — correct amber usage per `DESIGN.md` Phase 102 tone split) |

Accent reserved for: the strategy equity curve color and the leverage input focus ring only —
never a general interactive tint.

**Color decision — the leverage disclosure moves OFF amber (rationale, load-bearing):**
Today an amber (`--color-warning` #B45309) `MODELED · {L}×` eyebrow sits above a **muted**
(`text-text-muted` #64748B) caveat line. Phase 107 **deletes the amber eyebrow** and **keeps
the caveat line at its existing muted treatment** (reworded). This is the minimal, conformant
choice — the caveat text is already muted today, so no new color is introduced. It is also the
*correct* semantic per `DESIGN.md`: amber is reserved for **transient / recoverable** states
(Phase 102 tone split, widened Phase 58). The levered numbers are now the **real re-derived
levered track** (honest, not a fabricated scalar rescale), so a persistent "excludes financing
cost" disclosure is steady-state information, not a recoverable-state warning → it renders
**muted neutral**, matching the honest-empty precedent. Amber survives **only** on the clamp
message, which genuinely is a transient recoverable input event.

## Interaction Contract — slider → whole-page re-derive

The core of this refactor. The leverage input (`#leverage-factsheet`) drives the ENTIRE
factsheet through the one shared view hook (`useBasisSeriesView` extended, per RESEARCH); every
chart/panel/rail already reading that hook follows with zero per-consumer wiring.

| Aspect | Contract |
|--------|----------|
| Input responsiveness | The `<input type="number">` stays **controlled and immediate** — the typed value renders in the field on every keystroke regardless of derive timing. An emptied field (`""`) is keep-previous, never a mid-edit snap to 0× (existing L-1 round-2 guard, preserved). |
| L = 1 path | **No re-derive.** The extended view short-circuits `sanitizeLeverage(L) === 1` and returns the base (basis-merged) view **by reference** → byte-identical render (SC-4). No caveat line, no loading state, no `Reset 1×` button, no announcement. |
| L ≠ 1 path | Client re-runs `deriveSeriesBundle` on the active-basis dailies scaled `r → L·r`; charts, distribution/rolling/heatmap panels, AND the right rail all re-render levered; α→L·α / β→L·β / IR render **honest real values** (never `"—"` for a leverage reason). |
| Debounce | **Default: none** — honest full re-derive on each committed change (CONTEXT performance decision, option a). **Conditional:** if plan-time measurement of `bootstrapCI` shows the interactive slider janks, debounce the *derive* (not the input) at **200ms** (`DESIGN.md` motion "short" 150ms → "medium" 250ms band; 200ms is the midpoint and a valid raw-CSS duration — do NOT use a `duration-250` Tailwind class, it is silently dropped per `DESIGN.md` §Motion). The input value stays immediate; only the recompute is debounced. |
| Re-deriving transition (only if debounced/slow) | **Never flash the charts to an empty/skeleton state.** The last-good rendered bundle stays visible until the new levered bundle resolves. No spinner, no blocking overlay, no reflow. This honors `DESIGN.md` "minimal-functional motion" + "no invented data" (never show a blank where real data was). A sub-frame synchronous re-derive simply re-renders in place with no transient state at all. |
| Chart animation | Governed by the **frozen chart islands'** existing config (`EquityChart`, `TimeSeriesChart`, `HistogramChart`, `MasterBrush` are `FROZEN_ISLANDS` — any byte edit reds the guard). Do NOT add or alter chart transition animation. Reduced-motion is inherited from the existing frozen config. |
| Reset | The `Reset 1×` button (kept, unchanged) restores L=1 → snaps back to the byte-identical base view. Non-destructive. Visible only while `leverage !== 1`. |
| Ephemerality (GUARD-04) | Leverage never persists — no storage / cookie / URL / history write. Slider is ephemeral component state only. Toggling basis away and back restores it. |

## Copywriting / Microcopy Contract

The disclosure copy is REWORDED (CONTEXT decision): keep a "modeled what-if / excludes
financing cost" framing, but drop the now-false "everything else stays on the base 1× track"
language. Executor MUST use these strings verbatim.

| Element | Copy |
|---------|------|
| Primary control (kept) | Leverage `<input>` — `LEVERAGE` label + numeric field + `×` unit + `Reset 1×` reset button (all existing; no relabel) |
| Input title / aria-label | `Leverage multiplier (1× = unlevered; excludes borrow / funding cost)` — already honest; **kept unchanged** |
| Reworded what-if disclosure (replaces `LEVERAGE_CAVEAT`; renders at L≠1 only, muted caption, inserted not reserved) | `What-if projection at {L}× leverage: daily returns are scaled r → L·r and the whole factsheet re-derives. Excludes borrow, funding, and liquidation cost — not the strategy's realized track record.` |
| Clamp — non-finite / invalid | `Invalid leverage — enter a number between 0 and {MAX_LEVERAGE}. The previous value was kept.` (unchanged; no "modeled" reference to reword) |
| Clamp — negative | `Leverage can't be negative — shorting isn't included in this what-if. Clamped to 0.` (reworded from "shorting isn't modeled in this projection") |
| Clamp — above max | `Leverage clamped to {MAX_LEVERAGE}× — the maximum in this what-if projection.` (reworded from "the maximum modeled leverage") |
| Empty state | **Not applicable** — the leverage cluster renders only when `leverageEligible` (single-key AND `periodsPerYear != null` AND an active basis), i.e. dailies always exist. No empty state exists for this control. |
| Destructive confirmation | **None** — leverage is ephemeral display-only; there is no persisted or destructive action in this phase. `Reset 1×` is non-destructive and needs no confirmation. |

Copy interpolation: `{L}` is the applied leverage (e.g. `2×`, `1.5×`); `{MAX_LEVERAGE}` is the
shared `MAX_LEVERAGE` constant from `src/lib/leverage.ts` (do not hard-code the numeral).

## State Matrix

| State | Trigger | Visual + copy contract |
|-------|---------|------------------------|
| **L = 1 (baseline)** | slider at 1 (default) | Byte-identical to pre-change: base view by reference; input shows `1`; **no** `Reset 1×` button; **no** disclosure caption; **no** amber eyebrow; α/IR at their base honest values; no state announcement. SC-4 golden pins this. |
| **L ≠ 1 (settled)** | valid L committed | Whole factsheet re-derived levered: charts + rail + honest α→L·α / β→L·β / IR; muted what-if caption visible (reworded copy); `Reset 1×` button visible; input shows `{L}`. Caption carries `role="status" aria-live="polite"` so entering/leaving the levered what-if is announced (replacing the deleted eyebrow's announcement). |
| **L ≠ 1 (re-deriving)** | only if derive is debounced/slow | Input reflects the typed value immediately; **last-good charts stay rendered** (no skeleton/blank flash, no spinner, no reflow); caption may lag by ≤ the debounce window (200ms). If the synchronous re-derive is sub-frame, this state is not observable. |
| **Clamp / invalid** | non-finite, `<0`, or `>MAX` input | Value clamped (previous kept on non-finite); the clamp message renders in **amber** `--color-warning` #B45309, caption tier, `role="status" aria-live="polite"` (existing). Charts/rail render the clamped value's levered (or unchanged) result. |

A11y minimums (per `DESIGN.md` §9-State a11y / DESIGN-05, unchanged): non-blocking state
changes use `role="status" aria-live="polite"` (the what-if caption + the clamp message);
recharts `accessibilityLayer` stays opted-out (existing codebase-wide contract); focus ring on
the input is `focus-visible:outline-2 outline-offset-2 outline-accent` (existing). No new axe
surface — this refactor removes DOM (the eyebrows) and rewords copy; it introduces no new
interactive element.
