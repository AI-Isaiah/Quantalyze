Evaluation order, each branch commented with the source it comes from:

1. `account_info.get("trade_allowed")` truthy → `"trade_capable"`. A positive account signal is
   conclusive and wins before any terminal reasoning; this preserves today's master-reject

2. `order_check_result.get("retcode") == _TRADE_RETCODE_DONE` (10009) → `"trade_capable"`.

3. `terminal_info` is `None`, is not a mapping, or lacks either `connected` or `trade_allowed`

   connection to the trade server" as a sibling cause of `trade_allowed` being false, so the
   account negative is not attributable to investor mode.
5. `not terminal_info.get("trade_allowed")` → `"undetermined"`. ⭐ **THE FIX.** This is the

   Python API"*, MetaQuotes' **default-ON** setting. With it in force a MASTER password produces

   available and we must refuse.
6. Otherwise → `"read_only"`. The terminal itself would permit trading and the account still
   says no, so the refusal is attributable to the account — the composition EVIDENCE §C12
