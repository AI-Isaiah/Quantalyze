<objective>
Close WIZFORM-03 as a **class**: a `fix[]` bullet carries a requirement, and ONE filter decides
whether it renders. Not three `if (code === …)` arms.

Purpose: D-17 says "switch to a different exchange" must never reach an MT5 user. The three
bullets that say it (`KEY_PROBE_FAILED`, `KEY_RATE_LIMIT`, `KEY_NETWORK_TIMEOUT`) are three
instances of one class — "a remedy that presupposes a fact about the context". Adding three code
branches re-ships the instance-not-class defect this repo has already paid for. The mechanism
here also serves Gate B (surface-conditional bullets), which is the same shape.

Output: `FixRequirement`, an optional index-aligned `fixRequires` on the copy entry, one filter
at the top of `formatKeyError`, the four bullets tagged, and three whole-table sweeps.

⛔ This plan mints **no new `WizardErrorCode`** and does not move `EXPECTED_TABLE_SIZE` — 153.1-04
owns the vocabulary. This plan changes only how existing bullets are selected.
