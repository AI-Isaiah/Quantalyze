  verified 2026-08-12: analytics-service/services/ingestion/adapter.py ValidationResult :98-123
  carries NO account-identity field, so ccxt venues have none; the residual is recorded in 154-06).

  A client-writable path would let a caller evade dedup by inventing an id. New sibling function
  `scrub_client_supplied_venue_account_id` + BEFORE INSERT trigger, SECURITY INVOKER, same
  `current_user IN ('postgres','service_role','supabase_admin')` allowlist as 20260811210000:515-546.
  (SECURITY DEFINER RPCs run as the function owner, so create_wizard_strategy's INSERT passes the
  allowlist; a direct authenticated INSERT gets scrubbed to NULL.)
- add_wizard_composite_key is NOT re-created: the composite path writes no venue identity (MT5
