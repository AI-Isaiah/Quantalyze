### 1. ⛔ No existing migration pins a hand-typed count of DATA rows and ABORTS on inequality

| Data backfill + count, **NOTICE only** | `20260429063138_seed_is_example_backfill.sql:38-58` | `SELECT COUNT(*) INTO flagged_count … RAISE NOTICE '… flagged % seed rows … (expected 8 …)'` — **cannot abort.** Its own comment anticipates a lower count in fresh test DBs. |

**Recommendation:** compose rows 2 and 3 — take the `IF v_x <> <hand-typed literal> THEN RAISE
EXCEPTION … USING ERRCODE` form from the schema-fact pins and point it at
`SELECT count(*) FROM public.api_keys`, framed by the pre-flight/post-verify pairing of

- The literal must carry a `-- MEASURED <date> against khslejtfbuezsmvmtsdn` comment, the convention
  `test_mt5_abandon_roster.py:64-66` and `20260726000225:98-99` both use.

### 2. ⚠️ No existing `analytics-service/services/` leaf holds a LIVE client and is shared by both a router and a worker

The two shared modules are shared but *not* live-client-holding:
- `services/mt5_validation.py` — **pure rules**, imported by `routers/exchange.py:41` and
  `services/ingestion/mt5.py:65`. Its own docstring calls it *"the ONE seam holding every [ASSUMED]
  investor-vs-master rule"*; `RESEARCH §Q7` rejects folding the probe body into it because a live

- `services/mt5_concurrency.py` — holds the **lock registry** and a `terminal_key` STRING only; its

  `services/ingestion/mt5.py:64`, `services/job_worker.py:139`, `services/allocator_positions.py:93`.

So `mt5_probe.py` is a **new kind** of module: a fourth rung that takes a live `Mt5Client` as a
parameter. **Recommendation:** copy `mt5_concurrency.py`'s docstring structure (single-source claim
→ enumerated consumers → leaf-module invariant → ⛔ DIRECTION paragraph) and `mt5_validation.py`'s
two-caller framing, and state the new fact plainly: *the client is a PARAMETER, never a
module-level handle, so this module owns no session and cannot fence one.* The import edge is
one-way and cycle-free: `mt5_client` → `mt5_validation` → **`mt5_probe`** → {`routers/exchange.py`,
`services/ingestion/mt5.py`}.

### 3. ⚠️ No existing ast roster spans MORE THAN ONE FILE / ONE CLASS

`test_mt5_abandon_roster.py` pins `CLIENT_RELPATH = "services/mt5_client.py"` + `CLIENT_CLASS =
