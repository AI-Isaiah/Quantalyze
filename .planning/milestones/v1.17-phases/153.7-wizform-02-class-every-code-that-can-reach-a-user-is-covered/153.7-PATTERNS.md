The depth-aware window (`rhsWindow`, line 115) — **this is the ~20-line generalisation target
RESEARCH Q3 names for balanced-paren argument extraction.** It already tracks `(`, `[`, `{`:

```typescript
/** The RHS of an assignment starting at `from`, bounded at paren depth 0. */
function rhsWindow(src: string, from: number): string {
  let depth = 0;
  let i = from;
  while (i < src.length) {
    const c = src[i];
    if (c === "(" || c === "[" || c === "{") depth += 1;
    else if (c === ")" || c === "]" || c === "}") {
      if (depth === 0) break;
      depth -= 1;
    } else if (depth === 0 && (c === "\n" || c === ",")) break;
    i += 1;
  }
  return src.slice(from, i);
}
```
