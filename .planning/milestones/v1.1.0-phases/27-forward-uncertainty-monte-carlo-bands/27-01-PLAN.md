## Contract (pure lib)
```ts
export interface MonteCarloRequest {
  portfolioDaily: DailyPoint[];   // engine's leverage+weight-baked joint daily returns (cumulative-RETURN-per-day form)
  horizonDays?: number;           // default 252
  paths?: number;                 // default 1000
  blockLength?: number;           // default auto: clamp(max(2, round(n^(1/3))), 2, n)
  seed?: number;                  // default a fixed constant → reproducible bands
  quantiles?: number[];           // default [0.05,0.25,0.5,0.75,0.95]
  floor?: number;                 // default SAMPLE_FLOOR_OVERLAPPING_DAYS
}
export interface MonteCarloBandPoint { step: number; q: Record<string, number>; } // q keyed "p5","p25",...
export interface MonteCarloResult {
  ok: boolean;                    // false => render honest empty state (caller routes by reason)
  reason: "ok" | "below-floor" | "no-usable-n";
  n: number | null;              // historical overlap N actually used
  paths: number; blockLength: number; horizonDays: number;
  bands: MonteCarloBandPoint[] | null;   // per forward step, cumulative-RETURN form aligned to projection (step 0 = 0)
  terminal: { median: number; lo: number; hi: number } | null; // terminal return + 5–95 interval
}
export function runMonteCarlo(req: MonteCarloRequest): MonteCarloResult;
export function handleMonteCarloMessage(req: MonteCarloRequest): MonteCarloResult; // == runMonteCarlo, the worker entry
export const MC_PATHS_DEFAULT = 1000;
export const MC_HORIZON_DEFAULT = 252;
```

## Method (locked — root-cause-correct)
1. Extract the daily-return values `r[]` from `portfolioDaily` (`.value`). `n = r.length`.
2. **Floor gate via the SoT:** `evaluateSampleFloor(n, floor)`. If not ok → return `{ ok:false, reason, n: verdict.n, bands:null, terminal:null, ... }` (no fabricated bands). A non-finite value anywhere in `r` → treat as no-usable-n (guard like the engine does).
3. **Block length:** `L = clamp(blockLength ?? max(2, round(n^(1/3))), 2, n)`.
4. **Seedable PRNG:** mulberry32(seed). NO `Math.random`.
5. **Circular moving-block bootstrap:** for each of `paths` paths, build a forward series of `horizonDays` daily returns by drawing blocks: pick a uniform start index `s` in `[0,n)`, copy `L` consecutive days with circular wrap (`r[(s+k) % n]`), repeat until `horizonDays` filled (truncate last block). Compound to cumulative RETURN per step (`cum *= 1+ret; band value = cum-1`), step 0 = 0.
6. **Bands:** at each forward step, sort the `paths` cumulative values and take the empirical quantiles (linear interpolation, consistent + documented — mirror the Phase-26 VaR quantile convention). Emit `bands[step].q = {p5,p25,p50,p75,p95}`.
7. **Terminal:** median + p5/p95 of the terminal-step distribution.
8. Never throws; degenerate → ok:false envelope.

## Honesty invariants (test-pinned)
- **Determinism:** identical `(portfolioDaily, seed, paths, horizon, block)` → byte-identical `bands` (golden snapshot). A method change fails CI loudly.
- **No Normal assumption:** pure resampling — assert the band at a step reflects the empirical sample (e.g. a series with a fat left tail produces an asymmetric band, which a Normal model could not).
- **Honest-to-N width:** a SHORTER history (smaller n, same vol) produces a **wider** terminal interval than a longer one (monotone-ish; pin the direction). Bands widen with horizon (p95−p5 at step H > at step 1).
- **Monotone quantiles:** at every step `p5 ≤ p25 ≤ p50 ≤ p75 ≤ p95`.
- **Floor:** `n < 60` → ok:false below-floor; empty `portfolioDaily` / non-finite → no-usable-n; never bands.
- **Leverage-aware by construction:** input is the already-leveraged `portfolio_daily_returns`, so 2× uniform leverage widens the bands (no separate handling — pin a sanity test).

## Risks
- **Vitest + worker:** the pure lib + `handleMonteCarloMessage` are tested directly (no worker). The worker glue is NOT exercised in vitest; guard the `self.onmessage` wiring (`if (typeof self !== "undefined" && typeof postMessage === "function")`) so importing the module in any environment never throws.
