# Phase 22 — UI Design Contract

> Visual and interaction contract for Phase 22 (Methodology-Honesty Scaffolding). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Brownfield, near-zero net-new visual language.** This phase adds NO new visual primitives. It (a) upgrades the already-shipped Phase-21 coverage caveat into a canonical **methodology line**, and (b) adds a shared below-floor **honest empty state** that reuses — verbatim — the Phase-21 `CorrelationHeatmap` empty-state treatment. The bulk of the phase is a non-UI pure lib primitive (`src/lib/sample-floor.ts`), which is out of UI scope. Every contract value below either PINS an existing shipped token or REUSES a Phase-21 token. Nothing here introduces a new color, type size, weight, or spacing value.

## Component Contracts

Two surfaces, both touched identically on the own-book composer and the `/scenarios` Sandbox. Numbered for checker/planner cross-reference.

### 1. Methodology line (HONEST-01) — `ScenarioComposer.tsx:1063` AND `ScenarioBuilder.tsx:300`

**Upgrade the existing Phase-21 coverage caveat in place.** Both files already render an identical `data-testid="scenario-coverage-caveat"` paragraph: `className="mt-2 text-[11px] text-text-muted"` containing `Projected from {n} overlapping days.{ Shortest history: {name}.} Not a forecast.`

- **Action:** fold the method label into that one line so it becomes the canonical methodology line. **Do not add a second line** — compose method + N + horizon into the single existing caveat slot (CONTEXT: "fold the method + horizon into one coherent disclosure rather than stacking two separate lines").
- **Method label (verbatim):** `Historical realized` — the engine computes realized statistics over the overlap window. Do NOT claim "bootstrap" (that is Phase 27).
- **Horizon wording (verbatim, already present):** `not a forecast`.
- **Token:** unchanged — `mt-2 text-[11px] text-text-muted` DM Sans regular. PINNED. No token change; copy change only.
- **`{N}` source:** the frozen engine's `ComputedMetrics.n` (`scenarioMetrics.n` in composer, `metrics.n` in builder) — read-only, never recomputed, never fabricated.
- **`{shortestName}` half:** keep the existing conditional that omits "Shortest history: {name}." when the de-aliased set is empty (`coverageShortestName !== null` in composer; `shortestName` in builder) — never name a phantom strategy.
- **Keep `data-testid="scenario-coverage-caveat"`** on both so existing Phase-21 tests stay green; planner may add a Phase-22 assertion for the new method-label substring.
- **ARIA:** static informative copy. No `role="alert"`. If the planner wants recompute announcements, `aria-live="polite"` only — never `assertive`. (Matches Phase 21 §4 rationale.)

**Canonical methodology line (the contract copy):** see Copywriting Contract below. Example rendered form (from CONTEXT): `Historical realized · 412 overlapping days · not a forecast`. The Phase-21 "Shortest history: {name}." clause is retained within the same line where present.

### 2. Below-floor honest empty state (HONEST-02) — shared treatment

A shared honest empty state rendered when the sample-floor gate (`src/lib/sample-floor.ts`, default floor **60 overlapping days**) routes a distributional/tail input as below-floor. **This phase builds the gate + the empty-state copy; it is consumed here for any below-floor surface and exported for Phases 26/27.** The visual treatment is a verbatim reuse of the Phase-21 `CorrelationHeatmap` empty-state shell — do NOT invent a new card.

Pinned visual shell (copy from `CorrelationHeatmap.tsx:188-190`, do not redesign):
```
<div className="rounded-lg border border-border bg-surface px-4 py-8 text-center text-text-muted text-sm">
  <div className="font-semibold text-text-secondary">{reasonHeading}</div>
  <div className="mt-1 text-[11px]">{body}</div>
</div>
```
- Card: `rounded-lg border border-border bg-surface px-4 py-8 text-center text-text-muted text-sm` (8px radius `lg`, 1px `#E2E8F0` border, white surface, 16px/32px padding) — PINNED.
- Reason heading: `font-semibold text-text-secondary` (14px DM Sans semibold `#4A5568`) — PINNED.
- Body: `mt-1 text-[11px]` (11px DM Sans regular, inherits `text-text-muted`) — PINNED.
- **Body MUST name the actual N and the floor** (CONTEXT: "NAMES the actual N and the floor"). Never a bare "No data". Never a fabricated number. See Copywriting Contract.

**Separation from Phase-21's correlation empty state (CONTEXT — do NOT retrofit):**
- The below-floor floor is **60 overlapping days** for distributional/tail outputs. This is DISTINCT from — and does NOT replace — Phase 21's `< 10`-overlapping-day correlation empty state and its copy ("Not enough overlap to correlate"). They share the same *visual shell* but are *different statistic-specific thresholds* with *different copy*. Do NOT unify the 10-day correlation bar with the 60-day floor; do NOT route correlation through `sample-floor.ts`.

**Degenerate-input routing (CONTEXT):** the gate routes ALL of — 0/1 strategy, below-floor overlap, and non-finite returns — to this one empty state. A null/NaN `n` is treated as below-floor, never as a passing value. The UI renders the honest empty state for every degenerate case; it never renders a fabricated number or false-precision output.

### 3. Single-source enforcement (HONEST-02) — regression lock, not a visual

Not a UI element, but the contract that protects the honesty primitive. A regression test pins the floor constant + gate behavior so Phases 26/27 reuse the one shared floor — it MUST FAIL if a future feature hardcodes a different floor instead of importing the shared one. (Mirrors the project's "prove it fails when neutered" convention, e.g. `scenario.test.ts` SCENARIO-05 pins.) A lint/grep guard against re-declaring a floor is acceptable but optional — the test is the gate.
