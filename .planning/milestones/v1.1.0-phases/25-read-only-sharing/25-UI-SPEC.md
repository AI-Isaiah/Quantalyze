# Phase 25 — UI Design Contract

> Visual and interaction contract for Read-Only Sharing. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note (HEAVY REUSE, not net-new visual design):** This phase invents NO new visual
> language. It (a) adds a per-row **Share** affordance to the existing `SavedScenariosList`,
> mirroring the shipped `ShareableLink.tsx` copy state-machine and the list's existing
> `role="alert"` mutation-failure copy; and (b) builds a dedicated read-only `/scenario-share/[token]`
> page that **reuses** the props-only presentational components (`ScenarioBenchmarkSection`,
> `CorrelationHeatmap`, `EquityChart`) fed by server-resolved data. Every token below is a
> confirmation of the existing DESIGN.md contract, not a new declaration. The load-bearing
> design work here is the **state matrix** (none / active / copied / error on the allocator side;
> valid / empty / degenerate / 404 on the recipient side) and the **honesty framing** of the
> recipient header — both fully specified below.

## Color

Confirmed from DESIGN.md. Color stays rare and meaningful; the recipient page is overwhelmingly neutral (numbers do the work).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8F9FA` page bg / `#FFFFFF` surface | page background + card/panel surfaces |
| Secondary (30%) | `#E2E8F0` borders, `#64748B` muted text, `#4A5568` secondary text | hairline dividers, labels, captions, the neutral PROJECTED pill |
| Accent (10%) | `#1B6B5A` (hover `#155A4B`) | see reserved-for list below |
| Positive | `#15803D` | equity curve direction / gains in numbers, the "Link copied!" check glyph |
| Negative / Destructive | `#DC2626` | Revoke (destructive) action, the copy-failed glyph, `role="alert"` mutation-failure text |
| Chart strategy / benchmark | `#1B6B5A` / `#94A3B8` | equity curve / benchmark overlay (reused EquityChart tokens) |

**Accent (`#1B6B5A`) reserved for:**
- The allocator-side **"Generate share link"** primary CTA (the verified/action color — minting a link is an affirmative action).
- Focus rings on interactive controls (`focus:ring-accent/50`, existing Button default).
- The equity curve stroke on the reused `EquityChart` (existing `--color-chart-strategy`).

Accent is **NOT** used for: the PROJECTED honesty pill (neutral `text-muted` outline — a calm metadata signal, never accent/warning), the "Copy link" or "Revoke" secondary affordances (`secondary` / `danger` variants), recipient-page section chrome, or empty-state cards.

**Destructive (`#DC2626`) reserved for:** the **Revoke** action (`Button variant="danger"`) and all `role="alert"` failure copy. Revoke is the one destructive action this phase introduces — see confirmation pattern below.

No new tokens introduced. The recipient page renders in **return / percentage form only** — there is no USD-scaled value, so no currency formatting and no AUM-derived color thresholds appear.

## Copywriting Contract

All copy below is final (no clients yet; locked autonomously, consistent with the existing list-mutation copy and the composer's PROJECTED framing).

### Allocator side — Share affordance (in `SavedScenariosList`, per row)

| Element | Copy |
|---------|------|
| Primary CTA (no active share) | **"Share"** → on click generates + copies link, label becomes the copied state |
| Generate-in-flight | **"Generating…"** (button disabled) |
| Copied confirmation (inline, ~2s, `role="status"` `aria-live="polite"`) | **"Link copied!"** with positive check glyph (mirrors `ShareableLink.tsx`) |
| Active-share state controls | **"Copy link"** (secondary) + **"Revoke"** (danger) shown together |
| Copy-failed (inline, ~4s, `role="alert"`) | **"Copy failed — copy the link manually"** with negative glyph (mirrors `ShareableLink.tsx` audit-#43 honest-failure pattern) |
| Generate failure (`role="alert"`) | **"Couldn't create a share link. Try again."** (mirrors existing `"Couldn't rename this scenario. Try again."` / `"Couldn't delete this scenario. Try again."`; `onMutated` NOT fired on failure — the T_SL7b/T_SL7c pattern) |
| Revoke failure (`role="alert"`) | **"Couldn't revoke this link. Try again."** |

### Allocator side — Revoke destructive confirmation

| Element | Copy |
|---------|------|
| Destructive confirmation (inline, NOT a modal — mirrors the existing inline Delete confirm) | **"Revoke this share link? Anyone with the link will lose access."** with **"Revoke"** (`danger`) + **"Keep link"** (`ghost`) |

Confirmation approach: inline reveal in the row (same affordance as the shipped `Delete "{name}"?` confirm), never a modal. Revoke is reversible-by-re-sharing (a new token is minted), so a single inline confirm is sufficient — no typed-name gate.

### Recipient side — `/scenario-share/[token]` page

| Element | Copy |
|---------|------|
| Page header (title) | The scenario **name** (Instrument Serif). **Never** the allocator's name/email/identity. |
| Header framing line (directly under the title) | **"Shared scenario · PROJECTED — hypothetical, not a live book"** (note: "**a** live book", owner-neutral — distinct from the composer's "not **your** live book") |
| PROJECTED pill (reused composer markup) | **"PROJECTED — hypothetical, not a live book"** |
| Methodology line (reused) | **"Historical realized · {N} overlapping days · not a forecast"** (verbatim from the shipped HONEST-01 caveat) |
| Correlation empty state (<2 strategies or <10 overlapping days) | reuse `CorrelationHeatmap` empty states verbatim (never a 1×1 grid / fabricated number) |
| Benchmark-unavailable empty state | reuse `ScenarioBenchmarkSection`'s honest "benchmark comparison unavailable" empty state (neutral `EmptyStateCard`, no alert role) |
| Degenerate metric | em-dash **"—"** (never a fabricated 0) — reuse existing formatter convention |
| Undecodable / version-ahead / dangling-ref draft (honest-absence, NOT 404, NOT a live-book substitution) | Heading: **"This shared scenario can't be displayed"** · Body: **"The link is valid, but this scenario was saved in a newer format we can't show here."** (rendered via `EmptyStateCard`) |
| Invalid / revoked / unknown token | `notFound()` → the existing global `not-found.tsx` (a 404; never a partial render or a different scenario) |

Empty-state heading must match its body (existing honesty invariant). The recipient page shows **no** Save / Update / Open / edit controls, **no** dashboard nav/tabs, **no** peer/percentile panels, **no** holdings / AUM / api_keys.

## Interaction State Matrix

### Allocator side (Share affordance per scenario row)

| State | Trigger | DOM / copy | A11y |
|-------|---------|-----------|------|
| none | row has no active, non-revoked share | single **"Share"** button (accent primary, `size="sm"`) | button; in row tab order after Delete |
| generating | Share clicked | **"Generating…"**, button disabled | `disabled` |
| copied | generate succeeded (link minted + clipboard write OK) | transient **"Link copied!"** + positive glyph (~2s), then settles to active-share controls | `role="status"` `aria-live="polite"` |
| active | a non-revoked share exists | **"Copy link"** (secondary) + **"Revoke"** (danger) side by side | both buttons in tab order |
| copy-failed | clipboard + `execCommand` both failed | transient **"Copy failed — copy the link manually"** + negative glyph (~4s) | `role="alert"` |
| confirming-revoke | Revoke clicked | inline reveal: **"Revoke this share link? …"** + Revoke(danger)/**Keep link**(ghost) | inline, focus moves to the confirm |
| generate-error | generate request failed | `role="alert"` **"Couldn't create a share link. Try again."**; `onMutated` NOT fired | `role="alert"` |
| revoke-error | revoke request failed | `role="alert"` **"Couldn't revoke this link. Try again."**; share stays active | `role="alert"` |

### Recipient side (`/scenario-share/[token]`)

| State | Condition | Render |
|-------|-----------|--------|
| valid | token resolves, draft decodes, ≥2 strategies, ≥ floor overlap | full read-only view: name header + framing line + PROJECTED pill + methodology line + KPI strip + EquityChart (+ benchmark overlay if available) + CorrelationHeatmap |
| correlation-empty | <2 strategies or <10 overlapping days | `CorrelationHeatmap` honest empty state in place of the grid; rest of the view renders |
| benchmark-unavailable | benchmark series missing / no window overlap | `ScenarioBenchmarkSection` "benchmark comparison unavailable" empty state; rest renders |
| degenerate-metric | a single metric can't be computed | em-dash "—" in that cell (never 0) |
| honest-absence | undecodable / version-ahead / dangling-ref draft | `EmptyStateCard` "This shared scenario can't be displayed" — NEVER a live-book substitution, NEVER a fabricated number |
| 404 | invalid / revoked / unknown token | `notFound()` → global `not-found.tsx` |

## Honesty & Safety Invariants (design-level)

These are visual/interaction contracts the checker and auditor enforce:

1. Recipient page renders **return / percentage form only** — no USD AUM, no book-size-derived value anywhere.
2. **No allocator identity** is shown — scenario name only.
3. PROJECTED framing ("Shared scenario · PROJECTED — hypothetical, not a live book") is **persistent** on the recipient page (not a tooltip).
4. **No** holdings / AUM / api_keys / peer-percentile panels / dashboard nav on the recipient page.
5. Revoke is **immediately** effective in the UI — the route is `force-dynamic` + `no-store`; a revoked token renders the 404, never a stale cached view.
6. Failure surfaces are honest and recoverable: `role="alert"` "Couldn't …" copy mirroring the existing list mutations; `onMutated` is NOT fired on failure; the copied-success badge fires only on a real clipboard success (the `ShareableLink.tsx` audit-#43 lesson).
7. Empty-state heading matches its body; degenerate → em-dash, never a fabricated 0; version-ahead/undecodable → honest absence, never a silent live-book substitution.

## Accessibility

- `role="alert"` on all blocking mutation failures (generate/revoke); `role="status"` + `aria-live="polite"` on the non-blocking "Link copied!" confirmation.
- Inline Revoke confirm: focus moves to the confirm control on reveal (matches the existing inline Delete-confirm behavior).
- All colour-carried meaning has a text/glyph backup (copied = check + text; failed = warning glyph + text; PROJECTED = text, not colour alone).
- Recipient page: single-column, hairline dividers (`border-t border-border`), heading hierarchy `h1` (name) → `h2` (sections); Recharts `accessibilityLayer={false}` per the codebase-wide rule so chart SVGs don't become empty focus stops.
- Contrast: all reused tokens are the AA-shifted DESIGN.md values (`text-muted` #64748B, `positive` #15803D, `negative` #DC2626) — no new colour pairings introduced.
