# Phase 71 — Plan 71-01: Allocator Deribit Positions

**Requirement:** DRB-09
**No DB migration** — `allocator_holdings` already accepts Deribit (venue allowed since P68);
pure Python. No supabase-migrate risk.

## Grounding (authoritative)
Deribit `/private/get_position` (official docs) + CCXT 4.5.x `parse_position`:
`size`=quote-ccy notional (USD/USDC) for futures; `size_currency`=base-ccy coin;
`floating_profit_loss`=settle-ccy (coin for inverse BTC/ETH, USDC for linear).
CCXT's unified `contracts`/`notional`/`unrealizedPnl` invert this vs the linear
assumption in `_normalize_ccxt_position` → today Deribit would swap qty/value and
leave PnL ~1e5× off.

## Tasks (TDD — failing tests first)

### T1 — `positions.py::_normalize_ccxt_position` Deribit branch (SC2)
Add a `exchange_name == "deribit"` branch reading raw `pos["info"]`:
- `symbol` = `instrument_name` (BTC-PERPETUAL, BTC-27DEC24, …).
- `size_base` = abs(base coin): futures→`size_currency`; options→`size`.
- `size_usd` = abs(USD notional): futures→`size`; options→`abs(size)·index_price`.
- `entry_price` = `average_price`; `mark_price` = `mark_price` (both USD).
- `unrealized_pnl` (USD):
  - inverse (`_is_inverse_perp(ccxt_symbol)`) OR option/combo → `floating_profit_loss·index_px`
  - linear (USDC settle) → `floating_profit_loss` pass-through.
  - `index_px = index_price>0 else mark_price>0 else FAIL LOUD` (ValueError — no invented value).
- `side`: buy→long / sell→short / zero|0-size→None (filtered).
Reuse `equity_reconstruction._is_inverse_perp`. Linear/other exchanges: untouched.

**Tests (hand-computed):**

  floating_profit_loss=+0.05 BTC, index=50000, mark=49900, avg=48000 →
