<interfaces>
LOCKED design pins (from deribit-ingestion-design.md — authoritative, supersedes 70-CONTEXT/RESEARCH):
- A1 (Wave-0, live): `type=settlement` rows carry an event-time `index_price` (acct3 218/218 present;
  `mark_price` absent). Inverse coin→USD = `coin_delta × index_price` at the ROW's own timestamp.
- A3 (Wave-0, live): `type=trade` rows carry ZERO cashflow; realized cash lives in settlement +
  delivery rows. On perpetuals funding is realized INSIDE the settlement cash delta (`interest_pl` is
  a breakdown line, NOT an additional cashflow) — summing settlement once already includes funding.
- Ledger sign is authoritative: credit +/debit − comes straight from the txn-log; NEVER re-derive
  sign from position side (that is where hand-rolled inverse calcs flip — the D-07 rule).

Consumers (downstream plans build against these — treat as contracts):
- `classify_instrument(instrument_name: str) -> str` — byte-identical to the harness version at
  scripts/deribit_ground_truth.py (re-grep `def classify_instrument` for the current line range;
  never raises; returns inverse_perpetual | linear_perpetual | option | future | unknown; markers
  _USDC/_USDT/_EURR; -C/-P; expiry regex).
- `txn_cashflow_to_usd(row: Mapping[str, Any]) -> float` — linear/USD passthrough; inverse =
  cashflow × event-time `index_price` from the row; ValueError naming the row id when index_price is
  absent on an inverse row (NEVER a current-price lookup).
- `txn_rows_to_daily_records(rows) -> list[dict]` — a SINGLE list of daily_pnl-shaped records, one
  per UTC day, whose amount is the summed USD cash delta of the cash-bearing rows on that day.
  Consumed by trades_to_daily_returns_with_status (order_type="daily_pnl", side "buy"/"sell" encodes
  sign, price = abs USD, timestamp ISO8601 UTC). NOTE: this replaces the prior (realized, funding)
  tuple — there is no funding stream for Deribit; funding is inside settlement.
- Existing daily_pnl record precedent to mirror: broker_dailies.funding_rows_to_daily_pnl_records
  (broker_dailies.py:73-104) emits {"exchange":"", "symbol","side","price","quantity":1,"fee":0,
  "fee_currency","timestamp","order_type":"daily_pnl"}.
