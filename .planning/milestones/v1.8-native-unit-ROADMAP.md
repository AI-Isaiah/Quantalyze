## Overview

v1.9 restores the invariant the v1.8 core cannot express: USD equity of a coin-margined account
decomposes as `E_usd(anchor) = E_usd(start) + Σ change·P(t_event) + Σ_c ∫ B_c·dP_c` (contract §0).
The shipped core (`services/nav_twr.py:266 reconstruct_nav`, driven from `reconstruct_nav_and_twr`
at `:627`) rolls `NAV_{t-1} = NAV_t − pnl_t − F_t` **in USD**, which omits the currency-translation
integral `Σ_c ∫ B_c·dP_c` — zero only when every held currency is USD-family, and otherwise
mislabeled as reconstructed "start capital" (the −$480,782 LTP068 case). **USD space is
category-invalid for coin-margined accounts**; the ONLY valid space is native units per settlement
currency: `B_c(t-1) = B_c(t) − change_c(t) − flowqty_c(t)` rolled per currency, then
`NAV_usd(d) = Σ_c B_c(d) × P_c(d)` valued at daily `{ccy}_usd` marks — the translation term is then
carried implicitly and exactly, nothing estimated, nothing mislabeled (§0; proven empirically on the
live account: BTC reconciles to 0.048 dust, USDC/ETH exact, §5.1).

The spine repeats what worked in v1.8: **shared-core-first / adapter-per-venue / parity-gates-last**.
Phase 79 builds the pure I/O-free `services/native_nav.py` (§1) with the inception-reconciliation
refuse gate (§5), strict-mode guard hardening (no silent chain-bridging, §6), and the
`_INVERSE_CURRENCIES` generalization (§7, fixes the SOL crash on Deribit key 1) — NO production
wiring. Phase 80 lands the Deribit adapter (§9.1) and routes the Deribit job path through the native
core behind three HARD SHIP GATES (§9.2): the SC-4 byte-identity suite, the §5 inception gate green
on the three real keys, and an old-vs-new golden parity panel with founder sign-off. Phase 81 moves
the ccxt venues (Bybit/OKX/Binance coin-margined) per-venue-when-verifiable and retires the
USD-space path. **SC-4 is non-negotiable: USD-native accounts stay byte-identical** — by
construction (branch-1 coalescing + IEEE-754 ×1.0 no-op + verbatim reuse of `reconstruct_nav` /
`chain_linked_twr` / `_guard_denominator`, §4.1), verified bit-exact (§4.2). No new dependencies
(stdlib + `pandas==2.2.3` + `numpy==2.4.6`); frontend untouched except the carried warned-UI polish
(backlogged). Leak discipline holds throughout: no raw NAV/balance/flow values in any log or
exception (§1.1, §3.4, §5.3; `nav_twr.py:443-444`).
