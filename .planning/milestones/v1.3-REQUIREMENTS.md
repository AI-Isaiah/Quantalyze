# Requirements: Quantalyze — v1.3 Mobile & Adaptive UI

**Defined:** 2026-06-27
**Core Value:** Allocators act on Bridge recommendations and see whether those suggestions actually worked — and can model the impact of composition changes before they make them.
**Milestone goal:** Every surface becomes fluidly responsive — adapting to resolution, mobile viewport, and browser/screen zoom (reflow-correct) — with UI best practices held as the bar throughout. A RETROFIT/gap-closing milestone (much mobile infra already exists); additive over the FROZEN `scenario.ts`/`compute.ts` engine.

## v1 Requirements

Requirements for v1.3. Each maps to exactly one roadmap phase (44–48). All are framed as observable guarantees, testable at the stated breakpoint/condition.

### Navigation (NAV)

- [x] **NAV-01**: A mobile user reaches role-appropriate primary navigation — the allocator gets `/allocations`, Bridge, and Risk from the bottom nav (today `MobileNav.TABS` is a role-blind 3-item stub).
- [x] **NAV-02**: Multi-tab surfaces (Overview / Holdings / Risk / Scenario) stay reachable on a phone via a scrollable tab strip at `<sm` (preserving the JOURNEY-03 `role=tab` a11y fix).
- [x] **NAV-03**: The mobile drawer traps focus and the app exposes a skip-link — keyboard and screen-reader navigable (generalize the existing factsheet skip-link to the app shell; prefer the `inert` attribute over a hand-rolled trap).

### Responsive Tables (TABLE)

- [x] **TABLE-01**: Every data table is usable at 320px with no horizontal page overflow and **no dropped material columns** — reshape (scroll / stack / labeled-summary), never hide (column-drop on a financial table is a no-invented-data violation).

### Responsive / Touch Charts (CHART)

> CHART-01 (touch-inspectable charts) spans two distinct chart families with different implementation paths; the roadmapper split it so each REQ-ID owns exactly one phase: **CHART-01a** (the 16 hand-rolled SVG charts, Phase 47) and **CHART-01b** (the ~19–23 Recharts charts + the 2200-LOC `EquityChart`, Phase 48). SVG is the cleaner learning pass; Recharts/EquityChart is the most-complex, touch-weakest, highest-regression family done last.

- [x] **CHART-01a**: Every hand-rolled SVG chart is touch-inspectable on a phone — a tap reveals (and pins) the value that hover gives on desktop, propagating the existing `TimeSeriesChart` tap-pins-crosshair recipe to the 16 SVG charts via `ResponsiveChartFrame`.
- [x] **CHART-01b**: Every Recharts chart (and the `EquityChart` widget) is touch-inspectable on a phone — an explicit tap-to-show/tap-to-pin tooltip (+ the DESIGN.md KPI-cell value fallback) replaces the hover-first default; `EquityChart`'s pointer handlers are tuned for touch WITHOUT rewriting the chart.
- [x] **CHART-02**: Chart text is legible at 320px (WCAG 1.4.4) — fixes the viewBox-downscale trap where axis text shrinks to ~4–5px (reduce tick density / bump font / HTML-overlay labels, not just shrink).
- [x] **CHART-03**: Charts render portrait-tuned (reduced density, taller aspect) on small screens with the **frozen math byte-identical** — SCENARIO-05 zero-diff and the factsheet byte-identity guard (BODY-02) stay green throughout.

### Forms / Wizard (WIZARD)

- [x] **WIZARD-01**: The onboarding / API-key wizard is usable on a phone — the `DesktopGate.tsx` hard-block below 640px is removed, keeping the `isNarrow===null` two-pass hydration-safe pattern.

### Layout, Zoom & States (REFLOW)

- [x] **REFLOW-01**: Every authed + public route reflows correctly at 320px CSS width with no horizontal scroll (WCAG 1.4.10 Reflow).
- [x] **REFLOW-02**: Every surface remains usable at 400% browser zoom; zoom is never disabled (WCAG 1.4.4 Resize Text).
- [x] **REFLOW-03**: Loading / empty / error / partial states render honestly across breakpoints — degenerate inputs keep their honest empty states (no fabricated data, no broken layout) at every viewport.

### Accessibility & Verification Gates (A11Y)

- [x] **A11Y-01**: The app-wide axe WCAG-AA gate covers all primary routes in CI (extended from the current 5-route coverage), wired into both the seed-guard and `ci.yml` (FLOW-01).
- [x] **A11Y-02**: Bespoke CI gates cover what axe structurally can't — a 320px reflow check (`scrollWidth <= clientWidth`), a zoom-meta grep guard (fails on `maximumScale`/`userScalable:false`), a 44px target-size measurement, and a mobile keyboard/focus check.
- [x] **A11Y-03**: A mobile performance budget gates public routes in CI — `@lhci/cli` + a Lighthouse-mobile job; thresholds seeded from a baseline run and ratcheted tighter over time.

## Out of Scope

Explicitly excluded. The first five are research-identified **anti-features** — patterns that look mobile-friendly but harm a data-dense institutional product or breach a LOCKED invariant.

| Feature | Reason |
|---------|--------|
| Dropping/hiding material columns on mobile (`hidden md:table-cell`) | No-invented-data violation — the mobile user would see a smaller truth. Reshape, never drop. |
| Zoom-blocking viewport meta (`maximum-scale=1` / `user-scalable=no`) | WCAG 1.4.4 fail and invisible to axe. The milestone explicitly requires zoom to work. |
| Downsampling chart points "for mobile performance" | Changes displayed data; regresses the frozen engine (SCENARIO-05 / BODY-02). |
| Rewriting `EquityChart` to the viewBox pattern | 2200 LOC, live-book Overview chart, already ResizeObserver-responsive — a rewrite is huge regression surface for zero benefit. Tune touch handlers only. |
| Touching `scenario.ts` / `compute.ts` math | Frozen engine — v1.3 is presentation-layer only. |
| Dark mode | DESIGN.md explicitly "not planned." |
| New charting library / UI component kit / CSS framework | The installed stack (Tailwind v4.2.2 container queries, axe/Playwright, existing chart families) is sufficient; net-new deps limited to `@lhci/cli`. |
