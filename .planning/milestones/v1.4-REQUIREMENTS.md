**Core Value:** Every surface in Quantalyze renders best-in-class across the full resolution range —
fluid typography that scales with no clipping/ellipsis, an evolved design system (refreshed DESIGN.md),
restructured information architecture, and React/Next-16 best practices applied app-wide — while the
scenario math engine, the `compute.ts`/factsheet parity, and the WCAG-AA accessibility floor stay
locked. **This is a quality milestone, not a feature build:** every surface already exists; the goal is
how it renders.

**LOCKED invariants (must not regress):** `scenario.ts` SCENARIO-05 zero-diff · `compute.ts` parity ·
`FactsheetBody` math (BODY-02) · no-invented-data · no-peer-rank-a-hypothetical-blend (one audited
aggregate `scenarioPeer` override aside) · the v1.3 WCAG-AA floor. Desktop byte-identity (v1.3's
invariant) is **LIFTED** — the visual layer is free to change.

## v1 Requirements

Requirements for the v1.4 milestone. Each maps to exactly one roadmap phase. Phases continue from
v1.3's Phase 48 (no reset) — this milestone is Phases 49–54. Dependency order (all four researchers
converged): **design-system spine → surfaces → verification last.**

### Design-system refresh + fluid token foundation (Phase 49) — ✅ shipped (#538, v0.35.0.6)

- [x] **DS-\*** — DESIGN.md refreshed to a state-of-the-art aesthetic (type scale, color, spacing, motion) as the single source of truth; fluid `--text-*`/`--space-*` tokens live in a **plain `@theme`** block (not `@theme inline`, which flattens the variable chain); contrast-validated colors; DESIGN.md↔token drift tests; a v1.4 frozen-spine guard.
- [x] **TYPE-01** — Truncation classification audit (legitimate ellipsis vs accidental clip; ~96 sites) + lint guards: `clamp-without-rem` (every `clamp()` carries a `rem` middle term or it fails WCAG 1.4.4 / W3C F94), `no-raw-hex`, `no-raw-px-font-size`, extending the local `eslint-plugin-quantalyze`.

### Primitive refresh + missing primitives (Phase 50) — ✅ shipped (#539, v0.35.0.7)

- [x] **STATE-03/04** — Skeleton + loading/error/empty primitives (the `ErrorEnvelope`, 9-state matrix, `MetricCell` em-dash-for-null patterns) established as reusable building blocks for the surface phases.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Editing the frozen `scenario.ts` engine | LOCKED (SCENARIO-05 zero-diff). The visual layer changes around it; the engine never does. |
| RSC-ifying client islands touching `scenario.ts` / the Web Worker / `FactsheetProvider` / `useBreakpoint` / chart interactivity | Silently breaks live recompute (237 `"use client"` files). Strangler migration, never big-bang. |
| Animated count-ups, demo numbers in empty states, optimistic un-computed metrics | no-invented-data violations, not merely taste. |
| Decorative motion (gradients/blobs/parallax), motion libraries | Against DESIGN.md (anti-decoration). Motion is native CSS transitions + View Transitions only. |
| Blind `--update-snapshots` to clear lifted-byte-identity reds | Masks real regressions. Deliberate per-chart re-baseline + tolerance goldens instead (VERIFY-04). |
