<objective>
Build `POST /api/scenario/peer-rank` (flow (a)): the client posts the blend's 3
sample-basis ranking metrics (sharpe/sortino/maxDD) + n; the route reads the cohort
via the `get_verified_cohort_rank` RPC and returns ONLY `{ peer: PeerPercentilePayload }`
or `{ peer: null }`. The cohort distribution never crosses the network.

Purpose: PEER-03's server boundary. The route owns auth + approval + CSRF + rate-limit +
no-store; the RPC owns the aggregate + min-N + identity-strip. Together they make
cross-tenant leakage structurally impossible — only the rank of the caller's OWN
hypothetical against an aggregate crosses the wire.

Output: one route handler + one route test + one new rate limiter.
</objective>
