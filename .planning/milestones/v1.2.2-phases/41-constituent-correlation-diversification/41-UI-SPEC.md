# Phase 41 — UI Design Contract: Constituent Correlation & Diversification

> Visual and interaction contract for the new diversification panel in ScenarioFactsheetChart.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Scope:** This is a REUSE-FIRST phase. The `CorrelationHeatmap` renderer is consumed
> unchanged. This spec covers only the NEW elements: the CollapsibleSection shell,
> the DR + ENB headline, the PCR list, the "too similar" flag treatment, and
> honest empty states.

### 3. DR + ENB headline block

A flat two-cell KPI row (no card borders — "data density > card density" rule). Layout: `flex flex-wrap gap-8 items-start`.

**Diversification Ratio cell:**
```
[label]   Diversification Ratio
[value]   2.14          ← 18px Geist Mono semibold tabular-nums
```

**Effective Number of Bets cell:**
```
[label]   Effective Bets
[value]   3.2           ← 18px Geist Mono semibold tabular-nums
[caption] ENB = 1 / Σ PCRᵢ²    ← 11px DM Sans muted
[interp]  3.2 effective bets across 5 constituents    ← 12px DM Sans secondary
```

The interpretation line template: `"{ENB_rounded_to_1dp} effective {bets|bet} across {N} {constituents|constituent}"`. Use singular/plural correctly. This is the only copy that is dynamically generated from live values.

When DR or ENB cannot be computed (fewer than 2 constituents, or any non-finite intermediate value), hide the entire headline block — do NOT render zeroed or "0.00" values. Show the whole-section "0/1-constituent" empty state instead (see Empty States below).

**DOM structure:**
```tsx
<div className="flex flex-wrap gap-8 items-start">
  {/* DR */}
  <div className="flex flex-col gap-1">
    <span className="text-[12px] text-text-muted">Diversification Ratio</span>
    <span className="text-[18px] font-metric font-semibold tabular-nums text-text-primary">
      {dr.toFixed(2)}
    </span>
  </div>
  {/* ENB */}
  <div className="flex flex-col gap-1">
    <span className="text-[12px] text-text-muted">Effective Bets</span>
    <span className="text-[18px] font-metric font-semibold tabular-nums text-text-primary">
      {enb.toFixed(1)}
    </span>
    <span className="text-[11px] text-text-muted">ENB = 1 / Σ PCRᵢ²</span>
    <span className="text-[12px] text-text-secondary">
      {enb.toFixed(1)} effective {enb < 1.5 ? "bet" : "bets"} across {N} {N === 1 ? "constituent" : "constituents"}
    </span>
  </div>
</div>
```

### 4. PCR list

Per-constituent percent-contribution-to-risk rows. Sorted descending by PCR (highest risk contributor first) — the allocator needs to immediately see which constituent dominates.

**Layout:** a flush list, no outer card border. Each row is `flex items-center gap-2 py-2 border-b border-border last:border-0` (hairline divider between rows, none after the last).

**Row anatomy:**
```
[name]           [bar_____________]  [pct]
Alpha Momentum   ████████░░░░░░░░░░  47.3%
```

| Element | Spec |
|---------|------|
| Constituent name | 12px DM Sans regular `text-text-primary truncate max-w-[160px]` |
| Bar container | `flex-1 min-w-[60px] h-1.5 rounded-full bg-border` (track = `--color-border`) |
| Bar fill | `h-full rounded-full bg-accent` — width = `${pcr * 100}%` |
| PCR value | 12px Geist Mono regular `text-[12px] font-metric tabular-nums text-text-primary w-[48px] text-right` |

Bar is decorative (aria-hidden). The PCR percentage value in text carries the accessible information. The `role="list"` + `role="listitem"` pattern is used on the wrapping `<ul>/<li>` so screen readers announce "N items".

Full DOM structure:
```tsx
<div>
  <p className="text-[12px] text-text-muted mb-2">Risk contribution per constituent (% of total)</p>
  <ul role="list" className="divide-y divide-border">
    {rows.map(({ id, name, pcr }) => (
      <li key={id} role="listitem" className="flex items-center gap-2 py-2">
        <span className="text-[12px] text-text-primary truncate max-w-[160px]">{name}</span>
        <div className="flex-1 min-w-[60px] h-1.5 rounded-full bg-border" aria-hidden>
          <div className="h-full rounded-full bg-accent" style={{ width: `${(pcr * 100).toFixed(1)}%` }} />
        </div>
        <span className="text-[12px] font-metric tabular-nums text-text-primary w-[48px] text-right">
          {(pcr * 100).toFixed(1)}%
        </span>
      </li>
    ))}
  </ul>
</div>
```

### 5. "Too similar" flag treatment

The heatmap already colors ρ ≥ 0.85 cells in deep burnt-orange (the diverging palette's high end). Do NOT re-color those cells or add a per-cell overlay — that fights the palette.

The ADDITIONAL treatment is a single aggregate warning badge rendered ABOVE the heatmap when one or more pairs have ρ ≥ 0.85. It is a summary note, not a per-cell annotation.

**Badge spec:**
```
[!]  2 pairs above the 0.85 similarity threshold
```

| Property | Value |
|----------|-------|
| Container | `inline-flex items-center gap-1.5 rounded-sm border px-2 py-0.5` |
| Fill | `#FEF3C7` (`bg-[#FEF3C7]`) |
| Border | `#FDE68A` (`border-[#FDE68A]`) |
| Text color | `#B45309` (`--color-warning`) |
| Label text | `{count} {count === 1 ? "pair" : "pairs"} above the 0.85 similarity threshold` |
| Font | 10px DM Sans medium uppercase tracking-wider — `text-[10px] font-medium uppercase tracking-wider` |
| Icon | None. Text only per DESIGN.md badge convention ("No icons; identity carried by border + text colour only") |

Placement: inside the CollapsibleSection, immediately BEFORE the `CorrelationHeatmap`. When no pairs exceed the threshold, the badge is absent (zero DOM). No "all clear" positive badge — absence of the warning is the signal.

Screen reader: the badge has no extra `role` — inline text in the flow is sufficient. Screen readers read it in document order before the heatmap grid.

**Legend note below the heatmap:** A one-line caption links the visual palette to the badge threshold:
```
Burnt orange = positive correlation (concentration risk). Pairs ≥ 0.85 are flagged above.
```
`text-[11px] text-text-muted mt-2` — renders only when the heatmap itself is rendering (not in empty states).

## Empty States

### 0 or 1 constituent

Condition: `constituents.length < 2` (before correlation data is even consulted).

The entire CollapsibleSection body (heatmap + headline + PCR) is replaced with a single `EmptyStateCard`:

```
heading: "Add a second strategy to see diversification"
body:    "Select at least 2 strategies to compare their pairwise correlation
          and see how diversified the blend is."
```

`EmptyStateCard` is the existing shared component (imported by `CorrelationHeatmap`) — reuse it directly at the CollapsibleSection body level. Do not build a custom empty state.

### n < 10 (engine-nulled matrix)

Condition: `correlationMatrix === null` with `overlappingDays >= 1`.

The `CorrelationHeatmap` component handles this path via its own reason-routed empty state. When the heatmap renders an empty state, the DR/ENB headline and PCR list are also hidden (they depend on the same data). The CollapsibleSection section itself remains open with just the heatmap's `EmptyStateCard` visible — do not add a second empty state message.

### Non-finite DR / ENB

Condition: DR or ENB intermediate computation yields NaN or Infinity.

Hide the DR + ENB headline block silently. Render the PCR list if PCR values are available. If PCR values are also non-finite, hide the PCR list too. Never render "NaN", "Infinity", or "0.00" as a metric value.

### Honest absence of "too similar" badge

When no pair has ρ ≥ 0.85, the badge is absent — no "no pairs flagged" affirmative message. Absence of the badge is the signal.

## Summary

Phase 41 introduces a single `CollapsibleSection` titled "Diversification" inside `ScenarioFactsheetChart`, stacking three children: the existing `CorrelationHeatmap` (reused byte-for-byte), a two-cell DR + ENB KPI headline using the factsheet's 18px Geist Mono semibold value tier, and a PCR list with proportional teal bars sorted by descending risk contribution. The "too similar" flag is an aggregate warning badge (amber `#B45309` on `#FEF3C7`) placed above the heatmap when any pair reaches ρ ≥ 0.85 — it adds a named threshold to the palette signal without re-coloring heatmap cells. Empty states are routed by existing `CorrelationHeatmap` reason-branches for the n < 10 / engine-null cases, and a `CollapsibleSection`-level `EmptyStateCard` for the 0/1-constituent case. All typography, color, spacing, and component patterns are drawn exclusively from DESIGN.md tokens and existing project primitives; no new colors, no new packages, and no new shadcn components are required.
