MODIFIED Next.js (16.2.10): read `node_modules/next/dist/docs/01-app/03-api-reference/04-functions/redirect.md` AND the layouts/nesting section of the App Router docs before editing. Two facts drive this plan: (1) `redirect()` throws NEXT_REDIRECT — never place the guard inside a try/catch; (2) a `layout.tsx` server component executes on every request for its segment and ALL descendant segments, and a `redirect()`/`throw` in it prevents any descendant `page.tsx` from rendering — a sibling `page.tsx` guard does NOT get this coverage. This is why the manager subtrees need layouts, not per-index-page guards.
