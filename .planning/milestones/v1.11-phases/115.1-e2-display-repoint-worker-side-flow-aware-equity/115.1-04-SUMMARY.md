# Phase 115.1 Plan 04: Worker wiring — Option-B epilogue + crawl-free compose Summary

**The key-mode broker derive now persists the per-key flows + live equity anchor it already fetched and enqueues an owner-scoped `derive_allocator_equity` compose job, which reads those DB inputs and atomically upserts the allocator `equity_curve` display row — zero added exchange I/O, zero second decryption, and the legacy snapshots store is never touched.**

## Accomplishments

### Task 1 — Option-B epilogue (job_worker.py, in the key-mode DONE region)
- Serializes the job's ALREADY-fetched `external_flows` (deribit native-ledger / ccxt `ccxt_rows_to_dated_flows`) as `[{utc_day_iso, usd_signed}]`.
- **Anchor equity source (NOT notional):** the live `equity` variable set earlier in the SAME derive — deribit `account_state.collapsed_equity_usd` (:2173), ccxt `fetch_account_equity_and_upnl_usd` (:2532). This is the venue's own total-equity read, never an `allocator_holdings` sum and never a blind `value_usd` sum (`value_usd` is notional contract size on a derivative). Proof it is not notional `value_usd`: the epilogue reads the single scalar `equity` from the account-equity fetch, and never queries `allocator_holdings` at all.
- `balance_error` truthy or `equity is None` → `anchor_usd: null` (honest), never a heuristic fallback.
- Upserts `kind='key_inputs:<api_key_id>'` to `allocator_equity_derived` on_conflict `allocator_id,kind`; DB errors bubble (job retries; csv upsert idempotent).
- Enqueues `derive_allocator_equity` for `allocator_id` (= `ctx.key_row['user_id']`, :1914) — the authoritative owner; a dedup/enqueue hiccup is logged + swallowed (inputs already persisted; next refresh re-enqueues).
- Log carries no USD magnitudes (counts + anchor-present bool only, T-115-05).

### Task 2 — run_derive_allocator_equity_job (crawl-free compose + registration)
- Loads api_keys → `eligible_key_predicate` (imported, never inlined) → eligible id set.
- Builds `returns_by_key` from `csv_daily_returns` with a **bare `YYYY-MM-DD` string index** (never `pd.to_datetime`/`DatetimeIndex`, carry-in #3).
- Parses `key_inputs:*` rows → `flows_by_key` (reconstructed `ExternalFlow`) + `anchors_by_key` (None when absent → compose honestly drops the key); deletes orphan `key_inputs` rows for no-longer-eligible keys.
- `compose_allocator_equity(...)` is the ONLY derivation call; structural `NavReconstructionError` → permanent FAILED (scrubbed); DB faults bubble transient.
- Single-row atomic upsert `(allocator_id,'equity_curve')`; **never** writes `allocator_equity_snapshots`.
- Registered `"derive_allocator_equity": 5 * 60` in TIMEOUT_PER_KIND (< 10 min → no watchdog override) + dispatch elif.
