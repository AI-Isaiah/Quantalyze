Math ground truth the oracle must encode:
- Legacy `_compute_sharpe_and_vol` (portfolio.py L596-625): vol = std(ddof=1)·√252,
  mean_ret = mean·252, sharpe = mean_ret/vol, with 6 mutually-exclusive status
  codes (ok / insufficient_history / zero_volatility / nan_vol / nan_mean /
  nan_sharpe). Backbone: `compute_all_metrics(returns, periods_per_year=252)`
  → metrics_json keys "volatility" = qs.stats.volatility(r, periods=252) and
  "sharpe" = qs.stats.sharpe(r, periods=252) (metrics.py L706-707, L1180-1181).
  Same math, different op order → expect agreement to ~1e-12 relative, NOT
  bit-exact.
- Legacy `compute_twr(equity, [])` collapses to a SINGLE segment:
  equity.iloc[-1]/equity.iloc[0] − 1, with guards len<2 → None and
  iloc[0]==0 → None. On a cumprod series whose first value is (1+r_0) this
  EXCLUDES day-0's return — whereas backbone "cumulative_return"
  (cumulative_twr_segmented, metrics.py L654) is Π(1+r)−1 over ALL days
  INCLUDING day 0. These genuinely differ whenever r_0 ≠ 0. The byte-identical
  mandate therefore requires the plan-02 re-route to derive TWR as an
  equity-endpoint ratio, NOT to read cumulative_return.
- `compute_all_metrics` requires a DatetimeIndex (monthly resample) — build all
  fixtures on pd.date_range indices.
