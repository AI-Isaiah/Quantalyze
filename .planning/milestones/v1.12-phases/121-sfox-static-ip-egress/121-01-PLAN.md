       echo the value) if the var is unset/empty, contains no colon, or either side of the first
       colon is empty. Split on the FIRST colon only (the secret may contain colons). Substitute
       the two placeholders in the template and write the rendered conf to
       `${CONF_OUT:-/etc/tinyproxy/tinyproxy.conf}` (CONF_OUT override exists so the smoke test
       below can render into the scratch dir). Then `exec "${TINYPROXY_BIN:-tinyproxy}" -d -c`
       the rendered conf (TINYPROXY_BIN override lets the smoke test stub the exec with `true`).
       `set -eu`; never `set -x`; never echo the secret.
    3. `Dockerfile` — `FROM alpine:3.20`, `apk add --no-cache tinyproxy` (distro package — per
       the RESEARCH Package Legitimacy Audit, no npm/PyPI surface), COPY the template +
       entrypoint, `EXPOSE 8888`, ENTRYPOINT the entrypoint script. Container starts as root so
       the entrypoint can write /etc/tinyproxy; tinyproxy itself drops privileges via the
       User/Group directives. Comment header explaining the render-from-secret design, in the
       style of analytics-service/Dockerfile's CMD-override note.
    4. `fly.toml` — `app = "quantalyze-egress-proxy"`, `primary_region = "ams"` (geo-allowed;
       matches today's Railway AS400940 Amsterdam egress — US is rejected: Bybit/Binance 403/451),

       `protocol = "tcp"`, `auto_stop_machines = false`, `auto_start_machines = true`,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → tinyproxy :8888 | Untrusted clients can reach the dedicated inbound v4 |
| Fly proxy → api.sfox.com | Egress hop; carries the tunneled TLS stream |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-121-01 | Spoofing/Elevation | tinyproxy open-relay abuse | mitigate | BasicAuth + deny-by-default (no Allow lines), ConnectPort 443 only |
| T-121-02 | Info Disclosure | Via/X-Tinyproxy/forwarded headers | mitigate | DisableViaHeader Yes + XTinyproxy No + Anonymous whitelist |
| T-121-03 | Info Disclosure | BasicAuth secret in git/image layers | mitigate | Rendered from PROXY_BASIC_AUTH fly secret at start; placeholders only in git; entrypoint never echoes |
| T-121-04 | DoS | Egress IP drift breaking the whitelist | mitigate | App-scoped `fly ips allocate-egress` (survives machine recreation) + the pre-whitelist verify gate |
| T-121-SC | Tampering | Package installs | accept | No npm/pip/cargo installs — tinyproxy from the signed Alpine distro repo (RESEARCH Package Legitimacy Audit) |
</threat_model>
