Create `src/app/api/allocator/holdings/sync/route.ts` per D-14.

Critical architectural point: the route uses the **user-scoped** `createClient()` (NOT `createAdminClient()`) to call `request_allocator_holdings_sync` — because the RPC is GRANTed to `authenticated` and is SECURITY DEFINER, it runs its own `auth.uid()` ownership check internally. The route does NOT need to do a separate ownership SELECT on `api_keys` first (the RPC owns that). This is the key delta from `src/app/api/keys/sync/route.ts` which uses `createAdminClient()` for `enqueue_compute_job` because that function is REVOKEd from authenticated.

**f8 passthrough:** The RPC response JSONB (shaped `{ok, job_id}` on fresh enqueue OR `{already_inflight, next_attempt_at}` on dup) MUST be returned to the client verbatim. Do NOT strip `next_attempt_at` or flatten the shape — Plan 04's `AllocatorSyncStatus` pill consumes `next_attempt_at` to render "Queued — retry in {N}s" helper text when rate-limit contagion defers the job.

Implementation:

```typescript
import { NextRequest, NextResponse } from "next/server";
import { z } from "zod";
import type { User } from "@supabase/supabase-js";
import { withAuth } from "@/lib/api/withAuth";
import { createClient } from "@/lib/supabase/server";
import { logAuditEvent } from "@/lib/audit";

const BodySchema = z.object({
  api_key_id: z.string().uuid(),
});

export const POST = withAuth(async (req: NextRequest, user: User) => {
  // Body validation (D-14)
  const raw = await req.json().catch(() => null);
  const parsed = BodySchema.safeParse(raw);
  if (!parsed.success) {
    return NextResponse.json({ error: "Invalid body" }, { status: 400 });
  }
  const { api_key_id } = parsed.data;

  // User-scoped client — the RPC is GRANTed to authenticated and does its own
  // auth.uid() ownership check + idempotent enqueue + sync_status='syncing'.
  const supabase = await createClient();
  const { data, error } = await supabase.rpc("request_allocator_holdings_sync", {
    p_api_key_id: api_key_id,
  });

  if (error) {
    // SQLSTATE '42501' = not authenticated OR api_key_not_found_or_not_owned (per Plan 01 RPC body)
    if (error.code === "42501") {
      return NextResponse.json(
        { error: "API key not found or not owned by you" },
        { status: 403 },
      );
    }
    console.error(`[allocator/holdings/sync] RPC failed for user ${user.id} key ${api_key_id}:`, error);
    return NextResponse.json(
      { error: "Could not start sync. Try again in a moment." },
      { status: 500 },
    );
  }

  // D-18: audit the request (user-scoped supabase client so user.id is the actor)
  logAuditEvent(supabase, {
    action: "allocator.holdings.sync_requested",
    entity_type: "api_key",
    entity_id: api_key_id,
  });

  // D-10 + f8: RPC returns either { ok: true, job_id } or { already_inflight: true, next_attempt_at }.
  // Pass the JSONB body through verbatim so the client can discriminate on `already_inflight` AND
  // consume `next_attempt_at` to render "Queued — retry in {N}s" during rate-limit contagion.
  return NextResponse.json(data, { status: 200 });
});
```
