## Interaction Contract

Additive to copywriting. Locks the behavioural contracts planner + executor must implement.

### Tabs (PURGE-07 / D-04)

- URL: `/allocations?tab=performance|scenario` — default `performance`. Missing or invalid → silent fallback to `performance`.
- State sync: shallow `router.replace(...)` on tab change (matches `ProfileTabs.tsx` lines 59–68 verbatim). `scroll: false`.
- Reload survival: tab state derived from `useSearchParams().get('tab')` on mount — survives full page reload by definition.
- Keyboard: each tab button is a native `<button>` in a `role="tablist"` container. Enter / Space activates. Focus ring uses `--color-border-focus`.
- Active indicator: 2px accent underline via `border-b-2 border-accent -mb-px`. Inactive: `border-b-2 border-transparent`. Label color: active `text-accent`, inactive `text-text-secondary hover:text-text-primary`.
- Transition: 150ms ease-out on underline + label color (DESIGN.md §Motion "hover states: 150ms ease-out").

### Live refresh (D-11 inherited from Phase 06)

- Performance tab polls via `router.refresh()` every 5s while the tab is focused. Scenario-stub tab does NOT poll (no data to refresh).
- Polling pauses on `document.visibilityState === 'hidden'` (already the Phase 06 pattern).

### Empty-state trigger (D-08)

- Condition: `allocator_holdings` count for `user.id === 0`. This is tested regardless of whether an `api_keys` row exists.
- When `api_keys` exists with `sync_status='syncing'` AND holdings still empty → render the first-sync inline state inside a thin `InfoBanner` (neutral grey, DESIGN.md `InfoBanner` primitive) at the top of the Performance tab body instead of the empty-state card.

### Stale gate (D-10 / D-11)

- "Active keys" = `api_keys WHERE is_active = true` for this allocator.
- "Stale" = all active keys have `last_sync_at` older than 24h.
- When stale: KPI numeric values render as `—` in `text-text-muted`; equity + drawdown charts get a `rgba(248,249,250,0.4)` overlay (`--color-page` at 40%) with the "Data may be stale" label rendered on top in `text-text-secondary` 14px medium. The `Sync your keys to refresh →` line renders above the strip using the existing `WarningBanner` primitive.
- When any single active key is fresh (<24h), data is fresh globally.

### Warm-up gate (D-03)

- When snapshot count < 30 days: annualised metrics (CAGR, Sharpe, Sortino, Calmar) render `—`. AUM + `value_usd` always render.
- Helper line shows per affected KPI (not per card): `Warming up — need {N} more days of synced data.` where `N = 30 - snapshot_count`.
