    """Full backfill on first key connect. One-time per (allocator, api_key).

    Mirror run_poll_allocator_positions_job (job_worker.py lines 755–880):
      1. _allocator_key_preflight (reads job['api_key_id'] — raises if missing).
      2. Idempotency early-return: if allocator_equity_snapshots already has
         rows for this allocator, return DispatchResult(DONE) with reason=
         "already_reconstructed".
      3. Determine backfill start_date: max(account_creation, now - BACKFILL_CAP_DAYS).
      4. Fetch trades + deposits + withdrawals + OHLCV (per symbol from trade tape).
      5. For symbols that raise BadSymbol: fall back to CoinGecko (cache-first).
      6. Compute daily equity via _compute_daily_equity.
      7. Resolve `history_depth_months = history_depth_months_for_venue(ctx.venue)`.
         If OKX terminus was hit, force to 3 regardless.
      8. Persist via persist_equity_snapshots(rows, allocator_id, history_depth_months).
