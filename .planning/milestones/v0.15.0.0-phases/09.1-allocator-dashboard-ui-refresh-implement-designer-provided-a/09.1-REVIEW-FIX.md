## Deferred Issues

### IN-05: Outside-click handlers swap mousedown/click semantics inconsistently

**Files (no changes applied):**
- `src/app/(dashboard)/allocations/components/CustomRangePicker.tsx` (mousedown — no change needed)
- `src/app/(dashboard)/allocations/components/Tweaks.tsx` (mousedown — no change needed)
- `src/app/(dashboard)/allocations/components/WidgetPicker.tsx` (click + setTimeout 0 deferral)
- `src/app/(dashboard)/allocations/components/WidgetChrome.tsx` (click)

**Reason for deferral:**

This is shipped production code (v0.15.x) and the reviewer themselves classified the finding as "style, not correctness." Switching the two `click` handlers to `mousedown` is a real behavior change that requires careful UX consideration:

1. **WidgetPicker** uses `click` + `setTimeout(0)` deferral specifically to avoid the open-then-close race when the same click that opens the popover would otherwise close it. Migrating to `mousedown` would require restructuring the deferral pattern (mousedown fires earlier in the event loop and the deferral idiom doesn't apply the same way).
2. **WidgetChrome** menu listens on `click` without any deferral. Switching to `mousedown` would close the menu BEFORE the click on a menu item is registered, breaking the menu interaction entirely. A correct port to mousedown would also need rework of the in-menu click targeting.
3. The reviewer's recommended `mousedown` standard is the more common popover idiom but it's explicitly a UX decision, not a correctness bug. The current behavior is consistent with the designer prototype.

Per the fix brief: "If a fix is too risky for production-deployed code (touches shipped behavior in v0.15.x), document as `deferred`." This finding qualifies. A proper migration belongs in a follow-up that:
- Pins the consistency rule in `tasks/lessons.md` (per the reviewer's recommendation)
- Reworks WidgetPicker's deferral idiom so mousedown doesn't introduce open-close races
- Reworks WidgetChrome menu's outside-click so mousedown doesn't break menu-item clicks
- Adds outside-click regression tests for all four popovers (none today)

**Original issue:** "Three popovers in the same surface use click for outside-click dismissal, two use mousedown. The behaviors are subtly different."
