## D-14 invariant — no double-mount

The cross-cutting reviewer flagged a forward-looking risk: registering `bridge-outcome-banner` as a widget while Plan 08's HoldingsTable also mounts per-row `BridgeOutcomeBanner` would double-mount for the same `holding_id`. The default Overview tile is the hero; the per-row banner stays exclusively in HoldingsTable.
