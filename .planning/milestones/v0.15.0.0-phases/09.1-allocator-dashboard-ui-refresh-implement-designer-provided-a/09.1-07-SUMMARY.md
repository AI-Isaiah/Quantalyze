# Phase 09.1 Plan 07: SVG EquityChart + CustomRangePicker + V2 wiring Summary

Ports designer-bundle/project/src/charts.jsx as `EquityChart.tsx` into the V2 widget barrel: SVG portfolio renderer with 7-period toggle (default 6M), crosshair hover, holding overlays, and stale dimmer — preserving the Phase 07 / VOICES-ACCEPTED f7 `equityDailyPoints` parallel-prop path verbatim. Wires through the existing WIDGET_REGISTRY + Plan 05 write-time normalization: `DESIGNER_KEY_TO_WIDGET_ID["equity"]` flipped from `"equity-curve"` to `"equity-chart"` so fresh V2 Overview defaults pick up the SVG renderer.

## Context

This is plan 07 of 11 in Phase 09.1's V2 dashboard refresh. Plan 05 landed the WidgetGrid + write-time normalization spine; now plan 07 fills the `equity` slot with a real SVG widget instead of the Recharts-based `EquityCurve` legacy stub. The legacy `EquityCurve` widget is preserved (still registered as `equity-curve`) so persisted user layouts that wrote `equity-curve` to localStorage pre-flip continue to render unchanged. Only freshly-defaulted V2 layouts pick up the new chart, matching D-19's normalization-only-at-write-time stance.

Holding overlays (the per-holding lines that show how each holding contributed) get a prop slot but no production wiring yet — Plan 08 will surface the HoldingsTable checkboxes that feed `overlays`. The chart degrades gracefully when `overlays = []` (no extra paths rendered).

The CUSTOM period button opens a minimum-viable two-input popover. The designer's full calendar grid + presets rail (`range-picker.jsx`, ~350 lines) is deferred to a future Tweaks-panel iteration; for now the chart contract only needs `{start, end}` ISO bubbling + dismissal handling.

## What Changed

### Task 1 — EquityChart.tsx (commit `8688ebe`)

`src/app/(dashboard)/allocations/widgets/performance/EquityChart.tsx`. ~570 lines of TypeScript implementing the full SVG renderer:

**Props contract:**

```ts
type Props = {
  equityDailyPoints: DailyPoint[];
  benchmark?: DailyPoint[];
  overlays?: OverlaySeries[];
  stale?: boolean;
  initialPeriod?: Period;
};
```

**Key elements:**

- **f7 anchor preserved:** `anchorFromFirstPositive(equityDailyPoints)` runs the same `findIndex(p => p.value > 0)` + `slice` + `value/base` arithmetic as `EquityCurve.tsx:52-61`. Composite is the anchored series. Period filter operates on the anchored composite, so the anchor stays stable across period switches.
- **Period filter:** `sliceByPeriod(points, period, customRange?)` returns the visible window. 1M = last 30d, 3M = 90d, 6M = 180d, YTD = Jan 1 → today, 1Y = 365d, ALL = full, CUSTOM = inclusive of both ends.
- **Period toggle UI:** 7 buttons (1M / 3M / 6M / YTD / 1Y / ALL / CUSTOM) in a `role="tablist"` with `aria-label="Period"`. Each button is `role="tab"` with `aria-selected`. Active uses `var(--accent)` background + white text. CUSTOM opens the `CustomRangePicker` popover; the chart only switches to CUSTOM after the user applies a range (cancel keeps the previous period).
- **Per-token grep verification:** each of the 7 period strings appears as a quoted literal in source (in the `PERIODS` const array AND in the `case` arms of `sliceByPeriod`).
- **Projections:** `pad = { t: 20, r: 48, b: 28, l: 8 }`, `width` from ResizeObserver (jsdom-safe undefined fallback to 960), `height = 260`. `x(i)` and `y(v)` projections clone the designer's math.
- **Path builders:** `toPath(arr)` builds `M x0 y0 L x1 y1 ...`; `toArea(arr)` extends with the bottom-edge close. Both handle `null` values (skip-and-restart) so missing benchmark days produce gapped paths instead of crashing.
- **Gradient fill:** `<linearGradient id="eq-grad">` with `#1B6B5A` stops at 0.22 → 0 opacity. Portfolio area uses `fill="url(#eq-grad)"`.
- **Tick density:** when `n > 90`, walks calendar months and emits one tick per visible month (mid-month label). Otherwise picks 7 evenly-spaced "MMM D" labels.
- **Crosshair hover:** `onMouseMove` computes `i = Math.round(((px - pad.l) / chartW) * (n - 1))` and sets `hoverIdx`. Renders a vertical dashed line at `x(hoverIdx)` plus a portfolio-color circle at `y(visible[hoverIdx].value)`. A tooltip popover (absolute-positioned outside the SVG) shows portfolio %, benchmark %, and per-overlay % — all percent-from-window-start.
- **Overlays normalization:** each overlay's points are normalized at the visible window's first date (per-render `useMemo` keyed on `[overlays, visible]`). The base is the overlay's first non-null positive value at or after the visible window's first date. Missing days produce `null` in the overlay series.
- **Benchmark:** if `benchmark` provided, anchors via the same f7 helper, then re-emits values aligned by date to the visible composite (missing benchmark days → `null`, dropped by the path builder). Renders as a 1.25-stroke dashed `#64748b` path.
- **Stale dimmer:** when `stale === true`, mounts a `bg-page/40` overlay with a "Data may be stale" pill in the chart well. Clones the legacy `AllocationDashboard.tsx:651-663` pattern verbatim. `data-testid="equity-chart-stale"` for test-targeting.
- **Empty state:** when `equityDailyPoints.length === 0` OR the anchored composite is empty, renders a centered "Equity data warming up" placeholder div with `role="img"` + `aria-label="Equity chart"` (matches the PURGE-04 idiom).
- **Intraday deferred:** explicit `// Intraday toggles (1D / 1W) deferred per CONTEXT §deferred` comment so future audits don't reintroduce 1D/1W by accident.
- **Accessibility:** SVG has `role="img"` + `aria-label="Equity chart"`; period buttons are `role="tab"` with `aria-selected`; tablist has `aria-label="Period"`.

**Default export — WidgetProps adapter:**

```tsx
export default function EquityChartWidget({ data }: WidgetProps) {
  const d = (data ?? {}) as EquityChartWidgetData;
  return (
    <EquityChart
      equityDailyPoints={d.equityDailyPoints ?? []}
      benchmark={d.btcBenchmark}
      overlays={d.equityOverlays}
      stale={d.allKeysStale ?? false}
    />
  );
}
```

This is what `WIDGET_COMPONENTS["equity-chart"]` lazy-imports. The named `EquityChart` export is consumed directly by tests so they can pass props without going through the data bag.
