## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] Row-cell color hex normalized to rgb in JSDOM**

- **Found during:** Task 1 test re-run after rewriting the timeline-row styling.
- **Issue:** The new "delta column" rewrite used `style={{ color: v >= 0 ? "#16A34A" : "#DC2626" }}` for the row delta cells. JSDOM normalized that to `rgb(22, 163, 74)`, which broke the `expect(style).toContain("16A34A")` assertion that the existing color-test relied on.
- **Fix:** routed the row-cell color through a CSS custom property (`--delta-color`) the same way the existing KPI strip does, preserving the literal hex in the inline `style` attribute. Visual result is identical in a real browser.
- **Files modified:** `src/app/(dashboard)/allocations/widgets/outcomes/OutcomesWidget.tsx`
- **Commit:** `b64e876` (folded into Task 1)

**2. [Rule 2 — Critical correctness] Suspense boundary around lazy risk widgets**

- **Found during:** Task 2 implementation while wiring `WIDGET_COMPONENTS[id]`.
- **Issue:** `WIDGET_COMPONENTS` exposes `React.lazy(...)`-wrapped components. Mounting a lazy component without a `<Suspense fallback={…}>` ancestor throws on first render and bricks the tab.
- **Fix:** each Risk-tab tile is wrapped in `<Suspense fallback={<div className="text-xs text-text-muted">Loading {id}…</div>}>`.
- **Files modified:** `src/app/(dashboard)/allocations/RiskTabPanel.tsx`
- **Commit:** `a20df34` (folded into Task 2)
