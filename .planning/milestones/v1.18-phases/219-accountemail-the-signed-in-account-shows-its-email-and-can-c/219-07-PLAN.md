<wire_contract>
Verbatim in plans 04, 05, 06 and 07.

Request: `POST /api/account/email`, `Content-Type: application/json`, body `{ "email": string, "password": string }`.

| Case | Status | Body | Form shows |
|------|--------|------|------------|
| success | 200 | `{ "ok": true, "pending_email": string or null }` | pending panel for pending_email (null: nothing pending, as today), password and address cleared, form closed, router.refresh() |
| same address | 400 | `{ "code": "same_address", "error": "That is already your sign-in email." }` | body.error (normally caught client-side first) |
| wrong password | 400 | `{ "code": "wrong_password", "error": "That password is not right. Nothing was sent." }` | body.error, password cleared, focus to the password field |
| no password on the account | 409 | `{ "code": "password_not_set", "error": "This account has no password yet. Set a password first, then change your email." }` | SET_PASSWORD_FIRST plus the `Set a password` link to /reset-password |
| check unavailable | 502 | `{ "code": "verify_unavailable", "error": "Could not check your password. Please try again." }` | body.error |
| Auth refused the change | 400 | `{ "code": "update_failed", "error": <Supabase message or fallback> }` | body.error |
| rate limited | 429 | `rateLimitDenyJson` body | TOO_MANY |
| anything else (401, 403, 503, malformed 400 without a code, non-JSON) | any | any | EMPTY_MESSAGE_FALLBACK |
| fetch throws | none | none | NETWORK_ERROR |

Redirect the route sends: `<origin>/auth/callback?next=` + `encodeURIComponent("/profile?tab=account&email_change=confirmed")`. The callback (plan 219-05) lands on /profile?tab=account with `email_change=confirmed`, or `email_change=partial` for the first of two links while Secure email change is ON.

Set-a-password destination: `/reset-password` (planner decision 6 of plan 219-06: public and bounce-exempt in src/proxy.ts, so every signed-in role stays on it; /forgot-password bounces a signed-in user and the Security tab is allocator-only).
</wire_contract>
