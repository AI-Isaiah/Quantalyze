## Pattern Assignments

### `analytics-service/services/mt5_client.py` (service, one-crossing request-response)

**Analog:** the same file's `_REMOTE_SESSION_SNAPSHOT_SRC` (comment block above it, then the constant), `_parse_session_snapshot`, `Mt5Client.session_snapshot`; read discipline from `Mt5Client.account_info` / `terminal_info`.

**Remote constant pattern** (symbol `_REMOTE_SESSION_SNAPSHOT_SRC`): a module-level AST string constant, a single expression, no braces, no `%`, no `import`, no dunder; the `scalar` lambda coerces non-scalars to `str` so the tuple is always brine-by-value:
```python
_REMOTE_SESSION_SNAPSHOT_SRC = """
(lambda scalar: (lambda terminal:
    ("terminal_unanswered", scalar(mt5.last_error()[0]))
    if terminal is None
    else (lambda build, connected, account:
        ...
    )(scalar(getattr(terminal, "build", None)),
      scalar(getattr(terminal, "connected", None)),
      mt5.account_info())
)(mt5.terminal_info()))(
    lambda value: value
    if value is None or isinstance(value, (bool, int, float, str))
    else str(value)
)
"""
```
For the new constant, RESEARCH "Pattern 1 Example" is the proposed text (it enumerates `mt5.symbols_get()`, keeps `s.visible`, reads `mt5.symbol_info_tick(s.name)`, returns `("answered", total, asked, answered, newest_time_msc_or_-1)` or `("listing_unanswered", code)`). Read ONLY `.time_msc`, `.visible`, `.name`; never a price field (D-04). Follow the comment-block style above the snapshot constant (shape tags, `last_error()` read immediately after the `None`, "Never exercised against the live bridge" caveat, with the WINDOWS entry or the spike-leg reference as the live-proof pointer).

**Method pattern** (symbol `Mt5Client.session_snapshot`, the one-crossing seam; copy its structure exactly, changing the constant, stage name and parser):
```python
# WIZFORM-ABANDON / D-36 — ahead of `_guarded_read` and `_timed`.
self._assert_live("session_snapshot")
conn = getattr(self._mt5, "_MetaTrader5__conn", None)
if conn is None:
    raise Mt5ClientError(
        0, "MT5 rpyc transport is not reachable for the session snapshot"
    )

def _remote_call() -> Any:
    return conn.eval(_REMOTE_SESSION_SNAPSHOT_SRC)

raw = self._guarded_read(_remote_call, stage="session_snapshot")
return _parse_session_snapshot(raw, expected_login, expected_server)
```
Required: `self._assert_live("server_tick_times")` as the FIRST executable statement (the abandon roster derives this from source), `stage="server_tick_times"`, a keyword-only signature if any argument, docstring stating tick TIMES only, never `symbol_select`, never `symbol_info_tick` as an attribute.

**Parser pattern** (symbol `_parse_session_snapshot`): `type(raw) is not tuple or not raw` first (a netref must not be indexed), then tag and `len(raw)` checks, then `isinstance(x, int) and not isinstance(x, bool)` on every int, raising `Mt5ClientError(0, "MT5 ... returned a malformed shape")` (scrubbed, value-free). A `listing_unanswered` tag is RETURNED (the caller records `unmeasured`/`no_tick` style outcome) the way `terminal_unanswered` is; a malformed shape and a far-side raise RAISE typed (`_guarded_read` converts the latter).

**Return type pattern:** a `NamedTuple` beside `Mt5SessionSnapshot` (symbol), carrying counts and the newest `time_msc` only; no symbol names.

**Do NOT copy:** `_materialize` (symbol; `{str(k): _coerce(v) for k, v in asdict().items()}` copies every tick field including prices, which breaks D-04). `Mt5Client.account_info` is the discipline template only for the `_assert_live` / `_guarded_read(..., stage=...)` shape:
```python
self._assert_live("account_info")
info = self._guarded_read(self._mt5.account_info, stage="account_info")
if info is None:
    self._raise_last()
return _materialize(info)
```
