## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Worker ↔ MT5 bridge | One committed far-side expression (`_REMOTE_SERVER_TICK_TIMES_SRC`) crosses the rpyc bridge; its reply is parsed as untrusted | Tick times, symbol counts, error codes (no credential) |
| Worker ↔ Supabase (service_role) | Write-once reading row inserted per leased derive | Offsets, verdict, reason, SHA-256 of the server label (never the label) |
| Worker → ops alert (Sentry) | Mismatch and final-attempt insert-failure pages | Rule id, offsets in hours, SQLSTATE tag, key uuid tag (no server value) |
| Spike CLI (founder-run) → stdout | `--leg clock` / `--leg band` report | Redacted report (login, password, server scrubbed) |
