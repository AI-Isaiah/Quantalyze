### Copy principles (binding on every string in this phase)

These are Phase 161's principles 1 to 6, carried forward unchanged. The three that matter most
here:

1. **Name the cause that was actually established.** If no cause was established, say that
   plainly and name none (SC2).
2. **The remedy has to be able to work on the surface where it renders.** A copy entry written
   for the wizard and reused on a dashboard surface is re-read on that surface. A bullet that is
   false there gets suppressed through `fixRequires`. The sentence is never left standing (SC3).
3. **Never invent a number.** Any duration this phase states comes from a recorded measurement
   with its source and window (SC4). Until that measurement exists, the copy carries a
   placeholder, and **the placeholder is never shipped**.

**Rule (from 164.6.6.3.5).** A pointer is a sentence that contains the exact lowercase substring
