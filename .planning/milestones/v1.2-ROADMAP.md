## Overview

v1.2 unified the three fractured allocator surfaces — the example-universe Strategy
Sandbox (`/scenarios`), the legacy Portfolios pages (`/portfolios*`), and the own-book
Scenario composer — into ONE factsheet-grade Scenario composer on the live blended book.
The journey: stand up the **unified composer spine** (one surface that composes from a
blank slate or seeds from the live book, browses verified + example strategies in one
tagged catalog, lazily resolves an added strategy's returns so it moves the projection,
and saves/reopens named portfolios) (29); mount **factsheet-grade graphs on the blend**
(equity/drawdown in the factsheet visual identity + a returns-distribution view + rolling
Sharpe/volatility/Sortino, each declaring method/overlap-N/horizon, with peer/percentile
panels structurally suppressed on a hypothetical blend) (30); make the **graphs lead** the
surface via collapsible composition controls (hide-not-unmount, so in-progress edits
survive) (31); **fix the dead links and retire the split route** (`/scenarios` → 307
redirect to the unified composer, ScenarioBuilder deleted, nav consolidated to one
allocator entry, portfolio-context add-strategy attach-back) (32); and **polish the
journey** (Bridge → composer continuity, DESIGN.md-consistent blank-slate focus rings, and
a live WCAG-AA axe gate on the composer) (33).

Every phase was additive client-TS/TSX over the **frozen** `src/lib/scenario.ts` engine
(SCENARIO-05 zero-diff): no schema change, no migration, no second annualization path. Each
phase carries a content-inspecting "frozen-spine" exit-gate guard that fails CI on engine
drift, a forbidden-migration, or an honesty-invariant regression. The no-invented-data and
no-peer-ranking-a-hypothetical-blend invariants were locked throughout.

## Milestone Summary

**Decimal Phases:** none (29–33 are all integer phases, continuing from v1.1.0's Phase 28 with no reset).

**Key Decisions:**

- Decision: Unify Portfolios + Scenario tab + Strategy Sandbox into ONE factsheet-grade composer (Rationale: three fractured surfaces + a dead `/portfolios` add-strategy link broke the allocator workflow end-to-end).
- Decision: "Factsheet parity" = graphs only; peer/percentile/signature panels stay structurally suppressed (Rationale: the no-invented-data honesty invariant — you cannot peer-rank a hypothetical blend; `ingestSource:"api"` path is never reachable from the composer).
- Decision: Lazy-fetch an added strategy's `daily_returns` via a scoped RLS route rather than SSR-lifting the full catalog (Rationale: 29-RESEARCH measured ~87KB gzip SSR-lift on every load vs ~7KB lazy per actual add).
- Decision: Entry-mode + dirty-draft mode switches route through the existing `ResetConfirmationModal`; the confirm path is the only mutator (Rationale: a mode switch can never silently wipe in-progress edits).
- Decision: Collapsible controls use a native `<details>` hide-don't-unmount wrap with edit state held above the boundary (Rationale: graphs lead with zero panel reorder, and in-progress weight/leverage edits survive collapse→expand by construction).
- Decision: Route retirement via a server-component 307 `redirect()` (Rationale: preserves auth context and is non-cacheable, unlike a `next.config` redirect or a 308 `permanentRedirect`).
- Decision: Per-phase content-inspecting frozen-spine exit-gate guards (Rationale: a silent schema change / engine drift / honesty-invariant regression fails CI even without rerunning the behavioral test; the engine stayed byte-frozen across all 5 phases).
- Decision (mid-milestone, at /ship #520): rework the planned FLOW-01 `?portfolio=` auto-attach into the shipped manual add-dropdown path (Rationale: the auto-attach was a dead/unreachable feature; the revert netted those files zero-diff).

**Issues Resolved:**

- Net security improvement: the `/scenarios` `createAdminClient()` RLS-bypass institutional-universe read (a C-0017-class leak vector) was eliminated at source by the route retirement.
- 3 genuine production WCAG-AA violations on `/allocations` (duplicate `<main>`, Export/+Allocation inside `role=tablist`, `role=region` on `<footer>`) caught by the new composer-axe CI gate and fixed at root.
- WR-01 (Rolling-Sharpe legend hardcoded "365d") and WR-02 (distribution panel re-derived sample floor) fixed in Phase 30.
- CR-01 (cross-account `composer-collapse:` localStorage leak) fixed before Phase 31 verification by registering the namespace in the sign-out purge inventory.
- A sibling-plan B15 limiter-registry omission (the new lazy-returns route was unclassified) caught + fixed by the Phase 29 consolidation gate.
