### ⭐ The same integer over a strictly smaller admissible set

The one substantive finding is that nothing moved *on the surface* while the guarantee underneath got stronger. `identity ok` used to mean the failure text carried this run's nonce — a secret the gate's own SQL could read back through `current_query()` ([R4-C02]). It now means three conjoined things: the psql prefix names this lane's gate file at the failing statement's last line, **and** the CONTEXT chain is exactly one `inline_code_block line N at RAISE` frame, **and** N resolves through the tokenizer's spans to the arm's recorded raise line.

So `biting: 30` is the same number over a **strictly smaller** admissible set, and a floor of 30 is harder to satisfy than it was. That is the safe direction for a ratchet, and it is the fact plan 10 must carry alongside the integer. Plan 05's SUMMARY asked plan 09 to make this note; it is now in the artifact (§3a), in the `ARMS_FLOOR` comment, and in the handoff.
