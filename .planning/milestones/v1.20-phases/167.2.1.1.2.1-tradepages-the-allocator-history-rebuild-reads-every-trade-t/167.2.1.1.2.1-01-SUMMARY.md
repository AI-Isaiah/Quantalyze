## Deviations from Plan

None that change scope. Recorded as choices made inside the plan:

1. **[Rule 3 - Blocker, test helper] `VenueTradeBook` carries `inspect.markcoroutinefunction(self)`.** `AsyncMock(side_effect=<instance with async __call__>)` does not await the returned coroutine unless the instance is marked as a coroutine function (the unmarked form returned a never-awaited coroutine and failed with `'coroutine' object is not iterable`). Found before the first GREEN; fixed in `_trade_pages.py`.
2. **Tracer data shape.** The plan says 250 trades from day 20 to day 40 and also more than 100 in one 7-day window, which an even spread cannot satisfy. Used 1 trade on day 20, 199 packed into days 22 to 27 (inside one window) and 50 over days 30 to 40: 250 distinct ids, nothing in the first 20 days.
3. **Tracer-first discipline.** The Task 1 module edit initially also contained the Task 2 other-venue change; it was reverted from a saved draft before the Task 1 commit so the other-venue test was genuinely RED at the Task 1 commit (`red-task2.log`).
4. **Venue label.** `_fetch_trades_paginated_one_pass` gained a keyword-only `venue` (default empty) so its WARNINGs name the venue (the plan's repeat test requires the venue in the message). Only the non-OKX call site passes it; the OKX call site is untouched for plan 02.
5. **Advisory (a), repeat test.** The Bybit repeat case uses a one-window range; the other-venue walk checks the page advances before appending, so the repeated page is held once. **Advisory (b), wording.** The other-venue WARNING fires only after a full page (at least `_TRADE_PAGE_LIMIT` rows) that cannot advance; a short repeated page ends quietly, and the same threshold governs the Bybit stop-and-warn rule.
6. **OKX inherits the walk change until plan 02.** OKX still calls `_fetch_trades_paginated_one_pass`, so it also loses the short-page stop now (its forward cursor is wrong on OKX; plan 02 replaces that branch). No existing OKX test went red from it.
7. **`real_ccxt_client`** leaves `markets` empty, so ccxt parses Bybit symbols as `BTCUSDT`, not `BTC/USDT`. The real-ccxt tests assert ids, counts and the raw requests only, never symbols.
8. **Branch namespace.** The worktree branch is `feat/167.2.1.1.2.1-p01`, not `agent-*`; the commit protocol's agent-namespace allow-list was treated as the sequential-dispatch case (orchestrator-assigned worktree and branch). It is not a protected branch.
