# Code review — 167.1.2-13

Scope is the sole-key empty-replace refusal, commits `6d5cd8956` and `ff3cde6ee`.

## Findings

### Warning — a head count with no count was treated as an empty book

`_allocator_has_equity_snapshots` selects with `head=True`. That response has no rows. When `res.count` was missing, the helper fell through to `len(data)` and returned absent. `replace_equity_snapshots` then sent the empty payload, which is the wipe this plan refuses.

A missing count is now the same fail-safe as a raised lookup: present, lookup failed, RPC not called. Pinned by `test_item7b_missing_head_count_refuses_purge`.

## Checked and left as specified

The refusal still returns DONE and audits `reconstruct_no_data` with `purge_refused`. The plan requires that outcome. A confirmed-present book sets `existing_history`; a failed lookup does not. An empty book with a real count of zero still calls the RPC once.
