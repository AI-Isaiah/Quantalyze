### MEDIUM-1 (a): the vol-matched comparator scaled by an unmeasured 1

**Files modified:**
- `src/lib/factsheet/comparator-block.ts`
- `src/lib/factsheet/comparator-block.volmatch-nan.test.ts`
- `src/lib/factsheet/return-stats.sites.test.ts` (the 166.2-04 T18 pin, see below)

**Commit:** `fd9ee9be7`
**Status:** fixed (requires human verification: this changes what the block emits)

**Applied fix:**
- `vmScale` fell back to `1` when `benchSummary` was null or `benchSummary.ann_vol` was not `> 0`. NaN and 0 both fail that test. The chart then drew the raw comparator under a legend reading `"<short> × 1.00"`, and nobody measured that factor.
- One predicate now covers both sides: `Number.isFinite(stratAnnVol) && benchVol != null && Number.isFinite(benchVol) && benchVol > 0`. When it is false, `volMatched` and `volMatchedLabel` are both null, the same form as the unavailable block. The `: 1` fallback is gone. `vmScale` is NaN when unavailable, but nothing reads it then.
- No change was needed in `chart-configs.ts`. `resolveSeries` already pushes no comparator series when the field is not an array.

**A deliberate change to a Phase 166.2 pin.**
- **The pin.** `return-stats.sites.test.ts` T18 asserted `volMatchedLabel === "B × 1.00"` for an all-zero benchmark. That is the exact label MEDIUM-1 calls invented, so fix (a) cannot land with the pin unchanged. The pin's update is in the same commit, so that commit is green on its own.
- **What stayed the same.** T18 protects one property: a compounding constant-yield benchmark answers exactly as an all-zero one does, and is never vol-matched by a scale of about 1e13. That still holds. Both now answer null, and the loop still asserts `toEqual(zero.volMatched)` and `toBe(zero.volMatchedLabel)`. The `cumEq(bench)` check moved from `volMatched` to `cumulative`, so the comparator itself is still pinned as drawn. The noisy case ("keeps a real scale, not 1") is unchanged and passes, so a real scale still gets through.
- **What moved.** For a comparator with zero vol, the answer changed from "scale 1" to "absent".
- **The describe title.** It still says "comparator-block.ts unedited", which is no longer true. It carries a dated `CORRECTED 2026-10-01` comment above it, and the original wording is kept as lineage.

**Evidence:**
- **New cases** in `comparator-block.volmatch-nan.test.ts`, all with a finite strategy vol of 0.2:
  - a flat comparator (ann vol 0)
  - one covered return (ann vol NaN)
  - no covered return (no summary)

  Each asserts that the label never matches `× 1.00`, and that the label and the series are both null.
- **Neuter run.** With the old two lines restored (`vmScale` falling back to 1, `vmAvailable = Number.isFinite(stratAnnVol)`), **5 of 51 tests fail**: the 3 new cases, each with `expected 'SPX × 1.00' not to match /× 1\.00/`, plus both updated T18 cases. The file was restored with `cp` and confirmed with `cmp`.

### MEDIUM-1 (b): a "Volatility Matched" panel that drew only the strategy line

**Files modified:**
- `src/app/factsheet/[id]/v2/FactsheetView.tsx` (the `PerformanceCharts` `configs` filter only)
- `src/app/factsheet/[id]/v2/FactsheetView.volmatched-panel.test.tsx` (new test file)

**Commits:** `f6cf56d50` (the filter), `3559fc7db` (the reason line)
**Status:** fixed

**Applied fix:**
- **The new filter.** `PerformanceCharts` drops the `volMatched` panel when the active block's `volMatched` is null. This extends the existing 2026-05-20 `cmpKey === "none"` filter for the same stated reason: a panel holding only the strategy line repeats the Equity Curve above it.
- **A one-line reason, following the page's own pattern.** `PerformanceCharts` already shows a reason when it hides a comparator panel: `{!beta.enough && cmpKey !== "none" && <NotEnoughDataPanel title="Rolling β — Not enough data" …/>}`. That is the exception the brief allowed for, so the hidden Volatility Matched panel uses the same pattern. Its title is "Volatility Matched — Not available", and its body reads "The strategy or the comparator has no measurable volatility on this basis, so there is no scale to match the comparator to. This panel will appear once both do."
- **When the reason shows.** Only when the comparator has a `summary`, which means it has covered returns and the match was skipped for want of a measurable vol. A comparator with no summary is hidden without a reason. That covers three cases:
  - an `unavailableComparatorBlock`, whose prices could not be read. The picker already says "prices unavailable".
  - a comparator with no covered day.
  - the composer's inert block (`scenario-factsheet-payload.ts` `inertComparatorBlock`), where the match is never computed.

  "No measurable volatility" would misstate all three.
- **Which block it reads.** The check reads `view.comparators[cmpKey]` from `useBasisSeriesView`, which is the block `TimeSeriesChart` draws. It does not read the cash payload's block, because the strategy-side null shows up mainly on the MTM and smoothed bundles. `volMatchedAbsent` is in the `useMemo` deps, so a basis switch recomputes the panel list.
- **Side effect, the same rule.** Two other blocks also carry a null `volMatched`, so their strategy-only panel is now hidden too, without the reason line:
  - an `unavailableComparatorBlock`;
  - the allocations composer's inert BTC block, when a benchmark is present. The composer renders `FactsheetBody`, and with it `PerformanceCharts`.

**Evidence** (`FactsheetView.volmatched-panel.test.tsx`, 4 cases, rendering the real `FactsheetBody`):
- **Control.** A built payload whose active comparator has a real `volMatched` array shows the panel title and no reason. The test asserts the array is there, so the absence cases below cannot pass on an empty fixture.
- **Null on the cash payload, with a summary.** The title is absent and the reason is present.
- **Null with no summary (the unavailable form).** Both the title and the reason are absent.
- **Null on the MTM bundle only.** On cash, the cash block keeps its series and the panel shows without the reason. After clicking "Mark-to-market", the panel is hidden and the reason shows.
- **Neuter runs** (each restored with `cp` and confirmed with `cmp`):

| Neutered | Result |
|---|---|
| New filter line removed | 2 red (the null-on-cash case, the MTM case) |
| Check reads `payload.comparators[cmpKey]` instead of the view | 1 red (the MTM case) |
| Reason panel never rendered (`false &&`) | 2 red (the null-with-summary case, the MTM case) |
| `summary != null` gate removed from the reason | 1 red (the unavailable form) |

The first two rows were measured on the 3-case file at `f6cf56d50`. The last two were measured on the 4-case file at `3559fc7db`.
