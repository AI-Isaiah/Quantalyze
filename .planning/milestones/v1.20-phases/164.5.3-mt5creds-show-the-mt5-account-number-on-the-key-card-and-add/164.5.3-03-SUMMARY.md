# Phase 164.5.3 Plan 03: MT5 Secret-Rotation Internal Endpoint Summary

**New `POST /internal/keys/{key_id}/rotate-secret` in analytics-service: decrypts the stored MT5 credential, re-validates the caller-supplied new password against the live broker via the existing `_validate_mt5_key` probe, and re-encrypts only on structural success — plaintext never leaves the service.**

## Performance

- **Duration:** ~20 min (approximate; not precisely instrumented this run)
- **Completed:** 2026-09-20
- **Tasks:** 2/2
- **Files modified:** 2 (1 modified, 1 created)

## Accomplishments
- Added `POST /internal/keys/{key_id}/rotate-secret` to `analytics-service/routers/internal.py`, immediately after `get_key_permissions`, reusing `_verify_internal_token`, `_consume_rate_limit`, `get_supabase`/`one`, `get_kek`, `decrypt_credentials`, `_validate_mt5_key` (imported from `routers.exchange`), and `encrypt_credentials` — no new crypto, no new broker probe, nothing built except the chokepoint that wires them together.
- Gating order matches `get_key_permissions`'s own: token (403) → rate limit (429) → existence (404) → venue-scope (422, MT5-only) → KEK (500) → decrypt (500) → live-broker validate (400, three distinguishable details) → re-encrypt + return (200).
- 10 tests in `analytics-service/tests/test_mt5_rotate_secret_internal.py`, all using synthetic placeholder credentials, asserting the exact placeholder strings are ABSENT from response bodies (not merely that a field name is missing) and that every downstream step is proven not-called on each failure path.

2. **Observed RED:** all three MT5-failure-detail tests failed —

3. **Restore:** `cp` from a pre-neuter byte backup; `cmp` confirmed **BYTE_IDENTICAL**.
4. **Re-verify GREEN:** full 10/10 pass, mypy `--strict` clean, after restore.

(A synthetic login value `9999999`, never a real account number, appeared in that observed assertion text above — recorded here only because it is a test fixture placeholder already declared synthetic at the top of the test file, not a specimen of anything real.)
