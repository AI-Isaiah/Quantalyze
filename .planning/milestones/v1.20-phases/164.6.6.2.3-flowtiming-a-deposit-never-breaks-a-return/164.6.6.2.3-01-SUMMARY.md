# Phase 164.6.6.2.3 Plan 01: FLOWTIMING core change in nav_twr.py Summary

A day carrying a `DayTiming` is now measured as `prod_k(1 + P_k/B_k) - 1` against the capital each position was opened on, a flow of any size no longer drops a day, and a full-history account's day 0 is its inception (opt-in, byte-identical by default).

## What changed

**`analytics-service/services/nav_twr.py`**
- `DayTiming(NamedTuple)`: `flows` (UTC epoch ms, signed amount, ascending) and `pnl` (position-open ms or `None` for overnight, cash effect). A fold that cannot resolve an instant must not build a record for that day.
- `_judged_cohorts` (single source of the cohort split and of which cohorts are measured) and `_timed_day_return(prev, timing, floors, *, inception)`. Bases `B_0 = prev`, `B_k = B_{k-1} + flow_k`; cohort index `bisect_right(flow_instants, open)` so a flow on an equal instant counts first (D-09); `None` opens go to cohort 0 (D-04); a cohort k >= 1 with zero P&L is skipped; cohort 0 is skipped only on an inception day with zero cohort-0 P&L. Each measured cohort runs the negative and dust checks and then `abs(P_k) >= PNL_DOM_RATIO * B_k` on its own base (D-06). Guards return `(nan, key)`; nothing is clamped or substituted.
- `chain_linked_twr(..., timing=None, full_history=False)` and `reconstruct_nav_and_twr(..., timing=None, full_history=False)` (forwarded). Defaults are byte-identical (SC-4).
- `_guard_denominator(prev_nav, dust_floor)`: the flow branch and `FLOW_DOM_RATIO` are deleted (D-05). Module docstring step 3 rewritten.
- Inception: `t == 0 and full_history and flow_t > 0 and abs(prev) <= floors.residual_abs_tol`. With a record: cohort 0 is not judged when empty, later cohorts measure against `prev + F`. Without: NaN, no flag.
- Annotations (`flow_timing_day_level` bool, plus the in-process ints `flow_timing_day_level_days` and `flow_timing_timed_days`) in `NavTWRMeta` and `NAV_TWR_ANNOTATION_KEYS`, carried present-only in `_build_nav_meta`, NOT in `NAV_TWR_GUARD_KEYS`, never promoting `computation_status_hint`.
- The D-25 small-base accounting runs on a timed day over the smallest measured cohort base.

**`analytics-service/tests/test_nav_twr.py`**: 76 -> 114 tests (38 new, 2 reworked in place).

- **Found during:** Task 1 (threat model: "the core trusts their shape only after validation", T-164.6.6.2.3-01)
- **Issue:** the plan names the boundary but lists no validation. A malformed or inconsistent record would be measured silently.

Tested (`test_timed_record_must_reproduce_the_days_nav_change`, `test_timed_record_flows_must_be_ascending_integers`).
