> Per-phase validation contract for feedback sampling during execution. Seeded from
> `164.6.6.3.5-RESEARCH.md` `## Validation Architecture`. The real-Postgres SQL gate for the

| Property | Value |
|----------|-------|

| **Full suite command** | `npm run typecheck && npm run lint && npm test` |
| **Estimated runtime** | per-file seconds; full suite several minutes |

---

## Sampling Rate

- **After every task commit:** the task's own `npx vitest run <files>`, plus the canonical-domain gate once it exists.
- **After every plan wave:** `npm run typecheck && npm run lint && npm test`.
- **Before `/gsd-verify-work`:** full suite and `npm run lint` green; the SQL gate green AND shown RED once under a neutered index; post-deploy `curl -sI` measurements recorded.
- **Max feedback latency:** 60 seconds per task command.
