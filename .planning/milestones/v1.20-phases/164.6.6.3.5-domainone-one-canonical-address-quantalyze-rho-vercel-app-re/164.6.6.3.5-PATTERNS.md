**Tracked-file enumeration** (`listTrackedFiles`): no shell, NUL-delimited.
```typescript
export function listTrackedFiles(rootDir: string): string[] {
  const raw = execFileSync("git", ["ls-files", "-z"], {
    cwd: rootDir,
    maxBuffer: 1 << 28,
    encoding: "buffer",
  });
  return raw.toString("utf-8").split("\0").filter(Boolean);
}
```

**Core scan loop** (`runCheck`): injectable `files`, `latin1` byte-exact read (this is what makes the gate see the `mailto:` link annotation inside `public/security-packet.pdf` and a NUL-carrying `src/lib/wizardErrors.test.ts`, which `git grep` misses), unreadable files skipped and NOT counted, EMPTY-SCAN refusal.
```typescript
export function runCheck(rootDir: string, files: string[] = listTrackedFiles(rootDir) /* , ... */) {
  const violations: string[] = [];
  let filesScanned = 0;
  for (const rel of files) {
    let contents: string;
    try {
      // latin1 = byte-exact 1:1 decode. A NUL neither truncates the read nor
      // hides what follows it, which a grep-based gate cannot promise.
      contents = readFileSync(resolve(rootDir, rel), "latin1");
    } catch {
      // A tracked path that cannot be read (deleted in the working tree,
      // submodule gitlink) is skipped - and deliberately NOT counted as scanned
      continue;
    }
    filesScanned += 1;
    // ... push violations for this file
  }
  if (filesScanned === 0) {
    violations.push("EMPTY-SCAN: zero files were scanned. A gate that walks nothing reports OK forever ...");
  }
  return { violations, filesScanned };
}
```

**Self-match avoidance:** the gate and its test must name the literal. Build the needle from char codes like `HOME_PREFIX` does, so the script does not trip itself:
```typescript
const HOME_PREFIX = String.fromCharCode(47, 85, 115, 101, 114, 115, 47);
```
Here nothing secret is hidden, so a split-literal is enough, but the char-code form is the house idiom.

**Exclusions differ from the model (D-10):** `check-planning-hygiene` has NO path allowlist by construction; this gate MUST have exactly two founder-mandated path exclusions (`.planning/`, `CHANGELOG.md`) plus a **count-pinned named allowlist** (`file -> expected occurrences`). Copy the allowlist shape from `LINEAGE_ALLOWLIST` in `scripts/lint-app-guc.mjs` (`{ file, occurrences, reason }`, fails when the count moves in EITHER direction). Proposed members: `src/lib/analytics.test.ts`, `src/lib/analytics/usage-events.test.ts` (the `.not.toBe("quantalyze.com")` lineage assertions).

**Exit codes + main + CLI guard:** copy `main()` and the `entryPath` / `pathToFileURL` direct-invocation guard verbatim from `check-planning-hygiene.ts` (`if (entryPath !== undefined && entryPath.length > 0) { if (import.meta.url === pathToFileURL(entryPath).href || import.meta.url.endsWith(entryPath)) main(); }`). **Wiring:** `package.json` has `"check:planning-hygiene": "tsx scripts/check-planning-hygiene.ts"` and the `lint` script ends `&& tsx scripts/check-planning-hygiene.ts`. ## Shared Patterns

### Public-repo hygiene (applies to every file written, including this one)
**Source:** `scripts/check-planning-hygiene.ts` (rules 1-3, runs in `npm run lint`).
No home paths, no machine username, no PROD ids or secrets in tracked text. The LIVE-IMPACT record (D-09) carries domain parts only.

### Copy is pinned by tests that quote it verbatim
**Source:** CONTEXT "Established Patterns", RESEARCH Q2 pin table.
Every copy change moves its pins in the SAME commit. The pin map is in RESEARCH Q2 ("Which pins move with which change"). Prefer making pins derive from the exported constant rather than restating the string.

### One validator, status-mapped client strings
**Source:** UI-SPEC "Error rendering rule".
Route is the single Zod validator; clients pick form-level text by HTTP status and never render `err.message` or the raw server `error`.

### Never write a CI skip token
**Source:** project CLAUDE.md, "CI gate integrity". Not in a commit message or PR body, not even to deny it.

### Version and CHANGELOG
**Source:** project CLAUDE.md "CHANGELOG discipline". One unified entry in the `chore(release): vX.Y.Z.B` commit, `VERSION` and `package.json` byte-equal 4-digit strings; never `npm version`. Repo section vocabulary: `### Fixed / Added / Changed / Removed / Tests / Notes / Security / Root cause / Why`.

### `next dev` rewrites `AGENTS.md`
**Source:** RESEARCH "Project Constraints". Restore `AGENTS.md` from `HEAD` before any commit if an executor ran `next dev`; use `--webpack` in a worktree (Turbopack fails on the symlinked `node_modules`).
