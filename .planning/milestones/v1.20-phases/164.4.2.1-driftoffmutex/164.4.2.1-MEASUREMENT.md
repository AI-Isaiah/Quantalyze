## Which runs count

- **Admissible:** a `push` run of `ci.yml` on `main` that CONCLUDED, whose head SHA has THIS
  phase's merge commit as an ancestor. Paste, per run:
  `git merge-base --is-ancestor <164.4.2.1 merge sha> <run head sha> && echo AFTER-CONFIRMED`.
- **Bind each run to its SHA and COUNT that SHA's workflow runs** (an empty or short list is a
  finding, not a pass):
  `gh api "repos/AI-Isaiah/Quantalyze/actions/runs?head_sha=<sha>" -q '.workflow_runs | length'`.
- **Not admissible:** a `pull_request` run, a `workflow_dispatch` run, any run on the phase branch,
  or a re-attempt (`run_attempt` > 1) standing in for a first attempt.
- **Degenerate** = 164.4.2's rule: `python`'s acquire-wait NOT near its 0m05s floor means the run
  sat in a cross-run pile-up. **Plus a recorded "overlapped a sibling run?" column**: yes if the
  run's `run_started_at` falls inside another admissible run's `run_started_at` → `updated_at` span,
  or vice versa. This column exists because 164.4.2's Runs 2 and 4 passed the old rule while
  overlapping a sibling. The column is recorded for every run; the degenerate classification itself
  stays 164.4.2's rule, so the two phases are graded on the same criterion.
- **MIGRATION STRATUM.** A run whose SHA has a `supabase-migrate.yml` run (Step 4) is its own
  stratum: its ordering wait inherits `apply-test`'s own queue (research Pitfall 4), which no
  164.4.2 AFTER run measured. It is recorded in `### Migration-stratum runs` below and reported
  separately, never averaged in.
- ⛔ **A migration-stratum run does NOT count toward "the first 5 non-degenerate".** The five graded
  runs are all non-migration pushes. Stratum runs are recorded in their own table beside them, in
  addition to the five.
- **How many:** the first 5 admissible, non-degenerate, non-migration-stratum runs are graded, in
  order of `run_started_at`. EVERY degenerate run met on the way is recorded in full and marked,
  never dropped, and is compared against the full spread (16m18s–62m20s), not the non-degenerate
  band.
