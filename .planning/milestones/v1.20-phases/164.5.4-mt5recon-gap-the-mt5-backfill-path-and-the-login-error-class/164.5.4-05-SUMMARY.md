## Decisions Made

### The levels function's shape (A-01, executed as the plan bound it)

The plan's `<decision_a01>` was binding and was followed without re-litigation. `reconstruct_mt5_nav_levels` reproduces `reconstruct_nav_and_twr`'s own first four steps in its own order — `_flows_to_daily_usd` → `_union_flow_days` → `terminal_nav = anchor − upnl` → `reconstruct_nav` — and stops before `chain_linked_twr`.

`allocator_equity_derive.replay_key_equity` was NOT used, for the three measured reasons the plan recorded: it inverts the returns rather than reusing the roll they came from, it refuses non-finite returns (exactly the DQ-01 guard-broken days the guards exist to MARK), and it demands an ISO-day-string index where the combiner emits a `DatetimeIndex`.

### Two judgment calls inside the plan's Claude's-Discretion envelope

1. **`terminal_nav` is written as the subtraction, not as `account_balance`.** They are equal in real arithmetic but not necessarily bit-for-bit in IEEE floating point. Writing `account_equity - (account_equity - account_balance)` makes it the byte-identical expression `reconstruct_nav_and_twr` evaluates, which is what turns "levels and returns agree" from a tolerance claim into a construction fact. It also keeps the realized-basis derivation visible at the call site rather than hidden behind a variable name.
2. **The test tolerance band is imported by SYMBOL.** `_SELF_CHECK_ABS` / `_SELF_CHECK_REL` come from `services.allocator_equity_derive` rather than being restated as `1e-6` / `1e-9` literals, so a future tightening moves this gate with it. This was checked against the test file's own stated import discipline first: `services.allocator_equity_derive` pulls in **no** pandera and no `csv_validator` module (measured by importing it and inspecting `sys.modules`), so the file stays importable on a pandera-less local environment as its docstring promises.

### The MT5-12 completeness verdict on the levels path

The levels sibling stamps `series_completeness = "ledger_complete"` on the non-empty path and takes the `MT5-12 EXEMPT` un-stamped early return on the empty path — mirroring the returns combiner exactly, and for the identical recorded reasons. It does not form a second opinion: the meta is the returns path's own core call's meta, and `test_empty_ledger_yields_an_empty_level_series_never_a_flat_curve` asserts `nav_meta == returns_meta` rather than spot-checking keys.
