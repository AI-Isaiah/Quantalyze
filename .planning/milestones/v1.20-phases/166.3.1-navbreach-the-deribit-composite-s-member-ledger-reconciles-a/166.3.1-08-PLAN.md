**What the code does today (read at planning, 2026-10-13, cite by symbol).** The derive's key-mode
epilogue (`_run_key_mode_compose_epilogue` inside `run_derive_broker_dailies_job`) stamps
`_anchor_null_reason` on a NULL anchor in a fixed ladder: `native_unit`, `native_unpriced`,
`balance_error`, `nonfinite`, `nonpositive` (basis at or below 0), `dust` (basis at or below
`DUST_NAV_FLOOR`, an alias of `USD_FLOORS.dust_nav`), `flow_drop`. It still stores the key's
`realized_terminal_usd` / `realized_terminal_day` (Deribit through `native_ledger_realized_terminal`,
MT5 as the balance on the last NAV day) and, for Deribit, the writer basis. The compose job
(`run_derive_allocator_equity_job`) copies the NULL anchor and the token into `anchors_by_key` and
`null_anchor_reasons`. `compose_allocator_equity` puts a NULL-anchor key that HAS a return series
into `unanchored_return_keys` and raises `NO_ANCHOR` plus the blocking `DROPPED_KEY` for every token
except `native_unit` / `native_unpriced`. Only a NULL-anchor key with NO returns
(`null_anchor_without_returns`) is silently omitted when the token is `dust`. Precedent for the
recommended rule: the 164.6.6.2.1 T1 block in the same job loop, which composes a `native_unpriced`
key at its realized level on `priced_through`, sets `departed_end_by_key` to that day, and trims
later flows and dropped-day P&L, so the key leaves as an exit and the book stays trustworthy.
`replay_key_equity` already composes an emptied stretch as zero capital (DERIBITWEDGE D-01, D-09)
and accepts an in-band last-day anchor.
