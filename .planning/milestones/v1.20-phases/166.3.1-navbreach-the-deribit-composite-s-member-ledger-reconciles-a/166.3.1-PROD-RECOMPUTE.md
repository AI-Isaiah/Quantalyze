Counts only. The join is on date, restricted to dates strictly before run 1's finish date (2026-10-14),
inside each member's `strategy_keys` window; the comparison spans 257 days (every stored day, the
series ends in April 2026, long before the cut-off). A day "differs" when |run 1 - run 2| exceeds 1e-9.

| member window | common days | days differing | days in one run only | largest absolute difference |
|---|---|---|---|---|
| m1 | 51 | 0 | 0 | 0 |
| m2 | 63 | 0 | 0 | 0 |
| m3 | 143 | 64 | 0 | 5.5e-08 |

Over all 257 days no date is present in one run and missing from the other.

Shape of the 64 differing m3 days (counts and unitless magnitudes): 63 sit between 1e-9 and 1e-8,
1 between 1e-8 and 1e-7, none above 1e-7; the median difference is 2.3e-09. The stored values are
of order 0.3 to 1.7 with 15 significant digits, so the largest difference is a relative 3e-08 or
smaller. Before the fix the same count over the same kind of pair was 116 to 117 of m3's days with
single-day gaps of 1.4 to 3.4 percentage points (RESEARCH, "Measured on PROD"). So the
session-dependent gap of percentage-point size is gone (m1 and m2 are identical to the last digit, and
no m3 day moves by more than 5.5e-08), but the plan's pass condition, zero days above 1e-9, is not met.
Both sessions were quiet, so even a zero count would have read only `DETERMINISTIC-BOTH-QUIET`, weak
evidence. Whether the residue is floating-point or a sub-1e-7 anchor movement between sessions is
NOT determined by this plan; the threshold was written as an exact-equality test and the counts do
not tell which.

Verdict: NOT DETERMINISTIC

Founder decision (2026-10-15, AskUserQuestion "Accept, book the cause"): SC-3 is accepted at a stated
tolerance of |run 1 - run 2| <= 1e-7 absolute. Measured against it: the largest difference is 5.5e-08
on m3, 0 on m1 and m2, and 0 dates are present in one run only; before the fix the same comparison
read 1.4 to 3.4 percentage points on m3. The literal-threshold line above stays as measured.

Verdict (founder tolerance): DETERMINISTIC-WITHIN-1e-7-BOTH-QUIET

This is weak evidence: both sessions were quiet (`run 1 session quiet: true`, `run 2 session quiet:
true`), so neither session carried unbooked realized P&L to disturb the anchor. The residue is booked
as `166.3.1-M3-ANCHOR-OPTIONS-UPL-RESIDUE` in TODOS.md.

`done` on attempt 2 after a reclaimed first attempt), so the recompute half of SC-3 is met. The
