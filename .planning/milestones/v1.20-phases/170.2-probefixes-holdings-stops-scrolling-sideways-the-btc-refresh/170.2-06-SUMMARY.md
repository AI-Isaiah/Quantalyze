# Phase 170.2 Plan 06: Holdings tab overflow (SC-1) Summary

The Holdings tab no longer scrolls `#main-content` sideways at 390, 640 or 735 CSS px: its four grids now have a zero minimum track, so each wide table scrolls inside its own named `ResponsiveTable` region. The seeded wide-book case that proves it was RED on the old code at all three widths and is GREEN now, on the local lane.

## What changed

- **Four grids.** `HoldingsTabPanel`: `grid gap-8` became `grid grid-cols-1 gap-8` on the root, and `grid gap-4` became `grid grid-cols-1 gap-4` on the Exposure, Watchlist & Optimizer and Exchange Positions sections. Notes is untouched. No `overflow-x-hidden`, no px `max-w`. A comment names the cause (an implicit `auto` track sizes to the widest table's min-content).
- **Exposure drill-down (H-3).** `ExposureByClass` wraps its table in `<ResponsiveTable label="Exposure by venue and symbol">` inside `<div data-testid="drilldown" className="mt-4 min-w-0">`. The 12-row vertical cap (`max-h-64 overflow-y-auto`) rides on the region. The table, columns and cap are unchanged. `ExposureByClass.test.tsx` moved the cap assertions to the region with the dated comment `// 2026-10-09 Phase 170.2 H-3: the cap moved onto the ResponsiveTable region`; none loosened, and the 5-row negative still holds.
- **Seed.** `seedAllocatorBook` takes `wide?: boolean`. When set it adds 4 spot rows (8-digit `value_usd`) and 4 derivative rows (long and short, `entry_price`, `mark_price`, `unrealized_pnl_usd`), all with about 60-character single-token symbols, the same `asof`, `api_key_id`, `allocator_id`. Without the option the book is byte-identical.
- **Spec.** `"/allocations holdings — SC1-HOLDINGS"` in `e2e/layout-narrow.spec.ts`, `HAS_SEED_ENV`-gated, local viewport array V390 (390x844), V640 (640x400), V735 (735x450); shared `VIEWPORTS` not widened. Order per case: regions visible, precondition (each table >= 780 px at min-content), `assertNoReflow`, then per region right edge inside the viewport and `assertScrollsInside`, plus unique `aria-label`s across every `role="region"` in `[data-tab-panel="holdings"]`.
- **Class guard.** Five cases in `HoldingsTabPanel.test.tsx` (root, Exposure, Watchlist & Optimizer, Exchange Positions carry `grid-cols-1`; Notes has no `grid`).
