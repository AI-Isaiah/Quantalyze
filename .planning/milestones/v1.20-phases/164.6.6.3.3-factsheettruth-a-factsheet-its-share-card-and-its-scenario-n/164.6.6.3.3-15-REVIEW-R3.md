## Warnings

### WR-01 (MEDIUM, data truth, user-facing; missed by R2): the Monthly Returns heatmap's last month cell IS the dashed Month-to-date figure, and in January also the dashed Year-to-date figure

**Files:**
- `src/app/factsheet/[id]/v2/HeatmapPanels.tsx:150-165`. The month cell prints `formatPctShort(v)` as text and `formatPct(v, 2)` in its `title`.
- `src/app/factsheet/[id]/v2/MetricsColumn.tsx:414`. The Returns panel's `Month-to-date` row (`pctSigned(m.mtd, 2)`) reads "—" on a Withheld row because `withSuffixWindows` nulls `mtd` with the other six windows (`src/lib/factsheet/build-payload.ts:663-664`).

**Issue:** R3 dashed the last row's YTD cell because "the last row's YTD cell IS the Year-to-date figure, which the Returns panel dashes" (`HeatmapPanels.tsx:48-52`). The same identity holds for the last row's last month cell and the Month-to-date figure:

- `compute()` takes `mtd` as `returnFrom(last day of the previous month)`, over the current month's dates (`compute.ts:314-315`, `:350`).
- `monthlyReturnsMatrix` compounds or sums the same dates into `byMonth[lastMonth]`, using the same geometric or arithmetic switch.

I measured the identity on a 600-day synthetic series, `tsx` against the two library functions:
- geometric: `mtd -0.009504680641438057`, `cell -0.009504680641438057`
- arithmetic: `mtd -0.009032619969499923`, `cell -0.009032619969499923`

R2 called the month cells "per-period entries (class d)" and out of question. That missed this identity. The fix record carried it forward ("every month cell (per-period entries) stay").

The class-d label does not save it. Plan 15's SUMMARY lists class (d) as "EOY Returns years, Calmar by Year Return, Rolling Now, Worst 10 Depth". The last-year EOY row, the last-year Calmar row and Rolling Now were each dashed afterwards, on the rule that a per-period entry which IS a dashed window figure goes with it. This cell meets that rule. It is not among the founder's "Plan 15 residue" items (Worst 10 Drawdowns, break-year EOY/Calmar rows, Style Drift). In January the same cell also equals the dashed YTD, because the year has one month.

**Failure scenario:** A Withheld row whose record ends on 2026-10-21, at full history, any zoom:
- Returns › Month-to-date reads "—".
- Monthly Returns › 2026 › Oct prints "−1.0%" in the cell, tinted. Its tooltip and accessible name read "2026-10: −0.95%", the dashed figure at the same 2 dp the Returns panel would use.
- On a stale record the Returns label becomes "Final month (Oct 2026)" (`monthRowLabel`, `MetricsColumn.tsx:803-811`). That names the very cell.

This is printed unprompted on every Withheld row, every day. It is not a hover-only path.

**Test gap:** the R3 WR-03 test asserts `row.months` equals the clean render's months (`headline-coverage.test.tsx`, "the per-month cells are per-period entries and stay"). So it pins the leak as intended behaviour.

**Fix:** under `ytdWithheld`'s scope (`fullHistoryWithheld && r.year === lastYear`), render the month cell that holds the record's last date as "—":
- no tint, `background` set to the no-data surface;
- a `title` without a figure, for example `${year}-${mm}: withheld`.

Earlier months stay. Pass the last month index from `MonthlyReturnsHeatmap`, for example `lastMonthIdx = parseInt(view.dates.at(-1).slice(5, 7)) - 1`, next to `lastYear`. Then:
- Flip the `row.months` assertion so that only the last month index differs and reads "—".
- Add a clean-row premise: the last month cell's `title` figure equals the Returns panel's MTD to 2 dp.
- Add a Dated-row keeps-it case.

If the founder prefers to keep the cell, book it in `164.6.6.3.3-WITHHELD-RESIDUE` with that call. Do not leave the test asserting it as a per-period entry.

### WR-02 (MEDIUM, data truth, user-facing, transient): the rolling charts' avg gate reads the held/deferred range while the label is computed over the live range, so a zoom-out gesture prints the whole-record avg

**Files:**
- `src/app/factsheet/[id]/v2/FactsheetView.tsx:719-720`: `zoomed = useWindowedView(payload).scope.kind === "selected"`.
- `src/app/factsheet/[id]/v2/basis-context.tsx:697-698`. `useWindowedView` resolves its scope from `RangeGestureContext.held ?? useDeferredValue(xRange)`.
- `src/app/factsheet/[id]/v2/TimeSeriesChart.tsx:969-1003`. The avg is computed over the live `xStart..xEnd`. The chart "keeps following the live xRange" (`:118-123`).

**Issue:** while a gesture is held, `held` is the range the gesture STARTED on.

- **Zoomed to full, held:** a user starts zoomed and expands to the whole record by an x-gutter drag (`:462-474`, which clamps to `[0, n-1]`) or a wheel burst (`:621-649`). The chart now draws the full axis. `zoomed` stays true, so `railAvgWithheld` is false, and the label prints the whole-record average (`avg 1.87`). That is the figure the rail's Rolling Metrics › Avg dashes.
  - For an x-gutter drag, this lasts as long as the pointer is held, with no limit.
  - For a wheel burst, it lasts until `WHEEL_SETTLE_MS` (150 ms) after the last tick.
  - On a double-click or preset reset, the deferred value lags the live `xRange` by one render, so the label shows for that commit as well.
- **Full to zoomed:** the reverse over-dashes a slice average for the same window. That is harmless.

The rail does not show the figure meanwhile. It holds the start range's slice. So during the gesture the chart is the one surface printing the whole-record avg.

**Test gap:** the three WR-04 tests set the range through `setXRange` with no gesture hold and then flush, so `held` is null and the deferred value has settled. No test holds a gesture.

**Fix:** gate on the range the label is actually computed over, which is the shared live `xRange`. For example:

```tsx
const { xRange } = useXRange();
const zoomed = resolveRangeScope(xRange, payload.dates.length, view).kind === "selected";
```

`resolveRangeScope` is exported from `basis-context.tsx`. This drops the `useWindowedView` call from `PerformanceCharts`. Pin it with a test that calls `useRangeGesture().begin(zoomedRange)`, then sets the live `xRange` to full, and asserts there is no `avg` text on a Withheld row.
