## Names and call sites

- `recordCoversWindow(dates, cutoff)` is exported from `compute.ts`. `compute()`'s window path calls it: `const windowReturn = (cutoff: Date): number | null => recordCoversWindow(dates, cutoff) ? returnFrom(cutoff) : null;`. The rail calls `recordCoversWindow(view.dates, 182)` and `(view.dates, 365)`. The long D-11 / WR-02 / WR-R2-01 comment moved with the code, so no second calendar rule exists.
- `withSuffixWindows` runs after `overlayBasisScalars`. It fires only when `dataQuality.twrChainBroken === true` and `headlineCoversFrom` is a string; the slice starts at the first index whose date is `>=` it, `compute()` runs with the build's own `periodsPerYear`, `cumulativeMethod`, `dayBasis` and `calendarDense`, and only `mtd, ytd, p3m, p6m, p1y, p3y, p5y` are copied. A date at index 0 returns `metrics` unchanged; a date past the last observation nulls all seven. A Withheld row (no valid date) and a clean row are untouched; the MTM and smoothed bundles are untouched.

## Behaviour measured on the 12-day suffix (D-12)

Note: YTD is null too, because the suffix starts after 1 Jan; the plan text named only 3M and 6M but the same coverage rule applies, and the test pins it.
