### R3-WR-01 (heatmap last month cell): **closed**

**Where the gate sits:** `HeatmapPanels.tsx:56-58`, `:114`, `:159-175`.

`withheldMonthIdx` reaches only the row where `fullHistoryWithheld && r.year === lastYear`. That is the same scope as the YTD cell, so:
- earlier rows get `-1`;
- earlier month cells take the unchanged tint path;
- a Dated row or mark-to-market gets `-1`, because `useFullHistoryWithheld` is false there.

**Edge cases, each checked in the code:**
- **The record ends on the 1st of a month.** `lastMonthIdx` is that month. Its cell holds one day, which is exactly `mtd`, so the cell is dashed. Correct.
- **Stale record.** The index comes from the record's last date, not from today. The dashed cell is the one the "Final month (Mon YYYY)" label names (`monthRowLabel`, `MetricsColumn.tsx:803-811`). Correct.
- **January.** `lastMonthIdx = 0`. The Jan cell and the YTD cell are both dashed. Correct.
- **The last month's cell is null.** The `v == null` branch runs first and prints "·" with a "no data" title. No figure leaks.

**Tests:**
- The clean premise pins the identity: the cell's title figure equals the Returns panel's Month-to-date to 2 dp.
- The flipped assertion compares the earlier month cells and titles with the clean render.
- The Dated case asserts that every non-empty month cell is a figure and that no title reads `withheld`.

### R3-WR-02 (rolling avg gate on the live range): **closed**

**The gate:** `FactsheetView.tsx:724-726`.

`zoomed` now reads the same context `xRange` that `TimeSeriesChart` averages over, through the same `useBasisSeriesView` view (`TimeSeriesChart.tsx:75-76`). That gives the right result in every case:
- **Held zoom-out (wheel or x-gutter drag).** The live range is `[0, n-1]`, so the result is `full` and the labels are hidden, whatever `held` is.
- **Reset.** `resetXRange` sets `fullRange` eagerly. The gate and the chart re-render from the same value, so the one-commit lag that `useDeferredValue` used to cause is gone.
- **Real zoom.** The result is `selected`, so the labels print.
- **Gate and chart agree on "full".** Under cash, which is the only basis where the flag can be true, `resolveRangeScope`'s `fullEnd` and the chart's `maxIdx` are the same index.

**The fake-timer test cannot pass vacuously:**

- After `WHEEL_SETTLE_MS`, the trailing note disappears. That proves the live range actually reached the whole record. A no-op wheel would leave the note and fail that premise. A wheel that stopped short of full would keep the labels and fail the main assertion.
