<objective>
PR 2, migration (D-06, D-08, D-09, D-17). Switch the daily fan-out from "zero-snapshot books" to "every owed key", count attempts at the enqueue, cap them at 5 and leave a durable trace for a capped key.

Purpose: SC-2 (a key whose first sync collided never got a backfill when its book already had snapshots), SC-4 (a sibling's success hid a failed key behind the allocator-wide count) and the SQL half of SC-7 (a failed_final reconstruct on a zero-snapshot book was never retried once a refresh row existed). All three are the zero-snapshot term this plan deletes.
Output: migration M2, its rollback, and a new SQL gate for the owed-key arm. The old fan-out gate's rewrite and the census move are plan 07; the worker side is plan 05.
</objective>
