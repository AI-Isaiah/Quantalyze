<objective>
The D-12 census, before PR 2 merges. Count, read-only, how many PROD keys PR 2's fan-out would start reconstructing, and how many of those reconstructs would replace a sole-key allocator's live-written rows; bring the counts to the founder.

Purpose: `retention_compute_jobs_done` reaps `done` jobs at 30 days, so even after the audit-log evidence (D-12) some old keys may stay owed, and for a sole key `replace_allocator_equity_snapshots` replaces refresh-written rows with replayed ones. The founder decided (D-12) to see this number before the merge, not after.
Output: counts in this plan's SUMMARY and the founder's decision line. No tracked file changes.

Re-run rule (revision 1, INFO): plan 09's review round runs after this census. If any review fix changes M2's owed predicate, its qualifying filters, `v_reconstruct_attempt_cap`, `v_bootstrap_cap` or the backfill evidence rule, plan 09 Task 1 re-runs Task 1 here and restates the counts to the founder, who records a fresh `census-decision:` line, before plan 09 Task 2 runs.
</objective>
