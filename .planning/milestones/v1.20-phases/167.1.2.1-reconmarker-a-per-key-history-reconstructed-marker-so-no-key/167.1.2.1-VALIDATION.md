## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (pytest slice, narrowed mutation run, or one vitest file).
- **After every `job_worker.py` edit:** the C8 source-scan censuses and `make typecheck` (plan 05 Task 3).
- **After every plan wave:** full pytest; for waves that touch SQL, the local lane `up` (replays every migration, so a stale gate goes red here).
- **Before each ship (plans 03, 09):** the three migration reviewers, every plan verify re-run on the fixed tree, then the two release contracts.
- **Max feedback latency:** 60 s for pytest and vitest; SQL arms are bounded by the lane.
