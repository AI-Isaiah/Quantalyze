Measured by the planner (cite by symbol):
- `holdingEquityContribution(h)`: derivative -> `h.unrealized_pnl_usd ?? 0`, then `Number.isFinite(pnl) ? pnl : 0`;
  anything else -> `Number.isFinite(h.value_usd) ? h.value_usd : 0`. `holdingEquityContributionLocal` has the
  same body (a client-side copy kept in lockstep because `@/lib/queries` is server-only).
- `getMyAllocationDashboard.scenario.test.ts` already imports `holdingEquityContribution` from
  `../queries` after `vi.mock("server-only", () => ({}))`. Copy that seam.
- `Number.isFinite` is false for null, a string, a bool, NaN and +/-Infinity. The Python mirror therefore
  counts only an int or float that is not a bool and is finite; anything else is 0.0, EXCEPT a derivative's
  `unrealized_pnl_usd` that is None, which returns None (D-18).
- JSON cannot carry NaN/Infinity, so the fixture encodes them as `{"nonfinite": "NaN" | "Infinity" | "-Infinity"}`,
  decoded identically by both runners.
