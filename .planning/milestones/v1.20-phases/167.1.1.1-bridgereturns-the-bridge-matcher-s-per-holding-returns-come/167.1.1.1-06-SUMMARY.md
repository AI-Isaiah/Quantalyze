# Phase 167.1.1.1 Plan 06: Signed derivative rule in both runtimes Summary

**A derivative's return is now the mark-price return negated for a short, with a per-day direction read from `side` only, an option withheld as `option_premium`, a -100% floor, and a NAV kernel for the metrics, all replayed by pytest and vitest from one hand-typed fixture.**

## Accomplishments

- Python `holding_marks.py`: `daily_directed_marks` (contract check adds `side in {long, short, flat}` with a `bad_sides` count; direction from ALL rows of a day including gap-mark rows and every key), `signed_adjacent_returns` (interval carries the earlier day's direction, floored at `SIGNED_RETURN_FLOOR`), `is_option_symbol` (via `classify_instrument`), `classify_derivative_marks` (ladder option_premium, contract, no_price, no_direction, too_few_priced_days on USABLE days) and `classify_holding_marks` (dispatch; `ValueError` on any other type). The spot per-day pick moved into one shared helper; `daily_mark_prices` behaviour is unchanged.
- TypeScript adapter: the same functions plus `analyzeSignedReturns` (NAV from 1, cumulative = NAV_last - 1, max drawdown over the running peak starting at NAV 1, null cumulative and drawdown on an empty list, vol and Sharpe exactly as the spot kernel). `HoldingMarkContractError` gained `badSides`, `PriceRow` an optional `side`.
- The fixture's top-level `withheld_reasons` and both constants were widened in the same task (six strings), so plan 01's set assertions stayed green between tasks.
- Fixture: 19 new derivative cases (worked examples long/short, flip day, flat day x2, mixed sides, gap-mark vote, two keys, all flat, all non-positive, put/lowercase/linear options, perp and linear perp not options, 150% short spike, 29 and 30 usable days, empty signed returns, bad side, null side). Every expected number was typed by hand; the Python run agreed with them on the first run.
- Independent invariants in both runtimes: short = minus long on the same prices, a direction-less day neither signs nor receives a return, the floor holds, the option classifier; TS also: long-only gap-free equals `analyzePriceSeries` (cumulative, drawdown, vol), NAV never below zero, empty list gives nulls.
