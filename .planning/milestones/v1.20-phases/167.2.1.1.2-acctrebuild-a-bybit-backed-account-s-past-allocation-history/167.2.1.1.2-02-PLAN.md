reader: the dashboard payload carries it, parsed defensively, so any chart or return can name the seam.

curve would describe a jump the drawn curve does not have. The record, the parser and the payload field ship; the
note does not.

Purpose: SC-2 ("the 90-day boundary is stated"): the boundary is stored by plan 01 and readable here.

`src/lib/queries.my-allocation.test.ts`.
