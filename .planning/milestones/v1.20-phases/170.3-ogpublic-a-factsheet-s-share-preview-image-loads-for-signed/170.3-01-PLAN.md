opening the route leaks nothing about a strategy that is not published.

because the proxy's session gate runs before the route handler and no `PUBLIC_ROUTES` entry covers it.
Slack, LinkedIn and X fetch the card without cookies, so no share ever shows a preview. Found by the
2026-10-03 PROD browser pass.

proxy half), and a route test proving an unpublished id renders the generic card (D-02, D-03, route half).
</objective>

before editing (a premise is a claim, not a fact):
- `PUBLIC_ROUTES` in `src/proxy.ts` has no entry covering `/api/og` (it lists `/api/factsheet`, which
  does not cover `/api/og/...`).
- The route reads `strategies` through `withPublishedOnly(...)` with `.eq("id", id)` and
  `.maybeSingle()`, and renders `name ?? codename ?? "Strategy"` on a null row.
- RLS (`supabase/schema/baseline.sql`, `CREATE POLICY "strategies_read"`, `"strategies_org_read"`
  and `"analytics_read"`; SELECT policies combine with OR): `strategies_read` lets ANYONE read a
  `status = 'published'` row, org-scoped or not, and an owner read their own rows. `strategies_org_read`
  additionally lets an org MEMBER read every row of that org, unpublished included. `analytics_read`
  follows the parent strategy for published and owned rows. So a signed-out read of a published row
  returns the row and its analytics embed, and of anything else returns nothing. A signed-in owner or
  org member CAN read unpublished rows through RLS, which is why the route's `withPublishedOnly`
  predicate is load-bearing: it makes the card identical for every caller and keeps an unpublished
  row out of a publicly cached image.
- API routes never take the signed-in bounce (`isApiRoute` excludes them), so no bounce exemption is
  needed for this path.
- `src/lib/routing/route-contract-manifest.ts` governs PAGE routes; API routes are governed by
  `PUBLIC_ROUTES` plus `src/proxy.test.ts` (its `/api/health` entry says so). No manifest entry is
  added; `npm run check:route-contract` must still exit 0.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet (no cookie) -> proxy | crawlers and signed-out visitors now reach `/api/og/factsheet/*` without a session |
| route handler -> Supabase (anon key, cookie-scoped client) | the route's read runs with whatever session the request carries, none for an unfurler |
| route response -> CDN and unfurl caches | the card is cached publicly (`s-maxage=86400`, `stale-while-revalidate=604800`) and copied by Slack, LinkedIn and X |
