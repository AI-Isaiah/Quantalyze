## Non-blocking observations (not threats of this phase, no action required to ship)

- `seed-portfolio-benchmark-local.ts` checks `--out` lexically (`path.resolve`, no `realpath`), so a symlink outside the repo that points into it would pass. Local developer tool, credentials are lane-only loopback ones, `.stack-env` and the handoff are never tracked. Informational at ASVS L1.
- The compute endpoint's inline response spreads `**result`, which includes `data_quality.benchmark_error`. That is pre-existing, service-to-service, and `computePortfolioAnalytics` has zero call sites (`analytics-client.ts:941`). The UI path reads the stored row and never selects `data_quality`. If a caller is ever added, it must not forward that field to a browser.
- Playwright `reuseExistingServer: true` is unchanged by design; T-10 depends on the lane-only credentials, and the spec documents that.
