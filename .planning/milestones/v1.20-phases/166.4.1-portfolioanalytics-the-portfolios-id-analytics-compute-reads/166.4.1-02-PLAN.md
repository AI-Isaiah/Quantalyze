<objective>
Carry the stored benchmark note from the `portfolio_analytics` row to the screen: one optional type field, one conditional parse, one rendered status line, each pinned by a test that fails without it.

Purpose: Plan 01 makes the compute write a named note (D-04, D-05) on a flagged-empty `benchmark_comparison`. Nothing on `/portfolios/[id]` reads `data_quality` (RESEARCH Pitfall 6), so the comparison object is the carrier; without this plan the note is persisted and invisible.

Output: `note?: string` on `BenchmarkComparison` in `src/lib/types.ts`; `parseBenchmarkComparison` emitting `note` only when the stored value is a string; `BenchmarkComparison.tsx` rendering it; a new component test file and one new adapter case.

Contract shared with Plan 01 (it runs in parallel; these strings are fixed by D-04 and the founder wording and must match byte for byte): the stored note is one of `benchmark unavailable: stale`, `benchmark unavailable: fewer than 30 shared days`, `benchmark unavailable: computation failed`; on the stale path the stored `stale` is `true`, on the other two `false`; a full comparison has no `note` key.

Tracer note: the phase tracer is 166.4.1-01 Task 1. This plan's Task 1 is itself a thin vertical slice of the render surface (stored JSON -> adapter -> component -> DOM) proven by one component test.
</objective>
