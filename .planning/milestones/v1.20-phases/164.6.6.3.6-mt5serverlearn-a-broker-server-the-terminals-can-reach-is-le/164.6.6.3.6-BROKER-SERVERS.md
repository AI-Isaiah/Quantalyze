## Caveats

- **Numbered servers.** Many brokers assign a numbered server per account: Exness `MT5RealN`, XM `MT5 N`, Vantage `Live N`, HFM `LiveN`, IC Markets `MT5-N`, FTMO `ServerN`, FundedNext `Server N`. The exact string is only in the welcome email or client portal. My lists are observed values, not the full set. Prefer a free-text server field over a fixed allow-list.
- **Spacing and case matter.** Vantage, XM, FundedNext and FxPro use a space before the number (`XMGlobal-MT5 2`). HFM and Exness do not. OANDA uses an underscore (`OANDA_UK-Live-1`). IG is all caps (`IG-LIVE`). Dukascopy is lowercase (`Dukascopy-live-mt5-1`).
- **Entity prefix changes with the regulator.** Exness, XM, Vantage, Pepperstone, IC Markets, Tickmill and OANDA each use a different server prefix per legal entity (SC, EU, UK, AU, MU). The same broker brand can therefore have unrelated server names, and a user's entity decides which applies.
- **Pepperstone is unusual.** Its own FAQ tells users to type a hostname such as `MT5-2.pepperstone.com`, not pick from the dropdown. The `Pepperstone-*` strings from the directory may differ from what MT5 shows.
- **Prop-firm servers.** The firm names the server, but the real broker often sits behind it, as with FTMO US on OANDA. Several prop firms (The5ers, E8) have thin or ambiguous directory entries. The5ers' `FivePercentOnline-Experience` looks like an evaluation server, not a plain demo.
- **Coverage gaps.** ThinkMarkets, Darwinex, ISPrime and X Open Hub are absent from both directories. FXCM and Axi appear only with MT4 strings, and Saxo has no MT5 offering I could find. Global Prime appears only under the Vantage entities, and Match-Prime only as `MatchSecurities-Live`.
- **Directory freshness.** The directory is a VPS vendor's compilation and can include retired servers. Entity-to-brand mapping (Moneta, Match-Prime, E8) is inferred from entity names and is uncertain.
- **Not independently re-verified.** Search-snippet claims I could not check are noted inline, for example `FPMarkets-Live`, `EightcapSC-Live`, and the `XMGlobal-MT5Live1` style that appeared in one XM guide.
- **Where to confirm.** To confirm any string, run `curl` against the directory page for the entity slug, or ask the user to paste the server from their welcome email.
