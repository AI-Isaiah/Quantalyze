## Decisions Made

- The ddof at each site was read from the code before editing. compute, bootstrap and the OG card are all population (divide by n), and each now calls with `ddof: 0`.
- Each site maps null to the value it gave an exact constant before: 0 in compute and bootstrap, NaN in the OG card. A NaN input still gives 0 in compute and bootstrap (old `s` was NaN, so `s > 0` was false). In the OG card, non-finite rows are filtered out before the Sharpe, as before.
