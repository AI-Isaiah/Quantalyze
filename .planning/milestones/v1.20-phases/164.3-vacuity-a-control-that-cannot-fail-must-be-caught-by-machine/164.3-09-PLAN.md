<objective>
Make a plan's claims about the tree verified, not trusted (VAC-05, D-06): a resolver that re-resolves every `file:line` anchor and named-symbol claim in a PLAN.md and fails loud on a miss — mechanizing exactly what caught both stale wave-3 plans in Phase 164 (a two-argument signature that no longer existed, and edits anchored at lines 563-573 of a file that had shrunk to 423 lines). Kept in this phase because the root cause is the same — the claim and the thing are never compared — and kept as its OWN wave so it can be lifted out if it bloats (D-06).

The gsd-core hook seam was measured EMPTY and gsd-core is out of scope, so this lives in this repo with two seams: a CI step over pending plans (machine, every push) and a plan-task convention (each future PLAN's first task invokes it — enforced socially by this phase's own plans and checked by the CI step; state this limitation honestly, do not pretend it is mechanical for future phases).

</objective>
