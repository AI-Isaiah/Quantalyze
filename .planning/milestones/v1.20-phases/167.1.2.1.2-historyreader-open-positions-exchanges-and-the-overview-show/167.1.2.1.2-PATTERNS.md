**Guard helper to reuse** (lines 144-154). Note the one comparison is written with `!==`, which the census regex does not match (see Pitfall in Shared Patterns):
```typescript
export function cleanPollDay(metadata: unknown): string | null {
  if (metadata === null || typeof metadata !== "object") return null;
  const m = metadata as Record<string, unknown>;
  if (m.final_status !== "complete") return null;
  const rowCount = m.row_count;
  if (typeof rowCount !== "number" || !Number.isInteger(rowCount) || rowCount < 0) {
    return null;
  }
  const asof = m.asof;
  return typeof asof === "string" && ISO_DAY.test(asof) ? asof : null;
}
```

**New exported pure helper** (place directly after `cleanPollDay`; mirrors the SQL `empty_day`). Do not write the exact-equality form of the `complete` literal anywhere in a comment or code:
```typescript
export function cleanEmptyPollDay(metadata: unknown): string | null {
  const day = cleanPollDay(metadata);
  if (day === null) return null;
  return (metadata as Record<string, unknown>).row_count === 0 ? day : null;
}
```

**The two reads already in place** (lines 358-382): `pollRes` (newest CLEAN, filter `metadata->>final_status = 'complete'`) and `newestPollRes` (newest of ANY outcome, `partialPollDay` at line 401). D-02 derives from `newestPollRes` only:
