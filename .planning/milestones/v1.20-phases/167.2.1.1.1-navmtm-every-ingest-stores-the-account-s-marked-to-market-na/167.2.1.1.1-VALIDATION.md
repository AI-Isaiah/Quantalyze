## Sampling Rate

- **After every task commit:** the quick run command plus the task's own `<automated>` verify (every task has one).
- **After every plan wave:** the full analytics suite, the mypy line, Vitest for touched TS, the SQL lane for touched `supabase/tests`.
- **Before `/gsd-verify-work`:** all of the above green, the mutation runner, `lint-sql-gates --self-test`, the GDPR hook and `npm run schema:functions:check`.
- **Max feedback latency:** 60 seconds per task verify (the plan 01 and 02 lane runs are the declared exceptions: they boot a database).
