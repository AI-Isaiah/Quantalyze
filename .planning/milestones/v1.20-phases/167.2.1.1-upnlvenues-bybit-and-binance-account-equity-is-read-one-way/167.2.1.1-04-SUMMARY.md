# Phase 167.2.1.1 Plan 04: force_rebuild flag for the reconstruct Summary

**A strict `force_rebuild: true` job-metadata flag lets the product's own enqueue path re-run `reconstruct_allocator_history` for an already-marked key (no migration, no hand SQL), with the default byte-identical, and pins who can set it and its one limit (multi-key allocators).**
