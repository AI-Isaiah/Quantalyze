# Phase 167.2.1.1 Plan 05: forced reconstruct is anchored or nothing Summary

**A forced reconstruct (job metadata `force_rebuild: true`) now writes a curve only when it is anchored to today's venue equity including the open-position uPnL; an unreadable positions read, an unreadable balance or any existing anchor skip fails the job `permanent` with a static named reason and leaves the stored curve, the marker and the completion audits untouched. The unforced path is unchanged in behaviour and in call shape.**

- `run_reconstruct_allocator_history_job`: the crawl is built with `require_anchor=True` only when `forced`; a dedicated `except ForcedRebuildRefusedError` arm (before the generic ones) logs one WARNING with the reason only, emits `allocator.equity.reconstruct_failed` with `{error_kind: permanent, sanitized_message: <static text>}` and returns FAILED/permanent. Every FAILED return in that try precedes the persist half and the marker writer, so nothing is written.
