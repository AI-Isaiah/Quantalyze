**Module conventions to match** (`limiter_stub.py:49-53`): `from __future__ import annotations`, `import sys`, `from types import ModuleType`, `from typing import Any, Callable`. Docstrings are long and explain WHY, with a dated measured failure (see the `evict_module` docstring: "48 failures, none of them at the line that looked wrong"). The new helper's docstring should carry the same kind of measured line: the RED pair command from RESEARCH.md Flake 2.

**Skeleton to adopt** (RESEARCH.md Flake 2, helper design is the planner's call; keep `_ABSENT` sentinel, restore both `sys.modules[name]` and the package attribute):
```python
_ABSENT = object()

@contextlib.contextmanager
def evicted(name: str):
    package_name, _, attribute = name.rpartition(".")
    package = sys.modules.get(package_name)
    prior_module = sys.modules.get(name, _ABSENT)
    prior_attr = getattr(package, attribute, _ABSENT) if package is not None else _ABSENT
    evict_module(name)
    try:
        yield
    finally:
        ...restore exactly...
```
Note `monkeypatch.delitem(sys.modules, name, raising=False)` is NOT a drop-in (records nothing when the key is absent). The existing fixtures use `monkeypatch.setitem(sys.modules, "slowapi", ...)` for slowapi stubs (restored by monkeypatch); only `routers.*` eviction is unrestored.

**Also keep:** `patch_shared_limiter(monkeypatch)` (lines 111-120) is the model for a function-scoped, auto-reverting helper ("Function-scoped by construction"). A fixture-style variant that takes `monkeypatch` is an acceptable alternative shape.
