- **HoldingRow / OpenPositionRow**: optional `key_label`; both tables render it as `text-caption text-text-muted` under the symbol (`data-testid="holding-key-label"`). No new token.
- **Matrix** (`AllocationsTabs.connect-key-predicate.test.tsx`): payload P (empty holdings, empty optimizer portfolios, `equityHistoryState: "rebuilding"` / `awaiting_derivation`, `apiKeysCount: 1`, one key row). Per tab (`overview`, `holdings`, `risk`, `scenario`): Arm A has no "Connect Exchange" link and no text starting "Connect a read-only exchange API key"; Arm B has the link.
