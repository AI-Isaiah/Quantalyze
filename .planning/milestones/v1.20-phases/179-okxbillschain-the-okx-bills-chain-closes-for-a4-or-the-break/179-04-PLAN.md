## The close rule, decided here once (D-06, with the planner's fail-closed reading of "the bill's own decimal places")

Every refinement below only TIGHTENS the founder's wording; none accepts a residual the literal wording would refuse.

1. Exact Decimal equality of the newest bill's `bal` and today's cash passes (today's behaviour, kept).
2. Precision arm. `places` is the most decimal places any `bal` of that currency's WALKED bills prints, each counted
   as `max(0, -exponent)` of the Decimal the oracle already parsed (`_decimal`). So trailing zeros count
   (`100.5000` is 4 places), exponent notation counts its true places (`1.5E-7` is 8), and a non-negative exponent
   counts 0 (`100` and `1E+2` are 0). The chain's most, not the newest bill's alone: when OKX prints at a fixed
   precision the two are equal, and when one print dropped its trailing zeros the chain's places keep the bound
   tight instead of widening it. The arm passes when `places >= 1` and `abs(newest_bal - cash)` is at most half a
   unit in the `places`-th decimal (`Decimal(5).scaleb(-(places + 1))`), inclusive at the tie, so a cash balance
   that rounds to the bill's printed value passes under either tie rule. A currency whose bills print no decimal
   place gets NO precision allowance: an integer print cannot be told apart from an exact balance whose zeros were
   dropped, and the existing diagnostic worlds already treat "1" against "0.9" BTC as a broken close.
3. Relative arm. Passes when `abs(newest_bal - cash) <= CLOSE_RESIDUAL_REL_BOUND * max(abs(newest_bal), abs(cash))`,
   with `CLOSE_RESIDUAL_REL_BOUND = Decimal("1e-12")`, inclusive, computed by multiplication (never a division). The
   denominator is the one `analyse_chain` uses for `max_close_residual_rel`, so a4's `lt_1e-12` reading (strictly
   below 1e-12 on that denominator) passes this arm.
4. cashBal's own places never govern (D-06 names the bill's). When cashBal is the coarser print, only the relative
   arm can pass it.
5. The interior arm (`bal` against the previous `bal` plus `balChg`) stays EXACT. No allowance of any kind there.
6. The allowance decides only whether the chain is proven. The opening is still the oldest bill's `bal - balChg`;
   the cash value never enters it.
