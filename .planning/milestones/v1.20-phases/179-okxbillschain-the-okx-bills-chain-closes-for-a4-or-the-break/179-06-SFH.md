# Phase 179 plan 06 silent-failure hunt

No finding at MEDIUM or above. LOW and INFO are omitted by instruction.

## What was checked and how

1. **Consumers of the tolerance.** The only production reader of `OPENING_TOLERANCE_REL` is the body of
   `opening_agrees` (unchanged). Its only caller is `_okx_forced_opening_check` in
   `services/equity_reconstruction.py`, which returns `agreed` or `disagreed` with both residual ratios, and the
   forced path refuses `anchor_skipped_implausible` on anything but `agreed`. A tighter tolerance can only turn an
   `agreed` into a `disagreed`: a refusal, never a fallback. The refusal is not swallowed: the job ends FAILED, the
   `reconstruct_failed` audit carries `anchor_opening_check` and the residual ratio, and a WARNING line is logged.
   The unforced and non-OKX paths return `not-run` before the tolerance is read.
2. **Probe.** `scripts/allocator_history_probe.py` `_measure_anchor` does not decide agreement ("Agreement is NOT
   decided here"); it prints `opening_residual_over_anchor` as a ratio. `_read_member` takes
   `anchor_opening_agreed` from the rebuild's own telemetry. Nothing in the probe hardcodes 0.05 or recomputes
   the tolerance, so its telemetry cannot go stale or misleading with the change.
3. **Vacuity of the new tests (mutation, no source edited).** A throwaway pytest plugin in the scratchpad set
   `obal.OPENING_TOLERANCE_REL` at import time:
   - At the old 0.05: 8 of the new tests go RED (both forced-path refusals at +/-3%, all six unit cases at
     2.1%, 3% and 4.9% on both sides). The a4 agreement tests stay green, as they should.
   - At 0.013 (below a4's -0.0136): both a4 tests go RED (the unit case and the forced-path case).
   So the tests can fail in both directions the module docstring claims. `opening_agrees` reads the module global
   at call time, so the patch is a faithful mutation.
4. **Expected values are test constants.** The forced-path expectations (-0.03, +0.03, -0.0136, `totalEq` 70000)
   are literals derived from fixture constants, not recomputed by the module under test. The forced-path
   tests assert the refusal token (`disagreed`), so a different refusal reason (chain_break and so on) cannot
   satisfy them vacuously, and the a4 forced test asserts both the `agreed` verdict and the anchored last row.
5. **Helper imports.** The new file imports only underscore-prefixed helpers and `_TOTAL_EQ` from
   `tests/test_okx_anchor_rule.py`. Pytest does not collect them as duplicate tests, and a change to the helper
   fixture constants would fail the literal expectations loudly rather than silently change semantics.
6. **Suite.** `cd analytics-service && python3 -m pytest tests -k "okx or opening or anchor or allocator_history_probe or reconstruct"`:
   2418 passed, 2 skipped. The four touched or new test files: 111 passed.
