# Phase 170.5 Plan 05: Panel 7 series ladders Summary

Net and gross exposure, Turnover and Correlation with BTC each draw a valid series or name one cause: exposure carries a dated "through {date}" caption, turnover is gated on the `{date, value}` contract (legacy `{date, turnover}` rows are never charted), and the rolling correlation names the 90/91-day cause through an optional resolver context rendered in the v2 caption token.

**Task 3, commit `df956c4a9`.** `CorrelationResolverInput` gains optional `context`. With it, an absent key (after the `computing` check) and a well-formed series of fewer than 2 points return `rollingCorrelationWhy`; without it every branch is byte-for-byte today's (`CorrelationWithBenchmark.test.tsx` untouched and green).
