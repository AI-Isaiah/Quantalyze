# Phase 167.1.2.2.2.1 Plan 21: billId export-wrap strip and the non-digit id shape Summary

**`parse_archive_csv` strips the whitespace, apostrophes and double quotes the export wraps around each `billId` before any check, so the real files chain and calibrate DONE as the bare files do; an id still not ASCII digits stops `unchainable_row` as before and now names its value-free shape (`9-Po-9{2}-A-Sm-9{2}` for `1.23E+17`) and length, never the id.**

## Accomplishments

- `_strip_bill_id` (`okx_archive_files.py`) repeats `str.strip()` and a strip of the two quote characters until the value stops changing. `parse_archive_csv` applies it to the `billId` cell right after the row dict is built and records `tuple(row.values())` as the de-duplication tuple, so `missing_bill_id`, the within-file de-dup and conflict, the cross-file de-dup, the D-16 tally and the chain order all read the stripped id. No other cell is stripped and the inside of an id is untouched.
- A wrapped file calibrates DONE through `dispatch()` with the bare file's `fingerprint`, `census`, `reconcile`, `excluded`, `d03`, `strategies`, `info` and per-quarter content readings (four wraps on a Q3 file, and a Q2 + Q3 pair with every id wrapped).
- `_bill_id_shape` and `NONDIGIT_SHAPE_RE` (`okx_archive_classify.py`): digit `9`, ASCII letter `A`, `TAB` / `SP` / `DQ` / `SQ`, any other character its Unicode category, runs `<symbol>{n}`, joined by `-`, at most 8 runs then `-MORE`. `verify_bal_chain` records the first non-digit id's shape and length in file order then row order, skipping a bill seen in an earlier file.
- The job renders ` first_nondigit_shape=<shape> first_nondigit_len=<n>` after `last_day=` and before `rows_by_quarter=` (`none` when no bill stopped for its id, `unreadable` for a missing key or a value outside the grammar or not a count), and carries both in `info.bal_chain`.
- Runbook Step 2's `info.bal_chain` bullet names the strip, `missing_bill_id` for a wrap-only id, the two tokens, the grammar and the scientific-notation example.
