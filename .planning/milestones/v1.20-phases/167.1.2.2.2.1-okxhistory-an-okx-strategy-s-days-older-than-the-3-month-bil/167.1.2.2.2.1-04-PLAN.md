**Interface this plan exports (plan 08 imports exactly these names).** It takes plain dicts so it does not import plan 02's modules (same wave).
- `days_to_ranges(days: Iterable[str]) -> list[dict[str, str]]`: inclusive `{from, to}` islands sorted by `from`.
- `subtract_ranges(gaps: Sequence[Mapping[str, str]], days_with_rows: AbstractSet[str]) -> list[dict[str, str]]`: the gap days not in the set, as islands.
- `class RebuildRefused(Exception)` with `stop_class` (`live_anchor_unusable`, `identity_violation`).
- `rebuild_union(*, live_realized: list[dict], live_funding: Sequence[Mapping], live_flows: Sequence[ExternalFlow], equity: float | None, balance_error: bool, open_unrealized_usd: float, full_history: bool, archive_realized_by_day: Mapping[str, Decimal], archive_funding_by_day: Mapping[str, Decimal], archive_flows_by_day: Mapping[str, Decimal], covered_days: AbstractSet[str], from_day: str) -> RebuildResult`.
  `RebuildResult` (frozen dataclass): `returns: pd.Series` (union), `live_first_day: str`, `first_live_day_differs: bool`, `archive_days_prepended: int`.
  `full_history` is the value the caller computed exactly as the derive does (`_ccxt_full_history_verdict` on the live inputs); both calls receive the same keyword arguments the derive passes at its `combine_realized_and_funding` call site in `run_derive_broker_dailies_job`.
- `rows_for_strategy(result: RebuildResult, gaps: Sequence[Mapping[str, str]], existing_days: AbstractSet[str], covered_days: AbstractSet[str]) -> tuple[list[dict], list[dict[str, str]]]`: rows `[{date, daily_return}]` for days in covered ∩ gap, finite, not in `existing_days`, strictly before `live_first_day`; and the expected narrowed gaps `subtract_ranges(gaps, inserted ∪ (existing ∩ gap days))`.

**Archive days prepended:** only days in `[from_day, live_first_day)` where `from_day` is the earliest start among the target strategies' stored gaps (days before it cannot change a gap day under a backward roll, and adding them only risks a guard tripping on old history). Realized and funding records use the shapes the core already consumes (`fetch_daily_pnl` record dict; `funding_rows_to_daily_pnl_records` input rows); a covered quiet day gets one explicit zero-P&L realized record (RESEARCH Pattern 3). Archive flows become `ExternalFlow(day, float(usd), currency="USD", quantity=None)` for days in the same interval. `live_first_day` is the first day of the LIVE-ONLY core's index (it already includes live flow days), so live flows are never dated before it and no flow is counted twice.
</context>
