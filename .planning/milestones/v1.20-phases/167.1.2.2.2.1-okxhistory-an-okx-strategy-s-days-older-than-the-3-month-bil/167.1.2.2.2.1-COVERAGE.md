# Phase 167.1.2.2.2.1 OKXHISTORY — OKX REST API coverage

Planned 2026-10-15. Capability rows for the OKX v5 endpoints this phase touches, and opt-outs for the rest of OKX's surface. Source: RESEARCH.md Sections 3, 5, 7 (OKX docs fetched 2026-10-15) and PATTERNS.md section 6.

## INTEGRATE

| Endpoint | Method | ccxt 4.5.85 implicit method | Used by | Plan | Notes |
|---|---|---|---|---|---|
| `/api/v5/account/bills-history-archive` | POST | `private_post_account_bills_history_archive` | apply for a quarter's archive (idempotent; `result: true` = exists) | 07, 16 | ccxt cost 72000: the LAST call on its own fresh instance; one attempt; a venue 429 defers, never stamps the key |
| `/api/v5/account/bills-history-archive` | GET | `private_get_account_bills_history_archive` | request state (`finished`/`ongoing`/`failed`), `ts`, `fileHref` | 07, 16 | via `_okx_bills_fetch_with_backoff`; the link is never stored or logged |

## OPT-OUT

| Surface | Reason |
|---|---|
| Trading (orders, algo orders, positions write, leverage, margin mode) | read-only analytics; keys are read-only by policy |
| Funding account transfers, withdrawals, deposit address | write or funding-account surfaces; not needed (flows come from history and transfer bills) |
| Market data (tickers, candles, order book) beyond the existing flow valuer | not needed; the existing price index is reused |
| `/api/v5/account/bills` changes (chunking for `[167.1.2.2.2-OKX-PERSISTENT-TRUNCATION]`) | not fixed here (orchestrator decision 7); the reconciliation is the detector |
| OPTION / EVENTS bill P&L in the live path | not changed; reported as an excluded class (RESEARCH Open Question 5), any fix is a founder decision |
| Automatic archive rebuild on new key onboarding | deferred (D-04) |
| Sub-account, broker, earn, convert, copy-trading, block trading APIs | out of scope for the two named gaps |
