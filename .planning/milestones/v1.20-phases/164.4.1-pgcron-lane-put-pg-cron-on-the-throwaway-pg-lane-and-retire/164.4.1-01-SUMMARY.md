## Decisions Made

1. **REAL pg_cron, by measurement** (see the two tables above). The shim is rejected on both axes: it saves nothing measurable, and it would have to reimplement `cron.schedule()` faithfully enough to satisfy three gates that read `cron.job.command` as an ORACLE — an oracle written by the same hand as the claim.
2. **`cron.max_running_jobs=0`** (Claude's discretion, per the plan): the launcher never starts a job, so a lane straddling `:00/:15/:30/:45` cannot run a scheduled reaper body concurrently with the gate.
3. **The `--help` byte range moved 2,45 → 2,59** because the header gained 14 lines. Left alone, `--help` would have silently stopped printing the ⛔ TEST/PROD paragraph. The new range carries a comment saying it is a byte offset, not a semantic one.
4. **Two of the nine `/5` sites were history prose and were reworded, not renumbered** (see Deviations #3).
