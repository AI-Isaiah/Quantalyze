## Deviations from Plan

**1. [Rule 3 - Blocking] The rolling-chart tick selector.** The plan names `.recharts-xAxis .recharts-cartesian-axis-tick-value`; on this Recharts 3 build the tick labels are drawn in a sibling `g.recharts-xAxis-tick-labels` layer, so that selector matches nothing and every rolling-chart wait timed out. The describe and the helper's `inXAxis` flag use `.recharts-xAxis-tick-labels`. Plan 03 must keep its custom tick renderer's labels in that layer (or move the selector with it). Commit `a6d33a498`.

**2. [Rule 1 - Bug in the probe rule] Vertical axis of an overflow-visible svg.** The plan says an overflow-visible svg is bounded by "the padding box of the nearest overflow-clipping ancestor (or the viewport when none)". Taken literally, a vertical scroller such as `#main-content` or the page's own scroll makes every text below the fold an offender. Horizontally any non-visible ancestor (or the viewport width) bounds the text; vertically only `hidden`/`clip` ancestors do, and with none the vertical axis is unbounded. Documented in the block comment of `geometry.ts`. No overflow-visible text was an offender on the base, so no result depends on this.

**3. [Rule 3 - Blocking] Dev server on webpack.** `next dev` (Turbopack) cannot resolve `next` through the symlinked `node_modules` in the worktree. The lane ran `next dev --webpack`. Geometry and hydration behaviour are the same; CI's `e2e-seeded` builds its own server. The `AGENTS.md` the dev server regenerates was restored from `HEAD` and never staged.

**4. [Describe shape] The BEFORE file merges per surface** with a synchronous read-modify-write and a rename, so the Overview and composer cases write one file. It was captured with `--workers=1`.
