## Decisions Made

- Kept `judge()`'s parameters to exactly the two epoch strings plus two
  optional path labels used only for messaging, per the plan's explicit
  instruction — this keeps the pure function trivially testable without
  requiring the self-test to fabricate real file paths.
- The stale-message wording was written to contain the load-bearing phrase
  (`the baseline dump is STALE`) and both bare epoch numbers verbatim, because
  `scripts/restore-test-from-baseline.sh`'s own self-test arm 5 greps for
  exactly those substrings in the relocated caller's captured output — sharing
  the message text (rather than re-deriving a second wording bash-side) is
  what keeps that arm honestly exercising the real decision logic.
- Chose not to name other env seams (`BASELINE_FILE`, `MIGRATIONS_DIR`,
  `FRESHNESS_TS_CMD`) by their literal identifiers inside the new
  `CURRENCY_CHECK` doc entry — see Deviations below.

**1. [Rule 1 - Bug] `CURRENCY_CHECK` doc entry broke the WR-04 per-seam ENV SEAMS calibration test**
- **Found during:** Task 2 (verifying `src/__tests__/restore-test-from-baseline.test.ts` after the relocation)
- **Issue:** The first draft of the new `CURRENCY_CHECK` header doc entry named
  the three seams it forwards (`BASELINE_FILE`, `MIGRATIONS_DIR`,
  `FRESHNESS_TS_CMD`) by their literal ALL-CAPS identifiers in prose. The repo's
  `restore-test-from-baseline.test.ts` has a WR-04 calibration arm that strips
  each seam's own header entry in turn and asserts the "undocumented seams"
  scanner correctly flags it — but the scanner matches on ANY mention of the
  name anywhere in the ENV SEAMS block, not just within that seam's own entry.
  With my entry also naming `BASELINE_FILE`, stripping `BASELINE_FILE`'s own
  entry left the name still present (inside my entry), so the calibration
  arm's expectation (`toEqual(['BASELINE_FILE'])`) failed with `[]` — a false
  "still documented" reading.
- **Fix:** Reworded the `CURRENCY_CHECK` doc entry to say "the three seams
  immediately above" instead of repeating their literal names.
- **Files modified:** `scripts/restore-test-from-baseline.sh`
- **Verification:** `npx vitest run src/__tests__/restore-test-from-baseline.test.ts` — 43/43 passing (was 42/43 before the fix)
- **Committed in:** `cff6fb8c` (part of task 2's commit — caught and fixed before committing)
