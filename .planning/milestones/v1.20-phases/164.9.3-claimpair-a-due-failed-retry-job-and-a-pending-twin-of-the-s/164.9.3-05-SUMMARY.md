## Deviations from Plan

**1. [Rule 3 - Blocking, coordinator correction] The mutation runner runs without the shared lane lock**
- **Found during:** Task 1, while the first `<automated>` verify was running (run 3)
- **Issue:** The coordinator corrected the lock rule mid-run. `lane.lock` guards only the local-stack lane. The pg-lane and the mutation runner are per-run and need no lock. Another phase was waiting on the lock.
- **Fix:** I released the lock I held. To keep that run's EXIT trap from later removing a lock another phase might have taken by then, I killed only the wrapping shell with SIGKILL, which skips the trap, and then removed the lock myself. The node runner ran on to completion and printed `✅ No defects` at 506. Because its exit code was lost, I re-ran the plan's Task 1 `<automated>` command with only the lock prologue removed (run 4): `runner rc=0`, `VERIFY rc=0`. Runs 1 and 2 held the lock, as the plan's wording then required.
- **Files modified:** none. This changed how the runs were done, not what was committed.
- **Commit:** n/a

**2. [Sequencing] One run separated both too-high directions**
- **Found during:** Task 1
- **Issue:** The plan says "set each floor to measured+1 and re-run the runner".
- **Fix:** I raised both floors together in one full run. The runner reported exactly two defects, one naming each floor, so each floor is individually shown to bite. This saved one 12-minute run.

**Total deviations:** 2 (one coordinator-directed process change, one sequencing change). **Impact:** none on the committed values or the verdict.
