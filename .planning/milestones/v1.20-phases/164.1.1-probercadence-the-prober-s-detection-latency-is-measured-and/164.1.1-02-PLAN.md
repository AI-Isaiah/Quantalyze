<objective>
Expand out from the proven slice. Plan 01 pinned the happy pair — stale posts, fresh does not.
This plan pins the five ways that pair can be true while the alarm is still worthless: an ABSENT
contact row read as healthy, a fresh row belonging to somebody ELSE's cron satisfying the read, a
self-observability row that never lands so the observer's own death is invisible, a destination
control one `ALTER TABLE` deep, and a post built over a NULL key.

Purpose: a staleness gate that has never been seen red has not met criterion 3, and a gate that
only ever exercises the two states its author was thinking about is the vacuity class this
milestone ranks above ordinary correctness. Each arm here is a state the implementation could get
wrong while both of plan 01's arms stayed green.

Output: five more annotated arms in the same gate file, and `ARMS_FLOOR` raised from a measured
full-corpus run with every sibling pin moved in lockstep.
</objective>
