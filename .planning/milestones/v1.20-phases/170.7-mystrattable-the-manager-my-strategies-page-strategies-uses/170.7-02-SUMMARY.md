## Task 2: mount-once probe (D-01)

Probe slot counts mounts (empty-deps effect) and cleanups per strategy id; the table is driven through two Sharpe header clicks, Compact and back, and a search every row survives. Rows have distinct Sharpe values so a sort really reorders (asserted), and a note sits on every other row.

**Deviation found by the neuter (Rule 1, test defect in my own first draft).** The plan's neuter (Fragment keyed by loop index) stayed GREEN with a mount counter alone: React keeps one component instance per position under an index key and re-points its props, so the counter stays at 1 while the DOM node at that position now belongs to another strategy. Fixed by also asserting per-strategy DOM node identity (slot node and data-row node) after each step; the default sort is Sharpe descending and two clicks return to it, so the identity check runs after EACH step, not only at the end (a final-only check also stayed GREEN under the neuter). Neuter now RED: `AssertionError: expected <span …(1)></span> to be <span …(1)></span> // Object.is equality`. Restored, `cmp` clean.

Page-change narrowing, as the plan required: rows leaving the page unmount by construction; that cannot reach the modal because an open native dialog is modal (pagination is unreachable while it is open). The UI-SPEC's "across page changes" means this; it is stated in the test comment. Focus return itself stays with plan 07 (Playwright).
