## Column order (manager mount)

`#` (rank) · **Strategy** · **Status** · **Created** · Return % · CAGR · Sharpe · Max DD · Volatility · 6 Month · AUM · Return (sparkline) · Underwater (sparkline) · Details (below `@3xl` only) · **Actions**

**"Pending Review" vs "Pending review": a 170.1 COPY coordination item.** This phase renders the existing `Badge` label `Pending Review`, unchanged, and tests assert `Pending Review`. ### Created column (D-09)

| Element | Contract |
|---------|----------|
| Placement | Immediately after Status, in `thead` and every `tbody` row kind (emitted in the same `Fragment` after index 0); mirrored in placeholder rows |
| Header cell | Sortable, same markup as a `COLUMNS` header: `<th scope="col" aria-sort={…} className={`sticky top-0 z-20 bg-surface px-4 py-3 text-left`}>` containing the existing sort `<button>` with `HEADER_LABEL` and the `↑`/`↓` glyph. Visible text `Created`. `z-20`, not pinned horizontally |
| Body cell | `<td className="px-4 py-3 whitespace-nowrap font-metric tabular-nums text-text-secondary group-hover:bg-page/50 transition-colors">{s.created_at.slice(0, 10)}</td>`, i.e. `YYYY-MM-DD` (UTC date of the stored timestamp). Not `toLocaleDateString()`: it differs between server and browser locales and between time zones, and the table is a client component, so it would also risk a hydration mismatch. A missing or malformed `created_at` prints `—` |
| Sort key | `created_at`, compared by the ISO string. For this key the STALE-01 partition (unranked rows below ranked rows) does **not** apply: rows sort purely by date, which is what makes "a new strategy is always at the top" true for a strategy with no analytics. For every metric key the partition is unchanged |
| Initial sort | New optional prop `initialSort?: { key: SortKey; dir: "asc" \| "desc" }`, seeding the existing `useState<SortKey>("sharpe")` / `"desc"`. Absent means `sharpe` / `desc`, so Discovery, Browse and `/my-strategies` are byte-identical. `/strategies` passes `{ key: "created_at", dir: "desc" }`. The rank column numbers rows in the active sort, as today |
| Collapse | Not collapsed below `@3xl` |

### Actions column (D-01)

| Element | Contract |
|---------|----------|
| Header | The existing final `th`, text `Actions`, `text-right`, unchanged |
| Cell wrapper | `<td className="px-4 py-3 text-right group-hover:bg-page/50 transition-colors">` (existing) containing `<div className="flex flex-nowrap items-center justify-end gap-3 whitespace-nowrap">` |
| Order, left to right | 1. **Edit** link · 2. **private-link control** (`ShareableLink`) · 3. `StrategyActions` (renders per status; nothing for a status with no action) |

| Edit link | Rendered by the table from `managerRows[s.id].editHref` (`/strategies/<id>/edit`), so its class stays in the one file that owns `GHOST_ROW_ACTION`: `<Link href={editHref} aria-label={`Edit ${s.name}`} className={`${GHOST_ROW_ACTION} inline-flex items-center pointer-coarse:min-h-[44px]`}>Edit</Link>` |
| Private-link control | `<ShareableLink strategyId={s.id} published={isPublishedStatus(s.status)} hasActiveShare={liveShareIds.has(s.id)} size="sm" />`, built once per row on the server and passed in `managerRows[s.id].actions`. | Not rendered in manager mode | `ownerRowActions` (Mark ownership, Rename) and `SimulateImpactButton`. The `s.status === "published"` literal stays directly in front of `<SimulateImpactButton` with `&& !managerRows` after it (pin 7) |

**`ShareableLink` mounts exactly once per row.** The `actions` slot renders in the one Actions `td` and nowhere else: not in the `@3xl:hidden` Details disclosure, not in a CSS-hidden duplicate. Rows stay keyed by `s.id`; the data row and its note row share one `Fragment` keyed by `s.id`. The modal, its `modalMounted` latch and its native `<dialog>` focus return are untouched (founder UAT #4). Mechanism pinned in jsdom by a mount-once probe across sort, page and density changes; focus return after Close, Escape and a revoke asserted in Playwright.

`managerRows` shape (absent means byte-identical output on Discovery, Browse and `/my-strategies`):

```ts
managerRows?: Record<string, { editHref: string; actions: ReactNode; note?: ReactNode }>
```

`emptyRowColSpan` gains `+ (managerRows ? 2 : 0)` (Status and Created); its column-count comment is updated.

### Note row (D-06)

A second, full-width `<tr>` directly under a data row, rendered only when that strategy has a note. It carries, in this order: review feedback, the KCS-06 untrusted-key lines, the KCS-12 share note. When none applies, no note row renders.

| Element | Contract |
|---------|----------|
| Row | `<tr className="bg-surface border-b border-border last:border-0" data-testid="strategy-row-note">`. The data row above it drops its own `border-b` when a note follows, so the pair reads as one record with one hairline under it. No hover tint |
| Cell | `<td colSpan={emptyRowColSpan} className="p-0">` |
| Inner block | `<div data-testid="strategy-row-footer" className="sticky left-0 w-[100cqw] space-y-2 pb-3 pl-4 pr-4 @3xl:pl-18 overflow-visible text-caption">`. `w-[100cqw]` resolves against the `ResponsiveTable` `@container` region, so the note is as wide as the visible scroller and stays in view at any `scrollLeft`. No top padding: the note hugs its row |
| Review feedback (D-08) | Shown for `s.review_note && s.status === "draft"`: `<p className="rounded px-2 py-1 text-caption font-normal text-warning bg-warning/5">Review feedback: {review_note}</p>` |
| Key line (each) | `<div data-testid="strategy-row-key-mark" className="flex items-start justify-between gap-3"><p className="text-caption font-normal text-text-muted">{caption}</p><AllocatorSyncStatus … /></div>` |
| Share note | `<p data-testid="strategy-row-share-note" className="text-caption font-normal text-text-muted"><ContactPointerText … /></p>` |

**The `@3xl` note-indent relation.** The note's text lines up with the strategy name it belongs to once the table is wide enough to pin, and spends no width on an indent below that:

| Table container width | Relation (asserted in Playwright, at `scrollLeft` 0 and at maximum) |
|-----------------------|---------------------------------------------------------------------|
| at or above `@3xl` | the left edge of the note's first text line equals the left edge of the Strategy name link's text in the row above, within 1 px |
| below `@3xl` | the left edge of the note's first text line equals the region's left edge + 16 px, within 1 px |

The class `@3xl:pl-18` (72 px = the 56 px rank column + the Strategy cell's 16 px left padding, with no star column on this page) is the implementation; the relation is the contract. If 170.2's merge changes the rank column's width, the relation, not the class, decides.

**Typography and colour of the note row.** Every line is DM Sans `text-caption` (12→13 px), weight 400. Captions and share notes `text-text-muted` (`#64748B`, 4.85:1 on white). The key pill keeps `AllocatorSyncStatus`'s own tokens (12 px `text-xs`, weight 500, inherited, see Typography). Review feedback is amber per D-08: `text-warning` (`#B45309`) on `bg-warning/5` over `bg-surface` measures **4.68:1**, AA for 12 to 13 px text.

**No third chip-contrast pair.** `tests/a11y/chip-contrast.test.ts` pins exactly two `text-text-<x> bg-track` pairs in `StrategyTable.tsx`, both `secondary`. Nothing in the Status, Created or note cells writes `bg-track`: the note background is `bg-surface`, captions are `text-text-muted` ink with no fill, the review-feedback block is `text-warning` (not a `text-text-*` class) on `bg-warning/5`, and the Status badge's tints live in `Badge.tsx`.

### Review feedback, amber in both places (D-08)

DESIGN.md's colour gate: amber is the recoverable state, red the permanent one. A draft sent back for changes is recovered by revising and resubmitting, so both places that print review feedback on `/strategies` move from red to amber.

| Site | Today | After |
|------|-------|-------|
| Note row, review-feedback line | (on the card) `text-xs text-negative bg-negative/5 rounded px-2 py-1` | `rounded px-2 py-1 text-caption font-normal text-warning bg-warning/5` (4.68:1) |

The banner's title, body, `Revise & resubmit` button and the non-rejected (accent) banner are unchanged. The banner keeps `text-xs` (12 px) because it is outside the table and its other lines are `text-xs`; only colour changes there.

## Pinning and width, inherited from 170.2 by relation (D-04, D-07)

170.7 adds no pinning rule and copies no 170.2 constant. It asserts on `/strategies`, with Status, Created and Actions present, the relations 170.2's UI-SPEC asserts on Discovery:

| Relation | Assertion on `/strategies` |
|----------|----------------------------|
| Table width keys the pin | The pin follows the table container's `@3xl` step that 170.2 merges. Below it, after setting the `Strategies` region's `scrollLeft` to its maximum, the Strategy `th` and every Strategy `td` have moved left with the row (within 1 px). At and above it, they have not moved |
| Names content-sized | The Strategy column carries no width class added by this phase |
| Pinned cells as wide as the header | At and above the step, every pinned Strategy `td` satisfies `|td.width − th.width| <= 1` and `|td.right − th.right| <= 1`, at `scrollLeft` 0 and at maximum |
| Pinned header not covered | At maximum `scrollLeft`, `document.elementFromPoint(th.right − 2, th.top + th.height / 2)` is the Strategy `th` or a descendant. The Status and Created headers are `z-20`, under the Strategy header's `z-30` |
| Nothing paints past the pinned edge | For every descendant of a pinned Strategy `td`, `rect.right <= cell.right + 1` |
| Note row stays in view | At any `scrollLeft`, the note block's left edge equals the region's left edge within 1 px and its right edge is inside the region |
| Note indent | The `@3xl` note-indent relation above |
| No page scroll | At 360, 375 and 390 px, `#main-content` and `document.documentElement` each have `scrollWidth − clientWidth <= 1` (`assertNoReflow`) |

Viewports: 360 × 780, 375 × 667, 390 × 844 (phones, unpinned); 1080 × 800 (just under the step, unpinned); 1100 × 800 and 1280 × 800 (pinned). Reuse 170.2's merged geometry helper; do not copy it.
