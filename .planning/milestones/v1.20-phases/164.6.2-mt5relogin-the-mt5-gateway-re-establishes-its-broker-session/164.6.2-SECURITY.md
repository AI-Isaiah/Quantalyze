| Finding | Why the register missed it | Resolution |
|---|---|---|
| `[164.6.2-LOGIN-ESCAPE-BLIND]` — `Mt5Client.login` kept its OWN private raw-literal redaction loop, bypassing the shared redactor, across four shipped per-account callers passing a real vault password | the plan-time model declared `login` FROZEN under D-07 and therefore out of scope. **The scoping rule was itself the blind spot.** | D-07 amended (`d1fff452`); `login` now routes through the shared helper; `ESCAPE_AWARE_METHOD_FLOOR` raised 1 → 2 |
| CR-01 — redaction matched only the RAW literal, so any credential containing `\`, `'`, `"` or a tab leaked via `repr()`-escaped renderings | the register said "by-value redaction" and the code did by-value redaction — of one rendering | `_credential_renderings` covers raw + `repr` + `ascii` + `json.dumps` (`6bf94a5b`) |
| B1 — per-literal redaction in FIXED ORDER let the login's span be consumed first, leaving the password PARTIALLY masked | no register entry contemplates a redactor that is correct per-literal and wrong in composition | ONE global longest-first pass (`8665d205`); corpus gains `credential-substring-overlap` |
| WR-05 / IN-05 — Sentry captured frame locals for every frame while `before_send` scrubbed by KEY, and `password` was on the freeform-string alternates but NOT on `DENYLIST_EXACT`; the three frames this phase added each held the plaintext password under exactly that name | **absent from all four plan-time registers** — no trust boundary named Sentry frame locals | `include_local_variables=False` PLUS `password`/`investor_password` on the denylist in BOTH `services/redact.py` and `src/lib/admin/pii-scrub.ts`, with a set-EQUALITY cross-language gate |

⭐ **The vacuous-corpus class is closed.** Every credential fixture was historically
`[A-Za-z0-9-]` and every assertion checked the FULL literal absent — neither could fail on
the actual bug class. The corpus now carries escape-bearing, non-ASCII and
substring-overlapping values, and the overlap case asserts the REMAINDER rather than the
whole value.
