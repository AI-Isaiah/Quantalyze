## Sampling Rate

- **After every task commit:** that task's `<automated>` command, which covers the touched files.
- **After every plan wave:** `npm test && npm run typecheck`.
- **Before `/gsd-verify-work`:** the full suite plus lint green, and the live-DB spec green on the local lane. After deploy, check `/strategies` and an owner factsheet in the logged-in browser.
- **Max feedback latency:** 60 s for unit runs. The live lane is run twice, in plan 01 only.
