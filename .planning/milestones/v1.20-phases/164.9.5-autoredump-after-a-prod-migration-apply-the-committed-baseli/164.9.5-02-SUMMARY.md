## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The `'--redact'` acceptance grep does not match the file's quoting**
- **Found during:** Task 2 acceptance
- **Issue:** The criterion `grep -c "'--redact'" ≥ 1` expects a single-quoted literal. `scripts/baseline-redump.mjs` is double-quoted throughout, like plan 01.
- **Fix:** Kept the house quoting (CLAUDE.md Rule 11). The equivalent `grep -c '"--redact"'` gives 2. The `gitleaksArgv` arm asserts `--redact` is in the argv, and the real-binary arms prove the output is redacted. No later plan greps for the single-quoted form (checked plans 03 to 09).
- **Files modified:** none beyond the task's own.

**2. [Rule 1 - Bug, in my own test] The basename arm expected position 1 and the new-migration arm had a wrong clause**
- **Found during:** Task 1 GREEN and Task 3 RED
- **Issue:** `git ls-tree` lists in byte order, and `_` sorts after every digit, so `2026_bad.sql` sits at position 3, not 1. Separately, the Task 3 new-migration arm required `changed=true` to be absent from the captured text, but the gate summary line legitimately contains it.
- **Fix:** Expected position 3, with a comment saying why, and dropped the wrong clause. The arm still asserts the emitted `changed=true` and that M3 is in the marker. The Task 3 RED was re-run and recorded above, after that fix.
- **Commit:** folded into `5a8aa5293` and `da84965e5`.

**3. [Rule 3 - Blocking] RED evidence needed TAP**
- **Issue:** `gsd-tools check tdd-red-evidence` classifies TAP output. The house self-test prints `ok`/`FAIL` lines.
- **Fix:** A scratch transliterator mapped each `ok`/`FAIL` line one-to-one to TAP, and each record named its target arm. All three records returned `RED_EVIDENCE_OK`. The transliterator lived in the scratch directory and is not committed.

**4. [Rule 3 - Blocking] node_modules symlinked instead of `npm ci`** (standing constraint 15)
- The symlink was proved with `npx vitest --version` (`vitest/4.1.10`) and removed before every commit.

**Total deviations:** 4 (2 environmental, 1 quoting mismatch in an acceptance grep, 1 bug in my own test fixture). **Impact:** no change to the script's CLI or to any locked decision.
