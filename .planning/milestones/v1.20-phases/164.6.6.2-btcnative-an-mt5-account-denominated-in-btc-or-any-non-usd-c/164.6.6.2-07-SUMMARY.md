## Deviations from Plan

**1. [Rule 3 - Blocking] `generateMetadata` has no payload in scope**
- **Found during:** Task 1
- **Issue:** the plan says `ogImage` appends the unit from "the payload in scope", but `generateMetadata` in `v2/page.tsx` reads only a `strategies` row (`id, name, codename, description, disclosure_tier`); no payload exists there, and building one would defeat the point of a light metadata probe.
- **Fix:** the metadata probe's select gained `strategy_analytics ( data_quality_flags )` on the same `withPublishedOnly` read, and the unit is parsed with `parseReturnsUnit` (object or array embed). Only the parsed unit is used; this is the same column, same published-only path, same request client the OG route itself reads. Three tests added to `page.public-cache-key.test.tsx` (BTC object and array embed, USD URL byte-equal to before, malformed unit never reaches the URL).
- **Files modified:** `src/app/factsheet/[id]/v2/page.tsx`, `src/app/factsheet/[id]/v2/page.public-cache-key.test.tsx` (both already in the plan's files_modified)
- **Commit:** 77b4ee96b

**2. [Rule 3 - Blocking] tear sheet reuses one request client**
- **Found during:** Task 2
- **Issue:** the plan asked for the request-scoped `createClient()`, but the page already creates one inside the attestation `try`; a second `createClient()` would consume a second `mockResolvedValueOnce` in the existing tests.
- **Fix:** `supabase` is hoisted out of the `try` (one line), the unit read shares it, and a null client (the attestation lookup already threw and logged) reads as USD. The security-gate logic is otherwise byte-unchanged; the existing five C-0189 tests pass unedited in behaviour (their `stubAuth` stub was made table-aware).
- **Files modified:** `src/app/factsheet/[id]/tearsheet/page.tsx`, `page.test.tsx`
- **Commit:** f5ac43078
