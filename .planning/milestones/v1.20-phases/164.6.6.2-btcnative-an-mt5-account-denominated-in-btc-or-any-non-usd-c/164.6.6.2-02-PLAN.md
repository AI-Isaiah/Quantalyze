<objective>
Add the storage D-02 and D-14 need: the account's currency code and its native-unit balance on
`api_keys`, written only by the analytics worker (service role), readable by nobody user-scoped.

Purpose: D-02 stores the currency so D-03 can compare reads; D-14 keeps the native balance beside
`account_balance_usdt` instead of writing BTC into a USD field. Deploy shape per CONTEXT Claude's
Discretion: a single PR, and plan 03's worker write tolerates `PGRST204` for the window where the
worker deploys before PROD `apply`. No TypeScript reads these columns (the factsheet reads the unit
from `strategy_analytics.data_quality_flags`), so the Vercel-before-migration race that split earlier
api_keys migrations into two PRs does not exist here.

Output: one DDL-only migration, its rollback, regenerated `database.types.ts`.
</objective>
