## Sampling Rate

- **After every task commit:** `node scripts/mutation-runner/run.mjs --parse-only`, plus
  `node scripts/mutation-runner/run.mjs --file <gate> --arm <ARM>` for the arm just written.
  ⚠️ A non-zero exit from the `--file` form is EXPECTED (no working subset mode — `--file` never
  exits 0); read the verdict line, not the exit code.
- **After every plan wave:** full `node scripts/mutation-runner/run.mjs`, then
  `npx vitest run src/__tests__/mutation-runner-floors.test.ts src/__tests__/mutation-annotation-parser.test.ts src/__tests__/gate-family-meta.test.ts`
  serially, then `git status --porcelain` must be empty.
- **Before `/gsd-verify-work`:** full runner + `--self-test` + full vitest green, AND `sql-mutation`
  green on ubuntu **at the PR head SHA** (an ancestor-SHA green is not evidence — this exact trap
  was caught in 164.3.1's UAT), AND the printed floors equal the run log.
- **Max feedback latency:** ~1 s static / ~9 min full corpus at phase end.

## Anti-Vacuity Clause

⭐ **The house rule: a test that CANNOT FAIL is worse than none.** This phase authors ~365 claims
that a machine proves an arm bites. The failure mode it must not manufacture is an annotation that
satisfies the DETECTOR rather than the ARM.

- Every batch's floors must move by the **measured delta**, in the same commit as the annotations —
  `run.mjs` constants + `gate-family-meta.test.ts` registry + the exact-equality pins together.
- ⛔ **Do NOT lower a floor to make a batch pass.** A falling floor is the failure mode the floor
  exists to catch.
- ⛔ **An arm that cannot fail AT ALL is the FINDING, not a waiver.** Record it, book it to
  `TODOS.md`. Waivers are only for arms that DO bite but cannot be mutated mechanically.
- Waiver volume > 5 total → STOP and escalate to the founder rather than ratchet `WAIVED_CEILING`.
- Every floor moved must keep a measurement token AND a date within 80 lines above the constant, or
  the `gate-family-meta.test.ts` bare-measurement arm goes RED (name class is now
  `FLOOR|MIN|CEILING|MAX|LIMIT`, exact registry `KNOWN_THRESHOLD_SITES`).
