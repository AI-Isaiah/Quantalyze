## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| git history -> derivation | Commit metadata and changed file names reach the verdict and `$GITHUB_OUTPUT`. A fork PR chooses its file names. | file names, commit email/subject |
| `github.event.*` -> step env | `before` and `forced` are event payload fields | SHA string, boolean |
| `changed-paths` -> `sql-mutation` | Mode, file list and reason cross a job boundary | `sql_gate_mode`, `sql_gate_files`, `sql_gate_reason` |
| `changed-paths` -> GitHub API | WR-03 predecessor proof for a narrowing push | `checks: read` token, `classify` and `sql_gate_subset` steps only |
| floors data file -> CI gate | The runner and assert step compare the corpus to these values | three integer constants |
| nightly runner output -> public issue | Log text is filed into a GitHub issue | summary lines, `::error::` lines, 60-line tail |
| `report` job token | The only job in the phase that holds a write scope | `issues: write` |
