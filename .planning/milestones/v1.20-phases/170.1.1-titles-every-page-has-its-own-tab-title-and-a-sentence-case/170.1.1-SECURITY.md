## Sentry payloads (captureToSentry)

Every new call has the form `captureToSentry(new Error(error.message), { tags: { route, stage: "generate-metadata" } })`.
There is no `extra`, no user id, no email, no route param and no row data. The payload is a static route tag plus the PostgREST error message.
`captureToSentry` scrubs the message and stack through `scrubSeamString` and `scrubSeamError` (`src/lib/sentry-capture.ts`), and fails safe on a scrub error.
Sites checked: users/[id], match/[allocator_id], discovery strategyId, portfolio-pdf, factsheet v2, portfolios/[id], manage, documents, strategies/[id]/edit. Result: no PII beyond error.message.
