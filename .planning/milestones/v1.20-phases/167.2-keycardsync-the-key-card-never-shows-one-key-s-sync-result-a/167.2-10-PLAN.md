<objective>
Close the warned-row early terminal research found (KCS-18): a sync attempt on the key card shows a
success only when the job queue agrees no factsheet-chain job is still in flight.

Purpose: a strategy whose previous run ended complete_with_warnings can have its analytics row
re-stamped complete_with_warnings mid-chain while the stitch or compute job is still pending; the
panel would then say Synced with warnings for a run that has not finished. Plan 03 already proves a
terminal belongs to this attempt; this plan adds the one remaining check before a success is said.
Output: SyncProgress reads the existing owner-scoped sync-progress projection before forwarding an
evidenced success, and the tests that pin it on both the panel and the key card.
</objective>
