## Closing paragraph — the one thing worth routing (NOT a Critical, and not enumerated as a Warning)

Per the brief I did not collect Warnings or Infos. One measurement genuinely gave me pause and is
recorded here rather than filed, because it is adjacent to booked residual 2 and should be routed
with it rather than fixed in this phase.

`MIGRATION_FILENAME_RE` is `^[0-9]{14}_[a-z0-9_]+\.sql$`, and its docstring argues that the
14-digit prefix and the `.sql` suffix are what stop it being "a one-step off-switch — append `.sql`
to a key inside a comment and `long-token-anywhere` goes quiet". That argument is narrower than it
reads: the body charset `[a-z0-9_]` is exactly the charset of an `sk_live_`-style key. MEASURED:

```
-- 0123456789abcdef0123456789abcdef                          -> ["long-token-anywhere"]
-- 20260907130000_0123456789abcdef0123456789abcdef.sql       -> []
```

I am **not** calling this a Critical, and the reasoning is the same one the fix pass used to add
the comment producer in the first place: the realistic path that rule exists for is *an operator
"removing" an inline key by commenting it out*, and that operator does not also rename the key into
a fourteen-digit migration filename. Reaching this needs deliberate construction, it is confined to
comment bodies, and every other rule (header anchors, `jwt-shape`, `service-role`, `pg-password`)
still runs beside it. It is a residual of the same family as "a `||`-split value outside a header
region" and "a purely alphabetic 32+ character key", both of which are already booked open. The
honest remedy is a whole-token measure rather than a wider filename pattern — a decision, not a
fix — and it belongs wherever residuals 2, 5 and 7 are routed.

Nothing else alarms me. A production credential reaching `cron.job.command` by any spelling I could
construct — inline, behind `coalesce`/`nullif`/`(SELECT …)`, `||`-joined inside a header, in a host
label, in a path segment, in a comment, under a NULL jobname, beside a too-deeply-nested `DO`, with
the oracle absent / stale / schema-bumped / hand-edited / marker-mismatched, or with the functions
snapshot deleted — was **named** in every case I drove, and its text was withheld from the public
log in every case.
