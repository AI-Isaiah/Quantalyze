# Phase 164.6.6.3.1 Plan 01: Strategy edit form keeps its own name Summary

The strategy edit form now offers and preselects a strategy's own off-list name (e.g. "MM-2x") instead of displaying "Alpha Centauri", and an edit save sends `name` only when the user actually changed the picker.

## What changed

- `src/components/strategy/StrategyForm.tsx`
  - `nameOptions` (a `readonly string[]`): when `strategy?.name` is set and not in `STRATEGY_NAMES`, the strategy's own name is prepended; otherwise `STRATEGY_NAMES` unchanged. The "Strategy Name" `<Select>` is fed from it, label equal to value, no marker. The `name` `useState` initialiser is untouched.
  - The `payload`'s `name,` became `...(mode === "create" || name !== strategy?.name ? { name } : {})`, the same idiom as the `api_key_id` spread below it.
- `src/components/strategy/StrategyForm.test.tsx`: a new `describe` with 6 tests (2 tracer, 4 guards). No existing test pinned `name` in an unrelated edit-save payload, so none was modified.
