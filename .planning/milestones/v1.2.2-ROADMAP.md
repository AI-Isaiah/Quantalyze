## Overview

v1.2.2 makes the /allocations Scenario composer render the **REAL factsheet** on a
hypothetical blend, computed client-side (`compute.ts`) with parity-by-construction to
the real `/factsheet/[id]/v2` route. The north-star directive (user, 2026-06-25): do
NOT rebuild any factsheet UI — take the existing factsheet wholesale and feed it the
blend as input. The milestone collapsed to: build ONE adapter (`blend → complete
FactsheetPayload`) + mount the REAL `FactsheetBody` with it, plus the one genuinely new
panel (constituent correlation / diversification).

The journey: extend `buildScenarioFactsheetPayload` minimal→complete so every scalar +
panel-array metric is computed client-side from the blend (39); mount the real
`FactsheetBody` under the existing scenario `FactsheetProvider(persist=false)` behind an
additive `scenarioMode` flag that keeps the real factsheet byte-identical (40); add a
constituent correlation matrix with a "too similar" flag, percent-contribution-to-risk,
and cluster reordering — the diversification check (41); land an honest aggregate-only
peer rank for the blend (a deliberate, scoped override of the no-peer-rank-a-hypothetical
invariant via an additive `scenarioPeer` carve-out — NEVER an `ingestSource` flip) plus
per-constituent mandate chips and an own-book delta (42); fold the compose toggles into
the factsheet-shaped layout behind four permanent guards — byte-identity, axe a11y,
coverage ratchet, no-state-bleed (43).

Additive client-TS/TSX + Python over the **frozen** `src/lib/scenario.ts` engine
(zero-diff this milestone). No storage migration. The no-invented-data invariant stayed
LOCKED; the no-peer-rank invariant got its one deliberate, audited override (aggregate
peer vs the verified universe, never per-constituent, never via `ingestSource`).

## Milestone Summary

**Decimal Phases:** none.

**Key Decisions:**

- **Factsheet wholesale reuse, never rebuild** (user north-star, 2026-06-25) — take the
  existing factsheet and feed it the blend. The milestone = ONE payload adapter
  (`buildScenarioFactsheetPayload` minimal→complete) + the REAL `FactsheetBody` under an
  additive `scenarioMode` flag, plus the single new constituent-correlation panel. Factsheet
