## Spacing Scale

Declared in DESIGN.md (base unit 4px). **This phase MUST NOT add ladder values** — it conforms to the
existing ladder and the documented exceptions below. The main ladder contains only multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| 1 | 4px | Icon gaps, inline padding |
| 2 | 8px | Compact element spacing |
| 3 | 12px | Tight card padding / dense rows |
| 4 | 16px | Default element spacing, card padding (sm) |
| 6 | 24px | Card padding (md), section gaps |
| 8 | 32px | Section gaps (large) |
| 12 | 48px | Major section breaks |
| 16 | 64px | Page-level spacing |

Exceptions:
- **`--space-grid-gap: 10px`** — designer-bundle-origin grid gap (WidgetGrid 4-col, Bridge family). NOT a ladder
  member; documented in DESIGN.md. **Do not snap to 12px** (shifts the 4-col grid 6px cumulative, regresses
  the 980px/640px breakpoints). Stays at 10px.
- **`py-0.5` (2px)** — Tailwind badge/pill standard sub-unit (Tailwind `spacing.0.5`). Scoped exclusively to
  badge/pill vertical insets (`py-0.5` in `Badge` / `TrustTierLabel`). Not a general layout spacing value;
  never used for margins, gaps, or padding outside badge contexts.
- **`--row-h: 44px` / `--density-pad: 16px`** (and tight `36px`/`12px`) — density-modifier tokens read by
  KpiStrip / HoldingsTable. Preserve; do not hardcode row heights.
- **Touch target 44px** min-height on buttons/inputs/table rows (DESIGN.md, WCAG; v1.3 floor). Preserve.
- A **second fluid `--space-*` suite is DEFERRED** (CONTEXT.md `<deferred>`) — introduce only if a surface
  provably forces it. Default: use the fixed ladder.

## Typography

Use the **named fluid `--text-*` tiers** (Phase 49 spine), not raw `text-[14px]` / `text-sm`. This is the
per-surface migration onto the spine that Phase 49 deferred. Tiers map the px scale 1:1 and re-evaluate
`clamp()` on zoom (WCAG 1.4.4). Weights: exactly **2 — 400 regular + 600 semibold**; sub-headings differentiate
via `uppercase tracking-wider`, never a third weight (per the v2 single-strategy 4-size/2-weight precedent).

The **full 8-tier spine stays valid in `globals.css`** (it is the system-wide token source). But no single
surface may stack all of it — each surface CATEGORY below is constrained to **≤ 4 active tiers** (the same
4-size / 2-weight contract DESIGN.md locked on 2026-04-29 for the v2 single-strategy surface, applied
per-category). The per-surface subset is the enforceable contract; the spine table is the reference for
how each tier renders.

### Spine reference (system-wide tokens — NOT a per-surface license to use all of them)

| Role | Token | px (min→max) | Family | Weight | Line height |
|------|-------|--------------|--------|--------|-------------|
| Hero (landing only — not these surfaces) | `--text-hero` | 32→48 | Instrument Serif | 400 | 1.1 |
| Page title (factsheet/strategy H1) | `--text-page-title` | 24→32 | Instrument Serif | 400 | 1.2 |
| Section H2 | `--text-h2` | 20→24 | DM Sans | 600 | 1.2 |
| Panel H3 / card title | `--text-h3` | 16→18 | DM Sans | 600 | 1.3 |
| Body | `--text-body` | 14→16 | DM Sans | 400 | 1.5 |
| Small / table cell | `--text-small` | 13→14 | DM Sans | 400 | 1.5 |
| Caption / label / axis tick | `--text-caption` | 12→13 | DM Sans / Geist Mono | 400 (600 for labels) | 1.4 |
| Micro / badge | `--text-micro` | 10→11 | DM Sans | 600 (uppercase tracking) | 1.2 |
| **Numbers (all data values)** | (size from row above) | — | **Geist Mono `tabular-nums`** | 400 / 600 | — |

### Per-surface type subset (≤ 4 tiers per category — this is the enforceable contract)

Each surface category MUST use only the tiers listed for it. Hero is excluded everywhere (landing-only).
`--text-micro` is **not a general 5th tier** — it is permitted ONLY as a labeled badge-text exception.

| Surface category | Surfaces | Permitted tiers (≤ 4) | Badge exception |
|------------------|----------|------------------------|-----------------|
| **Data surfaces** | Allocations (1), Scenario composer (2), Risk (3), Discovery (5), Compare / Bridge (6) | `--text-h3` (card/panel title) · `--text-body` · `--text-small` (table cell) · `--text-caption` (label/axis tick) | `--text-micro` permitted ONLY for badge text (trust-tier pill, status chip) — documented exception, never a body/heading tier |
| **Prose / factsheet / single-strategy** | Factsheet (4), Single-strategy (7) | `--text-page-title` (H1) · `--text-h3` (panel/section title) · `--text-body` · `--text-caption` (label/axis tick) | `--text-micro` permitted ONLY for badge text — documented exception |

- The factsheet's embedded data panels (KPI strip, chart axis) read their values at `--text-small` /
  `--text-caption` like the data surfaces; the prose subset above governs the page's H1 + section + body
  prose. A factsheet panel that needs `--text-small` for a dense KPI cell uses it as the data-surface idiom —
  it does not introduce a 5th prose tier.
- `--text-h2` is reserved for landing/marketing section headers and is **not** in either application subset;
  application card/panel titles use `--text-h3`. Don't reach for `--text-h2` on these seven surfaces.

**Hard typographic rules for this phase:**
- Every columnar number stays **Geist Mono `tabular-nums`** — preserve column alignment under fluid type and
  inside `@container` reflows. Container-query migration MUST NOT break `tabular-nums` alignment (CONTEXT.md TYPE-04).
- Migrate raw font-px on each surface onto the named tiers; the DS-04 `no-raw-font-px` lint ratchets to **error**
  per-surface as each is migrated (DESIGN.md Phase-49 entry). Leaving a raw `text-[Npx]` on a migrated surface
  is a contract violation.
- Page titles stay Instrument Serif (factsheet/strategy H1); UI labels/body stay DM Sans; no new font.

## Truncation / No-Clip Contract (TYPE-02)

**Default: WRAP. Single-line + `title=` only where tabular row-alignment requires it.** The Phase-49 truncation
audit (`.planning/audits/truncation-audit.md`) is the classification source of truth — legitimate clips stay,
accidental clips get fixed. **Do NOT relocate a clip** (introducing a new `truncate`/`line-clamp` without a
`title`/tooltip when re-typing is the exact regression this contract prevents).

### Two standardized treatments

| Context | Treatment |
|---------|-----------|
| Entity names (strategy / scenario / holding / deck / portfolio names) in cards/lists/headings | **Wrap** via `break-words` + `min-w-0` (the `ScopedBanner.tsx` reference pattern). Nothing silently cut. |
| Dense data-table name cells where wrapping breaks `tabular-nums` row alignment | **Single-line + `title={fullText}`** (and `aria-label` where AT needs it) so full text recovers on hover/AT. |
| Emails / mandate / status strings | `title=` or wrap — **never a bare ellipsis** (mid-clipped email is unrecoverable). |
| `line-clamp` descriptions | Add an expand/"read more" affordance, OR accept the clamp only where a full-detail surface is one click away and that link is documented as the recovery. |

### The 5 known accidental clips in scope (must fix)

| Site | Element | Fix |
|------|---------|-----|
| `AlertBanner.tsx:127` | alert message (`head.message`) | wrap or `title=` — message is meaningful, currently no recovery |
| `SavedScenariosList.tsx:529` | saved-scenario name (`row.name`) | wrap (`break-words min-w-0`) or `title=` |
| `ScenarioComposer.tsx:2779` | constituent strategy name (`max-w-[160px]`) | `title={name}` (table-aligned context) |
| `StrategyGrid.tsx:63` | marketplace/discovery tile name (`<h3>`) | `title={s.name}` or 2-line clamp — `wizardErrors.ts:481` even warns managers "longer names truncate" |
| Holdings / Discovery / Compare table **name cells** | dense-table name columns | single-line + `title=` (tabular-alignment context) |

### Legitimate clips — DO NOT remove their recovery affordance

`CompareCorrelationMatrix.tsx:90/113`, `allocations/widgets/risk/CorrelationMatrix.tsx:182/195` (axis labels with
`title=`), `FactsheetView.tsx:647/653` (fixed KPI labels + tabular values), factsheet chart-legend `…` with tooltip
recovery (`TimeSeriesChart.tsx:1109`, `build-payload.ts:161`), `ScopedBanner.tsx:30` (deliberate no-clip reference).
A 52 refactor that *removes* one of these recovery affordances is a regression caught in review.
