Use the **named fluid `--text-*` tiers** (Phase 49 spine), never raw `text-[14px]` / `text-sm`. Phase 53 is
the per-surface migration of these surfaces onto the spine. Weights: exactly **2 — 400 regular + 600

The full 8-tier spine stays valid in `globals.css` (it is the system-wide source). But **no single surface
may stack all of it** — each surface CATEGORY below is constrained to **≤ 4 active tiers** (the same 4-size /
2-weight contract DESIGN.md locked 2026-04-29, applied per category).
