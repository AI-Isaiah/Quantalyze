# Phase 50 — UI Design Contract

> Visual and interaction contract for the primitive-library refresh + missing
> primitives. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Source of truth:** `DESIGN.md` governs every token value below. This spec
> binds DESIGN.md's tokens to the specific primitives this phase ships and pins
> the interactive-state + a11y contracts an executor implements and a reviewer
> checks. Where DESIGN.md is silent, a default is recorded and flagged
> `[default]`. Nothing here re-opens a `50-CONTEXT.md` locked decision.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (hand-rolled token system; **no `components.json`, no shadcn** — confirmed absent) |
| Preset | not applicable |
| Component library | native HTML everywhere it fits; **Radix (`@radix-ui/react-tabs` v1.1.x)** introduced this phase for Tabs ONLY (no native HTML tab widget exists — UI-04). Native `<dialog>` (Modal), native `<select>` (Select), native `<details>/<summary>` (CollapsibleSection) retained — Radix is NOT pulled in for these. |
| Icon library | inline hand-authored SVG (no icon dependency); `currentColor` stroke, 1.5 stroke-width convention (see Modal close, Breadcrumb chevron) |
| Font | Instrument Serif (display) · DM Sans (body + UI/labels) · Geist Mono (data, `tabular-nums`) — wired via `next/font`, FROZEN |
| Styling | Tailwind v4, `@theme inline` colors/radius/shadow + plain `@theme` fluid `--text-*` spine in `src/app/globals.css` |
| Token discipline | colors MUST use the `--color-*` prefix; type MUST use the `--text-*` tier utilities (`text-body`, `text-h3`, …). A bare token name resolves to `currentColor`/black under Tailwind v4 (Decisions Log 2026-05-06). |

**First runtime UI-widget dependency.** `@radix-ui/react-tabs` is the first
runtime UI-widget dep in an otherwise 100%-native app. It is NOT on the
banned-packages list. Scope is locked to no-native-equivalent widgets only.

## Spacing Scale

DESIGN.md base unit 4px; the declared ladder (multiples of 4, with the two
documented exceptions). Primitives consume the fixed ladder via Tailwind
spacing utilities — **space stays fixed (not fluid)** per DS-02's reconciled
type-only-fluid decision.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| 0.5 | 2px | hairline nudges (badge `py-0.5`) |
| 1 | 4px | icon gaps, `gap-1` tab strips, badge radius |
| 1.5 | 6px | Field label→control gap (`gap-1.5`), input radius |
| 2 | 8px | compact element spacing, badge `px-2` |
| 3 | 12px | button `px-3` (sm), input `px-3`, tab `px-3` |
| 4 | 16px | default element spacing, card `p-4` (sm), tab `px-4`, section gap min |
| 6 | 24px | card `p-6` (md), section gaps, tablist `mb-6` |
| 8 | 32px | major section breaks, card `p-8` (lg), empty-state `py-8` |
| 12 | 48px | layout gaps |
| 16 | 64px | page-level spacing |

**Exceptions (documented, do NOT flag as ladder violations):**
- **44px min touch target** — interactive primitives clear 44px (`min-h-[44px]`
  on Button md/lg, Input, Select; table row height ~44px). v1.3 WCAG target-size
  floor. This is a target-size requirement, not a spacing token.
- **`--space-grid-gap: 10px`** — designer-bundle-origin grid gap; NOT a member of
  the 4/8/12/16/24 ladder (DESIGN.md §Spacing tokens). Not consumed by Phase-50
  primitives; listed so the checker does not flag it.
- **Density-control row heights** — the StrategyTable density control reuses the
  existing `--row-h` / `--density-pad` token pair (44px default / 36px tight /
  52px loose) already in `globals.css`. 36/52 are deliberate density steps, not
  ladder members.

## Typography

Primitives migrate their **internal classes** to the Phase-49 fluid `--text-*`
tier utilities (additive/CSS-only; **no public-prop change**, so every consumer
inherits the refresh — UI-01). Weight discipline is **400 regular / 600 semibold
+ 500 (the DESIGN.md-established DM Sans label weight)** — three weights in lived
use, where 500 is reserved for UI labels per DESIGN.md §Typography and is NOT a
net-new weight. Sub-headings differentiate via `uppercase tracking-wider`
transform, never by adding a weight beyond these three. The line-heights in the
table below are pinned (DESIGN.md heading/label/caption rhythm), not executor
guesses.

| Role | Tier token | px (min→max) | Weight | Line height | Used by |
|------|-----------|--------------|--------|-------------|---------|
| Display | `text-hero` / `text-page-title` | 32→48 / 24→32 | 400 (Instrument Serif) | 1.1–1.2 | Modal title may use H3 tier; page titles out of primitive scope |
| Heading | `text-h3` | 16→18 | 600 | 1.2 | Modal title (`text-h3 font-semibold`), Card section headings |
| Label | `text-small` | 13→14 | 500 (medium) | 1.4 | Field/Input/Select/Textarea `<label>`, Tabs trigger text |
| Body | `text-body` | 14→16 | 400 | 1.5 | Button (md), Input/Select/Textarea control text, Card body, table cells |
| Caption | `text-caption` | 12→13 | 400 / 500 | 1.4 | Button (sm), Badge, Field hint/error, table secondary text |
| Micro | `text-micro` | 10→11 | 500–600, `uppercase tracking-wider` | 1.3 | Badge uppercase variant, count pills, metric-cell labels |

**Migration mapping (exact, additive — what each raw class becomes):**

| Primitive | Current raw class | Refreshed tier utility |
|-----------|-------------------|------------------------|
| Button md / lg | `text-sm` / `text-base` | `text-body` |
| Button sm | `text-xs` | `text-caption` |
| Input / Select / Textarea control | `text-sm` | `text-body` |
| Input / Select / Textarea `<label>` | `text-sm font-medium` | `text-small font-medium` |
| Input / Select / Textarea error/hint | `text-xs` | `text-caption` |
| Badge | `text-xs` | `text-caption` (status/strategy) · `text-micro uppercase tracking-wider` (DESIGN.md badge ladder) |
| Modal title | `text-lg font-semibold` | `text-h3 font-semibold` |
| Table cells (StrategyTable) | `text-sm` | `text-body`; numeric cells keep `font-metric` (Geist Mono `tabular-nums`) |

**Data/numeric rule (preserve):** every numeric value keeps `font-metric`
(Geist Mono) + `tabular-nums`. Fluid type must not break column alignment —
tabular-nums is load-bearing in the StrategyTable reshape.

## Color

Institutional light mode only (FROZEN — no dark mode for app surfaces; the
factsheet-v2 dark scope is untouched). 60/30/10 maps to DESIGN.md's restrained
palette: 1 accent + 3 semantic + neutrals. Color is rare and meaningful.

| Role | Token / value | Usage |
|------|---------------|-------|
| Dominant (60%) | `--color-page` #F8F9FA | page background, the canvas behind every primitive |
| Secondary (30%) | `--color-surface` #FFFFFF, `--color-border` #E2E8F0, `--color-surface-subtle` #FBFCFD | cards, modals, inputs, table surface, hairline dividers, sticky-header/first-column backing, nested/expanded-row surfaces |
| Accent (10%) | `--color-accent` #1B6B5A, hover `--color-accent-hover` #155A4B | see reserved-for list below |
| Destructive | `--color-negative` #DC2626 | Button `danger` variant, error text, `aria-invalid` border |
| Positive | `--color-positive` #15803D | gains, success/published status badges (existing) |
| Warning | `--color-warning` #B45309 | transient recoverable states only (existing) |
| Muted text | `--color-text-muted` #64748B | labels, captions, scroll-cue text, collapsed-column affordance, inactive tab text |
| Primary / secondary text | `--color-text-primary` #1A1A2E / `--color-text-secondary` #4A5568 | body, control text, active tab text |

**Accent (`#1B6B5A`) reserved for — explicit list (never "all interactive"):**
- Button `primary` fill (`bg-accent text-white`), hover `bg-accent-hover`
- Focus ring on every interactive primitive (`ring-accent` / `ring-accent/50`)
  and the input focus border (`--color-border-focus` = accent)
- The **active Tabs trigger** affordance: accent text + 2px accent bottom-border
  (`border-accent text-accent` / `text-text-primary` per consumer — see Tabs)
- Active/selected count pills (`bg-accent text-white`)
- Verified-via-exchange affordance (existing API-key check icon in StrategyTable)
- Sort-active and density-active control states in the table reshape (subtle
  accent text on the active control only)

**Accent is NOT used for:** card borders, table row hover (uses
`hover:bg-page/50`), secondary/ghost button rest state, breadcrumb links, body
links inside primitives, or any decorative fill. No gradients, no decorative
color (DESIGN.md anti-patterns).

**Honest-absence color rule (STATE-02):** below-threshold / empty states are a
neutral muted card (`bg-surface` + `text-text-muted`, NO `role="alert"`, NO
red/warning) — never an error color. Mirrors the existing `EmptyStateCard`
contract. Collapsed table columns degrade to a neutral detail affordance, never
fabricated zeros or demo numbers.

copy is mostly state/affordance labels, not feature CTAs.

| Empty state — watchlist | existing `<EmptyWatchlist>` (preserve) |

## Primitive Contracts (per deliverable)

> All interactive states list **default / hover / focus-visible / active /
> disabled** with AA-passing values. Focus indicator standard: a visible
> `focus-visible` ring in `--color-accent` (≥3:1 against adjacent surface,
> WCAG 2.4.7 + 1.4.11) — never `outline:none` without a replacement ring.

### Button (refresh — UI-01, NO public-prop change)
Public API unchanged: `variant: "primary" | "secondary" | "ghost" | "danger"`,
`size: "sm" | "md" | "lg"`, all native `<button>` attrs.

| Variant | default | hover | active `[default]` | disabled |
|---------|---------|-------|--------------------|----------|
| primary | `bg-accent text-white` | `bg-accent-hover` | `bg-accent-hover` (no transform) | `opacity-50 pointer-events-none` |
| secondary | `bg-surface text-text-primary border border-border` | `bg-page` | `bg-page` | `opacity-50 pointer-events-none` |
| ghost | `text-text-secondary` transparent | `bg-page` | `bg-page` | `opacity-50 pointer-events-none` |
| danger | `bg-negative text-white` | `bg-red-700` (existing) | `bg-red-700` | `opacity-50 pointer-events-none` |

- **focus-visible (all variants):** `focus-visible:ring-2 focus-visible:ring-accent/50 focus-visible:outline-none`. **Migrate `focus:` → `focus-visible:`** so keyboard focus shows the ring without it firing on mouse click (current code uses `focus:`; this is the one allowed behavioral nicety, no prop change).
- Radius `rounded-lg` (8px) — preserved. Type per migration map (`text-body` md, `text-caption` sm). Sizes keep `min-h-[44px]` on md/lg (target-size floor).
- Transition: `transition-colors` 150ms ease-out (DESIGN.md hover spec).

### Card (refresh — UI-01, NO public-prop change)
Public API unchanged: `padding: "sm" | "md" | "lg"`.
- `bg-surface border border-border shadow-card`, radius **`rounded-xl` (12px) preserved as-is** — note: DESIGN.md §Component Patterns specifies 8px (`lg`) for cards; the live primitive ships 12px (`rounded-xl`). This phase is **additive/CSS-only with no visual delta**, so the radius is NOT changed here (changing it is a visible restyle outside Phase-50 scope). **Flagged for Phase 52/53 reconciliation**, not this phase.
- No interactive states (static container). Padding `p-4/p-6/p-8` (sm/md/lg).

### Input / Textarea / Select (refresh — UI-01, NO public-prop change)
Public APIs unchanged (`label?`, `error?`, native attrs; Select also `options`).

| State | Treatment |
|-------|-----------|
| default | `border border-border bg-surface text-text-primary`, placeholder `text-text-muted`, radius `rounded-lg` |
| hover | (none beyond cursor) |
| focus-visible | `focus:border-border-focus focus:ring-2 focus:ring-accent/20 focus:outline-none` (accent border + soft ring — preserve) |
| active | n/a |
| error | `border-negative` + error message in `text-caption text-negative` |
| disabled | `disabled:bg-page disabled:text-text-muted` |

- Min height `min-h-[44px]` (target-size). Native `<select>` and the inline
  `label`/`error` markup retained — these stay native, NOT Radix (UI-04).
- Type migrates per the mapping table.

### Badge (refresh — UI-01, NO public-prop change)
Public API unchanged: `label`, `type: "strategy" | "status"`.
- Per-category / per-status color maps preserved verbatim (`bg-*/10 text-*`).
- Radius `rounded-md` for the soft-fill chip (existing) — note DESIGN.md badge
  ladder is `rounded-sm` 4px for the uppercase pill; the existing soft-fill
  Badge keeps `rounded-md`. No visual delta this phase. Type migrates `text-xs`
  → `text-caption`; the uppercase micro variant uses `text-micro uppercase
  tracking-wider` where a consumer already renders the uppercase form.
- Static; no interactive states.

### Modal (refresh — UI-01, NO public-prop change; stays native `<dialog>`)
Public API unchanged: `open`, `onClose`, `title`, `children`. **This IS the
Dialog primitive (UI-02 "Dialog") — native `<dialog>` + `showModal()`. Do NOT
swap to Radix Dialog (UI-04).**
- Surface `bg-surface rounded-xl border border-border shadow-elevated`,
  backdrop `backdrop:bg-black/40`. Title migrates `text-lg` → `text-h3
  font-semibold`. Close button `aria-label="Close"`, hover
  `text-text-muted → text-text-primary`, **add `focus-visible:ring-2
  focus-visible:ring-accent/50`** (current close button has no focus ring).
- Native `<dialog>` already provides focus trap, Esc-to-close, and the
  `::backdrop`. Keep.

### Skeleton (refresh — UI-01, NO public-prop change)
`SkeletonProps { className }`, plus `SkeletonText`, `SkeletonCard`.
- `animate-pulse rounded-md bg-border/60`, `aria-hidden`. The
  `prefers-reduced-motion` freeze for `.animate-pulse` already lives in
  `globals.css` (line 152) — **do not duplicate**; the Skeleton inherits it.
- No token-color change required; confirm `bg-border/60` is `--color-border`.

### Tabs (NEW — Radix-backed — UI-02 / UI-04)
**Structure (Radix anatomy):** `Tabs.Root` → `Tabs.List` (`role="tablist"`) →
`Tabs.Trigger` (`role="tab"`) × N → `Tabs.Content` (`role="tabpanel"`) × N.
Ship a thin styled wrapper (`src/components/ui/Tabs.tsx`) that re-exports
`Root/List/Trigger/Content` with the DESIGN.md visual contract pre-applied.

**Controlled + URL-driven support (load-bearing for the 3 consumers):**
- Expose `value` / `defaultValue` / `onValueChange` passthrough so `ProfileTabs`
  can keep its `?tab=` URL-derived controlled pattern (derive-each-render, no
  state snapshot — preserve the IN-06 fix) and `AdminTabs` its local-state
  pattern. **Do not regress** either consumer's existing controlled behavior.

**Keyboard / focus contract (Radix-provided, must verify in axe + ported tests):**
| Key | Behavior |
|-----|----------|
| Tab | focus enters the active trigger, then moves to the active panel (roving tabindex: only the active trigger is `tabIndex=0`) |
| ArrowRight / ArrowLeft | move between triggers (horizontal orientation), `loop` default true |
| Home / End | first / last trigger |

- **`activationMode`**: default `"automatic"` (selection follows focus) — matches
  the existing WatchlistTabs behavior (arrow also changes scope). Keep
  `automatic` for the 3 ports unless a consumer test asserts manual.
- `aria-selected` is managed by Radix on the active trigger; `aria-controls` /
  `aria-labelledby` wired between trigger↔panel automatically.

**Visual states (DESIGN.md tab pattern — underline tab strip):**
| State | Treatment |
|-------|-----------|
| default (inactive) | `text-text-muted border-b-2 border-transparent` |
| hover (inactive) | `hover:text-text-primary` (Admin) / `hover:text-text-secondary` (Profile) — keep each consumer's existing hover |
| active/selected | `text-accent border-accent` (Admin/Watchlist accent) **or** `text-text-primary border-accent` (Profile) — preserve each consumer's exact active treatment; the wrapper exposes a variant or `className` hook so the 1:1 port is byte-faithful |
| focus-visible | `focus-visible:ring-2 focus-visible:ring-accent focus-visible:outline-none` |
| disabled | `data-disabled` → `opacity-50 pointer-events-none` |

- Trigger type `text-small font-medium`, `px-4 py-2` (Admin) / `px-4 py-2.5`
  (Profile) — preserve each consumer's padding. Tablist `border-b border-border
  mb-6` (existing). Count pill: `bg-accent text-white text-micro rounded-full
  px-1.5 py-0.5` (existing AdminTabs pattern).

**Segmented variant (WatchlistTabs):** WatchlistTabs is a 2-option segmented
control (`inline-flex border rounded`, active `bg-accent/10 text-accent`), not
the underline strip. The wrapper supports both via a `variant: "underline" |
"segmented"` prop `[default]` so all 3 consumers map onto ONE primitive 1:1.

**Consumer mapping (1:1, tests ported in same PR — BP-03):**
| Consumer | Tabs | Variant | Active treatment | Notes |
|----------|------|---------|------------------|-------|
| AdminTabs | 5 (Intro Requests…Compute Jobs) | underline | `text-accent border-accent` + count pill | local `useState` controlled |
| ProfileTabs | 4–6 (role-gated) | underline | `text-text-primary border-accent` | `?tab=` URL controlled, derive-each-render |
| WatchlistTabs | 2 (All / My Watchlist) | segmented | `bg-accent/10 text-accent` + count badge | controlled via `scope`/`onScopeChange`; preserve `idBase`/`panelId` so the StrategyTable `role="tabpanel"` wiring stays intact |

### Table base (NEW — UI-02 / STATE-03 foundation)
A semantic, a11y-correct `<table>` wrapper + parts (`src/components/ui/Table.tsx`)
that the StrategyTable reshape (and 52/53 replicas) build on. Builds ON the
existing `ResponsiveTable` scroll wrapper — does NOT replace it.

**a11y wiring (mandatory):**
- Header cells `<th scope="col">` (and `scope="row"` for the sticky first
  column). A `<caption>` (visually-hidden ok) or an `aria-label`/`aria-labelledby`

- **Preserve the `ResponsiveTable` unique-`aria-label` landmark contract** — a

  `landmark-unique` and the SR landmark rotor stay clean. Do not regress.
- No outer border; header row bottom-border; rows hairline-separated; hover

### Field (NEW — UI-02)
Consolidates the `<label>` + control + hint + error wiring the wizard/connect
forms hand-wire today. `src/components/ui/Field.tsx`.

**a11y wiring (the whole point):**
- `<label htmlFor={id}>` ↔ control `id` (generate via `useId()` when not supplied).
- `aria-describedby` points at BOTH the hint id (when present) AND the error id
  (when present), space-joined.
- `aria-invalid={true}` on the control when `error` is set.
- Visual: label `text-small font-medium text-text-primary`; hint `text-caption
  text-text-muted`; error `text-caption text-negative`; `flex flex-col gap-1.5`.
- Field WRAPS a control (children or a passed control) — it does not duplicate
  the Input/Select/Textarea inline label/error (those keep their existing inline
  markup for back-compat; Field is the explicit wrapper for new/migrated forms).

### Breadcrumb (EXISTING — keep API stable, NAV phase 51 consumes it)
`BreadcrumbProps { items: { label, href? }[] }`. **Do NOT change the API.** May
migrate its `text-sm` → `text-small` and `hover:` → `focus-visible:` ring for

## StrategyTable Dense Reshape (STATE-03 — the template for 52/53)

Discovery `/discovery/{slug}` table, table view mode. Public surface, lowest
blast radius, axe-gated by `e2e/discovery-axe.spec.ts` (zero violations
required — the reshape MUST keep it green). Builds on the existing
`overflow-x-auto rounded-xl border` wrapper + `ResponsiveTable`.

**Four required behaviors + their exact contract:**

1. **Sticky header + sticky first column**
   - Header: `<thead>` cells `position: sticky; top: 0; z-index: 2;
     background: var(--color-surface)` so column labels persist on vertical
     scroll.
   - First column (Strategy name, + the leading star column when `userId`
     present): `position: sticky; left: 0; z-index: 1; background:
     var(--color-surface)` (header corner cell `z-index: 3`). A 1px right hairline
     (`border-r border-border`) on the sticky column so it reads as pinned during
     horizontal scroll. Backgrounds MUST be opaque (not transparent) or scrolled
     cells bleed through.

2. **Priority collapse of low-priority columns → reachable detail**
   - Priority order (high→low): **Strategy (name) > Return % > CAGR > Sharpe >
     Max DD** (always visible) ; **Volatility, 6 Month, AUM, Return spark,
     Underwater spark** collapse first at narrow widths.
   - Collapsed columns move into a **reachable per-row detail** (a `<details>`
     disclosure / "More" affordance in the row, or an expandable row) — keyboard-
     and SR-reachable. **Honest degradation:** collapsed cells show the SAME real
     values relocated, NEVER fabricated zeros, demo numbers, or `—` placeholders
     (no-invented-data — STATE-02). If a value is genuinely null it shows the
     existing honest null rendering, not a zero.
   - Actions column (Simulate Impact) stays reachable at every width.

3. **Visible scroll cue**
   - A persistent visual affordance when the table overflows horizontally —
     e.g. a right-edge gradient fade + a "Scroll for more columns →" hint in
     `text-caption text-text-muted`, shown only when `scrollWidth > clientWidth`.
   - Pairs with (does NOT replace) the existing `ResponsiveTable` `aria-label`
     scroll-affordance announcement — avoid double-announcing to SR (the visible
     cue is `aria-hidden`; the region name already announces the affordance).

4. **Working density control**
   - A segmented control ("Comfortable" / "Compact") that drives row height +
     cell padding via the existing `--row-h` / `--density-pad` tokens (44px
     default → 36px compact). Reuse the `data-density` mechanism already in
     `globals.css`; the active option uses the accent-text active state. The
     control has an accessible name ("Table density") and is keyboard-operable.
   - "Compact" must NOT clip text (fluid type + the truncation audit posture);
     density changes row height, not legibility.

**Preserve:** existing sort-on-header-click, pagination, watchlist scope wiring,
sparkline cells, `font-metric tabular-nums` alignment, the `role="tabpanel"`
wiring with WatchlistTabs.

## Motion (STATE-04 — native CSS + View Transitions only)

**Library:** none. `framer-motion` / `motion` / `@headlessui` are banned for
this milestone. Native CSS transitions + the View Transitions API only. All
motion is restrained and purposeful (DESIGN.md Motion: minimal-functional, no
decorative animation).

**Durations / easings (DESIGN.md Motion):**
| Token | Duration | Easing | Applied to |
|-------|----------|--------|-----------|
| micro | 50ms | — | — |
| short | 150ms | ease-out (enter) | hover states (buttons, links, table rows, tab triggers) — `transition-colors` |
| medium | 250ms | ease-in-out (move) | tab-panel switch, density toggle, disclosure open/close |
| long | 400ms | — | reserved; not used this phase |

> Tailwind-utility caveat (DESIGN.md): use `duration-300` for the 250ms tier in
> Tailwind classes — `duration-250` is not a valid Tailwind v4 token and silently
> drops. Use literal `250ms` only in raw CSS / inline style.

**View Transitions — opt-in, small purposeful set ONLY:**
- **Tab-panel switch** (Tabs Content swap) — a 250ms cross-fade via
  `startViewTransition` (or the CSS `view-transition-name` on the panel), so the
  panel change reads as a transition not a jump. Wrap the state update; fall back
  to an instant swap where `startViewTransition` is unsupported.
- **Density toggle** (StrategyTable row-height change) — optional 250ms ease for
  the row-height/padding change so density feels intentional, not a snap.
- View Transitions are NOT applied to: route changes (Phase 51 owns nav),
  charts, factsheet/composer islands (frozen), or anything decorative.

**`prefers-reduced-motion` (mandatory):**
- Extend the existing 3 `@media (prefers-reduced-motion: reduce)` blocks in
  `globals.css` — never bypass them. Under reduced-motion: View Transitions fall
