Build the falsifiable oracle, and cut the wire that makes the existing one unfalsifiable. This is the
phase's spine, not a chore.

Purpose: `SEAMCORE-07` / ROADMAP SC3. Ten simultaneous semantic mutations to the seam core produced
`8859 passed | 287 skipped` — byte-identical to the number Phase 140 certified as "5/5 success
criteria mutation-tested". **The mechanism is a two-layer self-referential oracle and this plan
closes BOTH layers.** Closing only one leaves the phase able to report 55/55 while every behavioural
breaker test still runs against a double that cannot disagree with production.

> **Layer 1 — the DOUBLE.** `fakeRatelimitFor(store, opts.limiter.tokens)` where `opts.limiter.tokens`
> is whatever `Ratelimit.slidingWindow(BREAKER_FAILURE_THRESHOLD, …)` was called with. The fake
> harvests its threshold from production's own constructor argument, so it cannot disagree with
> production, ever, by construction. Raise `BREAKER_FAILURE_THRESHOLD` to 30 and the fake silently
> raises with it: the trip-at-threshold test still passes, having proved nothing.
> **Layer 2 — the ASSERTION.** Every loop bound and expectation is `mod.BREAKER_FAILURE_THRESHOLD` or
> `mod.SEAM_BUDGETS.<key>.timeoutMs`. The assertion reads its expected value out of the table under
> test. **0 of 13 budgets and 5 of 6 breaker constants are unpinned.**

Output: a pin file whose every expectation is a hand-typed literal; a fake whose tuning values are
hand-typed in the fake and pinned literal-against-literal to production's; a row-contents pin for
`SEAM_ROUTE_BUDGETS`; and all of it registered so none of it can be silently deleted.

⚠️ **Keep the existing plumbing assertions.** `expect(timeoutSpy).toHaveBeenCalledWith(mod.SEAM_BUDGETS.bridge.timeoutMs)`
is a correct PLUMBING test — it proves the table reaches `AbortSignal.timeout`. It is simply not a
VALUE test. Add the value assertion; delete neither. They are different tests and removing the
plumbing one would be TRAP-9 (relaxing an assertion silently deletes coverage).

📐 **Task-count deviation, stated rather than hidden.** This plan carries three tasks, but Task 1 does
double duty (two pin files) because Task 2 could not be dropped and this phase's wave structure is
fixed at twelve with no room for a new wave-2 sibling. The alternative — leaving Layer 1 unfixed —
is the phase's headline defect, so the density is the right trade. If Task 1 runs long, split its
commit, not its scope.
