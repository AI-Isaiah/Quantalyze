## Falsifiability Ledger

> **Coverage answers "is it verified?". This section answers "CAN the verification FAIL?"**

**Rules (binding).** The mutation is a **semantic** edit to PRODUCTION source — a value, a boundary, a
branch direction. **Never a syntax error. Never a test edit.** Each row must be OBSERVED red
first-hand and reverted, with the failing test name and assertion text pasted. **"Asserted — not
observed" is not acceptable.** Where a class has more than one member, **mutate the SECOND** — that is
what detects an instance-fix masquerading as a class-fix.

*Why this is not ceremony:* Phase 140 certified "5/5 mutation-tested" while **ten simultaneous
semantic mutations** produced a byte-identical `8859 passed | 287 skipped`.
