<objective>
Make the wizard classifier read the **code the wire already carries**, and stop the breaker trip at
finalize from rendering as an unknown-code dead end.

Purpose: obligation `TS-35`; requirements `SEAMUX-01` (the classifier half), `SEAMUX-02`,
and the `SubmitStep` half of `SEAMUX-08`.

Two independent defects, one file each, both of which make a real outage read as a mystery:

1. **`SubmitStep.tsx`'s `KNOWN_FINALIZE_CODES` is a five-member hand-written set that omits the two
   codes a breaker trip actually produces.** `finalize-wizard` emits `code: "CIRCUIT_OPEN"`; the set
   holds `KEY_SCOPE_BROADENED`, `KEY_NETWORK_TIMEOUT`, `GATE_DRAFT_GONE`, `GUARD_BLOCKED`,
   `COMPOSITE_MEMBERSHIP_UNKNOWN`. So `surfaced` becomes `"UNKNOWN"`, which renders *"Our team has
   been notified"* **and** emits `wizard_error { code: "UNKNOWN" }`. **One line fails SC1, SC2 and SC6
   simultaneously** (correction C-9). `CIRCUIT_OPEN` is also not a `WizardErrorCode` at all —
   `grep -rn "CIRCUIT_OPEN" src/lib/wizardErrors.ts` → 0 hits — while two routes emit it.

2. **`classifyKeyValidationError` is a substring cascade over the human string** and derives BOTH the
   wizard code and the returned HTTP status from it, discarding the upstream status entirely. Phase
   140.1.2 made all seven venue-transient sites emit a machine `code` and a `recoverable` flag on the
   wire. Nothing reads them.

## ⚠️ TS-35 under-counts by one, and the third member fails SILENTLY (correction C-6)

Replaying the cascade's real predicates over the committed fixture's own bytes:

`DDOS_PROTECTION`'s detail ends *"Check region / IP allowlist."* and the cascade's fifth branch tests
`includes("ip") && includes("allow")`. **A venue WAF block is rendered to the user as a problem with
their key.** It is invisible to an audit asking "does it fall through to UNKNOWN?", which is why the
row missed it. **Bind the parity test to the fixture's OUTCOMES, never to UNKNOWN-ness.**

**How the machine code reaches the classifier — decided here so it is not re-derived at execution.**

`classifyKeyValidationError` is called from inside a catch arm at
`src/app/api/strategies/create-with-key/route.ts` and `src/app/api/strategies/composite/add-key/route.ts`,
where the only value in hand is the thrown `Error`. Sixteen route test files `vi.mock` the seam
clients wholesale, so **anything a catch arm reaches through a mocked module evaluates to `undefined`
and throws from inside the catch.** Therefore:

- `analytics-client.ts` attaches the extracted seam code to the Error it throws, as a **plain own
  data property** (not a subclass). A data property survives every wholesale module mock, because it
  is read with `typeof`, not with `instanceof`.
- `classifyKeyValidationError` gains a branch that reads that property with a
  `typeof … === "string"` guard and looks it up in a **hand-typed `Record`** mapping wire code →
  `{ code, status }`.

**Do NOT add a class to `src/lib/seam-errors.ts`.** Its exported surface is pinned to a hand-typed
TWO-member `EXPECTED_EXPORTS` set in `seam-errors.purity.test.ts`; a third class means editing that
set in the same commit, and it buys nothing a data property does not.

**Branch ORDER inside `classifyKeyValidationError` — load-bearing:**
```
1. err instanceof CircuitOpenError        (EXISTING — must stay first, must stay a type check)
2. the code lookup                        (NEW — a Record lookup, NOT a substring test)
3. the substring cascade                  (EXISTING — KEEP as the fallback)
4. return { code: "UNKNOWN", status: 500 } (EXISTING)
```
**Do not delete the cascade.** TS-35 is explicit: keep it until every emitter carries a code, or the
class re-opens from the other side.

**The new `WizardErrorCode` members and their `actions`.** `actions` drives `recoverable` via
`RECOVERABLE_ACTIONS = new Set(["clear_and_retry", "try_another_key"])` in `src/lib/envelope.ts`, so
**`actions` is a BEHAVIOUR decision, not a copy decision.** Add `KEY_EXCHANGE_UNAVAILABLE` and
`KEY_VENUE_TRANSIENT` and give `CIRCUIT_OPEN` a home. Whether `CIRCUIT_OPEN` becomes its own union
member or is aliased at the boundary onto the existing, correctly-worded `SERVICE_UNAVAILABLE_RETRY`
is the executor's call — but it must be ONE decision applied at every emitter, recorded in the
SUMMARY, and it must not create two codes with the same meaning.

⚠️ **W-4 RIDER — read before consuming `recoverable`.** Its `unknown ⇒ true` polarity is correct
**only while it is a RENDER hint**. `PERMANENT_VALIDATION_ERROR_CODES` is an allow-list OF PERMANENT,
so non-membership means "not known to be permanent", and the harm asymmetry (a wrong `true` costs one
pointless click; a wrong `false` IS the dead end) points at `true`. **If any code here is wired into
an automated retry loop the polarity must be re-derived. Retry is Phase 141. Do not wire it.**
