<objective>
Make every seam call site observe the **HTTP outcome**, not just transport rejection.

Purpose: requirement `SEAMUX-05` (ROADMAP SC3), plus one `SEAMUX-04` copy lie that lives in the same
block and cannot honestly be left behind.

Three defects, each with its fix shape already present **in the same file or one directory away**:

1. **`ApiKeyManager.tsx` background sync (B-06).** `fetch("/api/keys/sync", {…}).catch((err) => {…})`
   with a comment claiming it handles failure. `.catch()` fires only on **transport** rejection — a
   401, 403, 500 or 503 is completely invisible. The comment asserts what the code does not do.
2. **`ApiKeyManager.tsx` explicit sync (B-15).** `handleSyncTrades` DOES check `res.ok`, but never
   reads the body, so an **unrecognised 200 sets `syncStatus("computing")` with no backstop** — the
   UI polls for a job that was never enqueued. This is SC3's named case verbatim.
3. **`AllocatorMatchQueue.tsx` `handleRecompute` (B-05 / B-17).** `const body = await res.json();`
   with **no `res.ok` and no `res.status`** — a breaker 503 falls to the `else` and calls `load()`, so
   **a trip reads to an admin as a completed recompute.** Its own sibling `handleDecision`, twenty
   lines below in the same file, does `if (!res.ok) throw new Error(await res.text());`.

**Plus one copy lie in the same block (C-9):** `ApiKeyManager`'s non-JSON `!res.ok` arm throws
*"Analytics service unavailable. Ensure `SUPABASE_SERVICE_ROLE_KEY` is configured."* — user-facing copy
naming an internal environment variable. That is a DESIGN.md voice violation and an
information-disclosure smell, and it sits inside the exact arm this plan is rewriting. Fixing it here
is not scope creep; leaving it would mean touching the block twice.

⚠️ **`WeightOptimizerSection.tsx` (B-13) is in this plan and NOT in `140.3-07` deliberately.** That file
is simultaneously the **locked fix-shape source** plan `140.3-07` copies (`setResult(null)`) and a
defect of its own (`} catch { setStatus("error"); }` — the body is never read and the status is never
read). **TRAP-8: the two must be sequenced, and the invalidation line must survive this plan
untouched.** An acceptance criterion asserts it.
</objective>
