## 0. Executive answer

The poll pin is **not** an instance. It is the visible member of a class of **21 source-scanning
guards**, of which **exactly one** — `seam-ssr-exposure.pin.test.ts` — asserts its own needle
against a hand-written positive and a hand-written negative.

Three findings dominate:

1. **The `fetch(` needle class is real and has two members**, and only one of them is written
   correctly. `seam-poll-disjointness.pin.test.ts:147` uses `/\bfetch\s*\(/`;
   `critical-regressions.test.ts:141` uses `/(^|[^a-zA-Z0-9_])fetch\s*\(/m` **and carries an

   the second is paired with a *positive* assertion (`resilientFetch(` must be present) that

   call edge.

2. **BOTH of the poll pin's negative predicates are inert against the hazard's real shape**, not
   just the `fetch(` one. Its second needle (`SEAM_IMPORT_EDGE`) looks for a *module import* of a
   seam client — an edge that a browser module structurally never uses, because a browser reaches
   the seam over HTTP to `/api/…`. Measured: **0** of the `"use client"` modules in this repo carry
   a seam import edge, and all three roster modules are `"use client"`.

3. **The stale-count class is real and has at least 2 more live members**, both in the same shape
   as the `53`: a number written in prose that nothing asserts, sitting next to a guard that
   asserts a different number correctly.

**Anatomy — four assertions, two per polarity, and each pair has a job:**

| Assertion | Polarity | Job |

| 3 | negative, **prose mention** | the needle does not cry wolf on a docblock (a guard that cries wolf gets deleted) |
| 4 | negative, **near-miss subject** (`seam-errors` ≠ a seam client) | the needle is not so wide it matches a neighbour |

| Slot | Literal | Must be |

The near-miss slot is the important one: it is what forces the needle to be **the seam route
