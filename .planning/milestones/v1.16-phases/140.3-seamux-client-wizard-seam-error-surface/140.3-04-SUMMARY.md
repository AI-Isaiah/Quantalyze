# Phase 140.3 Plan 04: Seam breaker copy — one source of truth Summary

Ten independent production declarations of the seam breaker sentence collapsed onto one
dependency-free, browser-bundle-safe leaf, with a pin file that makes drift between any two
production copies fail a test — while leaving all twelve independent test oracles untouched.

## What shipped

`src/lib/seam-copy.ts` holds the single declaration of
`"The analytics service is temporarily unavailable. Please try again in a moment."` — zero imports,
zero env reads, zero module-load side effects. All ten production emitters import it. Nine keep the
identifier `CIRCUIT_OPEN_COPY` (so the diff at those sites is import-add plus declaration-delete,
with zero churn at the emit expression); `src/lib/process-key-client.ts` keeps its
`CIRCUIT_OPEN_HUMAN_MESSAGE` binding via `import { CIRCUIT_OPEN_COPY as CIRCUIT_OPEN_HUMAN_MESSAGE }`.

Two guards ship with it:

- **`seam-copy.purity.test.ts`** — mirrors `seam-discriminator.purity.test.ts`: comment-stripped and
  `^`-anchored no-import / no-re-export / no-require / no-`process.env` assertions, a hand-typed
  `EXPECTED_EXPORTS` **set** equality (a length check passes a rename), and a `typeof === "string"`
  guard that keeps the copy from becoming a function — which is how "static by design" dies.
- **`seam-copy.pin.test.ts`** — two describes. (1) The expected sentence is typed **in the test file**
  and the leaf's export is pinned to it, plus a banned-infrastructure-token assertion (`http`,
  `railway`, `circuit`, `breaker`, `5xx`, `upstream`) that outlives a byte pin someone updates
  alongside a reword. (2) A comment-stripped, repo-wide scan of every non-test `.ts`/`.tsx` under
  `src/` asserting **zero** re-declare the sentence and **exactly ten** import the leaf, with `10`
  hand-typed rather than read from the discovered list's own length.

## The twelve test literals: untouched, and why

CONTEXT's locked text calls them *"a self-referential oracle."* **Correction C-1 inverts that, and
C-1 governs.** Nothing was exported anywhere (**0 hits**, measured above), so those twelve literals
*cannot* have been reads of the module under test — they are hand-typed, which is exactly correct
oracle independence, and `src/app/api/keys/sync/route.seam.test.ts` says so out loud: *"Duplicated
deliberately: a test that imported the constant from the client could not detect it changing."*

Consolidating them onto the new leaf would have converted twelve independent oracles into one
self-referential oracle — **manufacturing** the defect the locked text believed already existed. That
is TRAP-9, which is binding. `git diff --name-only` for this plan contains **zero** `.test.ts` paths
other than the two Task 1 created. The pin file's scan excludes every `.test.` file by construction,
with a comment saying why, so no future editor "tidies" the fence away.

**The counting note is load-bearing and is now recorded in the ledger.** Nine production files bind
`CIRCUIT_OPEN_COPY` and the tenth binds `CIRCUIT_OPEN_HUMAN_MESSAGE`; on the test side six declare a
named const and **six inline the literal in the assertion**. A symbol grep therefore finds **9 of 10**
and **6 of 12** and reports success — the exact under-delivery shape this programme keeps hitting.
Every enumeration in this plan grepped the sentence.
