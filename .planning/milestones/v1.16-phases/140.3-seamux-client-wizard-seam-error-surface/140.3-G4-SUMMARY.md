# Phase 140.3 Plan G4: Key-Verification Route Error-Code Surface (SEAMUX-03) Summary

Every error arm the PUBLIC teaser `/api/verify-strategy` and `/api/keys/validate-and-encrypt` themselves emit now carries a stable top-level machine `code` alongside `error`, so a client discriminates the fault without sniffing prose. Both routes carried ZERO coded arms at HEAD (140.3-VERIFICATION §3.1: 0/11 and 0/10); they now carry 9 and 11 respectively, with per-arm `body.code` test assertions that redden if any single code is dropped. Additive `code:` only — no status, sentence, header, or body key order changed anywhere.
