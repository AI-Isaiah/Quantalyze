# Phase 140.3 Plan G9: strategy-review SEAMUX-03 Machine Codes Summary

Every error arm of `/api/admin/strategy-review` — the tenth seam-importing
production route, the one the 140.3-VERIFICATION nine-route list MISSED — now
emits a top-level machine `code`, with two new tokens each used uniformly across
its fact class and a source-scan fence that reddens if any future non-2xx arm
ships without one.

## Scope-honesty note (required by the gap directive)

This route's ONLY seam import is `scrubSeamError` from `@/lib/seam-redaction`
(route.ts:17). It makes NO analytics-service call — its error arms are Supabase
reads and publish-gate refusals, not upstream calls. It is in the SEAMUX-03
class **by the class definition** (a seam-importing production route), and the
requirement's words are "every seam-touching route … on every arm". **Every arm
enumerated below is a reachable admin-facing route arm** (behind CSRF +
`getUser` + `isAdminUser` + a validated POST body); none was force-coded onto a
dead arm, and none was skipped as "not-seam". No unreachable arm was found.

## Deviations from Plan

### Plan enumeration correction (recorded, not a code error)

The plan's known-floor listed the error arms it expected but its POST-only
plan-time scan **missed three arms** that a whole-file read surfaced. All three
are genuine, reachable admin route arms and were coded per the vocabulary rules
(plan directive: "Anything beyond these found during enumeration gets mapped per
the vocabulary rules and recorded"):

**1. [Rule 2 - completeness] 409 status-pin 0-row arm (route.ts:489)**
- **Found during:** Task 1 whole-file enumeration
- **Issue:** the plan named "four 409s" but there are FIVE; the status-pinning
  UPDATE's 0-row branch ("Strategy is no longer awaiting review.") is a fifth.
- **Mapping:** REVIEW_RECHECK_FAILED — it is exactly the re-check fact class
  (state changed during review; publish refused), so it takes the same token.

**2 & 3. [Rule 2 - completeness] Two 500 "Update failed" write faults (route.ts:479, :501)**
- **Found during:** Task 1 whole-file enumeration
- **Issue:** the approve-path and reject-path publish-UPDATE error arms were
  outside the plan's floor.
- **Mapping:** UNKNOWN — a write fault is neither a source READ we depend on
  (REVIEW_SOURCE_READ_FAILED) nor a re-check state move (REVIEW_RECHECK_FAILED);
  it is an unclassified server fault, so it takes the union's terminal token,
  matching the `admin/match/eval` sibling's 500 (`code: "UNKNOWN"`). No new
  token minted, per the interfaces rule ("maps to the nearest of the above or
  UNKNOWN, with the choice argued").

No other deviation. No packages installed (T-140.3-G9-SC honored).
