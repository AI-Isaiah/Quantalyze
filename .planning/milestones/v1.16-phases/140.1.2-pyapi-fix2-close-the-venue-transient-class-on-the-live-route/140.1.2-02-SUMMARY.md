### Oracle shapes

- **Fixed windows (3 sites):** `== "3600"`, the string literal typed in the test file, never imported.
- **Dynamic (match):** two pins, not one. **(a) Consistency** — parse `N` out of the body's `"retry after {N}s"` and assert `header == str(N)`; a header that disagrees with the sentence beside it is worse than either alone. **(b) Tight band** — `27 < int(header) <= 30` with `30` typed as a literal. A bare `0 < x <= window` was **survivor #5** in the 140.1.1 review: it passes for any window, so widening 30s to an hour ships green under it.
- **No clamp.** `max(1, wait_s)` was explicitly rejected: `int()` truncation near expiry yields 0, and `Retry-After: 0` ("retry now") is RFC-valid and is exactly what the body says. Clamping would make header and body disagree — the very thing pin (a) exists to prevent.
