# 140.4 — declared deviations

## DEV-140.4-01 — `.gitignore` un-ignored `.planning/` mid-phase

**Flagged by:** `140.4-VERIFICATION.md`, as an undeclared deviation against CONTEXT §8, in no
plan's `files_modified`.

**The flag is correct and the provenance is not a plan.** This was a **founder-directed
change made by the orchestrator**, not by any executor, which is exactly why it appears in no
plan's fence. Commit `885e6023`, landed separately as PR #647 on founder instruction:

> *"1. Triage the 12 — confirm each is a fixture, scrub anything that isn't 2. Add allowlist
> entries to .gitleaks.toml (same pattern as the PYAPI canaries) 3. Drop .planning/ from
> .gitignore, set commit_docs: true 4. Commit the 2171 files … do it"*

**Why it was needed, since CONTEXT §8 predates the reason.** `.planning/` had been gitignored
since 2026-04-17 (`16f1ab17`) for gstack, whose model treats planning as per-developer
scratch. GSD's model is the opposite — `planning.commit_docs` defaults to `true` and the
ledgers are project history. Keeping the gstack line cost three things concretely:

1. **Executor worktrees could not read their own PLAN.md**, so waves ran sequentially and
   lost their entire purpose. This phase is the one that fixed it — waves 2–4 ran in
   worktrees.
2. **The ledgers had no git backup.** A bad `sed` truncated `ROADMAP.md` with nothing to
   restore from, and `git checkout` silently deletes untracked ledgers.
3. **We inherited upstream bug classes that only exist in the gitignored configuration**
   (`gsd-build/get-shit-done#2838` destroys `SUMMARY.md` files exactly this way).

**Security note carried forward.** The key-shaped strings in these markdowns were triaged and
confirmed to be redaction-test fixtures; they are allowlisted **by path** in `.gitleaks.toml`.
⚠️ Path-based allowlisting means **a real credential pasted into a future plan will NOT be
caught by the secret gate.** That residual risk is accepted and belongs to whoever writes
plans, not to this phase.

**Status:** intentional, founder-approved, out of every plan's fence by construction. Not a
gap. Recorded here so the code reviewer and the end-of-milestone red team do not re-flag it.
