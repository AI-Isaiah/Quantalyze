### 4. `src/lib/resilient-fetch.ts` — D-01 `Retry-After` fail-fast (SC-C, SC-C′)

**Analog: `readDependencyBody`, in the same file** (`:1789-1808`). Copy the capability-guard shape *and* its docblock reasoning:

/**
 * The `clone` capability check is not defensive decoration: `SeamResponse` is

async function readDependencyBody(res: Response): Promise<unknown> {

## Anti-patterns for THIS phase (each one is a real, named failure mode)

1. **A new census / guard / regex file.** D-09 and D-06 both extend existing mechanisms. A parallel file is reproducing the exact defect the phase exists to fix.
2. **Adding the registry to `SEAM_CITATION_SURFACE` and calling D-06 done.** Zero offences today — the rot is in string literals.
3. **`res.headers.get(...)` with no capability check.** Throws inside the classification window on the repo's bare-literal fixtures; the real upstream error is replaced by a bookkeeping one *and counted as Railway degradation*.
4. **A flat route-level `(1 + retries)` on `storeMs`.** `retries` is a leg property; multi-leg branches have no single value.
5. **`STORE_COMMANDS_PER_SEAM_CALL.failing → 6`.** Double-charges non-retried legs; false-REDs `finalize-wizard` composite at 405 000 ms.
6. **Deleting `SEAM_BUDGETS[*].retries` after D-08.** SC-4b and `EXPECTED_RETRIES` both read it.
7. **Interpolating `requestInit`, `path`, `res.headers` or the body into a log line.** SC-M′; the JWT incident is already on the record.
8. **`vi.stubGlobal("fetch")` without teardown.** The repo's CI-only Node-22 red. Use `vi.spyOn` + `restoreAllMocks`, as the harness already does.
9. **Moving `retriesOverride` validation below the classification window** (D-08). `SeamConfigError` exists precisely to keep config faults out of the breaker counter.
10. **Writing D-07 site #4 or D-10's comment before D-08 lands.** Both describe a post-D-08 world; written early they become false a second time.
11. **A migration.** This phase writes zero DDL. If a plan proposes one, that is scope creep.
12. **A Python production edit.** D-03's fence. D-04/D-05/D-16 *read* Python and *write* TypeScript/markdown.
