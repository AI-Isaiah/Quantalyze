### Task 1 — the 18 past-EOF citations, symbol-anchored

**15 of the 18 are ONE EVENT, not fifteen rots.** `analytics_runner.py` and `simulator_scoring.py` both **shrank** under their citers in a refactor, so every coordinate into them fell off the end simultaneously (12 → `analytics_runner.py`, 3 → `simulator_scoring.py`). The remaining 3 are independent. Each citation is now anchored on a **symbol** — `run_csv_strategy_analytics`'s `csv_status`, `_denominator_config`, the `HARD-04` lift, `_cumulative_curve`, `PARTIAL_HISTORY_THRESHOLD`, `validate_key_permissions`'s branch condition, a `data-testid` literal, a test name — because a name survives its target being edited by someone who never opens the citer.

**Two findings from doing it:**

1. ⭐ **`ScenarioCompareTable.all-columns.test.tsx` was never a citation rot at all.** prettier had **wrapped** the coordinate across the comment's line break, splitting the component's name in two. A line-based scanner read only the tail fragment, resolved it by basename to the unrelated shared table primitive under `src/components/ui/`, and reported a past-EOF **against a file this test never mentions**. The line number had *also* drifted inside the file it actually meant. Both defects die with the coordinate. **A citation guard must be told that its own input can be line-wrapped** — DEF-16-2's mirror image, and a design constraint for 140.5-08.

2. ⭐ **The first draft of the correction re-created the defect it documents.** It quoted the old coordinate verbatim while explaining it; the census promptly re-reported the very row the note claims to have fixed (`PAST-EOF: 1`). **A correction's own prose is scanner input.** Every note in this plan now paraphrases the discredited text and says so at the site.

## ⚠️ Three acceptance criteria that would have failed on CORRECT code

All three are DEF-16-2 one level up, and all three are 140.5-08 design constraints.

1. **`"5 minutes"` absent AND `"15 minutes"` present, in the same file** — *unsatisfiable as written*. The false needle is a **substring** of the true sentence. A left boundary (`(?<![0-9])`) is required. A guard that greps durations without boundaries will red a corrected tree.
2. **`"sixteen"` absent from `seam-budgets.invariant.test.ts`** — the surviving hit is inside a paragraph the file **explicitly quotes and marks "IS NOW FALSE"**. Editing a marked quotation to satisfy a grep falsifies a historical record. 3. **A correction that quotes the false sentence re-seeds the needle** — measured live in Task 1 (`PAST-EOF: 1` from the fix's own note). Every note here paraphrases.
