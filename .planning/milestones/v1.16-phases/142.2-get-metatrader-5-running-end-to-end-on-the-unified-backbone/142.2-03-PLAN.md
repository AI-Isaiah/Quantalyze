class-fix site ledgers are the defect, the path count itself must be honest: eight, not five.

`SERIES_COMPLETENESS_VALUES` here, because the derive-seam assert (plan 05) validates against it.

**Exemption rule (the honest accounting — never silent):** the three empty-series early returns
(:292, :306, :530) yield < 2 interpretable rows, and `run_derive_broker_dailies_job` short-circuits
on `int(returns.notna().sum()) < 2` at job_worker.py:4340 BEFORE plan 05's persist-seam assert —
an empty series is never persisted, so an absent verdict there is unreachable at the seam. Stamping
them would FABRICATE a verdict about inputs that produced no series (the same fabrication Pitfall 6
forbids for the backfill). And the exemption is fail-CLOSED even if it rots: were a future refactor
to remove the :4340 short-circuit, the plan-05 seam assert refuses the unverdicted persist loudly.
Each of the three returns gets an inline comment stating exactly this, naming job_worker.py:4340.

have ever had. sFOX with interior NAV holes → newly refused (sFOX dormant, blast radius zero —

not tighten here).
