## Why this snapshot exists

Opening v1.17 mid-flight rewrites the live planning ledgers: `state.milestone-switch` zeroes
`progress.*` and rewrites `## Current Position`, and the roadmapper rewrites `ROADMAP.md` and the
`REQUIREMENTS.md` traceability table. For a *completed* milestone that is fine — the record is already
in `MILESTONES.md`. For a *parked* one it would destroy the working state needed to resume.

Every file here was taken from **git**, not the working tree, because the roadmapper was actively
writing those files at the time. Each is therefore provably the committed pre-switch content.
