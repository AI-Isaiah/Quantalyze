<objective>
Wire the per-key channel into the composer: build per-key projection units from the Plan-01 payload via the Plan-02 sibling builder, render the gated "Data sources" toggle control (DSRC-02), thread the ephemeral toggle into `projectionState.selected` so the frozen engine honestly recomputes the curve + KPIs on exclusion (DSRC-03), and render the honest-absence shells (all-excluded → EmptyStateCard; gate-not-satisfied → InfoBanner).

Purpose: This is the user-facing deliverable. DSRC-03 honesty is the load-bearing requirement — exclusion must move the actual KPI/curve numbers, not just dim a row. The recompute is engine-native: setting `selected[api_key_id]=false` drops the key from `activeStrategies` and the per-day weight mass; the engine renormalizes over the remaining selected set (`r / activeWeightSum`). NO manual renormalization (Pitfall 1). Toggle state is ephemeral, mirroring R4 `leverageByRef` — never persisted, never in the commit diff (Pitfall 5).
Output: The composer renders + recomputes per-source toggles; the load-bearing honesty test proves KPIs move.
</objective>
