# Phase 37 — UI Design Contract

> Visual and interaction contract for the **per-data-source toggle** inside the
> own-book ScenarioComposer. Generated by gsd-ui-researcher, verified by
> gsd-ui-checker. Grounds every token in DESIGN.md + the existing composer
> conventions — invents no new tokens.

This phase adds **one new affordance** to an existing, heavily-pinned surface:
a compact **"Data sources"** control near the top of the composer (book mode
only) that lets the allocator include/exclude each connected exchange `api_key`
from the projection, with **honest instant recompute** of the curve + every KPI.
The contract below is deliberately narrow: it reuses the entry-mode segmented
recipe, the InfoBanner "honest note" shell, the EmptyStateCard "honest absence"
shell, and the fail-loud `role="alert"` posture already shipped for
weight/leverage what-ifs. **Nothing here repoints or restyles an existing
element.**

## Color

60/30/10 split per DESIGN.md. This control is overwhelmingly neutral; accent is
**reserved for the included/active state only**, mirroring the entry-mode pill
recipe (`border-accent text-accent`, **no** accent fill).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-page` #F8F9FA / `--color-surface` #FFFFFF | the composer canvas + the control's surface |
| Secondary (30%) | `--color-border` #E2E8F0, `--color-text-secondary` #4A5568, `--color-text-muted` #64748B | row borders, hairline dividers, row labels, masked-key text, the section heading |
| Accent (10%) | `--color-accent` #1B6B5A | **included-state border + label on a source row's toggle**, and the toggle's focus ring (`focus-visible:ring-accent/50`). Nothing else. |
| Destructive | `--color-negative` #DC2626 | **not used** by this control. Excluding a source is a normal modeling action, not destructive or an error. |

**Accent reserved for:** (1) the **included** state of a per-source toggle
(border + label, no fill), and (2) the keyboard focus ring on toggles. The
**excluded** state is neutral (`border-border text-text-secondary`), never red.
The fallback honest-note InfoBanner uses the calm `border-accent/30 bg-accent/5`
recipe (informational, **not** a red error and **not** an amber warning).

> Honesty-color rule (load-bearing): the all-excluded empty state and the
> per-key-incomplete fallback note are **honest absence**, not errors. Both use
> neutral/calm tokens with **no** `role="alert"` and **no** `--color-negative` /
> `--color-warning`. The only `role="alert"` surface this phase touches is the
> pre-existing clamp/guard inline message, whose posture is unchanged.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Control heading | **Data sources** (12px uppercase caption label above the rows) |
| Per-source row label (with nickname) | `{Exchange} — {nickname}` — e.g. **Binance — Main**, **OKX — Funding desk** |
| Per-source row label (no nickname) | `{Exchange} — {masked key}` — e.g. **Bybit — ••••3F9A** (masked tail in Geist Mono, muted). Never show the full key. |
| Toggle accessible name | `Include {Exchange} — {label} in projection` (per-row `aria-label` on the toggle control) |
| Toggle states | **Included** (default, accent outline) / **Excluded** (neutral outline). No "On/Off" word badge in v1 — the accent outline + `aria-pressed`/`aria-checked` carry state. |
| Control helper (optional, one line under heading) | **Toggle a source off to model the book without it. Resets on reload.** (12px `text-text-muted`; states ephemerality so no one expects it saved) |
| Empty state heading (ALL sources excluded) | **Select at least one data source** |
| Empty state body (ALL sources excluded) | **Every data source is excluded — there's nothing to project. Re-include a source to see the curve and metrics.** |
| Fallback note (per-key dailies incomplete — control HIDDEN) | **Per-source modeling needs per-key history.** Body: **One or more connected keys don't have a per-key return series yet, so this projection blends your whole book. Per-source toggles appear once every key has its own history.** |
| Error / clamp inline message (pre-existing posture, reused) | Matches the shipped weight/leverage clamp copy verbatim in form — e.g. **"Weight clamped to 1 — the maximum allocation is 100% of portfolio AUM."** This phase adds **no new error string**; toggling never errors. |
| Destructive confirmation | **none** — there are no destructive actions in this phase. Excluding the last source does **not** hard-block and does **not** confirm; it falls through to the honest empty state. Toggle state is ephemeral and never written to the saved draft, so there is no diff to confirm. |

**Copy rules:**
- Em-dash separator between exchange and label (`Binance — Main`), matching the
  PROJECTED pill's em-dash and the composer's existing voice.
- "Excluded" / "included", never "disabled"/"enabled" or "hidden"/"shown" —
  the verbs must read as *modeling the blend*, never *cosmetically hiding a row*
  (DSRC-03 honesty: exclusion truly recomputes).
- The fallback note is one calm sentence + a "why/when" clause. Never the word
  "error", never red.

## Component Inventory & Interaction Contract

The control is built entirely from existing primitives + recipes. No new
primitive is introduced.

### 1. "Data sources" control (book mode only)

- **Placement:** in the composer header region, **directly below the entry-mode
  row** (`scenario-entry-mode` radiogroup, ~line 1677) and **above** the
  KpiStrip / EquityChart block. Reuses the header's `flex-col` rhythm with a
  `md` (16px) gap. `data-testid="scenario-data-sources"`.
- **Gate:** rendered **only when** `entryMode === "book"` **AND** the Phase-36
  D3 per-key eligibility gate is satisfied (every active key has a per-key
  series covering the window). Absent in blank mode entirely (no live keys).
- **Structure:** a 12px uppercase caption heading **"Data sources"** + optional
  one-line ephemerality helper, then **one row per connected exchange
  `api_key`**, vertically stacked with `sm` (8px) gaps, separated by hairline
  `border-border` dividers (no card-on-card nesting — data-density rule).
- **Per-row layout:** `[ toggle ] [ {Exchange} — {label} ]`. Label left-aligned,
  toggle leading. Minimal v1: **name + include/exclude only** — no
  contribution-%, no sparkline (deferred to v2 per CONTEXT Area 3).

### 2. Per-source toggle (the include/exclude control)

- **Recipe:** reuse the **entry-mode pill recipe** exactly —
  - Included: `border border-accent text-accent` (NO accent fill).
  - Excluded: `border border-transparent text-text-secondary` (or
    `border-border` if a visible resting outline reads better in the row;
    executor picks the one matching the entry-mode pill's resting state).
  - Focus: `focus:outline-none focus-visible:ring-2 focus-visible:ring-accent/50`.
- **Semantics:** a labeled two-state control. Either a checkbox semantics
  (`role` implicit, `aria-checked`) **or** `aria-pressed` toggle button —
  executor picks one and keeps it consistent across rows. Each carries the
  per-row `aria-label` from the Copywriting Contract. Default = **included**.
- **Hit target:** ≥ 44px row height (DESIGN.md table-row-height / touch
  compliance). The toggle's own box may be smaller, but the **row** is the click
  target where practical.
- **Motion:** state change uses the 150ms ease-out hover/transition convention
  (`transition-colors`), no decorative animation.

### 3. Instant recompute (DSRC-03 honesty core)

- On every toggle, the curve **and every KPI** (Sharpe / volatility /
  max-drawdown / return / avg-ρ) recompute **synchronously** through the same
  client-side adapter → frozen `computeScenario` path the weight/leverage
  overlays already use. **No debounce in v1.** No skeleton/spinner — recompute is
  in-memory and instant, like the existing what-if overlays.
- The KpiStrip (`mode="scenario"`), EquityChart, and DrawdownChart re-render
  from the new blend. Excluding a key **drops its weight share** and
  **re-normalizes** the remaining keys to sum to 1 (per CONTEXT Area 2). This is
  a real recompute — never a cosmetic hide.
- **A11y on recompute:** the existing rolling-metrics / projection
  `role="status"` + `aria-live="polite"` regions already announce blend
  changes; the toggle change is announced through the same non-blocking channel.
  Do **not** add a `role="alert"` — a toggle is a normal state change, not an
  error.

### 4. All-excluded honest empty state

- **Trigger:** the user toggles off the **last** included source.
- **Behavior:** do **NOT** hard-block the last toggle-off. Instead the
  projection region swaps to an **honest empty/zeroed state** — never a stale or
  last-known blended number.
- **Surface:** reuse **`EmptyStateCard`** (`src/components/ui/EmptyStateCard.tsx`)
  with the heading/body from the Copywriting Contract. Neutral muted card, no
  `role="alert"`, no red/warning color (it is honest absence). The KPIs render
  as em-dash / neutral "—" placeholders (the composer's existing degenerate-blend
  convention), **never** zeros that could read as a real result and **never** a
  stale prior number.
- **Recovery:** re-including any source instantly restores the live projection.

### 5. Fallback note (per-key dailies incomplete)

- **Trigger:** the Phase-36 D3 gate is **not** satisfied (≥1 active key lacks a
  per-key series for the window). Per CONTEXT Area 1, the composer stays on the
  existing **blended baseline** and the per-source control is **hidden**.
- **Surface:** reuse **`InfoBanner`** (`src/components/ui/InfoBanner.tsx`,
  `border-accent/30 bg-accent/5`, calm informational) in the control's slot, with
  the fallback copy. **Not** an `ErrorEnvelope`, **not** red, **not** a
  `role="alert"`. A short honest note, mirroring Phase 36's all-or-nothing gate.
- **No degraded per-source mode** ever renders — it is the full control or the
  one-line note, never a half-per-key/half-snapshot curve.

### 6. Blank mode

- The control is **absent** entirely (no live book → no live keys). No note, no
  empty card — the entry-mode segmented control already explains blank mode.

## Accessibility Contract

Inherits the composer's a11y posture (axe-core CI is green on these surfaces;
do not regress):

- **Group semantics:** the source rows live in a labeled group
  (`role="group"` / fieldset-style) with an accessible name **"Data sources"**.
- **Per-toggle name:** every toggle has a unique `aria-label` naming its
  exchange + key label (Copywriting Contract). Never an unlabeled icon-only
  control.
- **State announcement:** `aria-checked` / `aria-pressed` reflects
  included/excluded. The recompute result is announced via the existing
  `role="status"` `aria-live="polite"` region — non-blocking. The all-excluded
  empty card and the fallback note are **not** `role="alert"` (honest absence,
  not an error).
- **Keyboard:** toggles are reachable in DOM order via Tab; Space/Enter toggles;
  visible `focus-visible:ring-accent/50` ring. No keyboard trap.
- **Contrast:** all text meets WCAG 2 AA — `text-text-muted` #64748B (4.85:1 on
  white), `text-accent` #1B6B5A, `text-text-secondary` #4A5568 are all
  DESIGN.md-blessed AA pairs. No new color introduced, so no new contrast risk.
- **Recharts:** the EquityChart/DrawdownChart keep `accessibilityLayer={false}`
  (codebase-wide opt-out, DESIGN.md 2026-04-30) — recompute does not change this.
