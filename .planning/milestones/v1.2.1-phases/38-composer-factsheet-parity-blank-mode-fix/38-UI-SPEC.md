# Phase 38 — UI Design Contract

> Visual and interaction contract for the composer factsheet-parity + blank-mode-fix phase.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> ⭐ **GOVERNING PRINCIPLE (user, 2026-06-25):** "The factsheet is the truth. The scenario
> is just a blended strategy, so it should look **exactly the same** and use the **same
> assets** as the factsheet." This contract is therefore **descriptive of the existing
> factsheet chart visual identity**, not inventive. The acceptance test for every token,
> layout, and interaction below is: *does the composer chart now look and behave
> indistinguishably from `src/app/factsheet/[id]/v2/TimeSeriesChart.tsx` + `MasterBrush.tsx`?*
> Nothing in this phase introduces a new visual; it makes the composer reuse the factsheet's.

## Source-of-Truth Components (the assets to reuse, NOT reimplement)

| Asset | Path | Role in this phase |
|-------|------|--------------------|
| `TimeSeriesChart` | `src/app/factsheet/[id]/v2/TimeSeriesChart.tsx` | The canonical interactive chart engine. The composer equity (and drawdown) charts render **through this**, not through the legacy custom SVG. |
| `MasterBrush` | `src/app/factsheet/[id]/v2/MasterBrush.tsx` | The 60px sparkline timeline-overview brush pinned above the chart stack. Wheel-zoom / drag-pan / edge-resize / click-to-anchor / double-click-reset window control. |

Do not lift a parallel range state — reuse this one. |

**Guardrails (from CONTEXT.md "Out of scope"):**

- The frozen `computeScenario` engine (`src/lib/scenario.ts`) is **untouched** — this is a RENDER swap, not a data change. Data path stays byte-identical.

## Color

All values are existing DESIGN.md tokens consumed as `var(--color-*)` (Tailwind v4 convention —
bare `var(--positive)` resolves to `currentColor`; the `--color-` prefix is mandatory per the
2026-05-06 DESIGN.md decision). **No new colors are introduced.**

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8F9FA` page bg / `#FFFFFF` surface | Page background, chart card surface, tooltip card fill |
| Secondary (30%) | `#E2E8F0` border / `#FBFCFD` surface-subtle / `#F1F5F9` track | Hairline gridlines, panel borders, brush plot background, muted dimming |
| Accent (10%) | `#1B6B5A` (`--color-accent` / `--color-chart-strategy`) | **The scenario/strategy equity line**, brush sparkline + window outline, active period-button fill, active log/linear tab, focus ring |
| Benchmark (muted) | `#94A3B8` (`--color-chart-benchmark` / `--color-text-muted`) | Benchmark comparator series, muted-baseline live drawdown when a scenario is present |
| Destructive / negative | `#DC2626` (`--color-negative`) | Drawdown (underwater) fill + line in the live-only drawdown state, negative daily-return bars |

**Accent reserved for (explicit list — never "all interactive elements"):**
1. The scenario/strategy equity line (the primary teal series).
2. The `MasterBrush` sparkline stroke + selected-window outline + drag handles.
3. The active period-control segment fill and the active log/linear scale tab.
4. Focus-visible outline ring on the chart SVG + legend buttons (`focus-visible:outline-accent`).

**Color-mapping contract for the scenario overlay + benchmark (PARITY-01 / Q2):**
- **Scenario blend = the primary "strategy" series** → `var(--color-accent)` teal, full opacity,
  stroke width 1.6. (A blended strategy is just another strategy — render it where the factsheet
  renders the strategy line.)
- **Benchmark = the muted comparator series** → `var(--color-text-muted)` / `var(--color-chart-benchmark)`,
  opacity 0.85, stroke width 1.3. (Exactly how `resolveSeries` colors a non-primary comparator.)
- **Live baseline, when a scenario is overlaid** → muted slate `var(--color-chart-benchmark)`
  (it becomes the comparison baseline, not the focal point — already the DrawdownChart behavior at
  `liveStroke = hasScenario ? var(--color-chart-benchmark) : CHART_NEGATIVE`).
- The "natural zero / par" baseline gridline keeps the factsheet's emphasized treatment
  (`var(--color-text-muted)` solid at 0.6 opacity, weight 1.2 vs dashed `2 3` border gridlines).

## Interaction Contract (PARITY-01 — must match the factsheet exactly)

Inherited verbatim by reusing `TimeSeriesChart` + `MasterBrush`. The acceptance bar is "works in
the composer exactly as on the factsheet."

| Interaction | Source mechanism | Expected behavior in the composer |
|-------------|------------------|-----------------------------------|
| **Wheel-zoom** | `TimeSeriesChart.onWheel` (non-passive listener, preventDefault) | Scroll wheel zooms toward the cursor's x-index anchor, ~12% per tick, clamped to `MIN_VISIBLE=5`. |
| **Drag-pan** | `TimeSeriesChart.onPointerDown` (plot interior) | Drag inside the plot pans the visible window; pointer-capture; clamps at history ends. |
| **Y-axis pull** | drag in left gutter (`vbX < PAD.left`) | Scales the y-domain around the cursor's anchor value. |
| **X-axis pull** | drag in bottom gutter (`vbY > PAD.top + plotH`) | Scales the x-range around the cursor's index anchor. |
| **Brush window** | `MasterBrush` | Drag window = pan; drag edge handle = resize; click outside = re-anchor same-width window; double-click = reset. Bidirectional with the charts via `XRangeContext`. |
| **Keyboard nav** | `TimeSeriesChart.onKeyDown` (SVG `tabIndex=0`) | Arrows pan (±10%); `+`/`=`/ArrowUp zoom in, `-`/`_`/ArrowDown zoom out; `Home`/`0`/`Esc` reset. SR hint via `sr-only` describedby. |
| **Crosshair + tooltip** | `crossIdx` + `CrosshairTooltip` | Vertical dashed crosshair, per-series value dots, white SVG tooltip card (hairline border, date bold, one row/series). Touch: tap-to-pin. |
| **Period control** | composer `SegmentedControl` (3M / 6M / 12M / ALL) — KEPT (Q3) | Drives the window; `MasterBrush` refines within it. Keep the existing composer period buttons; they coexist with the brush exactly as the factsheet's period + brush coexist. |
| **Shared brush-zoom window (Q4)** | one `XRangeContext` provider wrapping BOTH panels | Equity + drawdown move together — pan/zoom either and both windows track. |
| **Export menu** | `TimeSeriesChart.ExportMenu` | CSV / SVG / PNG of the visible window (inherited free). |

**Accessibility (inherited, must stay green):** Recharts `accessibilityLayer` opt-out still
applies to any remaining Recharts usage (DrawdownChart currently uses Recharts — if it is moved
onto `TimeSeriesChart` the SVG-`tabIndex=0`+`role="img"`+`aria-label` pattern replaces it). SVG
charts expose `role="img"` + `aria-label` + `aria-describedby` keyboard hint. Focus ring is the
accent `focus-visible:outline-2 outline-offset-2 outline-accent`. No new axe violations.

## Blank-Slate Contract (PARITY-03)

**The bug:** `EquityChart.tsx` projection memo guard (line 675):
`if (equityDailyPoints.length === 0 || composite.length === 0) return null;`
— bails on an empty baseline **before** considering `scenarioSeries`/`composite`, so blank-slate
mode (no live book) renders nothing even when a scenario exists.

**The fix contract — mirror `DrawdownChart`'s `hasScenario` guard exactly:**
- `DrawdownChart.tsx:147` already does the correct thing:
  `if (liveDrawdownData.length === 0 && !hasScenario) { /* empty state */ }`.
- The equity guard must gain the same `&& !hasScenario` term: only short-circuit to the empty/
  warm-up state when there is **neither** a live baseline **nor** a scenario. When `hasScenario`
  is true, the projection proceeds and renders the **scenario overlay only**.
- `hasScenario` is already defined in `EquityChart.tsx:507`
  (`!!scenarioSeries && scenarioSeries.length > 0`).

**Visual rules for blank-slate:**
- Render the **scenario overlay only — NO synthetic/fabricated baseline.** There is no live book
  in blank mode; inventing a flat baseline would be a dishonest line. (CONTEXT.md §specifics.)
- The scenario line keeps its accent-teal identity (`var(--color-chart-strategy)`).
- The **"PROJECTED — hypothetical, not your live book"** honesty pill stays rendered
  unconditionally (it already is — `ScenarioComposer.tsx:1874`). Blank-slate must NOT remove or
  weaken it.
- Y-axis still anchors honestly to the scenario's own range; period control + brush still operate
  on the scenario series alone.
