<objective>
Create the pure adapter `buildScenarioFactsheetPayload` that bridges the composer's date-keyed
scenario data (`scenarioWealthSeries: WealthPoint[]`, optional `baseline`, optional `benchmark`)
into a minimal, valid `FactsheetPayload` the factsheet `TimeSeriesChart` + `MasterBrush` consume
verbatim. This is the enabler for the full engine-reuse mount in Plan 03 — it isolates the
date-keyed→index-aligned transform (the bulk of PARITY-01) into a cheap, high-coverage pure
function with no DOM/provider dependency.

Purpose: The factsheet chart engine is context-bound and index-based (`xRange=[startIdx,endIdx]`
into `payload.dates`, every series `values[i]` aligned to `dates[i]`). The composer has date-keyed
`{date,value}[]` series. Reusing the SAME factsheet asset (governing principle) requires
synthesizing a payload — and synthesizing keeps the factsheet files byte-identical (their tests
cannot break). Covering this pure function offsets the coverage lost when Plan 03 deletes the
legacy projection memo (coverage is a BLOCKING CI gate).

Output: `scenario-factsheet-payload.ts` (adapter + the equity/drawdown `ChartConfig` objects) and
its LOCKED-convention unit test.
</objective>
