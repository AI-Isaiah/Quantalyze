<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated allocator → csv_daily_returns (per-key rows) | An allocator's JWT (`auth.uid()`) must only read its own per-key rows; cross-tenant read of another allocator's per-key series is the highest-cost silent failure (RLS fails to empty, not error). |
| service-role worker → csv_daily_returns | The Railway worker writes per-key rows via SUPABASE_SERVICE_KEY (bypasses RLS); it must set allocator_id from the authoritative api_keys.user_id, never from a job payload (enforced in Plan 02). |
| legacy strategy rows ↔ new per-key rows | Both row-types share one table; the XOR + per-key CHECK prevent a malformed/ambiguous row; the two non-partial unique indexes keep each row-type's identity isolated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-01 | Information Disclosure | csv_daily_returns per-key SELECT (cross-tenant) | mitigate | New `csv_daily_returns_allocator_owner_select` policy (`allocator_id = auth.uid()`); proven by the two-actor content-level cross-tenant test (Task 4) + rls-policy-auditor review. |
| T-35-02 | Tampering | malformed row (both axes set, or per-key row missing allocator) | mitigate | `csv_daily_returns_axis_xor` (num_nonnulls = 1) + `csv_daily_returns_perkey_allocator` CHECK reject at write time; dual-axis test asserts 23514 (Task 3). |
| T-35-03 | Tampering | strategy-path regression (dropped strategy uniqueness → duplicate/garbled strategy dailies) | mitigate | Explicit `csv_daily_returns_strategy_date_key` recreates the (strategy_id, date) uniqueness; DO-block + dual-axis test assert the strategy upsert arbiter still resolves (no 42P10). |
| T-35-04 | Information Disclosure | anon role reading per-key rows | accept | Existing anon-deny is unchanged (no anon SELECT policy; GRANT/RLS deny). Covered by the existing anon-deny test; no new anon surface added. |
| T-35-SC | Tampering | npm/pip/cargo installs | accept | Phase 35 installs ZERO packages (RESEARCH Package Legitimacy Audit: not applicable). No install task in this plan. |
