# Phase 29 — UI Design Contract

> Visual and interaction contract for the Unified Composer Spine. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This is a unification phase, not a redesign.** Every token below is sourced from `DESIGN.md` (LOCKED) and `src/app/globals.css` (`@theme inline`). Every interaction reuses an affordance that already ships in `ScenarioComposer.tsx` / `StrategyBrowseDrawer.tsx` / `SavedScenariosList.tsx`. Do NOT invent new primitives, new tokens, or new layouts. Where this phase adds something genuinely new (the entry-mode segmented control, the "Example" catalog tag, "portfolio" copy), the contract pins it to an existing pattern.
>
> **Out of scope for Phase 29 (do NOT spec or build here):** factsheet-grade graphs on the blend (Phase 30), collapsible / graphs-lead layout (Phase 31), `/scenarios` redirect + `ScenarioBuilder` delete (Phase 32), Bridge→composer continuity polish + WCAG-AA audit (Phase 33). Peer / percentile / signature ranking of the blend is a **LOCKED honesty invariant** — never shown.

## Typography

Sourced from DESIGN.md scale. **New Phase-29 chrome uses exactly 4 distinct sizes — 32 / 16 / 14 / 12 — and 2 weights only** (400 regular, 600 semibold). Sub-headings differentiate via `uppercase tracking-wide`, never a third weight. All numbers use Geist Mono tabular-nums.

| Role | Size | Weight | Line Height | Font | Used for |
|------|------|--------|-------------|------|----------|
| Display / page title | 32px (`text-2xl` ≈ 24px in existing composer header — keep as-is) | 600 | 1.2 | Instrument Serif (empty-state H2) / DM Sans (composer "Scenario" H2) | Empty-state heading, composer title row |
| Section heading | 16px (`text-base`) | 600 | 1.3 | DM Sans | "Add more strategies", "Saved portfolios", drawer title region |
| Body | 14px (`text-sm`) | 400 | 1.5 | DM Sans | Row labels, drawer body, CTA labels, descriptions |
| Caption / label / badge | 12px (`text-xs`) | 400 body / 600 for `uppercase tracking-wide` labels | 1.4 | DM Sans (labels), Geist Mono (numbers) | Badges, pills, timestamps, helper text, methodology caveat, the "Example" tag, save/list captions |

**New-chrome scale = exactly 4 sizes: 32 / 16 / 14 / 12.** The caption/label/badge tier for any NEW Phase-29 element is **12px (`text-xs`)** — the canonical DESIGN.md caption size.

**Inherited micro-labels (NOT introduced by this phase):** the 10–11px `text-[10px]` / `text-[11px]` micro-labels are carried verbatim from EXISTING reused components — specifically the `TrustTierLabel` chip and the `PROJECTED` honesty pill — and render at their shipped size when those components appear inside the composer. Phase 29 does NOT introduce any new 10–11px text; new chrome (entry-mode control, "Example" tag, save/list captions) sizes its smallest text at 12px. The `Example` pill in §2 specifies its own size; treat its rendered micro-label as inheriting the existing neutral-outline pill recipe, not as a new size token added by this phase.

Weights: exactly 2 for new chrome — **400 (regular)** and **600 (semibold)**. (DESIGN.md also blesses 500 medium for some labels; existing reused components use 500 — keep those verbatim. New chrome uses 400/600 + `uppercase tracking-wide` for emphasis, never a third weight.)

Line heights: body 1.5, headings 1.2–1.3 (per DESIGN.md).

## Color

60 / 30 / 10 split per DESIGN.md. Accent is rare and meaningful.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8F9FA` (`--color-page`) / `#FFFFFF` (`--color-surface`) | Page background + card/panel/drawer surfaces |
| Secondary (30%) | `#0F172A` sidebar (`--color-sidebar`); `#FBFCFD` (`--color-surface-subtle`) nested panels; `#E2E8F0` (`--color-border`) hairline dividers | Chrome, nested surfaces, dividers, borders |
| Accent (10%) | `#1B6B5A` (`--color-accent`), hover `#155A4B` (`--color-accent-hover`) | See reserved-for list below |
| Destructive | `#DC2626` (`--color-negative`) | Delete portfolio confirm; save/load/browse hard-failure error text + `role="alert"` |
| Positive | `#15803D` (`--color-positive`) | Gains in projection KPI strip (existing); "Link copied!" status (existing share affordance) |
| Muted / neutral | `#64748B` (`--color-text-muted`) | The "Example" tag + "PROJECTED" pill border+text, timestamps, helper copy, methodology caveat |

**Accent reserved for (explicit — never "all interactive elements"):**
1. Primary CTA buttons: "Save portfolio", "Update portfolio", inline name-input "Save", the per-row "Add" button in the catalog drawer.
2. The active segment of the entry-mode segmented control (selected state: `border-accent text-accent` or accent underline, per the active-segment pattern below).
3. Active filter pills in the Browse drawer (`aria-pressed` → `border-accent text-accent`, existing pattern).
4. Focus rings on inputs (`--color-border-focus` = accent; `focus:ring-2 focus:ring-accent/50`, existing).
5. Inline text links ("Try the Strategy Sandbox", "Clear filters").
6. Equity-curve stroke in the projection chart (`--color-chart-strategy`, existing).

**Accent must NOT be used for:** the "Example" catalog tag (that is muted neutral — it is metadata, not action/verified), the "PROJECTED" honesty pill (muted neutral), inactive segments, Ghost-variant secondary actions (Open/Rename), or any decorative fill. The accent = "verified / action" semantic is LOCKED (DESIGN.md). Tagging an example strategy with accent would falsely imply "verified".

## Component Inventory (Phase-29 specifics)

### 0. Visual hierarchy / primary anchor

- **Composed (non-empty) state:** the **primary visual anchor is the projection KPI strip** (the existing return / Sharpe / drawdown values in Geist Mono at the top of the composer body) — it carries the highest information value of any element on the surface. The eye enters top-left at the KPI values, then scans down to the composition list (per-strategy rows + weights), with the entry-mode segmented control and PROJECTED pill reading as quieter chrome above. Do not let any new Phase-29 element (entry-mode control, "Example" tags) out-weight the KPI strip; new chrome stays calmer (muted neutral, smaller type) so the numbers remain the focal point.
- **Empty (no live book) state:** the primary anchor is the serif `Start a portfolio` heading + its dual CTA, centered in the empty-state card.

### 1. Entry-mode segmented control — NEW
- **Placement:** top of the composer body, in/under the title row (`Scenario` H2 + PROJECTED pill + save toolbar). Above the composition list.
- **Two segments:** `From my book` (default when `holdingsSummary.length > 0`) · `Blank slate` (default + only option when no live book).
- **Visual:** segmented button group, on-surface, 1px `--color-border` container, `--radius-md` (6px). Active segment: `border-accent text-accent` (or accent bottom-border) on `--color-surface`; inactive: `text-text-secondary` on transparent. 14px DM Sans, 8px/12px padding. NO accent fill (accent = action/verified; a mode toggle is neither). Mirror the existing filter-pill active treatment (`StrategyBrowseDrawer` FilterPill: `aria-pressed` → `border-accent text-accent`) for consistency.
- **A11y:** `role="tablist"` / `role="tab"` with `aria-selected`, OR a radiogroup (`role="radiogroup"` + `aria-checked`); keyboard arrow-key navigation; visible focus ring (accent).
- **Behavior:** "Blank slate" presents an empty working composition (no live-book holdings seeded) into which the allocator adds catalog strategies. "From my book" seeds the live-book holdings as today. Switching modes must NOT silently wipe an in-progress draft without the existing reset/confirm path — reuse the codec/reset discipline; a mode switch that would discard edits routes through the existing reset confirmation.
- **When no live book:** the empty-state front door IS "Blank slate" — do not render a dead "From my book" segment as the default; either disable it (with the existing empty-state CTA copy) or default to Blank slate.

### 2. "Example" catalog tag — NEW (pinned to existing neutral-outline pill pattern)
- **Where:** on each example-universe row in the merged Browse drawer (`is_example = true AND status = 'published'`). Verified strategies keep their existing treatment (no tag, or their existing mandate-fit chip).
- **Visual (LOCKED to the existing `Example universe` / `PROJECTED` pill recipe in `ScenarioBuilder.tsx:286` and the DESIGN.md trust-tier `csv_uploaded` neutral-outline family):**
  `inline-flex items-center rounded-sm border border-text-muted px-2 py-0.5 text-[10px] uppercase tracking-wide font-semibold text-text-muted`
  → 4px radius, 1px `--color-text-muted` border, `#64748B` text, no fill, no icon. Label: **"Example"**. The `text-[10px]` micro-label size here is INHERITED verbatim from the existing pill recipe (same family as the `PROJECTED` pill / `TrustTierLabel`) — it is not a new size token introduced by Phase 29 (see Typography note).
- **Why neutral, not a filled `Badge`:** the filled `Badge` primitive carries strategy-type/status color semantics (`bg-badge-*`, `bg-positive/10` published, etc.); accent means verified/action. An example-universe strategy is neither verified nor a status — it is provenance metadata. Neutral outline is the calm "label" signal, matching the PROJECTED honesty pill. Do NOT use accent, do NOT use the warning-amber family, do NOT use the filled `Badge`.
- **Pseudonymity:** the example row's display label comes through `displayStrategyName` (same as every browse row) — the tag must not reintroduce a raw `strategies.name` leak. The RLS leak test (exit gate) asserts example rows carry the pseudonymity-safe label.

### 3. Merged Browse drawer — EXTEND `StrategyBrowseDrawer`
- 620px right slide-over, `max-width: 96vw`, backdrop `rgba(15,23,42,0.32)`, 220ms slide-in / 160ms backdrop fade, Esc-to-close, `role="dialog" aria-modal="true"` — all existing; keep verbatim.
- One list, verified + example rows interleaved (alphabetical by `name`, existing order). Example rows carry the "Example" tag (§2). Search + market/type filter pills apply client-side across both (existing).
- **Add gesture (LOCKED):** one click on a row's "Add" → `scenario.addStrategyBrowse(...)` appends to the working composition → projection recomputes immediately through the frozen `computeScenario` engine. No confirm step, no second annualization convention. Existing "Added ✓ → dim" feedback stays. Drawer stays open for multi-add.
- Drawer title relabel: "Browse strategies" (drop "verified" — it now lists examples too).

### 4. Save / Reopen / Rename / Delete — REUSE `ScenarioComposer` toolbar + `SavedScenariosList`
- **Save toolbar** (composer header row, `scenario-save-toolbar`): no portfolio open → `Save portfolio` (primary); editable portfolio open → `Update portfolio` (primary) + `Save as new portfolio` (secondary); readonly open → `Save as new portfolio` only (Update suppressed). Inline name input (NOT a modal): `Name this portfolio` placeholder, `Save` (primary) / `Cancel` (ghost).
- **Saved list** (`SavedScenariosList`, relabel "Saved portfolios"): one row per saved portfolio — selection checkbox + name + `Saved/Updated {date}` timestamp + `Open` (ghost) · `Rename` (ghost, inline text input → PATCH) · `Delete` (ghost danger → inline `Delete "{name}"?` confirm → DELETE). All inline, no modal. The Share affordance and "Compare selected" gate stay as shipped (≥2 selections incl. the "Live book" pseudo-row).
- **Reopen codec trichotomy (LOCKED — success criterion 3):** Open decodes `row.draft` through `scenarioDraftCodec` (never a bare cast). `ok` → hydrate + adopt id (editable). `readonly` → hydrate real data + adopt id + block Update + show readonly notice. `reset` → do NOT hydrate, show the honest "older format" notice, refuse the open. A drifted draft never silently empties the composer. Reuse the existing decode logic; do not weaken it.

### 5. Honest empty / degenerate states
- **No live book → blank-slate front door:** the `isEmptyState` branch renders the empty-state card with `Start a portfolio` heading + dual CTA (`Connect Exchange →` accent / `Browse strategies` border). The "Blank slate" path is reachable from here. Keep the existing serif-title empty-state card shell (`rounded-lg border border-border bg-surface p-12 text-center`).
- **Below-sample-floor / degenerate projection:** honest absence via `EmptyStateCard` (neutral muted card, no `role="alert"`, no red/warning) — heading must match body (the #509 rule). Existing `EmptyStateCard` token shell; reuse.
- **Transport failure ≠ empty:** an unloaded saved-list or a failed catalog fetch renders the honest ERROR state (`role="alert"`, `--color-negative`), never the empty card. Existing `listLoadError` discipline; preserve.

## Motion

Per DESIGN.md (minimal-functional only):
- Drawer slide-in 220ms, backdrop fade 160ms (existing `StrategyBrowseDrawer` keyframes — keep).
- Hover states 150ms ease-out (buttons, links, rows).
- Tab/segment switches: use Tailwind `duration-300` (NOT `duration-250` — invalid Tailwind v4 token, silently drops; DESIGN.md). Raw CSS may use 250ms.
- No decorative animation. No bouncing, spinning, scroll-triggered effects.

## Accessibility (Phase-29 minimums; full WCAG-AA axe audit is Phase 33)

- Entry-mode control: keyboard-navigable tablist/radiogroup, `aria-selected`/`aria-checked`, visible accent focus ring.
- Drawer: `role="dialog" aria-modal="true"`, Esc closes, focus trapped while open (existing pattern).
- Live regions: `role="alert"` on blocking errors (save/load/catalog failure); `role="status" aria-live="polite"` on non-blocking transitions ("Link copied!", "Added ✓").
- Contrast: all text ≥ 4.5:1. The muted neutral `#64748B` "Example" tag text on `#FFFFFF` surface = 4.85:1 (AA pass, the DESIGN.md-blessed shade). Do not lighten it.
- All numbers in Geist Mono tabular-nums; never serif/sans for data.
