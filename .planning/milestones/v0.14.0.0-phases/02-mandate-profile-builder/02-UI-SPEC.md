## Layout Contract

Single-column form inside a single `Card padding="md"` (24px padding per DESIGN.md card padding). Max content width 720px (narrower than the page's 1100px for form readability). Form stacks vertically — no 2-column or grid layouts on the Basic section. The Advanced accordion body MAY use a 2-column grid only for the `correlation_ceiling` + `risk_budget` slider pair (parity with the admin `PreferencesPanel.tsx:218` 2-column risk group) — but only at viewport widths ≥ 720px; collapses to single column below.

Section order (top → bottom):

1. `PageHeader` with title `My Allocation Settings` + subtitle.
2. Live "Last saved" status region (aria-live="polite"), 12px above the Card, right-aligned. This region also hosts the transient `Mandate saved ✓` confirmation (appears for 2s, then reverts to the timestamp).
3. Card containing:
   - **Basics** section heading (14px medium).
   - `max_weight` (slider)
   - `preferred_strategy_types` (chip multi-select)
   - `excluded_exchanges` (chip multi-select, red when selected)
   - `target_ticket_size_usd` (number input)
   - `mandate_archetype` (textarea, 2 rows, char counter bottom-right)
   - **Advanced constraints** accordion (collapsed by default, caret right):
     - `correlation_ceiling` + `risk_budget` (two sliders, 2-col grid ≥ 720px)
     - `liquidity_preference` (3-segment radio pills)
     - `style_exclusions` (chip multi-select)
4. No footer. No submit button. No cancel button. No sticky bar.

Field-level vertical rhythm: 24px (`space-y-6`) between adjacent fields within a section, inherited from `PreferenceForm.tsx:76`. 32px between Basic's last field and the Advanced accordion trigger.

Each field block is laid out as:

```
[Field Label]                                          [Reset]   <- 14px label / 12px reset on the same baseline, justify-between
[Control]                                                        <- 44px min-height input/slider
[Helper text]                                                    <- 14px text-text-secondary, below control
[Inline error / save indicator]                                  <- only when active, aria-live region
```

The `Reset` link shows only when the field has a non-NULL value (it's a no-op if the field is already NULL — hide it in that case to reduce visual noise per DESIGN.md "Decoration level: Minimal").

## Interaction Contract

### Auto-save trigger

| Input type | Save trigger | Rationale |
|------------|--------------|-----------|
| Slider (`max_weight`, `correlation_ceiling`, `risk_budget`) | On `pointerup` / `touchend` / `keyup` of the thumb (per D-15 "thumb release") | Avoid saving on every drag tick; coalesce into one RPC per gesture |
| Chip multi-select (`preferred_strategy_types`, `excluded_exchanges`, `style_exclusions`) | On each toggle click (per D-15) | Each click is a complete atomic choice |
| Segmented radio (`liquidity_preference`) | On click | Single-value enum; no debounce needed |
| Number input (`target_ticket_size_usd`) | On blur (per D-15) | User may be mid-typing; blur signals intent complete |
| Textarea (`mandate_archetype`) | On blur (per D-15) | Same reason |
| Reset link | On click | Identical to any other field edit path |

**No debounced batch. No submit button. No save button.** Per D-15 / MANDATE-04.

### Save feedback sequence

1. User completes edit → auto-save trigger fires.
2. Field control enters "saving" visual state: right-side 14×14 inline spinner (reuse the `animate-pulse` class on a dot, per the `Skeleton` pattern — no new spinner dependency). Aria-busy="true" on the field block.
3. RPC responds:
   - **Success:** Spinner replaced by `text-accent ✓` glyph for 2 seconds, then fades. Simultaneously, the top-right "Last saved" status region updates to `Mandate saved ✓` for 2 seconds, then reverts to `Last saved: just now`. Aria-live="polite" announces `Mandate saved`.
   - **Validation error (400):** Spinner replaced by inline error text below the control (`text-xs text-negative`). Field value stays intact (D-16 — no optimistic revert). Aria-live="assertive" announces the error.
   - **RPC error (5xx):** Inline error `Couldn't save. [Retry]` below the control. `[Retry]` button re-invokes the same save with exponential backoff (1s, 2s, 4s — max 3 attempts). Aria-live="polite".
   - **Rate limit (429):** Inline error `Saving too fast. Will retry in {N}s.` Schedules auto-retry after `Retry-After` header interval. No user action needed; aria-live="polite".

### Keyboard / a11y contract

- Every field is tab-reachable. Focus ring = `focus:ring-2 focus:ring-accent/20 focus:border-border-focus` (already encoded in `Input.tsx:26`). Sliders use native `<input type="range">` for built-in arrow-key support.
- Chip multi-selects use `<button type="button" role="checkbox" aria-checked={selected}>` so screen readers announce `checked`/`not checked`. Space/Enter toggles.
- Segmented radio for `liquidity_preference` uses `<div role="radiogroup">` with `<button role="radio" aria-checked>` — arrow keys navigate within the group.
- Accordion trigger uses `<button aria-expanded aria-controls="advanced-panel">` with rotating chevron and `aria-hidden` body panel.
- `aria-live="polite"` region for save-success. `aria-live="assertive"` region for validation errors. Never both in the same region.
- Minimum touch target 44×44 (already enforced on `Button`, `Input`, `Select` via `min-h-[44px]`).
- Label-to-control association via explicit `htmlFor` + `useId()` (pattern from `Input.tsx:11`).

### State matrix coverage

| State | Visual |
|-------|--------|
| Empty (first visit, all NULL) | All inputs blank. Sliders at midpoint visually but with `aria-valuetext="unset"` and no value pill shown. `Last saved` region shows `Not saved yet`. No Reset links visible. |
| Loading (initial fetch) | Skeleton rows in place of controls, 44px tall each. Card container visible. `Last saved` region shows skeleton (20×120 px). |
| Partial (some fields saved, others NULL) | Saved fields show value pill + Reset link. NULL fields render as empty/midpoint with no pill, no Reset. `Last saved: N min ago` reflects the most recent `mandate_edited_at`. |
| Saving (transient) | Focused field shows inline spinner. Rest of form stays interactive. |
| Save success (transient, 2s) | Checkmark ✓ next to focused field. Top-right banner flashes `Mandate saved ✓`. |
| Save validation error | Inline red helper text under the control. Value preserved. Slider/chip visually unchanged. |
| Save RPC error | Inline `Couldn't save. [Retry]` link under the control. Value preserved. |
| Rate-limited | Inline `Saving too fast. Will retry in {N}s.` Auto-retry scheduled. |
| Global fetch error (initial load) | Card body replaced by `InfoBanner` with refresh instruction. |
| Unauthorized | N/A — route-level redirect to `/login` (already handled by `preferences/page.tsx:10`). |
