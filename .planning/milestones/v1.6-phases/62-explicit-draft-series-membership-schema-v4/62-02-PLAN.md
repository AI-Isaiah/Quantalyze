<objective>
Make compare select its per-key engine set from the draft's PERSISTED `memberKeyIds`
instead of the live gate. An empty membership computes added-only even when the live
gate is true — this closes red-team F5 by construction and retires `entryMode` as a
load-bearing signal for saved drafts. This is MEMBER-02.

Purpose: A blank-authored draft must never inherit the live book in its compare column.
The persisted membership is the self-describing selector; the eligible-set intersection
is also the MEMBER-04 drop point at compute time. To avoid a golden regression, the panel
must DERIVE membership for any column whose membership is underived (upgraded v2/v3 OR an
underived-v4 round-trip) BEFORE calling the engine — a naive `?? []` default would compute
an upgraded book draft as added-only and break the Atlas golden.

Output: `scenario-compare.ts` selector rewrite + `buildLiveBookDraft(eligibleApiKeyIds)`
membership stamp; `ScenarioComparePanel.tsx` passes eligible ids and normalizes membership
for EVERY underived column; F5-closure test + the scenario-compare.test.ts hand-built
fixture rebase; the Atlas golden preserved.
</objective>
