<objective>
Complete the persisted-membership contract at the composer: STAMP real membership on new
saves (entryMode-aware — book+gate ⇒ eligible ids, blank ⇒ [] even when gate=true, which
IS the F5 STAMP closure), make REOPENED upgraded/underived drafts self-describing by
deriving + stamping membership into the working-draft STATE (the blocker's spirit-of-(b)
fix), and DISCLOSE on reopen when a persisted member is no longer eligible (reuse the
ephemeral ProvenanceNote). This is MEMBER-04.

Purpose: New book saves must persist the correct membership (or every real book draft
would look blank and compare would compute added-only — a golden regression). Reopening an
upgraded v2/v3 (or underived-v4 round-tripped) draft must immediately resolve membership
into the working state so the draft is self-describing and the next persist converges to a
proper v4-with-membership blob — this is what retires `entryMode` as a load-bearing signal.
And a dropped member must never be a silent recompute (MEMBER-04 forbids the silence, not
the recompute).

Output: `ScenarioComposer.tsx` save-time membership stamping + reopen derive-and-stamp for
underived drafts + reopen ineligible-member disclosure gate; `ProvenanceNote.tsx`
parameterized for a membership variant; tests for all three, with the ephemeral
no-cross-tab-key contract grep-asserted.

is handled once at `/ship` / land time per the project convention (both files bumped in the
SAME commit or the frontend CI gate fails). The land/verify step below records it so it is
not forgotten.
