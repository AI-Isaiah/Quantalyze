## v1 Requirements

Requirements for the v1.2.2 milestone. Each maps to exactly one roadmap phase. Phases continue from v1.2.1's Phase 38 — this milestone is Phases 39–43.

### Complete payload adapter (Phase 39)

- [x] **PAYLOAD-01**: `buildScenarioFactsheetPayload` produces the full scalar metric set via `compute()` — no zeroed/stubbed summary block.
- [x] **PAYLOAD-02**: Panel arrays are populated from the pure helpers (bootstrap CIs, Calmar-by-year, rolling, streaks, monthly/daily heatmaps, EoY). `styleDrift` is deliberately deferred to STYLE-V2-01 (out of scope), not stubbed dishonestly.
- [x] **PAYLOAD-03**: The population-std / 252 / 365.25 annualization convention is locked by a golden-parity fixture that fails CI on any drift.
- [x] **PAYLOAD-04**: `strategyMetrics.n` is the true overlap count and the `n < 252` caveat fires from real data.
- [x] **PAYLOAD-05**: Degenerate blends (empty / non-finite / <2-date) collapse to a safe-empty payload (no NaN/Inf) via a returns-degenerate gate BEFORE `compute()`.

### Mount the real factsheet body (Phase 40)

- [x] **BODY-01**: The composer mounts the REAL `FactsheetBody` (not a reimplementation) under the `persist={false}` provider, fed the synthesized payload.
- [x] **BODY-02**: An additive `scenarioMode?: boolean` (default false) keeps every existing call site byte-identical; `scenarioMode={true}` suppresses exactly Share + Compare. Pinned by an innerHTML-equality test.
- [x] **BODY-03**: The factsheet body renders correctly across the test matrix: healthy / single-strategy / sub-N-overlap / non-finite blends.
- [x] **BODY-04**: API-only panels (allocator / signatures / peer) are absent on the csv blend, proven by render-absence assertions (no false data on a hypothetical blend).

### Constituent correlation & diversification (Phase 41)

- [x] **CORR-01**: The constituent correlation matrix reads the engine's frozen `correlation_matrix` (already computed; no second correlation path).
- [x] **CORR-02**: Constituent pairs at ρ ≥ 0.85 are flagged "too similar" (the diversification signal).
- [x] **CORR-03**: Sub-floor cells render "—"; a 0/1-constituent blend (or n < 10 overlap) shows an honest empty state — never a 1×1 grid or a fabricated number.
- [x] **CORR-04**: Rows/columns are labeled by de-aliased strategy name, never raw UUIDs.
- [x] **CORR-05**: Percent-contribution-to-risk is shown per constituent: PCRᵢ = wᵢ·(Σw)ᵢ / (wᵀΣw).
- [x] **CORR-06**: Constituents are cluster-reordered (hand-rolled pure-TS) so correlated groups read together.

### Peer-cohort override & mandate (Phase 42)

- [x] **PEER-01**: An honest AGGREGATE peer rank is computed for the blend via an additive `scenarioPeer` carve-out — a deliberate, scoped override of the no-peer-rank-a-hypothetical invariant (user decision 2026-06-25). The audit-c20 behavioral pin is REPLACED accordingly. NEVER an `ingestSource:"api"` flip; never a per-constituent rank.
- [x] **PEER-02**: The peer panel discloses "hypothetical blend · ranked vs verified strategies" and is suppressed below the `n < 252` sample floor.
- [x] **PEER-03**: Below a minimum cohort size (~20) the peer rank suppresses to an honest empty state rather than ranking against a too-small universe.
- [x] **PEER-04**: Per-constituent mandate chips are shown, drawn only from genuinely-available mandate data.
- [x] **PEER-05**: An own-book delta is surfaced — the blend's core ratios MINUS the allocator's live book.

### Edge states, toggle fold & guards (Phase 43)

- [x] **GUARD-01**: The data-sources toggle folds into `CollapsibleSection`; the leverage guard is corrected to `!== 1` (WR-01); color tokens are formalized; a static guard + degenerate-matrix cross-check are made permanent.
- [x] **GUARD-02**: `FactsheetBody.scenario-mode.test` is a PERMANENT gate — innerHTML equality + an Overview-untouched assertion (the real factsheet stays byte-identical).
- [x] **GUARD-03**: `e2e/composer-axe` Scan 2 gates on `#factsheet-main` + `#factsheet-diversification` visible anchors, CI wiring is confirmed, and the coverage ratchet (lines:82/fns:74/branches:72/stmts:80) holds.
- [x] **GUARD-04**: `FactsheetBody.guard04-no-bleed.test` is a PERMANENT no-state-bleed gate — `persist={false}` mount with keyspace-scoped predicates.

## Out of Scope

Explicitly excluded.

| Feature | Reason |
|---------|--------|
| Per-constituent peer ranking | The scenarioPeer override is AGGREGATE-only (blend vs the verified universe); ranking individual hypothetical constituents would re-invent data. |
| `ingestSource:"api"` flip to unlock factsheet peer panels | Would re-expose allocator/peer/signatures panels on a hypothetical blend — a no-invented-data violation. The override is a separate `scenarioPeer` path. |
| Rebuilding any factsheet UI | North-star directive: reuse the real factsheet wholesale; new code is the payload adapter + the one constituent-correlation panel only. |
| Style-drift on the blend | Deferred to STYLE-V2-01; `styleDrift: null` rather than a fabricated value. |
