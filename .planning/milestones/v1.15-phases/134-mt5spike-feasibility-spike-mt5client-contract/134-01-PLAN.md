## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → RPyC bridge | mt5linux speaks rpyc classic/SlaveService to the Wine gateway — an unauthenticated arbitrary-remote-code channel |
| Mt5Client → caller | error/detail text crosses into logs/exceptions — credential leakage surface |
| facade → mt5linux full surface | the underlying client exposes the trade path (order_send etc.); only the facade stands between a read session and a trade |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-134-01 | Information Disclosure | Mt5ClientError / all error paths | mitigate | detail passes scrub_freeform_string at construction; no-secret-in-str(exc) test; NEVER log the rpyc-interpolated code string (the investor password is f-string-interpolated into it by mt5linux) |
| T-134-02 | Elevation of Privilege | Mt5Client facade | mitigate | structural read-only: compose only login/account_info/history_deals_get/order_check/close; no __getattr__; parametrized forbidden-surface tests + exact-public-surface test |
| T-134-03 | Tampering / EoP | RPyC SlaveService transport | mitigate (constraint documented) / transfer (Phase 139 owns hardening) | module docstring + go/no-go doc record the hard constraint: bridge PRIVATE-network-only (Railway internal / WireGuard / SSH tunnel), NEVER a public port |
| T-134-04 | Denial of Service | hung Wine terminal wedging the sequential worker | mitigate | rpyc sync_request_timeout 30s (env MT5_REQUEST_TIMEOUT_S) + MT5 login IPC timeout 20000ms strictly below it, ordering asserted by test; outer to_thread/wait_for bound is Phase 136/137 |
| T-134-05 | Spoofing (fabricated data) | history_deals_get / account_info error paths | mitigate | None → typed raise via last_error(); () → honest empty; degenerate shape → raise; conflation tests are the load-bearing CI gate |
