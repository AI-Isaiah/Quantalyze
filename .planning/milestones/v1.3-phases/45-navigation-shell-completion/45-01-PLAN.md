## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server role props -> client nav rendering | DashboardChrome receives isAllocator/isManager/isAdmin from the server layout's auth lookup; MobileNav renders destinations from them. No new untrusted input crosses here. |

This phase adds NO new auth code, endpoint, data access, migration, or trust-boundary input.
