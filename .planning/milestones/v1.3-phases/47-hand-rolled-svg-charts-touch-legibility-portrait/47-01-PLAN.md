    - Touch tap (type==="touch", not moved past 8px slop, <350ms) at a valid index → selectedIdx = that index, pinned = true
    - Drag (moved past 8px slop) → no selection change (returns early)
    - Slow press (≥350ms) → no selection change (returns early)
    - Mouse pointer (type !== "touch") → no selection change (returns early; desktop hover path untouched)
    - pointerToIndex returns null → clears selection + unpins
    - Re-tap within re-tap threshold (3) of the current pin → un-pins (selectedIdx = null, pinned = false)
    - Tap elsewhere while pinned → moves the pin to the new index
    - pointerleave while pinned → selectedIdx survives; pointerleave while unpinned → selectedIdx clears
  </behavior>
  <action>
    Create `"use client"` hook `export function useTapPin(opts: { count: number; pointerToIndex: (clientX: number, clientY: number, rect: DOMRect) => number | null })`.
    Returns `{ selectedIdx: number | null, pinned: boolean, svgRef: RefObject<SVGSVGElement | null>, onPointerDown, onPointerMove, onPointerUp, onPointerLeave }` (pointer handlers typed `React.PointerEvent<SVGSVGElement>`).
    Define module constants verbatim from the source: `TAP_SLOP_SQ = 64` (8px squared), `TAP_MAX_MS = 350`, `RETAP_THRESHOLD = 3`.
    Internal state mirrors the source: `selectedIdx` (was `crossIdx`), `pinned`; refs `tapInfoRef` ({x,y,t,type}) and `movedRef`.
    onPointerDown: record `{ x: e.clientX, y: e.clientY, t: Date.now(), type: e.pointerType }`, reset movedRef=false, `e.currentTarget.setPointerCapture(e.pointerId)`.
