# Phase 48 — UI Design Contract

> Visual and interaction contract for the **Recharts chart family + the 2277-LOC hand-rolled `EquityChart`**,
> plus the verification scaffolding that makes "v1.3 done" falsifiable. Generated by gsd-ui-researcher,
> verified by gsd-ui-checker.
>
> **RETROFIT over a LOCKED design system.** This phase introduces ZERO new aesthetic direction. Every token
> (color / typography / spacing / radius / motion) is already locked in `DESIGN.md` and is treated as
> immutable here. It is the immediate sequel to the Phase-47 SVG-chart contract and mirrors its structure.
> The phase adds exactly two visual/interaction behaviors to *already-shipped* charts: (1) touch
> tap-to-show/tap-to-pin tooltip parity on the Recharts family via the dependency's own
> `<Tooltip trigger="click">` (NOT a new gesture layer), and (2) touch tap-pin + minimal small-width
> legibility on `EquityChart` by wiring the existing Phase-47 `useTapPin` hook onto its existing
> `nearestIndex` binary-search — NO rewrite. The desktop render/behavior of every chart stays
> **byte-identical**. The remaining work (app-wide axe matrix, `@lhci/cli` mobile perf budget, the bespoke
> gate matrix run app-wide, the real-device authed sign-off) is **verification infrastructure, not a visual
> surface** — recorded here as the mechanism that proves the contract, never as a new UI.
>
> **Reference precedents (do NOT re-decide):** desktop `TimeSeriesChart` tap-pins-crosshair recipe (Phase
> 47); the `useTapPin` hook (Phase 47); the composer-axe `serious+critical` scoped-filter (v1.2 GUARD-03);
> the vitest-coverage ratchet philosophy (thresholds a few points under measured actual).

## Interaction Contract — `EquityChart` (CHART-01b: touch tuning, NO rewrite)

**The 2277-LOC hand-rolled live-book chart at `src/app/(dashboard)/allocations/widgets/performance/EquityChart.tsx`.**
Rewriting it to the viewBox pattern is a **banned anti-feature** (`REQUIREMENTS.md` Out of Scope). Tune touch
handlers only.

**Reference gesture (Phase-47 `TimeSeriesChart`, reused via `useTapPin` — verified API):**

| Aspect | Contract |
|--------|----------|
| Wiring | `useTapPin`'s `pointerToIndex(clientX, clientY, rect)` maps to the **existing** `nearestIndex(visibleEpochs, targetEpoch)` O(log n) binary-search (`EquityChart.tsx` L1142–1159) — pixel → clamped px → target epoch → `nearestIndex`, the same math `handleMove` already runs. A tap pins the value the desktop hover shows. |
| Tap detection | inherited from `useTapPin`: pointer moved ≤ `√TAP_SLOP_SQ` (8px) AND gesture < `TAP_MAX_MS` (350ms) → tap, not drag. |
| Tap action | reveal + **pin** the value the existing `hoverIdx` reveal shows (stays visible after the finger lifts). |
| Re-tap | re-tap within `RETAP_THRESHOLD` (3 idx) of the pin **toggles the pin off**; a tap elsewhere **moves** the pin. |
| `pointerleave` | a **pinned** reveal **survives** `pointerleave` (touch lift); an unpinned reveal clears. (Matches `TimeSeriesChart`; CONTEXT.md Area 2.) |
| Auto-dismiss | **none** — no timer. |
| Hit target | the tap layer's hit rectangle measures **≥ 44 × 44 CSS px** under `pointer-coarse:`; verified by the extended Phase-44 target-size gate at 320px on `/allocations`. |
| **Desktop mouse path** | **BYTE-IDENTICAL.** `onMouseMove={handleMove}` / `onMouseLeave={() => setHoverIdx(null)}` / `hoverIdx` (L502) stay exactly as shipped. The touch path is **additive** (a parallel pointer/touch handler set), never a replacement. |
| **Measured-width / ResizeObserver path** | **DO NOT TOUCH** (`EquityChart.tsx` L517–528, floor 400px). SC#1 requires "its measured-width path holds at small widths" — only **verify** it holds; no width-logic refactor. |
| **Projection `useMemo`** | **DO NOT disturb its keying** (L652–670) — it is keyed on data, NOT `hoverIdx`/touch state, by design (the hoist that fixed multi-hundred-ms-per-pixel hover). A touch handler must NOT add `selectedIdx`/`pinned` to its dependency array. |

> **`EquityChart`'s own `<Tooltip>`:** the file contains an inline `<Tooltip>` (it is NOT a Recharts importer —
> it is hand-rolled SVG). The Recharts `TouchTooltip`/`trigger` contract above **does NOT apply to it**; its
> touch reveal is the `useTapPin` pin, not a Recharts `trigger`. Keep them separate.
