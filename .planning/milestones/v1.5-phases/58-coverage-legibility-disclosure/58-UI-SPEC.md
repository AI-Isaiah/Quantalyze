## Color

60/30/10 discipline from DESIGN.md. This surface is inside the already-white composer, so "dominant"
= the page/surface it sits on; the phase's own color budget is spent almost entirely on the
three-state semantics.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` surface / `#F8F9FA` page | Composer surface, timeline panel bg, blend-header bg (`bg-surface`) |
| Secondary (30%) | `#FBFCFD` surface-subtle · `#F1F5F9` track · `#E2E8F0` border · `#64748B` text-muted | Nested timeline panel (`bg-surface-subtle`), the out-of-window gantt track (`bg-track`), hairline borders, muted labels |
| Accent (10%) | `#1B6B5A` | See reserved-for list below |
| Warning (semantic) | text `#B45309` (`text-warning`) · bg `#FEF3C7` (`bg-warning-bg`) · border `#FDE68A` (`border-warning-border`) | Auto-excluded-only: the amber chip, the auto-excluded group, the auto-excluded gantt bar |
| Destructive | `#DC2626` (`text-negative`) | NOT used in this phase — auto-excluded is transient/recoverable, never red. No destructive action in Phase 58. |

**Accent (`#1B6B5A`) reserved for — explicit list, nothing else:**
1. The **in-blend** state chip (fill `bg-accent/10`, text `text-accent`) — "verified member".
2. The **in-window portion** of each coverage-timeline bar (solid `bg-accent`).
3. The **"Show full range"** inline action in the POLISH-03 note and the **include-cost** text-button
   (text `text-accent`, hover `text-accent-hover` `#155A4B`) — these are the only interactive text
   affordances this phase adds, and they read as accent-tinted links, not filled buttons.

**Three-state chip color mapping (LOCKED, DESIGN.md-grounded — do not deviate):**

| State | Text | Background | Border | Rationale (DESIGN.md) |
|-------|------|-----------|--------|----------------------|
| **in-blend** | `text-accent` `#1B6B5A` | `bg-accent/10` | none | Accent = "verified / member". |
| **manually-excluded** | `text-text-muted` `#64748B` | `bg-track` `#F1F5F9` or none | none | Muted neutral = deliberate + sticky, low-emphasis. |
| **auto-excluded (outside window)** | `text-warning` `#B45309` | `bg-warning-bg` `#FEF3C7` | `border-warning-border` `#FDE68A` | Warning is RESERVED for transient recoverable states the system handles — narrowing the window brings the strategy back. Reuses the HoldingsTable revoked-key chip precedent. **Never negative/red** (that = permanent failure). |

**Gantt bar encoding (color-safe, WCAG-AA — never color-only meaning):**
- In-window portion: solid `bg-accent` `#1B6B5A`.
- Out-of-window (covered by data but outside `[winStart,winEnd]`): muted `bg-track` `#F1F5F9`
  (or a hatched fill via CSS `repeating-linear-gradient` if the reviewer prefers texture — either is
  AA-safe because meaning is ALSO carried by the row's text chip + `aria-label`).
- Auto-excluded strategy's whole bar: `bg-warning-bg` with `border-warning-border` so the gantt and the
  row chip AGREE (both amber). The active `[winStart,winEnd]` window draws as a shaded vertical band
  overlay (`bg-accent/5` or a 1px `border-accent` framing band).
- **Color is never the sole signal:** every bar carries a text row-label + an `aria-label`
  ("{name}: covers {first}–{last}, {in-blend | auto-excluded — {reason}}"). Contrast floor: all text
  tokens above are the AA-shifted 2026-04-30 values (`text-muted` 4.85:1, `warning` 5.05:1 on white).

## Copywriting Contract

All strings below are LOCKED verbatim in CONTEXT.md / REQUIREMENTS.md. No new copy is authored beyond
these; reasons reuse `coverageDropReason()`.

| Element | Copy |
|---------|------|
| Primary CTA (include-cost, COVERAGE-04) | Honest per-moved-bound (the original single-string copy only read correctly for the tail case — corrected during code review WR-01/WR-02, `232c80f8`, so the disclosed date(s) always match the bound(s) that actually move): **end-only** (ended/tail-ragged strategy) → `Include → shortens window to {end} (−{N} mo)` (locked base copy); **start-only** (ragged-head strategy) → `Include → moves window start to {start} (−{N} mo)`; **both ends** → `Include → shortens window to {start}–{end} (−{N} mo)` (en-dash range, matching the BlendHeader date convention). Cost in the label, before applying; immediate + reversible, no modal. `{N}` = whole-month delta vs current window (round to nearest whole month, floor at 1 mo if the delta is > 0 but < 1). |
| Blend header — normal (COVERAGE-03) | `Mean of {N} strategies · {effStart}–{effEnd}` — `{N}` = `member_count`, dates = `effective_start`–`effective_end` from `computeScenario`. |
| Blend header — N=1 degrade | `1 strategy — not a blend` |
| Blend header — truncated degrade (append) | `· window truncated from full range` (appended when the effective window is narrower than the union of the selected set) |
| Blend header — N=0 empty state | Honest empty state: `No strategies span the selected window` (engine already guards BLEND-05; the header states it plainly — no fabricated zeros). |
| In-blend chip label | `In blend` |
| Manually-excluded chip label | `Excluded` |
| Auto-excluded chip label | `Outside window` |
| Inline drop reason | Reuse `coverageDropReason()` verbatim: `ends {Mon YYYY} — outside window` / `starts {Mon YYYY} — outside window` / `no data — outside window`. No new strings. |
| POLISH-03 default-change note | `Now showing the common period where all {N} overlap · Show full range` — "Show full range" is the inline escape-hatch action (triggers the existing Full-range preset). |
| Timeline toggle label | `Coverage timeline` (collapsed by default) |
| Destructive confirmation | none — Phase 58 has NO destructive action. Include (COVERAGE-04) is reversible via the Common-period / Full-range presets; it never deletes or reselects a manually-off strategy (manual-off stays sticky). |

**Empty / edge copy already covered upstream (do not duplicate):** the empty-intersection guided-fix
banner (WINDOW-06) and the partial-data banner live in Phase 57 and are unchanged here.

**Accepted divergence (UI-REVIEW #3, non-blocking):** the "Coverage timeline" toggle renders through the
shared `CollapsibleSection` primitive, whose title is `text-sm font-semibold text-text-primary` (an
established, accessible app-wide heading convention) rather than the quieter `text-fixed-11 font-medium
text-text-muted` this spec suggested. Accepted per Rule 11 (match the codebase's shared-primitive
convention) — forcing a per-instance title override on a shared component used across the app is not
worth the regression surface for a cosmetic tier match. The panel stays collapsed-by-default as specified.

## Interaction & State Contract (phase-specific — consumed by planner + executor)

| Behavior | Contract |
|----------|----------|
| Focal point / visual hierarchy | The **always-visible blend header (`BlendHeader`) is the primary visual anchor** of this surface — it states the honest member count · effective window and is what the allocator reads first. Everything else is subordinate: the three-state row chips are secondary (per-row legibility), and the coverage timeline is tertiary (collapsed by default, on-demand). The executor must preserve this priority — do not let the timeline or chips out-weight the header. |
| Timeline default | Collapsed behind the "Coverage timeline" `CollapsibleSection` toggle; expands on demand. Panel transition 250ms → Tailwind `duration-300` (`duration-250` is invalid v4), `ease-out`; honor `prefers-reduced-motion` via `motion-reduce:transition-none`. |
| Timeline scale | x-axis = `unionOf` of the selected set's spans; per-strategy bar = that strategy's `coverageSpanOf` mapped through a local date→x linear scale (lexicographic "YYYY-MM-DD", never JS `Date`). Active window = shaded band at `[winStart,winEnd]`. No new dependency — SVG or flex/div bars, whichever is simpler and passes axe. |
| Blend header source of truth | Reads `member_count` / `member_ids` / `effective_start` / `effective_end` ONLY. The header, the gantt member bars, and the row chips MUST agree on membership via the same `covers()` predicate / engine member set — never three independent derivations. |
| Include-cost apply | One click narrows the window (via the existing `applyWindow` path) to the intersection that includes this strategy, re-running the Phase-57 auto-toggle state machine. Immediate + reversible. Does NOT auto-reselect a manually-excluded strategy. No modal — cost is disclosed in the label. |
| POLISH-03 note visibility | Shown ONLY when the intersection default actually truncates the union (selected members have differing spans) AND the note has not been dismissed. Never when all spans coincide. `role="status"` + `aria-live="polite"`, dismissible via an `×`. |
| POLISH-03 persistence | A per-browser `localStorage` one-time flag (a UI education artifact — NEVER in `ScenarioDraft`, never a server flag; window persistence is Phase 59). Key name is Claude's-discretion (suggest `scenario.coverageDefaultChangeNoteDismissed`). Read must be SSR-safe (two-pass mount / `useEffect`-gated) to avoid a hydration mismatch, matching the composer's existing localStorage discipline. |
| A11y live regions | POLISH-03 note = `role="status"` `aria-live="polite"`. Blend-header state changes are non-blocking → also polite, never `role="alert"`. Auto-excluded group heading association (`aria-labelledby`) is unchanged from Phase 57. |
| Keyboard / focus | Timeline toggle, include-cost button, and "Show full range" action are real `<button>`s in DOM order, Enter/Space activate, `focus-visible:ring-2 focus-visible:ring-accent/50` (matches existing composer buttons at ~2862). No new tab stops that aren't operable. |
| Motion | Chip/reason appearance reuses the existing `AutoExcludedRow` fade+slide (opacity 0→1 + `translate-y-1`→`0`, `duration-300 ease-out`, `motion-reduce:transition-none`). No new decorative animation. |
