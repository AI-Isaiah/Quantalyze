(PERSIST-02). On reopen, seed the composer's Phase-57 window state from `draft.window` (or default to
intersection + show the provenance note for an upgraded v2 draft), then let the existing engineState

inside the draft. This plan makes it FOLLOW the scenario on the two paths where the OWNER's window is
authoritative — reopen (owner reopens their own) and share (recipient must see the owner's window
verbatim, deterministically). Compare (PERSIST-03) is the parallel Plan 03 (disjoint files).
