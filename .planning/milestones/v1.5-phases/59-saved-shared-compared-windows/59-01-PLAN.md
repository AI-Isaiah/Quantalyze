`ScenarioDraft` + its zod schema, bump `SCENARIO_SCHEMA_VERSION` 2→3, and — SIMULTANEOUSLY, in the
same change — add the NON-DESTRUCTIVE v2→v3 codec branch so existing saved scenarios are upgraded on

the dependency root every downstream plan (reopen, share, compare) consumes through the one codec.

(scenario-state.ts:653) → every existing saved scenario is dropped (in reopen it becomes a fresh live
book, in share it becomes honest-absence/404, in compare it becomes the "older format" stamp +
NULL_METRICS). The non-destructive branch, gated by a RED test written FIRST, prevents that data loss.
Implements PERSIST-01 (the storage-model + versioning half; reopen recompute + provenance UI is Plan 02).

Output: `ScenarioDraft.window?` field, bounded-optional zod field, version constant at 3 with a named
PREV constant, the new codec branch returning `outcome:"ok"` + `reason:"upgraded_v2_windowless"`, and
tests proving v2→ok / corrupt-v2→reset / future-version→readonly + save round-trip of the window.
