## Figure-state contract (the core of this phase)

One shared read helper decides the state of every annualised figure; every surface renders from it. It is new pure code in a shared module (planner names it; suggested `src/lib/figure-gate.ts`), consumed by `MetricsColumn.tsx`, `StrategyTable.tsx`, the tearsheet, Holdings and Scenario, so no page restates the thresholds.

**Annualised figures:** CAGR, Ann. Volatility / Volatility, Sharpe, Sortino, Calmar.
**Span:** calendar days from first to last return date. Same definition as `metrics.py` `_simple_elapsed_days`.
**Record (D-15, decides withholding):** the strategy's TOTAL record at full history (starting at `headline_since` when chain-broken), never a selected range or a window inside it. A crypto record (periods per year 365) clears at a span of 90 days; a non-crypto record clears at 60 return observations (`record_observations`; while a stored row lacks the count, at a span of 90 days, the failure direction being the dash). A Scenario blend's record is its overlapping record, crypto when any leg is (`blendPeriodsPerYear`).
**Window (decides the note):** the span of the figures shown: the record at full history; the selected range on a narrowed factsheet; the overlapping window for a Scenario blend; a half, an overlap or a rolling window for the D-11 kinds.

| State | Condition | Cell shows | Reason surfaced as |
|-------|-----------|-----------|--------------------|
| `withheld` | the TOTAL record does not clear D-15's minimum (crypto: span < 90 days; non-crypto: < 60 observations) | `—`, no tone | panel/section note (factsheet, tearsheet, Scenario) or cell `title` + sr-only text (lists, Holdings) |
| `short` | the record clears, and the window shown spans < 365 days (any length, a 20-day selected range included) | the stored figure, normal formatting and tone | one note per panel (factsheet, tearsheet, Scenario); `<1y` marker per cell (lists, Holdings) |
| `full` | the record clears and the window spans ≥ 365 days (D-14's 365-day rolling window included) | the stored figure | nothing |
| `null` | figure not computable / absent | `—`, no tone | nothing new (existing behaviour) |

Non-annualised figures (Return % / Cumulative, Max DD, 6 Month, 3 Month, VaR, CVaR, Best/Worst Day) are **never** gated by span. 6 Month / 3 Month are calendar windows (D-03: 182 / 91 days) and read `null` → `—` when the record does not cover the window.

## List contract (D-09)

Applies to `StrategyTable` (discovery, My Strategies, manager `/strategies`) and any other sortable/filterable metric list the planner finds (enumerate with `grep -n "?? 0" src/components/strategy/*.tsx src/app/**/allocations/**/*.tsx` and review each hit for a sort/filter on a metric).

1. **Missing means null or withheld.** A withheld (record under D-15's minimum) annualised figure counts as missing for sort and filter, exactly like a null.
2. **Sort:** a missing figure sorts **last in both directions**, ascending and descending. Ties among missing rows keep the existing secondary order. Replaces `getSortValue`'s `?? 0` (~:518-529) for every metric key, including `aum` and `six_month_return`.
3. **Filter:** a missing figure **never matches** an active range filter (from, to, or both). Replaces `matchesRange` / `matchesRangeRaw`'s `value ?? 0` (~:495-510). An inactive filter (both bounds empty) still matches every row, missing or not.
4. **Excluded count:** when one or more active range filters exclude rows because the filtered figure is missing, render ONE line directly above the table's scroll region, below the filter bar: muted caption, left-aligned, `px-4 mt-2`, `role="status"` `aria-live="polite"`. Count = distinct rows excluded by at least one active range filter whose figure is missing (a row excluded only by a value out of range is not counted). Hidden when the count is 0. It also shows beneath "No strategies match your filters." when the filter empties the table.
5. **Cell:** `—` in `.font-metric`, no tone, `title` carries the reason (withheld) or nothing (null). Never `0.00%`.
