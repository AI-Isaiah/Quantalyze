`$SCRATCH` is the executor's session scratchpad directory. Nothing below writes into the repo
except the lane's gitignored handoff. Run every command from the worktree root.

1. If `node_modules` is absent, run `npm ci --prefer-offline --no-audit --no-fund` (installs the
   committed lockfile and adds no package).

   `bash scripts/local-stack/run.sh up > "$SCRATCH/lane-up.log" 2>&1`. The boot log is about 250 KB:
   read its tail, never the whole file. On a postgrest `exec format error`, `docker pull` the
   postgrest image the log names and boot again.
3. `bash scripts/local-stack/run.sh --assert-local-handoff` must exit 0 (the handoff is loopback).
4. Write `$SCRATCH/lane-e2e.env` (never inside the repo). From `scripts/local-stack/.stack-env`, take
   `API_URL`, `ANON_KEY` and `SERVICE_ROLE_KEY`, and export them under the six names the CI
   `Lane handoff` step exports: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
   `SUPABASE_SERVICE_ROLE_KEY`, `TEST_SUPABASE_URL`, `TEST_SUPABASE_ANON_KEY`,
   `TEST_SUPABASE_SERVICE_ROLE_KEY`. Add `ADMIN_EMAIL`, `PLATFORM_NAME`, `PLATFORM_EMAIL` and
   `SHARE_TOKEN_SECRET` with the values the `Run seed-gated specs (MA-8 / BLOCK-3)` step's `env:`
   block uses. Add `NEXT_PUBLIC_ALLOWED_ORIGINS=http://127.0.0.1:3100` and
   `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3100`. Use the one host name `127.0.0.1` everywhere
   (server bind, base URL, allowed origin, curl): Node's `request` fixture can resolve `localhost`
   to `::1` first and miss a server bound to `127.0.0.1`.
5. Start the app bound to loopback only (the env carries a service-role key, so never use the
   repo's `dev` script, which binds `0.0.0.0`): source the env file, then run
   `npx next dev -p 3100 --hostname 127.0.0.1 > "$SCRATCH/dev.log" 2>&1 &`. Record the PID and wait
   until `curl -sf http://127.0.0.1:3100/login` answers.
   This exact form is NOT measured yet. The 2026-11-11 UAT ran `next dev -p 3100` on the default host
   with `localhost` URLs. If the `127.0.0.1` form misbehaves (a redirect to another host, a cookie
   that does not stick), fall back to `--hostname localhost` with `http://localhost:3100` in both
   variables and the curl, which is still loopback, and record the deviation in the SUMMARY.
6. Run specs with
   `set -a; . "$SCRATCH/lane-e2e.env"; set +a; CI=1 npx playwright test <spec> --reporter=list --retries 0 --timeout 60000`.
   `CI=1` switches off `playwright.config.ts`'s `webServer`, which would otherwise start or reuse a
   server on port 3000. `--retries 0` overrides the CI retries, so a failure shows on its first run.
7. At the end of the plan, always: kill the dev-server PID, then `bash scripts/local-stack/run.sh down`
   and `bash scripts/local-stack/run.sh --assert-teardown`.

If any page under test raises a React #418 (the hydration guard names it), that is a product defect
outside this gap. Stop and report it. Never empty `hydrationHits` and never retry to get past it.
