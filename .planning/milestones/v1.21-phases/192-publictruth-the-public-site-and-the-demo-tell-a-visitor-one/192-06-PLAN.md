## Decision notes (recorded for the founder)

- **Why not the product's own path.** `scripts/seed-full-app-demo.ts` refuses any project outside its staging allowlist and `scripts/seed-demo-data.ts` refuses a production URL; both guards are pinned by `src/__tests__/critical-regressions.test.ts`. That code is never shipped over empty books: plan 192-10 halts the phase unless this plan writes `D-08 repair: applied` or `not needed (...)`. If the founder declines, the phase stays unshipped until the books exist. The checkpoint says so in those words.
- **This plan's probe reads HEAD's code.** It runs before the phase deploys, so it shows that the data is back, not that plan 192-05's new throws pass on PROD data. Two other checks cover that. Before ship, plan 192-10 reads `D-10 unresolvable labels: 0` (plan 192-01). After deploy, the `/land-and-deploy` run probes PROD (192-VALIDATION.md Manual-Only).
- **Two seeders define the persona books.** `scripts/seed-demo-data.ts` (`STRATEGY_PROFILES`) and `scripts/seed-full-app-demo.ts` (`PERSONA_DEFS` through `ARCHETYPES`) compose the same three portfolios differently.
