## Decision notes (recorded for the founder)

- **Same retired-route rule as plan 192-11 (reversible).** With `/api/demo` out of PUBLIC_ROUTES, a signed-out request for the endpoint gets the proxy's sign-in redirect, the answer every unknown API path gets. The probe compares against a never-existing API control path.
- **Split from the nightly canary (revision 1).** The canary's retirement (the nightly jobs, its spec, the apt-bounded census move and the critical-regressions nightly describe) is plan 192-16, which runs first. The import graph sets the order: the spec imports the token module and `src/lib/demo.ts`, and the route imports both. So the order is spec, then route and token, then constants.
- **DEMO_PDF_SECRET is not renamed or removed.** `src/lib/pdf-render-token.ts` reads it through `SECRET_ENV` for the authed portfolio PDF route. The env-manifest's indirect-read set keeps it. Only comments that name the deleted signer change. Renaming a provisioned secret would be a Vercel change for the founder, outside D-11.
- **Seeders stay (left in place, reported by plan 192-10).** `scripts/seed-demo-data.ts` seeds the e2e-seeded and lighthouse lanes. `scripts/seed-full-app-demo.ts` and `scripts/seed-demo-profiles.ts` are local-dev seeders whose persona steps and comments still describe the retired page; their PROD-refusal guards are pinned by critical-regressions. They are listed as "left in place, unsure", not edited.
- **analytics-service stays.** The cron's exclusion of the demo allocator stays load-bearing while the PROD demo rows stay (D-11), and the `demo_only` recompute universe and its comments are analytics-service code. Both are listed for plan 192-10, not changed here.
- **Local build uses port 3199**, after checking it is free.
