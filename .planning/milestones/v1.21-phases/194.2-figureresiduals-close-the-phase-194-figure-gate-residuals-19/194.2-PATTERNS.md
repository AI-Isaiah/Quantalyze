## Shared Patterns

- **Unreadable means withheld with its reason** (194 D-01/D-15): `figureRecord` in `src/lib/figure-gate.ts:143` is the one verdict; producers carry the flag as a wire scalar, never re-derive it at render time.
- **Report at the producer, once** (`captureToSentry`, tags `{ op, reason: "figure-record-unreadable" }`).
- **Every closing change carries a neuter test** (RED when the fix is removed; neuter, see RED, restore from a byte backup, never git checkout on uncommitted work).
- **TS/Python/SQL twins move together**: `figure-gate.ts` `isReadableDay`/`coveredDays` <-> `analytics-service/services/metrics.py` `_index_span_days` <-> the cohort migration; pinned by `closed-sets.cohort-gate-parity.test.ts`, `test_figure_gate_span.py`, `figure-parity.test.ts`.
- **Muted-note style and DESIGN.md** for all copy; UI contract is `194.2-UI-SPEC.md`.
- **Pre-merge reviews for the migration** (migration-reviewer, rls-policy-auditor); a version bump and CHANGELOG entry ship with the phase; analytics-touching briefs include mypy strict.
