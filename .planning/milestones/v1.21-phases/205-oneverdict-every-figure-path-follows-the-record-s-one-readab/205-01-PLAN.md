<objective>
Close 194.2-REVIEW-R3 WR-01 under D-01: the USD view's record verdict is the native build's
verdict, threaded in and OR'd into the USD `totalRecord`, never re-derived from a second date
list. The `recordSourceDates` mechanism (194.2 R2), which scanned the `keepAbsent = true` series
and so withheld the USD view on a bad date the native build never judged, is replaced. The USD
build stops sending a second Sentry event for an inherited verdict.

disappear because of the toggle. This plan's first task is the phase tracer: it wires the one
verdict from the native build through `fetchAndBuildPayload` into the USD build and proves it on
the production fetch path. Plans 02 and 03 hang the stress block and the allocator blends off the
same verdict.

Output: the `inheritedUnreadable` opt and its threading, the own-verdict report predicate, two new
parity cases, and the neuter evidence in `205-01-SUMMARY.md`.
</objective>
