### Anti-patterns to avoid
- **Re-deriving a threshold or sentence** (60, 90, 365, "annualized from"): import it. A vitest in 194 pins the Python and SQL twins.
- **Counting `returns_series.length` as the observation count**: the stored series is capped; 194-10 proved this (`observations: series?.length` goes RED). Use the stored `record_observations` alias; the span, not the count, decides crypto.
- **Wrapping an annualised figure's *rank or score* in the gate**: 194 withholds the printed figure; Bridge `composite_score`/`fit_label` and the match score are untouched.
- **A plausibility test on a figure's size** (D-05). **`?? 0` for a missing figure.**
- **Projecting `returns_series`, `metrics_json` or `data_quality_flags` whole on a public read** (T-194-19/21/35): scalar JSON-path aliases only.

## Common Pitfalls

### Pitfall 1: A cached public artefact keeps the ungated figure
**What goes wrong:** the OG card is sent `public, max-age=3600, s-maxage=86400, stale-while-revalidate=604800` (`route.tsx` `LONG_CACHE_CONTROL`), and Slack/LinkedIn/Twitter keep their own copy. A deployed fix does not reach a URL the CDN already holds.
**How to avoid:** the factsheet page already moves the OG URL for a unit (`v2/page.tsx:335`, `?u=`); add a version query param in the same place so existing cards are not answered under the same URL, and keep `route.page-agreement.test.tsx` green (it pins the URL shape). The route never reads the param as data.
**Warning signs:** `route.page-agreement` red; a card with Sharpe on a 60-day record after deploy.

### Pitfall 2: The OG card has no slot for the one muted note, and carries a CAGR rule of its own
**What goes wrong:** `og-metrics.ts` hides CAGR under 0.95 calendar years (named exception E1) and for chain-broken rows (E2); D-15 would show CAGR from 90 days with a note. The card prints Sharpe with no qualifier. Gating only the withhold leaves Sharpe at full confidence between 90 days and one year.
**How to avoid:** see Open Question 2 (recommendation: withhold on the total record, keep E1/E2, and draw the existing `shortTrackNote("record", n)` as one muted line when the state is `short`). The route builds its own `rows` from `resolveDailyReturnSeries`, so the verdict inputs must come from the stored alias scalars, not `rows.length`.

### Pitfall 3: Client components cannot import `record-span-read.ts`
`SyncPreviewStep` (B6) queries from the browser; `record-span-read.ts` starts with `import "server-only"`. Add the alias fragment as a plain string constant in a non-server module, or inline it (as `queries.ts:244` does), and add `asset_class` to a `strategies` select. Pin the alias form: postgrest-js's type parser cannot read the `->-1` index, so the select string must be typed `string` and rows cast (documented at `queries.ts:236-243`).

### Pitfall 4: `STRATEGY_ANALYTICS_MATCH_COLUMNS` has a schema-sync guard
Adding `series_end:returns_series->-1->>date` to `src/lib/admin/match.ts:49-51` can fail `strategy-analytics-match-columns-schema-sync.test.ts`, which checks each name exists as a column (the file's comment says a 42703 is swallowed and blanks the whole analytics enrichment). Teach the test the alias forms first, in the same plan.

### Pitfall 5: Legacy window gates in the v2 panels contradict D-15
`HeadlineMetricsPanel` (`history_days < 30` banner), `RollingMetricsPanel` (`< 90` panel gate, per-window `history_days < windowDays`), and `ExposureAndGreeksPanel` (`< 30`, :127) withhold on window length, which D-15 forbids. Their tests (`HeadlineMetricsPanel.test.tsx` 674 lines, `RollingMetricsPanel.test.tsx` 490 lines) pin the old gates and will move. Another reason B2 is expensive and 196-conditional.

### Pitfall 6: Python and TS must move together for Bridge
Add the three keys to `bridge_scoring.py`, `BridgeCandidateSchema` (optional), `ReplacementCard`, and the TS type. `mypy --strict` over `services/ routers/ models/` is a CI gate; run it with the pytest. A response from an older analytics deploy (no state) must read as `null` state and print as before (194-22 "Known Limits").

### Pitfall 7: `ScenarioComposer.tsx` is shared with Phase 198
B8 edits one block (`:8499-8532`) of an 8500-line file that 198 (MYBOOK) may also touch. Keep the diff to that hunk and the prop plumbing; do not re-flow.
