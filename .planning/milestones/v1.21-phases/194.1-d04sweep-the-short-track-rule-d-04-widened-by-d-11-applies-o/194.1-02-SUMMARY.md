# Phase 194.1 Plan 02: Shared scenario page gate (B4) Summary

**The public shared-scenario page now withholds CAGR, Volatility, Sharpe and Sortino for a blend under D-15's minimum and prints the composer's own caption sentence, from the same five `figureRecord` inputs.**

## Accomplishments

- `page.tsx` builds `blendRecord = figureRecord({ seriesStart: metrics.effective_start, seriesEnd: metrics.effective_end, headlineSince: null, observations: metrics.n, periodsPerYear })`, takes `gateAnnualized(record)`, wraps the four annualised KPI arguments in `gatedValue(..., state)`, and renders one `<p data-testid="scenario-share-figure-gate-note" className="mt-2 text-fixed-11 text-text-muted">` under the KPI grid: `withheldReason("blend", record)` when withheld, `shortTrackNote("blend", spanDays)` when short, nothing when full, unknown or `metrics.n <= 0`.
- `grep -acE "\b(60|90|365)\b"` on `page.tsx` is 0 before and after: no threshold or sentence restated.
