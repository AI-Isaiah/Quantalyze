# Phase 194.1 Plan 12: Match-reason Sharpe follows the card's record Summary

**The match engine's `Strong risk-adjusted return (Sharpe X)` sentence is now left out when the candidate's total record is withheld, judged on the same stored record scalars and crypto rule the recommendation card uses; score, rank, eligibility, the stored `sharpe` and every other reason are unchanged.**

## Accomplishments

- `routers/match.py`: imports `RECORD_SCALAR_ALIASES` and `figure_record_from_scalars`; the `strategy_analytics` select gains `, {RECORD_SCALAR_ALIASES}` as an f-string continuation (every earlier column kept, one dated comment added); the candidate dict gains one key, `sharpe_record`, built with `crypto = asset_class == "crypto"` (as TS `annualizationPeriods` reads one strategy, unknown is not crypto here). A strategy with no analytics row gets an all-absent record (unknown).
- `services/match_engine.py`: `record_clears` joins the `services.metrics` import; only the Sharpe sentence's condition changed (plus its dated comment). Withheld means `sharpe_record` is a dict whose `unreadable` is true or for which `record_clears(span_days, observations, crypto) is False`.
- `tests/test_match_reason_record_gate.py`: 12 cases, loader to reason. Select entries (each alias present, no bare `metrics_json`, prior columns kept); crypto 40 days withheld; past one year kept word for word; traditional 59 over 120 days withheld; traditional 62 over 89 days kept (and the same row as crypto withheld); crypto 200 days kept with no qualifier; absent series end kept; `2026-13-01` start flagged unreadable and withheld; hand-built dict without the key kept; non-dict value kept; no analytics row (no sentence, `sharpe` None, all-absent record); a withheld record drops that one sentence and nothing else. Spans are computed from each fixture's own dates (D-20), sentences hand-typed.
