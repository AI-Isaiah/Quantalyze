### S2: scalars at the producer, verdict at the consumer (B2, B6, B8, B12a/b, B3 embed)

**Producer analog:** `src/lib/queries.ts` `figureRecordScalars` (~:2818-2860)
```typescript
function figureRecordScalars(input: {
  series: ReadonlyArray<{ date: string }>;
  dataQualityFlags: unknown;
  recordObservations: unknown;
  assetClass: string | null | undefined;
  strategyId: string;
}): Pick<OwnCapitalStrategy, "figure_span_days" | "figure_observations" | "figure_crypto"> {
  const record = figureRecord({
    seriesStart: series[0]?.date ?? null,
    seriesEnd: series[series.length - 1]?.date ?? null,
    headlineSince: typeof since === "string" && /^\d{4}-\d{2}-\d{2}/.test(since) ? since.slice(0, 10) : null,
    observations: typeof recordObservations === "number" ? recordObservations : null,
    periodsPerYear: annualizationPeriods(assetClass),
  });
  // 194 R5 SFH-M3: reported at the producer, once per call, never from a render-time gate.
  if (record.unreadable) { captureToSentry(new Error("holdings figure record unreadable: ..."), {...}); }
  return { figure_span_days: record.spanDays, figure_observations: record.observations, figure_crypto: record.crypto };
}
```
Rule: report an unreadable record at the producer, once; never from a render path.

**Consumer analog:** `strategies-row-adapter.ts` `gatedSharpe` (~:170-188), the scalar-to-verdict reconstruction:

## Shared Patterns

### One verdict, strings in one place
**Source:** `src/lib/figure-gate.ts`: `figureRecord` (:113), `recordClears` (:138), `gateAnnualized` (:153), `gatedValue` (:166), `gateDelta` (:198), `shorterSpan` (:182), `gateRollingWindow` (:244), `withheldReason`, `shortTrackNote`, `withheldCellTitle`, `shortTrackMarkerTitle`, `SHORT_TRACK_MARKER`, `widenedWithheldReason`, `widenedShortNote`.
**Apply to:** every file above. No file restates 60, 90, 365 or a sentence. Tests type the expected sentence by hand (oracle independence), exactly as `page.figure-gate.test.tsx` does.

### Withheld is `null` and a toneless dash, never 0, never a substitute
`gatedValue` returns `null` for withheld or non-finite; formatters print the em dash; pass the GATED value to `metricColor`, `signTone`, `magnitudeColor` so a dash is never tinted. No `?? 0`. No plausibility test on a figure's size (D-05): include one very large stored value in a test and assert it renders like any finite value.

### One muted note, no amber glyph (D-13)
Idioms already in the tree: `mt-2 text-xs text-text-muted` (browse page :190), `mt-2 text-fixed-11 text-text-muted` with a `data-testid` (`ScenarioBenchmarkSection.tsx` :201-207), `mb-2 text-fixed-10 italic text-text-muted` (factsheet rail), `annualizedCell` `<1y` marker (`annualized-cell.tsx` :54-67) for table cells. ONE note per figure group.

### Fail closed on an unreadable record
A scalar read that cannot be made prints dashes plus "Annualized figures are temporarily unavailable. Reload to retry." (browse page :100-104); the read helper reports to Sentry itself; the caller owns the single `console.error`. An unreadable record is reported once at the producer (`figureRecordScalars`), never from a render path.

### Scalars only on public and admin projections
Only `series_start`, `series_end`, `headline_since`, `record_observations` (+ `asset_class`) leave the database. `returns_series`, `data_quality_flags`, `metrics_json` are never projected whole (T-194-19/21/35). A test pins the select string.

### Observation count is the stored `record_observations`, never `returns_series.length`
The stored series is capped; 194-10 proved `observations: series?.length` goes RED. Span (not count) decides crypto.

### Python gates
`pytest` only from `analytics-service/`; `mypy --strict` over `services/ routers/ models/` runs in CI, include it in the same pre-push check; additive optional keys on the wire so neither deploy order 500s.

### Gates must be able to fail
Each plan records neuter, RED, restore evidence from a `cp -p` backup and `cmp` after (never `git checkout/restore/stash` on uncommitted work). `grep -a` always. A new test file moves censuses: grep them all.

### Release hygiene
CHANGELOG entry plus 4-digit `VERSION` bump byte-equal to `package.json` (never `npm version`), never write the CI skip-trailer tokens, a ship branch changes nothing under `.planning`, no AI-authorship trailers, no home paths, PROD ids or amounts in tracked text.
