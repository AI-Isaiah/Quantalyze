## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] AGE4 pin in `page.mandate-gate.test.tsx` widened for the new alias shape**
- **Found during:** Task 1
- **Issue:** AGE4 asserts the status select never contains `returns_series` after removing the `->-1->>date` alias. The plan's required `RECORD_SCALAR_ALIASES` adds `returns_series->0->>date`, so the literal `.replace` left a `returns_series` behind and the pin could not pass.

- **Files modified:** `src/app/(dashboard)/recommendations/page.mandate-gate.test.tsx`
- **Commit:** e4312f87b

### Neuter 1 needed both layers

`gatedValue` and `annualizedCell` each independently produce the dash for a withheld record, so removing only `gatedValue` on Sharpe (the plan's literal neuter) leaves the rendered cell unchanged and the suite stays green (11 passed, measured). That redundancy is by design (the value is nulled at the producer and the cell is withheld at the renderer), so no output test can see one layer alone. Neuter 1 therefore removes both layers for Sharpe and goes RED as quoted above. Neuters 2 to 4 were run as the plan states, with 2 widened to also treat the empty map as a known class (an empty map alone still nulls every card through `.has`).
