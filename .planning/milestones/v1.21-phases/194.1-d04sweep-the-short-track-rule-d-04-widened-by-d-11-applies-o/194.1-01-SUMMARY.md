# Phase 194.1 Plan 01: Record scalars and the every-page census Summary

**A client-safe `recordFromScalars` (alias list pinned equal to the server reader and the percentile read) plus a census test that goes RED for any ungated annualised figure under `src/app` or `src/components`.**

## Accomplishments

- `src/lib/figure-record-scalars.ts` exports `RECORD_SCALAR_ALIASES` (typed `string`), `RecordScalarRow` and `recordFromScalars(row, assetClass)`. It builds the record through `figureRecord` and `annualizationPeriods`, restates no threshold (`grep -acE "\b(60|90|365)\b"` prints 0) and imports no `server-only`, Supabase or Sentry module. Coercion twins `readRecordSpan`'s: non-empty string or null for dates, finite number or null for the count (a numeric string is absent).
- `src/lib/figure-record-scalars.test.ts` (14 cases) pins the alias string equal to `RECORD_SPAN_SELECT`'s inner list and to the `PERCENTILE_SPAN_COLUMNS` literal in `queries.ts` (regex on source text; a miss fails, never a vacuous pass). It covers crypto 89 / 90 / 400 covered days (withheld / short / full), crypto 62 observations over 89 days (withheld), non-crypto 59 / 60, the day bound with no count, null or undefined asset class, `headline_since` shortening the span, an unparsable end (unreadable, withheld), null / empty row, and the `"60"` string count.
- `src/__tests__/figure-gate-census.test.ts` (10 cases) walks `src/app` and `src/components` (non-test `.ts`/`.tsx`, `__fixtures__` and `.spec.` skipped), comment-stripped, and checks every file matching the figure pattern. Both maps, the closed reason set, the 196-redirect entries, the anchors and the planted self-test are in the file.
