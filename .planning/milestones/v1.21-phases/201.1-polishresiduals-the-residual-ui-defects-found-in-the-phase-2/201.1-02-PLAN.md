<objective>
D-01 (SC-1, WR-13): a failed key row with a long `sync_error` never squeezes the label below a readable width in the one-line key-row layout.

Purpose: the UAT measured a 20.2px label column ("U…") at 1440px on a failed row with a 60-character label, and 120px at 1920px. The cause (200-REVIEW WR-13): in the single-line layout the label column's flex basis is zero, so in the `flex-wrap` row the line-breaker counts it as 0px and every sibling that fits, the long status helper included, takes line one. A real basis makes the line-breaker reserve the label's width first (RESEARCH Pattern 1).

Output: the 12.5rem basis on both key-row sites, a seed option for a failed key, and a failed-row floor test at 1280, 1440 and 1920px that was RED on the old basis.
</objective>
