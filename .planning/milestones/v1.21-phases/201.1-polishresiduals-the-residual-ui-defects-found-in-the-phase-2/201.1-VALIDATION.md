- **After every task commit:** run the touched test file(s) with `npx vitest run <files>`
- **After every plan wave:** all touched vitest files plus `npm run typecheck` (the D-04 plan also runs the whole jsdom suite)
- **Before `/gsd-verify-work`:** full suite green locally; e2e-seeded green in CI at the head SHA with the golden commit in
- **Max feedback latency:** 60 seconds per task
