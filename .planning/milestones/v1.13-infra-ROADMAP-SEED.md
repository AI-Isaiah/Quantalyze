## Spine (sequenced by dependency, not number)

**Critical path — external long-pole, START DAY 1:**
- **Fly static-egress proxy + IP bind** (re-homes v1.12 **121-03**). Artifacts +
  worker wiring already landed (121-01/121-02); this is the founder ops: `fly
  deploy`, provision the dedicated inbound v4 (~$2/mo) AND the static EGRESS ip
  (~$3.60/mo — the egress IP is what sFOX whitelists), verify realized egress ==
  the static egress IP FROM the machine (`curl ipinfo.io` through the proxy)
  BEFORE whitelisting, then hand the IP to the trading team. Their binding is the
  async gate — kick it off before everything else.
- **sFOX flag flip** — `SFOX_ENABLED`/`NEXT_PUBLIC_SFOX_ENABLED` on, once all
  gates below are green and the key is IP-bound. (cron reschedule + flag flip are
  founder LIVE ops, NOT migrations — auto-apply + a skipped worker deploy re-wedges.)

**Worker rebuild (the big infra chunk, parallels the long-pole):**
- **Dedicated backfill worker** — split the derived-equity backfill off the
  single sequential prod worker onto its OWN worker; hard per-crawl
  `asyncio.wait_for` (groundwork landed in v1.12 123-01); off-hours batched
  backfill; re-schedule `cron.schedule('derive-allocator-key-dailies','30 5 * * *')`.
  This is what wedged the sequential worker and forced the v1.11 FLIP rollback.
- **Test-DB retention hygiene** — nightly purge of orphaned `running` compute_jobs
  on the TEST project. The `derive-allocator-key-dailies` cron re-pollutes daily
  and a SQL test (`test_derive_allocator_keys_fanout.sql` assertion 6) requires
  that cron to stay scheduled, so the recurring `python` fence-test CI flake will
  keep firing until a retention purge exists. Small, high leverage — do it early.
  See [[project_shared_testdb_concurrent_ci_flake]].

**Go-live gates (parallel):**

  strategy (the same strategy's edit-page tag + browse badge render fine). Likely
  fix: the factsheet degrades gracefully when the connected-key provenance render
  fails (also hardens prod against a transient analytics outage). See
  [[project_sfox_factsheet_e2e_deferred_golive_gate]].
- **E2 ground-truth validation** (re-homes v1.12 **123** FLIPRETRY-03) — the
  `api_verified` anti-fabrication anchor: `e2_allocator_ground_truth.py` +
