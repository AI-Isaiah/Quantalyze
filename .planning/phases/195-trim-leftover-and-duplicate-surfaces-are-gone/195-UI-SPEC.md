# Phase 195 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This is a **removal phase**. It adds no visual language. Every surface below is described as
the layout left once something is gone, plus two small new pieces: the "report retired"
landing (D-03) and the single combined disclaimer block (D-09). Both reuse existing tokens,
existing primitives and existing copy where it exists. `DESIGN.md` is the source of truth;
nothing here overrides it.

Sources: `195-CONTEXT.md` D-01..D-10 (locked), ROADMAP § Phase 195 SC-1..SC-5,
REQUIREMENTS LEAN-03 / LEAN-07 and the out-of-scope row "Dark mode", `DESIGN.md`, and a code
scout of the worktree at `feat/195-trim` on 2026-11-07. Line numbers below are from that scout;
re-resolve them by symbol before editing.

- Removals leave **no spacer, placeholder or empty band** where the control was (see the surface

## Typography

The two new pieces use exactly four sizes and two weights, all existing tiers.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Body | 14px (`text-body`, 14→16 fluid), DM Sans | 400 | 1.5 (`leading-normal`) | retired page paragraphs; the two CTA labels (the `Button` `md` size already sets `text-body`) |
| Label | 11px (`text-micro`, 10→11 fluid), Geist Mono, uppercase, tracked | 400 | 1.5 | retired page masthead eyebrow (`tracking-[0.22em]`), retirement stamp (`tracking-[0.18em]`) |
| Caption | 12px (`text-xs`), DM Sans | 400 | 1.625 (`leading-relaxed`) | the combined disclaimer block (unchanged from today's `Disclaimer` primitive) |
| Display | 32px (`text-page-title`, 24→32 fluid), Instrument Serif | 400 | 1.25 (`leading-tight`) | retired page H1 |

Weights: **400 regular** and **500 medium**. 500 appears only on the two CTA labels, through the
existing `Button` primitive (`font-medium`, `size="md"`). No semibold, no bold on any new piece.

Voices stay in their lanes (`DESIGN.md` § Typography): the eyebrow and stamp are data-annotation
voice (mono), the H1 is display voice (serif), paragraphs and buttons are interactive voice (DM
Sans). No raw `text-[Npx]` (the `no-raw-font-px` lint is `error` repo-wide).

The tearsheet's existing "Risk Disclosure" heading (`text-sm font-semibold`) and its 10px body
(`text-fixed-10`) are kept as they are: the tearsheet is a print document and Phase 196 reshapes
it. This phase only changes which sentences sit inside that block.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #F8F9FA (`bg-page`) | retired page background; all other surfaces unchanged |
| Secondary (30%) | #FFFFFF (`bg-surface`) | cards, panels, the `LegalFooter` band; unchanged |
| Accent (10%) | #1B6B5A (`bg-accent`, hover #155A4B) | see the reserved list below |
| Destructive | #DC2626 (`negative`) | **not used in this phase.** No destructive action is added. |

Accent reserved for, in this phase:
1. The retired page's single primary CTA, "Browse verified strategies".
2. Existing accent uses that survive the removals, unchanged: the allocations header
   "+ Allocation" / "+ Strategy" button, the sidebar active-item text, focus outlines.

Nothing else on the new pieces carries accent. The retirement stamp, eyebrow and paragraphs are
neutral (`text-text-muted`, `text-text-secondary`, `text-text-primary`).

**Semantic-color gate for the retired page.** A retired report is a deliberate, permanent state,
not an error and not a recoverable one. It renders in the **muted steady-state** tone: no red, no
amber, and it does **not** use the `ErrorEnvelope` shell (`border-negative/30 bg-negative/5`).

**Colour after the removals (the part a user could notice).**
- Every allocator sees the accent at `#1B6B5A`. The Tweaks "accent intensity: full" swap
  (`data-accent-intensity="full"` on `<html>`) never applies again, including for a browser whose
  `localStorage["allocations.tweaks"]` still holds `"accentIntensity":"full"`.
- No factsheet renders the dark slate palette (`.factsheet-v2-shell[data-theme="dark"]`) again,
  including on a URL carrying `?dark=1` and on a browser whose stored factsheet view state holds
  `dark: "1"`. The light palette, and the colorblind palette when chosen, are the only ones.

### S-5. One disclaimer block per page, at the page bottom (D-09)

**The block.** Visually it is today's `Disclaimer` `footer` variant, unchanged: a hairline top
rule (`border-t border-border`), `mt-12 py-6`, 12px DM Sans `text-text-muted`,
`leading-relaxed`. What changes is the text it carries on a page that needs more than the general
wording. It is the **last content element** of the page: after every CTA and every panel, directly
above `LegalFooter` (or the end of the document where a page has no `LegalFooter`).

**Composition rule.** The block carries the union of the sentences that apply to the page, each
sentence once, in this order: custody → data provenance → general risk. Sentence texts come from
the existing constants in `src/components/ui/Disclaimer.tsx` (`CUSTODY_TEXT`, `PROVENANCE[tier]`,
`FOOTER_TEXT`); no new legal sentence is written. Where two existing sentences state the same
thing, the block keeps one:
- "Past performance is not indicative of future results." (the `strategy` variant's suffix) and
  "Past performance does not guarantee future results." (in `FOOTER_TEXT`) are the same statement.
  The block keeps **"Past performance does not guarantee future results."** (the general wording,
  which every page already shows).

**Layout-level footer.** The layout's own footer disclaimer (`browse/layout.tsx` ~:40,
`DashboardChrome.tsx` ~:178 and ~:254) does not render on a page that renders its own block. On
every other page it renders exactly as today.

**Reference case — `/browse/<category>/<id>`** (today: custody box under the manager panel
~:95, strategy text at the bottom ~:190, layout footer ~:40 = three blocks).
- **After:** the custody box under the manager panel is gone (the hero metrics follow the manager
  panel with the existing `mb-6` rhythm), the bottom `strategy` paragraph is gone, the layout
  footer does not render on this page, and one block renders after the sign-up CTA card. Verbatim
  text for an `api_verified` strategy, platform name "Quantalyze":

  > Strategy monitored via read-only exchange API. Manager retains asset custody. Quantalyze
  > provides analytics only — no pooling, no fund administration, no custody of client assets.
  > Data verified from exchange API. Quantalyze does not independently audit trading strategies.
  > Not financial advice. Past performance does not guarantee future results. Cryptocurrency
  > trading involves substantial risk of loss.

  For `csv_uploaded` and `self_reported` (or a null tier), the provenance sentence is that tier's
  `PROVENANCE` text, exactly as the `strategy` variant picks it today. See UC-10 for the custody
  sentence on those tiers.

**Tearsheet — `/factsheet/<id>/tearsheet`** (today: a custody box section ~:675, then a
"Risk Disclosure" section ~:679 whose paragraph already repeats "Strategies are monitored via
read-only exchange APIs; managers retain asset custody.", then the contact CTA, then the

- **After:** the custody box section is gone. The "Risk Disclosure" section is the page's one

  > managers retain asset custody. Quantalyze provides analytics only — no pooling, no fund
