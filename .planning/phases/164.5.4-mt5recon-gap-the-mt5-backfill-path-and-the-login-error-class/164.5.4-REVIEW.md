## Warnings

### WR-01: New MT5 code depends on a distant, non-top-level `import math`

**File:** `analytics-service/services/equity_reconstruction.py:2549`
**Issue:** The NaN-anchor guard added by this phase —
`if not (math.isfinite(equity) and math.isfinite(balance)):` — is new code
(confirmed via diff), but `equity_reconstruction.py` has no top-level
`import math`. The only `import math` in the file is at line 3251, roughly
700 lines further down, inside the `EquityCurveBuilder` design-notes comment
block (an unrelated, pre-existing, Phase-19 class). This works today only
because Python executes all module-level statements — including an import
buried mid-file — before any function in the module can be called, so by the
time `_mt5_fetch_window` runs, `math` is already bound in the module
namespace. mypy and the test suite are both happy with this because it is,
in fact, correct at runtime.

The risk is that this is surprising and fragile: a future editor who deletes
or moves `EquityCurveBuilder` (or its "Design notes" comment block, which
`import math` sits directly under) as dead code, or who runs an
import-organizer that treats a mid-file import as misplaced and relocates it
under an unrelated class, would silently strip the only thing making the new
NaN guard resolve. The failure mode is a `NameError: name 'math' is not
defined` raised deep inside the MT5 backfill's exception-handling path —
itself inside a `try` block whose `except Exception` arm would catch it and
misclassify it via `classify_exception` as a generic unhandled fault, rather
than surfacing the real defect clearly.

**Fix:** Add `import math` to the file's top-level stdlib import block
(alongside `asyncio`, `json`, `logging`, `os`), where every other consumer of
`math.isfinite` in this repo puts it. A duplicate `import math` further down
is harmless in Python and can be left as-is, or removed as a follow-up
cleanup — but the new code this phase added should not rely on an import
whose only reason for being in scope is an unrelated class 700 lines away.
```python
import asyncio
import json
import logging
import math
import os
```

## SF-H1 — BLOCKER (data-integrity): the NAV quality meta is discarded at the backfill call site

**Symbol:** `services/equity_reconstruction.py` — `_mt5_fetch_window`, at its
`reconstruct_mt5_nav_levels(...)` call; and `_mt5_telemetry`.

`_meta` is bound to `_` and dropped, so the published MT5 equity curve carries no quality signal

**ORCHESTRATOR VERIFICATION (measured, not read):** the derive sibling in `services/job_worker.py`

`services/equity_reconstruction.py` contains **0 occurrences** of `negative_nav_guard`,

⚠️ Distinct from the `anchor_*` omission, which `_mt5_telemetry`'s own docstring argues correctly
