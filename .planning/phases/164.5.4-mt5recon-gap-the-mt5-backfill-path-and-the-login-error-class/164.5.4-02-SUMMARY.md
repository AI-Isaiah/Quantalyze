## Decisions Made

See `key-decisions` in the frontmatter. The one worth restating: **the identifier is `KEY_MUST_BE_RECONNECTED`, not `KEY_UNDECRYPTABLE`.** Code ids are PostHog-stable and outlive their copy; mirroring the wire name would bake the ciphertext mechanism into a permanent identifier, and the table's own discipline is to name what is true for the user. "Undecryptable" is what happened to us; "must be reconnected" is what is true for them, and it is the remedy Python already published.
