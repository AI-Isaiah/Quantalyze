## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] CorrelationMatrix precomputed path had a second id leak the plan did not name**
- **Found during:** Task 2
- **Issue:** the plan names `... ?? id` and `... ?? "?"`. On the precomputed path the id leaked twice: the name-map builder defaulted `name` to `id` (so `if (id && name)` stored the id as a name), and the consumer fell back to `nameMap[k] ?? k`. Fixing only the consumer would still have shown the id.
- **Fix:** dropped the `?? id` default in the name-map builder and made the consumer read "Unnamed strategy". Pinned by the precomputed-path case in `CorrelationMatrix.names.test.tsx` (RED when `?? k` is restored).
- **Files modified:** `src/app/(dashboard)/allocations/widgets/risk/CorrelationMatrix.tsx`
- **Commit:** `7381ae18d`
