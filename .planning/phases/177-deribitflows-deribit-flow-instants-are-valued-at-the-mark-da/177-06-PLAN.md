<objective>
Carry the fix into stitch composites, the last two places that value Deribit flow instants (`_deribit_apply_inputs`
for a plain member, `_twin_inputs` for an allocated member), each RED first, with the composite's own refusal and the
D-01 line.

In a composite the member's marks are EXACT (no prediction): `_apply_member_marks` holds `relevant` and
`_reconstruct_deribit` holds `_alloc_marks`, both with the member's exchange still open (RESEARCH "Where the moved
instants are known", Pattern 3, Composite members). So the composite runs the same `resolve_moved_flow_prices` with
those marks, then the same `unpriced_moved_flows` check, and lets failures take the arms the composite already has.

Design choice (Claude's discretion): the generic `_apply_member_marks` gains ONE optional keyword hook, awaited with the
member's exact marks after `relevant` is known and before `build_inputs` runs; only the Deribit plain member passes it,
so every ccxt member stays byte-identical. The allocated member's prices are resolved in `_reconstruct_deribit`, where
`_alloc_marks` already lives, and handed to `_apply_allocated_member_marks` as a keyword.

Purpose: SC-2 in composites, SC-1's composite line. Output: the hook, the refusal class, the wiring, the line, the tests.
</objective>
