## Deviations from Plan

**1. [Rule 1 - Harness correctness] Leg (e) uses an additive helper, not `mutate`**
- **Found during:** Task 1.
- **Issue:** The analog's `mutate` asserts that the target is gone after the replacement. Leg (e) adds a second step, so the real run line necessarily survives, and that self-check would fail for a correct mutation.
- **Fix:** I added `insertAfter`. It checks that the anchor occurs exactly once, that the added text is absent before the insertion, and that it is present after. The leg still feeds the mutated copy through `surfaceProblems`.
- **Commit:** `3afdefab2`.

**2. [Scope, additive] `ciMypyArgs` stops at the next `- name:` line**
- I made this choice so that a step whose `run:` is missing cannot pick up a later step's `run:` line. It is stricter than the plan's "next line whose trim starts with `run: `" and cannot loosen the pin.

Otherwise the plan was executed as written. The REGISTRY.md row follows its siblings' convention of a blank line before each row.
