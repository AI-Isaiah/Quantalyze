# Phase 164.6.5 Plan 02: Terminal-process supervision tracer Summary

`Mt5Client.recycle_terminal_process` is a new verb. It ends the Wine-hosted `terminal64.exe` by running ONE committed, non-interpolated Toolhelp32/TerminateProcess source over the existing rpyc channel. It then relaunches the terminal through the credential-free detector's own bare `initialize()`. It takes no parameter, sits behind `_assert_live`, and goes through `_guarded_read`. This is the mechanism the founder's 2026-09-25 live spike proved.

## Task 3: the verb

**What was built:**
- `_REMOTE_TERMINAL_RECYCLE_FN` / `_REMOTE_TERMINAL_RECYCLE_SRC`, modelled on `_REMOTE_MATERIALIZE_*`:
  - It is a plain literal, not an f-string, with the function name written inside it.
  - The one run-time value, `_TERMINAL_EXIT_WAIT_MS` = 5000, crosses as an int argument.
  - Inside, it runs Toolhelp32 enumeration, then `TerminateProcess` on every `terminal64.exe`, then `WaitForSingleObject`. It returns a JSON string `matched/terminated/exited`.
  - A snapshot failure raises.
- `Mt5Client.recycle_terminal_process()`, in this order:
  1. `_assert_live("terminal_recycle")`.
  2. The transport-seam lookup; an absent seam raises a typed error.
  3. `conn.execute` plus the namespace call, inside `_guarded_read(stage="terminal_recycle")`.
  4. JSON parse; a malformed verdict raises a typed error.
  5. `assert_session_authorized()` as the relaunch. Its `Mt5ClientError` is recorded as `authorized=False` / `relaunch_code=<code>`. `Mt5SessionAbandoned` still propagates.
- **Named apart from `restart`**, which reconnects the rpyc socket.

**Why the relaunch is inside the verb.** The spike showed the relaunch happens on the NEXT `initialize()`. Left to the next caller, that took 25 s in one run and 4m45s in the other. Issuing it in the verb bounds the delay by the registered `initialize` ceiling (20 s, below the 30 s rpyc bound). It also means the verdict carries the detector's own answer.

- The plan expected the spike to yield a Linux-side relaunch command to transcribe.
