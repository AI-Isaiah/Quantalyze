Justification (all verified at HEAD): `asset_class` is `NOT NULL DEFAULT 'traditional'`
(`supabase/migrations/20260709130000_strategies_asset_class.sql:26-27`), so on that column
"never classified" and "user chose traditional" are the SAME stored value — filling on
`asset_class='traditional'` would overwrite a legitimate user choice, which is exactly what the
economic oracle forbids. `category_id` has no default, the fold's INSERT never writes it,
`applyCsvMetadataUpdate` writes both fields in ONE atomic UPDATE (`route.ts:1455-1459`), and the
wizard always sends `category_id` (an explicit null is 400-refused pre-create, `route.ts:353-359`).
Therefore `category_id IS NULL` on the committed row is observable proof the metadata UPDATE
never ran. The plan MUST NOT key FILL on `asset_class`.

**FILL-safety — the orchestrator's hole, SETTLED WITH EVIDENCE (do not re-derive):**

that reconciles it. Evidence chain, all read from source at plan time:
1. Every stored-KPI writer path requires stored dailies: the finalize enqueue is gated on
   `dailyReturnsSeries.length > 0` (`route.ts:1938`), and the ONLY other enqueuer — the

   self-verify RAISEs if the body stops reading `public.csv_daily_returns` (`:449-450`).
   With no compute job, `strategy_analytics` has no row at all (`route.ts:1640-1654`).
   ⇒ **`trades` strategies carry NO stored KPIs — structurally pinned, not assumed.**
2. On any echo, the resolve arm's series-equality check (`route.ts:1060-1135`) guarantees the
   payload series ≡ committed series in count and boundaries, and an empty payload echoes only
   when the committed series is empty too (`:1076-1080`).
   ⇒ **enqueue fires on the echo ⟺ committed dailies exist ⟺ stored KPIs can exist.**
So FILL is clock-safe on BOTH arms: a series-bearing FILL is followed by a recompute under the
filled clock; an empty-series (trades) FILL has no recompute AND no stored KPIs to reconcile —
the hazard is vacuous by construction. FILL is therefore UNCONDITIONAL on `category_id IS NULL`;
the tests below pin both sides of the invariant.
