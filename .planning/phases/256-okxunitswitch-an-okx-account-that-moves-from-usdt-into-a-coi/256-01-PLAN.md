<objective>
Build the one pure seam that says whether, and when, an OKX account switched from its stable unit into a coin, and that splits its daily P&L at that switch.

Purpose: SC-1 (switch date derived from data, named refusal) and the day-accounting half of SC-2 (each day in one unit, none doubled or dropped). Implements CONTEXT "Decided autonomously" [Switch detection] (one pure function beside services/account_unit.py, never a constant), [Boundary day] (S is the last USD return day, coin base at end of S, first coin return day S+1, stored as the switch day), [Switch detection] COIN_LEAD_TOLERANCE_DAYS = 14, and CONTEXT "Switch detection" (first day value or P&L is in a coin, gradual mover does not refuse, missing or ambiguous refuses by name).
Output: `analytics-service/services/unit_switch.py` and its test file.
</objective>

## Interface contract this plan creates (later plans bind to these names)
- `UnitSwitch` frozen slots dataclass: `coin: str` (upper-case, `[A-Z]{2,10}`), `last_usd_day: str` (ISO UTC day S), `first_coin_return_day: str` (ISO, S + 1). `first_coin_return_day` is CONTEXT's "stored switch_day"; it is named explicitly because RESEARCH and CONTEXT use `switch_day` for different days (UI-SPEC rule 2). No field is called `switch_day`.
- `CoinBillCensus = Mapping[str, tuple[str, int]]`: coin code to (first UTC day ISO, bill count), built by the fetch (plan 03) from bills with a non-zero `pnl + fee` in a non-stable, regex-valid `ccy`.
- `EndOfDayHoldings = Sequence[tuple[str, Mapping[str, float]]]`: (end-of-day ISO day, {symbol: value_usd}), ascending, spot rows only.
- `UnitSwitchResolver = Callable[[CoinBillCensus], Awaitable[UnitSwitch | str]]`: the async keyword type plan 03 adds to the fetch. Declared here as a type alias only; this module performs no I/O.
- `SplitPnl` frozen slots dataclass: `usd_by_day: dict[str, float]`, `coin_by_day: dict[str, float]`.
- Closed refusal set `UNIT_SWITCH_REFUSALS: Final[frozenset[str]]` = `no_coin_evidence`, `coin_bills_without_majority`, `two_coins`, `switch_back`, `ambiguous_boundary`, `holdings_unavailable`, `bills_precede_majority_beyond_tolerance`, `coin_without_price_source`, `switch_day_unpriced`, `coin_segment_unpriced`.
