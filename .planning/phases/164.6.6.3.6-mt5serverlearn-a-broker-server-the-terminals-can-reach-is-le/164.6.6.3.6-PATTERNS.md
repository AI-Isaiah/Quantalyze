- **Founder-only acts:** no agent drives VNC, Railway, a broker or PROD for gate steps (the agent may read DB/logs/Reading B, per 164.6.6 preamble).
- **PROD reads:** dashboard Table Editor reads need no marker query; any WRITE does (project CLAUDE.md, MEMORY).
- **Teardown then L6 re-read** after any VNC session.
