## Decisions Made

See `key-decisions` in the frontmatter. The two worth reading in full:

**The stale current-behavior test was replaced, not flipped.** It asserted `toHaveLength(0)` — that the single-line idiom is NOT detected. Its own comment said to flip it to `>= 1`, but that would have made it a byte-for-byte duplicate of the un-skipped intended-behavior test. Instead it became a **false-positive guard**: a mid-line `.update(`/`.delete(` with no `.from(` anchor must stay invisible. The loosened regex had no such guard, and the obvious lazy fix (match `.insert(` anywhere) would have passed every other test in the file while flooding the gate with noise from `weights.update(...)` and `map.delete(...)`. A gate that cries wolf gets muted, which arrives at the same destination as a gate that cannot fail.

**The detected-sites floor was ratcheted 25 → 60, and it is explicitly documented as insufficient on its own.** A regression to the old anchor drops the count 81 → 71, which a floor of 60 does NOT catch. The comment says so out loud and names the two mechanisms that do catch it (the intended-behavior test and the exact-set allowlist). A floor wide enough to be quiet is too wide to bite; recording that honestly is better than a floor that looks protective.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] The fixed detector reported a fabricated 7th uncovered site**
- **Found during:** Task 1, first run of the fixed detector
- **Issue:** Matching the mutator mid-line put the detector's eyes on documentation for the first time. It reported `src/app/api/allocator/scenario/commit/route.ts:10` as an uncovered mutation — a JSDoc line reading ``every `supabase.from().insert()` commits independently``. The existing `stripLineComment` only handles `//` and a `/* … */` pair closing on one line; it cannot see a block comment whose body spans lines. Had this not been caught, the "counted allowlist" would have shipped with a fabricated entry — a number never compared to the thing it claims to count, which is the exact defect this phase exists to eliminate.
- **Fix:** Added `stripBlockComments`, a line-by-line block-comment state machine. Detection runs on stripped source; `snippet` still quotes the raw line so failure output stays readable. Entering block state requires the line's first non-whitespace token to be `/*` — entering on any occurrence would let a string literal such as `"src/**/*.ts"` open a phantom comment and blank the rest of the file, i.e. a detector going silently blind.
- **Verification:** census dropped 7 → 6; new control test `a from(...).insert(...) mention inside a multi-line block comment is NOT a mutation`.
- **Committed in:** `311ac9cd`

**2. [Rule 1 — Bug] `chainStart` anchored the pragma window to the wrong statement**
- **Found during:** Task 1
- **Issue:** The backward walk to the statement head ran unconditionally, even when the `.from(` line was already a statement head. For the single-line idiom the `.from(` line is *always* the statement head, so the 8-line `@audit-skip` window would have been positioned above the **preceding** statement — silently voiding a correctly-placed pragma. Latent before the fix (the leading-dot form usually made `.from(` a continuation); load-bearing after it.
- **Fix:** Only walk back when `lines[fromIdx]` is itself a chain continuation.
- **Verification:** the intended-behavior test now asserts `chainStart === 2` for the single-line sample, so the anchor is pinned, not assumed.
- **Committed in:** `311ac9cd`

**3. [Rule 3 — Blocking, self-inflicted] `npx prettier --write` reformatted ~100 unrelated lines**
- **Found during:** Task 1, pre-commit hygiene
- **Issue:** Ran `npx prettier --check`, it failed, ran `--write`. The diff jumped from 384 to 484 insertions. Investigating: **prettier appears in neither `package.json` nor `.github/workflows/`**, so `npx` downloaded an arbitrary version whose output disagrees with whatever produced the committed formatting — the HEAD version of the file fails the same check. (The first attempt to verify this was itself a broken instrument: checking a copy under `/private/tmp` resolves prettier config relative to *that* path, not the repo. Re-run inside the repo tree.)
- **Fix:** Reverted to the pre-prettier byte backup (shasum `c7f9b0cc`), verified by grepping the three newest edits. ESLint — which CI *does* run — is clean.
- **Committed in:** n/a (churn never committed)
