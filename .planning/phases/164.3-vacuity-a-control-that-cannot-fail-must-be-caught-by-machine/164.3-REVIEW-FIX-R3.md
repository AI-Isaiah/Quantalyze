## The meta-defect, and what was done about it

Round 3's verdict was not "these three fixes are wrong". It was: **each round
closed the reviewer's EXAMPLE and then declared the CLASS closed** — in code
comments, in `GRAMMAR.md`, and in the fix report. The named symptom was a test
titled *"INDEPENDENT ORACLE: no accepted neuter may leave a SET ROLE live"* that
was quantified over five hand-picked `--` comments.

So the rule for this round was: **an assertion that enumerates instances is not
an oracle over a class. Generate the inputs, or say out loud what is not
covered.** Concretely, in every finding:

- inputs are **generated as a cross-product** from a list the IMPLEMENTATION
  owns, so widening the implementation widens the test automatically —
  `BRANCH_HEAD_WORDS × 7 embeddings` (R3-C01), `{record body} × {both deferral
  routes}` (R3-W02), `21 invisible-character categories` (R3-W04), `5 spellings
  of a synthesised identity` (R3-C02);
- each generated family carries a **non-vacuity arm** asserting the generator is
  non-empty and complete, because an empty table makes every arm below it vanish
  silently;
- each carries the **opposite direction**, so a fix cannot pass by refusing
  everything (a branch head must still terminate the scan; a stamped identity
  must still be readable; a dated+owned deferral must still exempt; `⚠️` must not
  trip the invisible-character pin);
- where a rule genuinely cannot cover the class, the rule now says so **in the
  code and in `GRAMMAR.md`**, and the fixture that proves the residual is
  deliberately spelled so that only the *other* control can catch it.

Every fix was observed RED before and GREEN after, with the RED produced by an
input built from OUTSIDE the subject, or by neutering the SUBJECT (never the
measurement). Verbatim failure text is recorded per finding. Byte backups were
taken and restores verified by `shasum -a 256`; **`git checkout --` was never
used.**

## ⚠️ What is STILL NOT covered — named, not implied

The instruction was explicit: *if you cannot make an assertion range over the
class, say so and name what remains uncovered.* These are the residuals, each
measured or reasoned rather than asserted.

1. **`executableText` is a LINE-LOCAL classifier (R3-C01).** A string literal,
   block comment or dollar-quoted body whose delimiters straddle a newline is
   masked only on lines where both delimiters appear. **Measured** on three
   multi-line shapes (a `$q$…$q$` body whose interior line reads exactly `BEGIN`;
   one reading `DECLARE junk int;`; a multi-line literal whose interior line ends
   in `THEN`): all three **REFUSE** (`found=false`, no leak), because the closing
   delimiter line is itself unclassifiable and the scan stops there first. So the
   observed failure mode is the loud direction. **But I have not proven that no
   multi-line shape can leak** — only that the three I could construct do not. A
   stateful multi-line masking pass is the real close, and it is not in this
   round.

2. **Rule 3a cannot see `format()`, `chr()`, or any other runtime assembly
   (R3-C02).** This is deliberate and is now asserted as a test
   (`HONEST SCOPE: a spelling the rule CANNOT see`), which fails if 3a is ever
   widened to catch it — so the claim in `GRAMMAR.md` cannot go stale silently.
   The class is closed by 3c, not by 3a.

3. **The identity nonce is unforgeable to an annotation that only WRITES SQL —
   not to SQL that READS the stamped gate file back (R3-C02).** A `sql` step
   running as superuser could `pg_read_file` the scratch gate and echo a stamped
   identity. Nothing in the corpus does that and such an annotation would be
   obviously hostile in review, but that is the boundary of the control and it is
   written into both `run.mjs` and `GRAMMAR.md`.

4. **3b's failure-branch walk is BOUNDED at 40 lines (R3-C02).** Measured max in
   the real gate: 4 lines. A raise whose enclosing branch head sits further away
   falls back to the raise statement alone — the narrow direction. That is safe
   only because 3c, not 3b, closes the injection half. A test asserts the
   measured max stays under the bound, so a corpus that outgrows it reds rather
   than silently narrowing.

5. **`DEFERRED_CEILING` is still 1, and the record is still self-written
   (R3-W02).** A plan can be exempted by the same PR that adds it, provided that
   PR writes a date and an owning phase. The rule makes the exemption cost a
   sentence and makes it machine-legible; it does not make it independent. The
   ceiling bounds the blast radius to one plan, and raising it remains a reviewed
   edit to `ci.yml`.

6. **The invisible-character surface is `scripts/` + `ci.yml` +
   `src/__tests__/*.test.ts` (R3-W04).** It does not cover the rest of `src/`,
   `supabase/`, or `.planning/`. Widening it to all of `src/` would hit the owned
   NUL in `src/lib/wizardErrors.test.ts`, so widening needs an exception
   mechanism, which is a switch — deliberately not built this round.

7. **Three round-2 admissions that round 3 checked and found HONEST remain
   open, unchanged, and are restated here rather than dropped:**
