# Phase 164.3 Plan 04: VAC-07 Replay Spike + Local-Stack Lane Summary

**The migration chain does not replay — 69 of 262 migrations fail from at least six independent root causes, one of which refuses by design — so the lane loads a baseline, and the baseline itself is now a named blocking-human gate rather than a silent TEST touch.**

## Performance

- **Duration:** ~47 min (dominated by an 11-minute cold Docker image pull)
- **Tasks:** 2 of 2
- **Files modified:** 3

## Accomplishments

- **Answered the phase's biggest unknown by measurement.** RESEARCH A4 rated the replay HIGH risk and D-15 ordered it spiked first. It was spiked, and it failed — decisively, not marginally.
- **Root-caused the failure past the first symptom.** The CLI's failure (`SQLSTATE 25001`) was only the outer layer; removing it via `psql` still left 69 failures. Stopping at the first error would have produced the wrong decision.
- **Built the lane with teardown proven able to fail**, not merely observed passing.
- **Kept a shared environment untouched** while still producing a decision-grade answer.

## The measurement

| Applier | Result |
|---------|--------|
| `supabase start` / `db reset`, CLI 2.84.2 | dies at `20260416125432_rebalance_drift_weekly_index.sql` — `CREATE INDEX CONCURRENTLY cannot be executed within a pipeline (SQLSTATE 25001)`. 20 migrations use `CONCURRENTLY`. |
| `psql`, simple query protocol | clears that file, **still 69 of 262 fail** |

Independent root causes under `psql`:

1. `20260416201929_audit_log_hardening.sql` — `SAVEPOINT`/`ROLLBACK TO SAVEPOINT` inside `DO $$` (PL/pgSQL rejects it).
2. `20260417031851_user_app_roles.sql` — same pattern; **highest impact**, ~20 later failures are its cascade.
3. `20260515113637_resend_message_correlation.sql` — same class.
4. `20260510181440_trades_side_check_constraint.sql` — a self-verifying probe that **text-matches** a constraint definition; the definition it got was correct.
5. `20260515114555_compute_jobs_claim_token_fencing.sql` — overload ambiguity.
6. `20260823120000_revoke_api_keys_insert.sql` — **refuses by design** on a database it cannot identify. Can never replay onto a fresh local DB.

A5 converted from assumption to measurement: PostgREST **200**, GoTrue `/auth/v1/health` **200** (v2.188.1). D-15's two-lane premise holds.

## Decisions Made

- **MODE: baseline.** `run.sh` fails loud when the baseline is absent; it does not apply the 193 migrations that happen to work. A partially-applied schema is exactly the vacuity this phase exists to eliminate.
- **Derived workdir over config mutation.** `supabase start` applies migrations unconditionally and CLI 2.84.2 has no skip flag. Rather than set `[db.migrations] enabled = false` in the tracked `supabase/config.toml` — which would also make `supabase db push` skip migrations, and that file governs PRODUCTION deploys — the config is derived per run into a gitignored throwaway workdir. The awk flip is section-aware (a blind substitution would have disabled auth, storage and the API) and is asserted rather than assumed.

## Deviations from Plan

### 1. [Rule 4 → escalated, not taken] The TEST `db dump` fallback was NOT executed

- **Found during:** Task 1, after the replay failed.
- **Issue:** D-15's fallback is a read-only `supabase db dump` against TEST. My execution constraints forbid pointing any `supabase` command at a non-local host, and TEST is shared with other people's CI.
- **Action:** Did not touch TEST. Recorded the exact dump command, plus a secret-scan gate, in `REPLAY-SPIKE.md` under an explicit **⛔ BLOCKING-HUMAN** heading for a human to run.
- **Why this is the right call:** the plan's purpose was to make the decision *informed*. It is. The remaining step is a privileged action on a shared resource, which should not be taken silently by an executor.

### 2. [Rule 2 - Missing critical functionality] Teardown now removes the env handoff

- **Found during:** Task 2.
- **Issue:** an interrupt after the handoff was written (e.g. during baseline load) left `.stack-env` advertising a stack that no longer exists; the next Playwright run would trust it.
- **Fix:** `rm -f "$ENV_FILE"` added to the teardown path. Verified firing during the missing-baseline test.
- **Committed in:** `0b545f5f`

**Total deviations:** 1 escalated (Rule 4), 1 auto-fixed (Rule 2). No scope creep.
