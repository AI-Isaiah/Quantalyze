## Why this file exists

`scripts/verify-plan-anchors.mjs --pending` defines "pending" as *a `*-PLAN.md`
with no sibling `*-SUMMARY.md`*. A plan that a founder decided **not** to execute
can never acquire a SUMMARY, so before WR-06 was fixed this plan sat in the
scanned set permanently and coupled every unrelated PR's required `frontend`
check to its anchors. The only exit available was to fabricate a SUMMARY for
work nobody did.

This marker is the honest exit. The verifier prints it — `deferred: N plan
file(s) exempted by an explicit deferral marker` — so the exemption is visible
rather than silent, and it is not a flag: an empty `-DEFERRED.md` does not count.
