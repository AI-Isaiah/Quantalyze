| **Quick run command** | `npx vitest run <the touched test file>` |
| **Full suite command** | `npm run test` then `node scripts/mutation-runner/run.mjs` |
| **Estimated runtime** | quick ~10-30s · mutation runner ~1-3 min (spins a throwaway cluster per run) |

⛔ **Full vitest must NOT share the box.** Serialise vitest → pytest → mypy; contention has turned
1 red into 55, of which 54 were timeouts. And ⛔ **file-scoped vitest runs cannot clear
`src/__tests__/contracts/`** — those scan all of `src/`, so a contracts failure needs a full run.

⚠️ **Mode identity is a correctness property here, not hygiene.** The runner's local and CI
invocations must be byte-identical: wrapping a run changes its result (measured — a wrapper turned
3/3 GREEN into 5/5 RED). Every CI wiring task pastes the local invocation verbatim.
