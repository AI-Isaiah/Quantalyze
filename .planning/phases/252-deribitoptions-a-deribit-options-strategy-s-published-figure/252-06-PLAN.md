## Pass criteria (stated before the run; structural, no magnitude bound)

Each criterion is judged per Deribit member on the SMOOTHED basis (`PNL_BASIS_SMOOTHED_MTM`). The cash record is printed for contrast and never gates.

- **C1, the valuation builds.** `build_deribit_native_ledger(..., pnl_basis=PNL_BASIS_SMOOTHED_MTM)` returns and `assert_ledger_complete` passes. No `LedgerValuationError`, `OptionRowFieldMissingError`, `NavReconstructionError`, `LedgerCompletenessError` or other build error may occur. The smoothed assembly's own checks run inside this build: the cash-channel identity, `_assert_smoothed_book_channel` and `_assert_smoothed_summary_cross_check`, at the code's own tolerances. The probe never loosens them.
- **C2, every held option has daily marks.** The same build raises nothing from the daily-marks path. A transient read (`DeribitTransientReadError`) is a FAIL and is never retried. A structural hole raises from the hole guard and is a FAIL. C1 and C2 share one observation, the build outcome. The printed class name, and the field name that `classify_ledger_error` adds when the message names one, tell which criterion failed.
- **C3, no cash-bucketed option days.** The build's `CompletenessReport.pre_mark_retention_option_days` is empty. A non-empty list means those days fall back to the cash wallet inside a promoted headline, so the member fails. Limiting the promoted span to avoid them is a founder call that is recorded, never taken by the probe.
- **C4, the series reconciles.** `combine_native_ledger(ledger, indexable, denominator_config=<the strategy's>)` returns on the smoothed ledger. Its inception reconciliation (`InceptionReconciliationError`, a `NavReconstructionError`) is the telescoping identity at the code's own tolerance.
- **C5, report only, never a pass bound.** Per member and basis: the count of days with an absolute return of at least `PNL_DOM_RATIO` (imported from services.nav_twr, never restated), the count of days above one half (the Phase 185 SC-4 reading, printed so the founder can compare it with 185), and the ordinals (0-based day index from the series start) of up to five days with the largest absolute return.

**Verdict line.** `pass` only when every member passes C1 to C4. Otherwise `fail`, with the count of failed members. On `fail` the withhold stays and the result is recorded (CONTEXT). A partial result like Phase 185's is a `fail`.
