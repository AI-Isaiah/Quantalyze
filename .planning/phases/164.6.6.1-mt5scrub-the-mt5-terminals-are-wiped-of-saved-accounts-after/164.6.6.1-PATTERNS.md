### §2 Committed remote-source discipline (T-134-03): copy the call-site verbatim in shape

**Source:** `Mt5Client.recycle_terminal_process`.
```python
        self._assert_live("terminal_recycle")
        conn = getattr(self._mt5, "_MetaTrader5__conn", None)
        if conn is None:
            raise Mt5ClientError(
                0, "MT5 rpyc transport is not reachable for the terminal recycle"

            _TERMINAL_EXIT_WAIT_MS,
            int(self._request_timeout_s * 1000) // _TERMINAL_EXIT_WAIT_DIVISOR,
        )

            conn.execute(_REMOTE_TERMINAL_RECYCLE_SRC)
            return cast(
                str,
                conn.namespace[_REMOTE_TERMINAL_RECYCLE_FN](exit_wait_ms),
            )

        payload = self._guarded_read(_remote_call, stage="terminal_recycle")
        try:
            counts = json.loads(payload)
            matched = _recycle_int(counts["matched"])
            terminated = _recycle_int(counts["terminated"])
            exited = _recycle_int(counts["exited"])
        except (TypeError, ValueError, KeyError):
            raise Mt5ClientError(
                0, "MT5 terminal recycle returned a malformed verdict"
            ) from None
        diagnostics = _parse_recycle_diagnostics(counts)
        logger.warning(
            "Mt5Client.recycle_terminal_process: terminate crossed — matched=%d "
            ...

```
Copy:
- `_assert_live(<new stage>)` as the FIRST statement. `tests/test_mt5_abandon_roster.py` DERIVES its
  roster of session-touching methods from source, so a new verb without it reds there.
- The `_MetaTrader5__conn` seam with a typed raise; `_guarded_read(..., stage=...)`.
- The essential counts parsed strictly (`_recycle_int`) and every other field tolerantly through a
  `_parse_*_diagnostics` that cannot raise (`_RECYCLE_UNPARSED`, `_RECYCLE_CLASS_NAME_RE`).
- The counts LOGGED BEFORE anything else happens (SFH-06).
- The `_note_terminal_holder(..., holder=HOLDER_UNKNOWN, ...)` stamp once the terminate crossed.
- ⛔ **STOP THERE.** Do NOT copy the trailing `self.assert_session_authorized()` relaunch block. A
  bare call after a scrub hangs or returns `-10005` (S-03(b), S-10), and S-09 showed it also LAUNCHES

and its `budget_ms = 3 * exit_wait_ms` / `remaining_ms()` / `unprocessed` budget, and adds the delete

obligation beyond the copied block). It returns `json.dumps(dict(...))` of ints and exception CLASS
names only. Per-target "missing" and "could not delete" are SEPARATE counts (the R2-SFH-06
`enumerate_error` lesson).

**Refusal rule, stated exactly:** delete NOTHING unless `matched >= 1 and terminated == matched and
exited == matched`. ⚠️ `exited == matched` alone admits a `0/0/0` verdict, which is ambiguous: the
recycle's own IN-02 note in `_escalate_ipc_fault` records `matched=0` as "either no terminal was
running … or the process name did not match". On a name mismatch, a 0/0 delete would run under a
LIVE terminal. Whether `matched == 0` with zero enumerate errors may delete is a planner decision to
state, not to inherit.

Remote body skeleton (structure from the recycle; the planner writes the literal):

```python
_REMOTE_TERMINAL_RECYCLE_FN = "_qz_recycle_terminal_process"
_REMOTE_TERMINAL_RECYCLE_SRC = """
def _qz_recycle_terminal_process(exit_wait_ms):
    import ctypes
    import json
    import time
    from ctypes import wintypes
    ...
    def failure_name(exc):
        return type(exc).__name__

    budget_ms = 3 * exit_wait_ms
    deadline = time.monotonic() + budget_ms / 1000.0

    def remaining_ms():
        return max(0, int((deadline - time.monotonic()) * 1000))
    ...
    return json.dumps(
        dict(
            matched=len(pids),
            terminated=terminated,
            exited=exited,
            ...
        )
    )
"""
```
Scrub-specific requirements:
- The function name is written out INSIDE the literal (never interpolated from the `_FN` constant).
  The only run-time values cross as INT arguments (`exit_wait_ms` plus the planner's int flags).
- The install dir is ONE literal (S-07). `APPDATA` is read via `os.environ` inside the body to COUNT
  account-shaped files in the per-user hash dir. It is never deleted by default and never returned
  as a path.
- Default targets per the locked decisions: `Config\accounts.dat` always; `Bases\*\trades\*` only
  behind an int flag that the JOB path passes as 0 until 164.6.6.3 ships; `logs` never by default;
  `mail` / `subscriptions` never by default.
- The return dict uses the recycle's field names for the terminate half (`matched`, `terminated`,
  `exited`, `attempted`, `unprocessed`, `enumerated`, `enumerate_error`, `open_errors`,
  `terminate_errors`, `pid_errors`) so `_count` / `_recycle_landed` in `mt5_relogin` can be reused
  unchanged, plus per-target `*_deleted` / `*_missing` / `*_errors` ints and a `refused` int.
- **Relaunch-debt marker** (RESEARCH Pitfall 1(b)): set IMMEDIATELY BEFORE the terminate crosses,
  cleared only by a house-verified `session_snapshot`. Analog: the holder registry in the same file.
```python
_MT5_TERMINAL_HOLDERS: dict[str, str] = {}
...
def mt5_terminal_holder(terminal_key: str) -> str | None:
    """... A READ never mints an entry (``.get``)."""
    return _MT5_TERMINAL_HOLDERS.get(terminal_key)
```
  Copy: lock-free, keyed by `terminal_key`, `.get` reads, lives in `mt5_client.py` (the leaf;
  `mt5_concurrency` imports from it, never the reverse), and is CLEARED in
  `_reset_mt5_epochs_for_tests()`, which says it is "the one home" for every per-terminal registry:

  The same registry (or a sibling) carries the VALIDATION terminal's "scrub owed" marker (D-08).
  ⚠️ It is in-process only and a restart loses it. That gap is exactly D-09's boot widening.

```python
def _install_recycle_double(conn, *, returns=None, raises=None):
    record: dict = {"sources": [], "calls": []}

    def _execute(src):
        record["sources"].append(src)
        real_execute(src)
```
