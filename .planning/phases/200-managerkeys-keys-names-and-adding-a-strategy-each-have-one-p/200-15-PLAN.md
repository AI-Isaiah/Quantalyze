<objective>
Close gap 2 of `200-VERIFICATION.md`: at 320px the Profile `API keys` row truncates the key label to
about three characters ("UAT ...") and wraps the metadata one word per line. The row is
`flex flex-wrap items-center gap-4`: the 40px venue tag, then the `flex-1 min-w-0` label column,
then a `text-right` Last sync block, the `AllocatorSyncStatus` pill and the actions group
(`basis-full sm:basis-auto sm:ml-auto`). Below `sm`, the Last sync block stays on the first line and
squeezes the label column to a few dozen pixels. There is no page overflow, which is why the reflow
gates never saw it. The existing `/profile — SC2-PROFILE` describe in `layout-narrow.spec.ts` runs at
390px and wider, as an allocator, and asserts only that Disconnect is reachable.

Fix (planner's choice, minimal): below `sm`, the label column's flex-basis is the rest of the line
(`calc(100% - 3.5rem)`: the row minus the `w-10` tag and the `gap-4` gap), so it fills the first line
beside the tag and everything after it wraps. `sm:basis-0` restores today's layout from `sm` up. The
Last sync block's `text-right` becomes `sm:text-right`, so on a phone it reads left-aligned under the
label instead of right-aligned inside its own narrow box. Both key lists get the same change. No copy
changes, and the action group the SC2-PROFILE unit pins cover is not touched.

Purpose: a manager can read which key is which, and what each key feeds, on a phone. The Profile tab
is the one key manager (LEAN-04, D-06), and its feeds line is the ROUTE-09 surface.
Output: the row fix, an optional disconnected key in the seed, and two geometry tests.
</objective>
