### WR-01 (MEDIUM): The census's "no branded title" assertion cannot catch the shorthand form this repo actually used

**File:** `src/__tests__/page-titles.test.ts:155-159` (`findBrandedTitles`, regex `/\btitle\s*:\s*(?![\s{])/g`) and `:113` (`titleLiterals`)
**Issue:** Assertion 2 matches only `title:` followed by an inline string literal. It misses two forms:
- Shorthand property `{ title, ... }`: there is no colon, so the regex never matches.
- `title: someVar`, where the brand sits in a `const` declared earlier: no literal follows the colon.

The pre-phase `src/app/factsheet/[id]/v2/page.tsx` used exactly this shape: `const title = \`${name} — Quantalyze Factsheet\`;` at line 309, then `return { title, ... }` at line 328 (`git show 7b159bffe:"src/app/factsheet/[id]/v2/page.tsx"`). That file would pass assertion 2 today and render "X — Quantalyze Factsheet — Quantalyze". The test header says the census "proves, on every run" that no title doubles the brand, but it is blind to the regression shape this phase just removed.

**Failure scenario:** A later edit reintroduces `const title = \`${name} | Quantalyze\`; return { title }` in any `generateMetadata`. The census stays green, and the tab reads "Name | Quantalyze — Quantalyze".
**Fix:** Resolve shorthand and identifier titles to their declaration inside the same body, and add a self-test for each shape:
```ts
// in findBrandedTitles, after scanning `title:` literals:
const shorthand = /[{,]\s*title\s*[,}]/.test(body);
const ident = /\btitle\s*:\s*([A-Za-z_$][\w$]*)\s*[,}\n]/.exec(body)?.[1];
const varName = shorthand ? "title" : ident;
if (varName) {
  const decl = new RegExp(`\\b(?:const|let)\\s+${varName}\\s*=`).exec(body);
  if (decl) {
    const lits = titleLiterals(body, decl.index + decl[0].length);
    if (lits.some((t) => /Quantalyze/.test(t) || t.includes("|"))) hits.push(/* ... */);
  }
}
// self-test:
expect(findBrandedTitles(
  "export async function generateMetadata() {\n  const title = `${n} — Quantalyze Factsheet`;\n  return { title };\n}\n", "e.tsx",
)).toHaveLength(1);
```
