# Phase 170.1.1 Plan 07: Admin and portfolio tab titles Summary

Eight admin and portfolio routes now carry their own tab title, with the two service-role name reads (user detail, allocator match queue) placed behind the page's own `isAdminUser` check so a non-admin or signed-out caller gets a fixed title and causes no profile read.

`commits: 3` counts the three task commits (`plan_head_after` is the third); this SUMMARY is committed after it.
