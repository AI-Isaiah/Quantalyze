---

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (a CSV assertion for live reads, a grep or test for files).
- **Before the phase PR (plan 07):** every vitest file that reads `.planning/`, `TODOS.md`, `docs/runbooks/` or the cron manifest; `npm run lint`; `node scripts/verify-plan-anchors.mjs --pending`.
- **Phase gate:** plan 08's `sc3-verdict:` line and plan 09's browser results, then `/gsd-verify-work`. The VERIFICATION carries `verified_at_sha` and `drift_subjects`, never `covered_files` or `covered_digest`, and never lists `TODOS.md`, `CHANGELOG.md`, `VERSION` or `package.json`.
- **Max feedback latency:** 60 s for every automated command; the waits are checkpoints.
