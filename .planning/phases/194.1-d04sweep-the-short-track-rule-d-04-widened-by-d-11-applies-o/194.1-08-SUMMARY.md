# Phase 194.1 Plan 08: Wizard preview total-record gate Summary

**Both wizard preview arms (single-key and composite) now judge CAGR, Sharpe, Sortino and Volatility on the draft's total record, print a dash with one muted reason when withheld, and carry that note to the submit summary on the snapshot.**

## Accomplishments

- `SyncPreviewStep.tsx`: both `strategy_analytics` selects gain `${RECORD_SCALAR_ALIASES}` (the select argument is a `string`, rows cast, as the plan and `queries.ts` explain). Single-key adds one `Promise.all` member `strategies.select("asset_class")` with an error check that throws `strategy asset class read failed: ...` into the existing heavy-fetch escalation. Composite widens its existing read to `"returns_denominator_config, asset_class"` and keeps the null-tolerant config read.
- One module-level `draftFigureVerdict(row, assetClass)` builds the record (`recordFromScalars`), the state (`gateAnnualized`) and the note (`withheldReason("record", ...)` when withheld, `shortTrackNote("record", spanDays)` when short, null otherwise). Both arms pass `gatedValue(...)` into the unchanged `formatCagr` / `formatMetric`, so a withheld tile prints the formatter's own dash. Max DD and Cumulative are untouched.
- `SyncPreviewSnapshot.figureNote?: string | null` carries the note; both `FactsheetPreview` render sites and `SubmitStep`'s DRAFT preview pass `figureNote={snapshot.figureNote}`.
- `FactsheetPreview.tsx`: optional `figureNote` renders ONE `<p data-testid="factsheet-preview-figure-note">` under the metrics row; absent, null or empty renders nothing, so every other caller is unchanged.
- No step, poll, mint, sync or gate logic was touched.
