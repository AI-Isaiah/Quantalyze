# Phase 194.1 Plan 06: The share card follows the total-record gate Summary

**The factsheet share card now withholds Sharpe and CAGR on a record under the minimum (one muted reason line), qualifies a record under one year with one muted marker line, prints the stored CAGR at any span once cleared, and is published under a versioned `?v=` URL so cached cards are not reused.**

## Deviations from Plan

### Auto-fixed / judgment calls

**1. [Rule 2 - Correctness] The short-record line is drawn only while the card prints Sharpe or CAGR**
- **Found during:** Task 1
- **Issue:** On a legacy chain-broken row (no valid `headline_since`) `computeOgHeadline` returns three NaNs. If its record is cleared and under one year, a line "Annualized from N days of record, under one year." would sit under three dashes and name figures the card does not show, against the plan's own rule that the note names only what the card shows.
- **Fix:** the short line also requires `Number.isFinite(sharpe) || Number.isFinite(cagr)`. A case in `route.figure-gate.test.tsx` pins it. The withheld line is unaffected (it explains a dash).
- **Files modified:** `src/app/api/og/factsheet/[id]/route.tsx`
- **Commit:** d8c388722

**2. The verdict runs only inside the existing `analyticsComputed && rows.length >= 2` block**
- A failed or computing row, or one with fewer than two resolved returns, already prints three dashes. A "withheld" reason line under it would blame the record for what is a not-ready analytics run, so the gate sits with the figures it qualifies.

**3. The stored CAGR no longer depends on the series carrying two dated rows**
- The plan says a stored CAGR prints at any span. The old code nested it under `times.length >= 2`; it now reads the stored value directly (still subject to E2) and only the computed fallback needs the dates. This follows the strip, which prints the stored figure regardless of the card's resolved dates.

**4. `page.tsx` comment**
- The sentence "A USD strategy keeps today's URL exactly." became false (every URL now carries `v=`), so it was replaced by the new two-line sentence rather than kept beside it.
