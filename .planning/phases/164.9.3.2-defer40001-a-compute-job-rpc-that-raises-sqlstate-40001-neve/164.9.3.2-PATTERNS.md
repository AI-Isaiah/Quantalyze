## Research corrections (measured this session; the planner should take these over RESEARCH.md)

1. **Pitfall 3 is solvable without widening the needle.** `scripts/mutation-runner/GRAMMAR.md` `### apply steps` documents an optional `nth` field ("Which match to mutate. Must be <= `occurrences`"). `supabase/tests/test_mark_rpc_bridge_advisory_lock.sql` arms L1/L2 already use it: `"occurrences":2,"nth":1` and `"nth":2` on one repeated lock statement. The needle/`occurrences` pair must still be MEASURED against the file. Option (a) is sturdier, because `nth` is positional and silently re-targets if a raise is reordered.
2. **More Python tests carry the `"40001"` code than RESEARCH lists.** Measured with `grep -rn '"40001"' analytics-service`:
