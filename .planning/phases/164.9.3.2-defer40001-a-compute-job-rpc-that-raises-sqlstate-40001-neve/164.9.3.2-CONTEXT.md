# Phase 164.9.3.2: DEFER40001 — a compute-job RPC that raises SQLSTATE 40001 never makes PostgREST retry it without end - Context

**Gathered:** 2026-10-01
**Status:** Ready for planning
**Mode:** Smart discuss, infrastructure phase (no grey areas asked)

<domain>
## Phase Boundary

A compute-job RPC called through PostgREST never raises SQLSTATE 40001, so PostgREST never re-runs the call in a loop. A preempted worker's `defer_compute_job` (and any sibling RPC with the same errcode) fails once, with an error the caller can read. Owns `[164.9.4-DEFER-40001-RETRY-HANG]`. It is a blocker: Phase 164.9.4's SC-3 cannot pass until it lands (ROADMAP `### Phase 164.9.4`, routed 2026-09-27, "There is no waiver").

</domain>
