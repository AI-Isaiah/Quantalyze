covers the window ceiling and the stall alike, so plans 02-11 do not wait for the reading. The reading decides only
whether the ship goes ahead (plan 05's `d01-ship:` line, which plan 12 Task 1 step 0 enforces before the phase PR is
opened; a site plan 02 cannot pass is a founder decision) and is SC-3's before-picture.
