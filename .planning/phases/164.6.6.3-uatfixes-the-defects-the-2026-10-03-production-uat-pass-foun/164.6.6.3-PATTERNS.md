## Pattern Assignments

### `services/mt5_read.py` (leaf read helper, poll)

**Analog A, clock/sleep module attributes:** `services/mt5_relogin.py`, symbols `_clock` and `_sleep`.
```python
_clock: Callable[[], float] = time.monotonic
_sleep: Callable[[float], None] = time.sleep
```
The heal reads them as `_clock()` / `_sleep(...)`; the relaunch watcher `_RELAUNCH_POLL_INTERVAL_S` loop (`started = _clock()` ... `if _clock() - started >= _RELAUNCH_SETTLE_S` ... `_sleep(_RELAUNCH_POLL_INTERVAL_S)`) is the deadline-poll shape to copy. Reason recorded in the source: "A module attribute, not a bare `time.monotonic` call, only so the budget-gated paths can be driven against a clock whose every crossing costs its full ceiling".

**Analog B, exception shape:** `services/mt5_concurrency.py::_Mt5PostReadVerificationError` and `Mt5TerminalBusyError`: a PLAIN `Exception` subclass, never `Mt5ClientError` (the classify arm would turn it into a credential verdict) and never `asyncio.TimeoutError` (the timeout arm restarts a healthy terminal). Carries counts only. The new `Mt5HistoryUnsettledError` follows `RESEARCH.md` "Code Examples / The settle loop" (deal count, `material` boolean, no login/server/amount).

**Imports pattern** (existing block in `services/mt5_read.py`, keep leaf invariant, add only stdlib + `mt5_concurrency` constants + `mt5_client` accessor):
```python

from typing import Any, Final

from services.mt5_client import Mt5ClientError, Mt5Session
from services.mt5_concurrency import _Mt5PostReadVerificationError

```
Add `import math, time`, `from collections.abc import Callable`, and the two new constants from `services.mt5_concurrency`. ⛔ Never import `services.job_worker` (module docstring "Leaf-module invariant"); pass the material-equity floor in as a keyword parameter (callers already hold `_DERIBIT_EMPTY_LEDGER_FLOOR_USD`).

**Core insertion point** (`read_mt5_deal_ledger`, between the first `history_deals_get` and the POST bracket):
```python
assert_expected_login(info, login=session.login)
deals = session.client.history_deals_get(
    0, int(now.timestamp()) + _MT5_DEAL_FETCH_MARGIN_S
)

    post_info = session.client.account_info()
```

**Do not** return partial deals on expiry (never invent data). Settled = two consecutive equal counts AND (count > 0 OR equity not material); missing or non-finite `info["equity"]` skips the wait (callers' existing guards fail loud on it).

## Shared Patterns

### Plain-`Exception` typed refusals (never `Mt5ClientError`, never `TimeoutError`)
**Source:** `services/mt5_concurrency.py::_Mt5PostReadVerificationError` / `Mt5TerminalBusyError`; `services/mt5_client.py::Mt5SessionAbandoned`, `Mt5AccountMismatchError`.
**Apply to:** `Mt5HistoryUnsettledError`, the unknown-server refusal.
Rationale in source: the credential classify/stamp arms match on `Mt5ClientError`, so a plain `Exception` makes absorbing OUR fault into a USER-ATTRIBUTED verdict structurally impossible. Carry no host, port, terminal key, login, server or amount.

### Dispositions stay at the call sites; the shared module only performs and raises
**Source:** `services/mt5_read.py` module docstring ("THIS MODULE DECIDES NOTHING ABOUT WHAT A FAILURE MEANS") and `services/mt5_probe.py` module docstring (PARITY-01; "Concentrating the body here means a fix cannot land on one path only").
**Apply to:** item 0 (derive vs backfill each map the new exception) and item 9 (router vs adapter each map the refusal).

### Classifier-safe fixed messages
**Source:** `services/equity_reconstruction.py::_MT5_BACKFILL_MESSAGES` header comment, and the `Mt5SessionAbandoned` arm comment in `services/job_worker.py` ("THE MESSAGE MUST CLASSIFY BLAME-FREE (D-42)").
**Apply to:** the new derive message constant, the new backfill key, and the adapter `human_message` if it lands in `compute_jobs.error_message`.
```python
# test shape: run the real classifier over the exact message
from services.mt5_validation import classify_mt5_login_error  # then assert == "transient"
```
Never concatenate broker text into `error_message`; the scrubbed detail goes only to the audit event and the log.

### ERROR log plus one rate-limited Sentry capture
**Source:** `services/mt5_probe.py::_alert_park_failed` (shown above) and `_PARK_ALERT_WINDOW_S`; related: `services/mt5_terminal_scrub.py::_SCRUB_ALERT_WINDOW_S`.
**Apply to:** the unknown-server refusal (D-10). ERROR on every occurrence; capture deduped per server-per-window; a typo and a real new broker look identical, so the copy must cover both ("check the spelling; if it is right we have been notified").

### Injectable clock for bounded waits, tests never really sleep
**Source:** `services/mt5_relogin.py::_clock` / `_sleep`; `tests/test_mt5_relogin.py::_FakeClock`.
**Apply to:** `services/mt5_read.py` and its never-settling tests. Use `time.monotonic`, never wall clock.

### Per-terminal registries: lock-free, in-process, reset in ONE place
**Source:** `services/mt5_client.py::_reset_mt5_epochs_for_tests` (docstring lists the registries) reached via `services/mt5_concurrency.py::reset_terminal_state_for_tests`.
**Apply to:** the settled record. Tests call the one reset (autouse in `tests/conftest.py`), never a local `.clear()`.

### Failing-first, neuter-and-restore
**Source:** memory rule plus `RESEARCH.md` Validation Architecture. Each new gate must be seen RED against the neutered production code (comment out the wait; set the constant back to 0; skip the pre-check) and restored from a BYTE backup, never `git checkout/restore/stash` on uncommitted work. `grep -a` everywhere. pytest only from `analytics-service/` as `.venv/bin/pytest`.
