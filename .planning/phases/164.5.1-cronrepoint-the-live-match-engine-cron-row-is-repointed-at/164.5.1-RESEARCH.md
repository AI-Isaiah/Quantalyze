## Q1 — The cron-drift arm

**How it compares.** `compareManifest(manifest, prodRows)` (`scripts/prod-prober/arms/cron-drift.mjs:433-620`) is pure. Order of operations, quoted:

1. Oracle validation first (`:444-486`): missing/non-object, wrong `schema_version` (must be `1`, `:95`), wrong `normalization` (must be `"ws-collapse-v1"`, `:96`), empty `jobs`, a row without `jobname`, a row whose `command_sha256` fails `/^[0-9a-f]{64}$/`, a row with no `command` string and no reviewed withholding, or no `match_engine_cron` row at all — each returns a single `manifest-invalid` defect and **no comparison happens**.
2. Hygiene on BOTH sides independently of equality (`:492-520`): every manifest row and every PROD row goes through `hygieneViolations(jobname, command)`; any violation is a `cron-secret-in-command` defect "EVEN WHEN ITS SHA MATCHES THE MANIFEST" (header `:40-42`).
3. Jobname set equality both directions (`:560-566` shown; D-14 extra job is drift, missing job is drift).
4. Per-job: `schedule` (trimmed string equality), `active` (boolean), and command by sha (`:577-581`):
   ```js
   const prodSha = sha256Hex(normalizeCommand(p.command));
   if (m.command_sha256 !== prodSha) changed.push("command");
   ```
   `jobid` is printed but never compared (`:573`).

**What `command_sha256` is computed over** — `cron-drift.mjs:146-157`, verbatim:
```js
export function normalizeCommand(text) {
  return String(text ?? "")
    .replace(/\r\n/g, "\n")
    .trim()
    .replace(/\s+/g, " ");
}
/** sha256 over the UTF-8 bytes of the NORMALIZED text. */
export function sha256Hex(text) {
  return createHash("sha256").update(String(text ?? ""), "utf8").digest("hex");
}
```
i.e. CRLF→LF, trim, every whitespace run → one space, then sha256 of the UTF-8 bytes. The manifest's `command` field stores the NORMALIZED text (`run.mjs:2519-2520` writes `command: normalizeCommand(r.command)`), and the sha stored beside it is over that same normalized text. Verified this session: recomputing `sha256Hex(normalizeCommand(jobs[match_engine_cron].command))` over the committed manifest equals its stored `command_sha256` (`true`).

**A row whose sha is missing/malformed** → `manifest-invalid` for the whole manifest (`:470-474`, quoted):
```js
if (typeof row.command_sha256 !== "string" || !/^[0-9a-f]{64}$/.test(row.command_sha256)) {

}
```
`[VERIFIED: scripts/prod-prober/arms/cron-drift.mjs:146-157, 433-620]`

**Anti-vacuity check on this arm (existing control, can it fail?):** yes.
