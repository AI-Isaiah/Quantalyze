<objective>
Make the Allocations Risk tab read the same book the Overview and Scenario read (SC2). Every risk widget
receives the whole dashboard payload and falls back to `buildCompositeReturns(payload.strategies)`, the
legacy portfolio-strategies set, which is empty or zero-weighted for a key-connected book, so VaR says
"Insufficient return data" while the Overview shows values (169 RESEARCH root cause G). 167.1.2 (merged)
owns the book series; this plan owns only the Risk tab's consumption of it, through one pure adapter.

Output: an adapter (+test), a one-rule key-label helper (+test), and a RiskTabPanel that gates on
rebuilding and passes the adapted data (+test).
</objective>
