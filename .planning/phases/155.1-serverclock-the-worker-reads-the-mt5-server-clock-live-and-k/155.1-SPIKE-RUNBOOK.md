# Phase 155.1 — live tick spike: founder runbook

**When:** Monday 2026-11-16, in market hours, supervised. **Run by:** the founder. The agent
never touches the gateway.
**What it measures:** the five spike items in `155.1-CONTEXT.md` `<spike>`, using
`python -m scripts.mt5_spike --leg tick`. The command logs in once with the investor password,
makes read-only calls (symbol list, tick times, 30 days of deals), and prints counts, offsets,
ages and verdicts. It prints no symbol name, login, server or amount.

## Timing rule (all three must hold)

1. **Outside the derive window.** Not between 00:30 and 07:30 UTC. Key syncs land around
   01:00 UTC and the allocator derive fans out at 05:30 UTC. Any time 10:00–16:00 UTC on Monday is
   good. Just before you start, ask Claude to confirm over the Supabase MCP that no `mt5` job is
   in flight (`compute_jobs` with status `running`). The worker's lease covers its
   own process only. A spike login during a derive switches the shared terminal's account, and
   that derive then fails with `Mt5AccountMismatchError`.
2. **Away from the session-monitor tick.** In the analytics service logs, wait for a
   `mt5 validation liveness:` line. Start about 60 s after it, so the next tick is minutes away.
3. **Before the 157 rotation** of `MT5_SPIKE_INVESTOR_PASSWORD`. That rotation comes after this run.

## The one command

Open a shell in the analytics service with `railway ssh --service <analytics service>`. It
already has the code at `/app`, the private network and `MT5_GATEWAY_HOST/PORT`. Then run:

```bash
cd /app && read -rs -p "investor password: " MT5_SPIKE_INVESTOR_PASSWORD && echo && \
read -r -p "login: " MT5_SPIKE_LOGIN && read -r -p "server: " MT5_SPIKE_SERVER && \
MT5_SPIKE_INVESTOR_PASSWORD="$MT5_SPIKE_INVESTOR_PASSWORD" MT5_SPIKE_LOGIN="$MT5_SPIKE_LOGIN" \
MT5_SPIKE_SERVER="$MT5_SPIKE_SERVER" MT5_SPIKE_HOST="$MT5_GATEWAY_HOST" \
MT5_SPIKE_PORT="$MT5_GATEWAY_PORT" python -m scripts.mt5_spike --leg tick; echo "exit=$?"
```

- Use **MM2**'s investor login. It is one login, so the terminal ends on MM2. The next scheduled
  derive switches it back as usual.
- Optional second run: about 21:55–22:10 UTC, the usual daily session break, if you are free.
  That reading fills item 5 for a break. The weekend reading of item 5 can ride your D-E sitting.

## What to paste back

Paste the whole JSON block and the `exit=` line into the chat with Claude. It holds only counts,
offsets, ages, booleans and verdicts, but Claude still checks it before anything is committed.
Claude keeps the raw paste in the gitignored `out/155.1-spike/` directory and commits only the
readings it needs into `155.1-RESEARCH.md`.

The fields Claude will read:

| Field | Answers |
|---|---|
| `listing.observation`, `listing.visible_count`, `listing.symbols_total`, `listing.elapsed_s` | items 2 and 4 |
| `visible_ticks.answered` / `none` / `errors` | item 1, visible symbols |
| `nonvisible_deal_symbol.observation` | item 1, a deal symbol outside Market Watch without `symbol_select` |
| `offset.encoding`, `offset.rounded_offset_s`, `offset.matches_rule`, `deal_encoding.consistent` | item 3 |

| `verdict`, `verdict_reasons` | the leg's own call |

Exit codes: 0 report printed, 3 a variable missing, 1 another failure (the message is scrubbed).
