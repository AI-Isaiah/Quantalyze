## The three regression areas

**P&L byte-identity (`dollar-validation.ts`): holds.** `roundForDisplay(n, 2)` at scale 1 is `Number(n.toFixed(2))` with −0 folded to 0. The old code computed the same `Number(n.toFixed(2))`, and its non-finite guard is the same `isNumber` test. The magnitude is `Math.abs` of that same number in both versions, and `Math.abs(-0)` is `0`, so folding −0 changes nothing. I checked this by measurement as well as by reading. In a scratch copy I restored the pre-refactor `dollar-validation.ts` from `ff25ddc97` and ran the new 17-row characterization table and the non-finite case against it. All passed, so the table describes the old output, and the new code passes the same table.

**R7 without `dropJsxGroups`: no false positive, and the pin is honest.** The census passes with exactly one pinned R7 hit, `RiskAttribution.tsx:116/128`. I read that site. `assessable` chooses between a dash and a verdict, and the verdict's colour comes from `overweight` (`:131`), so the reason text is accurate. Newly scanned files (`portfolio-insights.ts`, `dollar-validation.ts`) add no R7 hit. Neuter check: in the scratch copy I appended the parenthesized `up ? (<span text-positive>) : (<span text-negative>)` form to the pinned file itself. The guard went RED with `RiskAttribution.tsx R7: 2 found, pinned 1`, so the pin does not shelter a second site in the same file.

**Reason line: renders only when figures are withheld.** `comparatorAnnualizationWithheld(hb)` is applied to the same `hb` object whose `ann_vol`, `sharpe`, `sortino`, `calmar` and `cagr` fill the cells below it (`MetricsColumn.tsx:333-344`), so the line and the dashes cannot come from different sources. The predicate is "`cum_ret` finite and `ann_vol` not finite". For a comparator, `compute()` makes `ann_vol` NaN only when `basisN < 2` (`compute.ts:166`), and that also means fewer than 2 dates, which is 0 elapsed days and therefore below the floor. So a non-finite `ann_vol` beside a finite `cum_ret` happens only under the floor. The other cases do not show the line:
- `withheldWindowView` sets `summary: null`;
- an inert or unavailable block keeps a null summary;
- `headlineWithheld` returns null;
- `cmpKey === "none"` makes `bn` undefined.
