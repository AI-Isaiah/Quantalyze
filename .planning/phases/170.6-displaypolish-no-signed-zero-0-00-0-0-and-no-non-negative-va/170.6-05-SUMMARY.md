## Deviations from Plan

1. **[Plan arithmetic] The heatmap title case.** The plan lists, for one month of `-0.0004`, a text of `0.0` and a title of `0.00%`. `-0.0004` is `-0.04%`, which is not zero at the title's 2 dp, so the title correctly stays `-0.04%`. The test uses two months: `-0.0004` (text `0.0`, title `-0.04%`) and `-0.00004` (text `0.0`, title `0.00%`). The rule is unchanged; only the plan's example pairing was impossible.
2. **[Reachability] The HistogramChart `-0.00001` tick.** The default window is at least +-0.5%, so a near-zero tick only appears after a wheel zoom. The test drives the real component with a wheel event (deltaY -577 at the plot's right edge, lower bound about `-0.0000082` by hand arithmetic in the test comment) and reads the `zoom … ` hint, rather than exporting `pctTick`.

Today's code compares the raw magnitude, and I kept that (a month of 9.96 percent still prints `+10.0`, as before) so no non-zero figure changes by a digit. Only the sign comes from the rounded value.
4. **[Process] Branch namespace.** The worktree branch is `wt/170.6-p05`, not `agent-*`; I committed on it because the orchestrator assigned it (same as plan 01). It is not a protected branch.
