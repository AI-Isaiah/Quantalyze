## WorstDrawdowns: no edit (D-04)

`MIN_DEPTH_PCT = 0.005` (`WorstDrawdowns.tsx:42`) filters both the server list (`Math.abs(e.depth_pct) >= MIN_DEPTH_PCT`) and the client segmentation (`segmentDrawdowns(series, MIN_DEPTH_PCT)`). `depth_pct` is a decimal, so every rendered depth is at least 0.50% in magnitude and prints at 2 dp (`formatPercent(ep.depthPct)`, default 2 dp) as a non-zero figure. Its constant `text-negative` (`CELL_DEPTH`) therefore never colours a rounded zero, and there is no "—" depth cell. Plan 12's guard can allowlist the file with that reason.
