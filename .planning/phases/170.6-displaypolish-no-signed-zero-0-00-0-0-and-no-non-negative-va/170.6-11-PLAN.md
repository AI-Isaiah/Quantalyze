Founder decisions, quoted from 170.6-CONTEXT.md:
- D-07: "The comparator annualization floor is a **90-day** overlap. Below the floor, the annualized set reads "—". That set is Sharpe, Sortino, Calmar, CAGR and annualized volatility. Cumulative return and max drawdown stay. A test must fail on today's behaviour (5-day SPX gives Sharpe 10.24)."
- D-08: "When the comparator ends before the strategy's window, the paired-floor sentence adds "{CN} prices end Mon D.". CN is the comparator's display name and the date is the comparator's last price day."
- D-05: "There is one rule, in one place. … delegate to it and do not re-implement it."
- Claude's Discretion: "Where the 90-day constant lives. It needs one definition and must be imported, not restated."

Where the comparator's annualized figures are computed and rendered (measured 2026-10-13):
- Computed ONLY in TypeScript: `buildComparatorBlock` in `src/lib/factsheet/comparator-block.ts` (its `summaryOf`, used for `summary` and `summarySince`), called by `deriveSeriesBundle` in build-payload.ts for BTC and SPX, for the full record, every basis bundle and every selected range. `analytics-service` computes no comparator summary (0 hits for `spx`), so there is no Python site.
- Rendered ONLY in `MetricsColumn.tsx` (the Main Metrics bench column via `headlineBenchSource`, plus `b`). The vol-match scale reads the raw compute result, not `summaryOf`, so it is unaffected.

Discretion choices (recorded):
- The constant lives in comparator-block.ts beside the gate it drives, exported so tests import it.
- "Overlap" is the elapsed calendar days between the comparator's first and last covered date inside the strategy's window. This matches `recordCoversWindow`'s calendar-day rule and does not depend on the comparator's calendar (SPX has about 63 weekdays in 90 days, BTC 90).
- Below the floor the five fields are NaN, the idiom `gateFlatLeg` already uses for withheld joint figures, so the rail's existing NaN-to-dash path prints "—" with no type change.

Consequence for the orchestrator: inside a selected range shorter than 90 days the comparator's five annualized cells read "—" while the strategy's still print (D-07 is comparator-only). No reason line is added beside those dashes; D-07 asks for none, and copy belongs to 170.6.2.

Purpose: SC-4, SC-5. (SC-3's single-source guard moved to plan 12 by plan-check W4.)
Output: the floor, the dated floor sentence, and tests that fail on today's output.
