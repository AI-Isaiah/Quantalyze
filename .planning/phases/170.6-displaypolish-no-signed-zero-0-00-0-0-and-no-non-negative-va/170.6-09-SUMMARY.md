## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Optimizer `liftClass` must read the percent scale**
- **Found during:** Task 1
- **Issue:** The plan says `liftClass` returns text-positive only when `signTone(value, 2) === "positive"`. `liftClass` serves all three units. For the percent cell (`dd_improvement`, x100), `signTone(0.004, 2)` is a rounded zero though the cell prints `+0.40%`, so a real 0.40% improvement would have lost its green.
- **Fix:** `liftClass(value, unit)` uses `signTone(value, 2, 100)` for `percent`, `signTone(value, 2)` otherwise. Pinned by a test (0.004 green, 0.00004 not green).
- **Files modified:** `PortfolioOptimizer.tsx`
- **Commit:** `3e7d1a3f2`

**2. [Rule 2 - Missing critical functionality] Impact-panel chip tone and screen-reader phrase read the raw sign**
- **Found during:** Task 1
- **Issue:** The plan changes only `formatDelta`. `DeltaChipCard` still derived red/green/neutral and the teal "improving" dot from the raw sign, so a delta printed "0.000" would be drawn red; `formatAnnouncementChip` would say "regressed by 0.00%". That is the D-03 defect on a surface this plan owns.
- **Fix:** both read `signTone` at the chip's printed precision (`deltaPrecision`: percent 2 dp x100, ratio 3 dp); a rounded zero is neutral and announced "unchanged". Non-zero figures unchanged.
- **Files modified:** `PortfolioImpactPanel.tsx`
- **Commit:** `3e7d1a3f2`

**3. [Rule 3 - Blocking] Plan 09 must be green without plan 02's `utils.ts` delegation**
- **Found during:** Task 3 (and Task 1)
- **Issue:** `formatPercent` and `formatNumber` are still the old formatters in this worktree (plan 02, same wave, owns them). The plan's `WinnersLosersStrip` and `EditorialHero` cases expect "0.00%" for -0.00004, which `formatPercent` prints as "-0.00%" until plan 02 merges.
- **Fix:** those two components print through display-sign `formatSignedPercent(x, 2)`, identical digits to `formatPercent` (`(v*100).toFixed(2)`) with `+` on a positive. Once plan 02 merges, both routes agree.
- **Not changed (plan 02's):** `PortfolioOptimizer` percent cell text (`formatPercent`) and negative decimal cell text (`formatNumber`, Intl), `WhatWedDoCard`'s `formatPercent(lift)`. Their rounded-zero TEXT depends on plan 02; this plan owns only their `+` and tone, and the tests pin only that. The `-0.004` Optimizer case therefore asserts "no `+`, not green", not the digits.
- **Commit:** `cb9d6e1a0`
