## Accomplishments

- `align.ts` `alignCoveredReturns(prices, dropped, dates)` returns `{ returns, paired, through }`. The docblock states the rule once and cites D-54, D-58, D-64, 166.4 D-A / D-04 / D-05 / D-07, WR-01 / `d1d1fc077` and `_interval_matched_benchmark`. Returns come only from `pricesToDailyReturns`. When an interval holds exactly one point, that point is used as is, as in the engine.
- `comparator-block.ts`: the summary uses `compute()` over the covered indices, on the comparator basis passed in. `jointMetrics` runs on the strategy basis over the paired indices. The five windows are null past `through`. Every block carries `through`. The per-day arrays stay `number[]` with an uncovered day entered as 0, until 169.5-02 / 169.5-04 replace them. `unavailableComparatorBlock` is exported.
- `build-payload.ts`:
  - New optional `benchmarkPrices` opt. It reaches all three `deriveSeriesBundle` axes (cash, MTM, smoothed) and the api arm.
  - Correlations and the correlation matrix are computed over the intervals paired for both legs.
  - Both `buildComparatorBlock(` calls pass `Math.min(periodsPerYear, annualizationPeriods(...))`.
  - The api arm and stress windows take named null-as-0 locals (D-65).
- `fetch-and-build-payload.ts` `readFactsheetBenchmark`, called once from `buildFromResolved` after `buildOpts` is assembled:
  - The bound is [earliest date on any axis minus one day, latest date on any axis], taken as min / max over every entry.
  - When no axis has a date, it issues no query.
  - One ascending `limit(1)` probe finds the DB's true first stored date. Only fixture rows before that date are merged, then everything is trimmed to the bound.
  - An empty covered span gives the unavailable form.
  - `ok:false`, a probe error, or a throw gives the unavailable form, with one stable `console.error` and no Sentry capture.
- The v2 page key moves from v8 to v9, with one lineage line. Both pins moved and the CACHE KEY REALITY paragraph was updated. The parity-table double answers `benchmark_prices` with an empty successful page.

## Known limits (recorded, not fixed)

- **D-52:** the honest unavailable form (summary null, `through` null) may be cached for the 1 h TTL after a transient read error.
- **D-65:** the api arm's allocator portfolios and event signatures, and the stress windows, take a comparator null as 0. Phase 169.4 ALLOCTRUTH owns the null-honest fix.
- **Calendar inference is per window.** The benchmark's own calendar is inferred from the prices handed to the helper, which on the route is the bounded window. On a window too short to contain a Saturday close, a 7-day benchmark's missing Saturday inside a weekday interval would not unpair it. The engine infers from its whole stored series. This only matters for records a few days long.
- **Zero-coverage fixture comparator.** A strategy wholly outside a fixture's dates (for example SPX on a record starting after 2026-05-08) now shows that comparator's summary and joint as null, not a flat 0% line. Its per-day arrays stay zero-filled until 169.5-02.
