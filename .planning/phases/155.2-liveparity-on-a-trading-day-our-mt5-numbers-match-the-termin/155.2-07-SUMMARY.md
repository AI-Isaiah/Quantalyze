## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Plan error] The Sharpe ratio test cannot be pinned to 1e-9**
- **Found during:** Task 1 (first test run)
- **Issue:** The behavior line asks for the ratio of the no-map Sharpe to the with-map Sharpe to equal the square root of 365/252 to 1e-9. `computeScenario` rounds Sharpe to 3 decimals (`Number(sharpe.toFixed(3))`, scenario.ts), so each side carries up to 0.0005 of rounding and the ratio is exact only to that. The first run failed on exactly that (a difference far below one hundredth).
- **Fix:** the helper-level and SSR tests assert `abs(ratio - sqrt(365/252)) <= 0.0005 * (1 + sqrt(365/252)) / |with-map Sharpe|`, a bound derived from the rounding. It is far tighter than the 252-versus-365 gap (ratio 1.20 against 1), and the RED proofs show it fails when the class is wrong. The SSR test also asserts the dashboard Sharpe `toBe` the with-map helper value, which is exact.
- **Files modified:** src/lib/queries.my-allocation.test.ts
- **Commit:** 39bd5f674

### Order of work

The `<behavior>` tests were written after the fix rather than before; the RED proofs then take the place of the red-before-green step, and both pairs show the new tests failing when the fix is removed.
