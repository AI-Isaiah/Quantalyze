**Shared helpers to use** (`src/lib/closed-sets.ts`):
```ts
export function isCryptoExchange(exchange: string | null | undefined): boolean {   // :604
  if (!exchange) return false;
  return (CRYPTO_EXCHANGES as readonly string[]).includes(exchange.toLowerCase());
}
export function blendPeriodsPerYear(legs: ReadonlyArray<{ asset_class?: string | null }>): number {  // :669
  return legs.some((l) => l.asset_class === "crypto" || l.asset_class == null) ? 365 : 252;
}
```
Fix shape: derive the leg class from the key's venue via `isCryptoExchange(venue) ? "crypto" : "traditional"`; venue lookup comes from `holdingsSummary` (`venue`) in queries.ts, and a new parameter on `buildPerKeyStrategyForBuilderSet` (callers by grep: `ScenarioComposer.tsx`, `scenario-compare.ts`, `book-risk-input.ts`, `mt5-parity-surfaces.test.ts`, plus tests). Never branch on `=== 'mt5'`; no local 365/252 ternary (closed-sets MD-01). Note `blendPeriodsPerYear` treats null/unknown as 365, so an unresolvable venue must stay conservative. Unknown asset class risk A3 (stored `asset_class` unmeasured): diagnose on the capture first.
