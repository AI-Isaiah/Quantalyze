<objective>
Recompute, on PRODUCTION, every `strategy_analytics` row that Phase 166 changes and that was computed
before the 166 worker deploy, through the normal compute-job path, one strategy at a time, each checked
before and after.

Purpose: Phase 166 OPEN-2, founder answer 2026-09-24: "After 166 merges, run plan 10's read-only census
and queue a recompute of the affected PRODUCTION rows. The recompute is enqueued through the normal job
path, never by hand-written data." The census (D-01) sized it to the PSR class (15 rows) and the rolling
alpha class (10 strategies). This plan is a founder-gated runbook: no agent connects to any database.
Output: a counts-only SUMMARY.
</objective>

    ```sql
    -- (C1) READ-ONLY. Classify the recompute set.
    WITH affected AS (
      SELECT sa.strategy_id
        FROM public.strategy_analytics sa
       WHERE jsonb_typeof(sa.metrics_json->'probabilistic_sharpe_ratio') = 'number'
      UNION
      SELECT sas.strategy_id
        FROM public.strategy_analytics_series sas
       WHERE sas.kind = 'rolling_alpha'
         AND jsonb_typeof(sas.payload) = 'array'
         AND jsonb_array_length(sas.payload) > 0
    )
    SELECT CASE WHEN EXISTS (SELECT 1 FROM public.strategy_keys sk WHERE sk.strategy_id = s.id)
                THEN 'composite'
                WHEN s.api_key_id IS NOT NULL THEN 'single_key_broker'
                ELSE 'user_csv' END                     AS class,
           s.status,
           sa.computation_status,
           (sa.computed_at < TIMESTAMPTZ '<T_DEPLOY>')  AS pre_fix,
           count(*)
      FROM affected a
      JOIN public.strategies s          ON s.id = a.strategy_id
      JOIN public.strategy_analytics sa ON sa.strategy_id = a.strategy_id
     GROUP BY 1, 2, 3, 4
     ORDER BY 1, 2, 3, 4;
    ```

    Step 1d (founder, READ-ONLY; skip when C1 shows no composite). Count the pre_fix composites that
    have an untrusted member key (D-09):
    `SELECT count(DISTINCT sk.strategy_id) FROM public.strategy_keys sk JOIN public.api_keys k ON k.id = sk.api_key_id WHERE sk.strategy_id IN (<the pre_fix composite ids>) AND (k.sync_status IN ('revoked', 'sign_in_failed') OR k.disconnected_at IS NOT NULL);`

    Step 1e (founder, READ-ONLY, kept LOCALLY, never committed). Capture the BEFORE snapshot for every
    pre_fix strategy with C2 and save the result as a local file outside the repo. Report only the row
    count. The same query, with the list reduced to one id, is the AFTER read in Tasks 3 and 4.

    ```sql
    -- (C2) READ-ONLY. Metric values of private strategies are not public: never commit the output.
    SELECT sa.strategy_id, sa.computation_status, sa.computed_at,
           sa.returns_series->-1->>'date'                     AS series_end,
           jsonb_array_length(sa.returns_series)              AS series_n,
           sa.metrics_json->'probabilistic_sharpe_ratio'      AS psr,
           sa.metrics_json->'sharpe'                          AS sharpe,
           sa.metrics_json->'alpha' AS alpha, sa.metrics_json->'beta' AS beta,
           sa.metrics_json->'treynor' AS treynor, sa.metrics_json->'r_squared' AS r_squared,
           jsonb_array_length(ra.payload) AS ra_n, ra.payload->-1 AS ra_last,
           jsonb_array_length(rb.payload) AS rb_n, rb.payload->-1 AS rb_last
      FROM public.strategy_analytics sa
      LEFT JOIN public.strategy_analytics_series ra ON ra.strategy_id = sa.strategy_id AND ra.kind = 'rolling_alpha'
      LEFT JOIN public.strategy_analytics_series rb ON rb.strategy_id = sa.strategy_id AND rb.kind = 'rolling_beta'
     WHERE sa.strategy_id IN (<the pre_fix ids>);
    ```
