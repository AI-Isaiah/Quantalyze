# Phase 166.1 Plan 01: dispersion floor to one module, variance sites S1-S7 on it Summary

`services/dispersion.py`. The seven exact-zero variance sites outside `metrics.py` all read it,
so a constant yield taken from a compounding NAV (std about 1e-16) no longer produces a
fabricated ratio. Before the fix these sites returned a 1.28e13 optimizer Sharpe, a CSV
error printing "Daily Sharpe 2296215230173376.50", and a 48.6% / 51.4% split of zero risk.
`metrics.py` values and the qstats-gate census are unchanged.

## Deviations from Plan

**1. [Rule 1 - plan-internal contradiction] S3 residue branch nested inside today's `std > 0` gate**
- **Found during:** Task 2, before the S3 edit.
- **Issue:** the plan says "if `r` has at least 2 rows and its std is residue". Residue includes an
  EXACT zero std (`0 <= floor`). Measured: `pd.Series([0.001]*n).std(ddof=1)` is exactly `0.0`
  for n = 2, 3 and 5, and about 2e-19 to 4e-19 for n = 10, 30, 120 and 366. The pinned fixture
  `test_csv_validator.py::test_valid_daily_returns_passes` (5 rows of 0.001, `ok=True`) and its
  siblings would then be REJECTED. That would flip a user-facing verdict, which is what D-04 exists
  to avoid. It would also break the plan's own Task 2 verify, and that test file is not in
  `files_modified`.
- **Fix:** the residue branch sits inside today's `len(r) >= 2 and r.std(ddof=1) > 0` block, so:
  - a residue series with a positive mean is still rejected, now with no number;
  - a residue series with a mean at or below the risk-free rate gets no error;
  - an exact-zero std and real dispersion take today's code, byte-identical.
  No verdict moves.
- **Residual, recorded for the orchestrator:** a SHORT exactly-constant positive CSV (std exactly 0)
  is accepted today and stays accepted, while a longer one is rejected. That boundary is
  float-summation luck, it predates this plan, and this plan does not widen it. Changing that
  verdict is a product decision outside 166.1.
- **Commit:** `614d7d8de`.

**2. [Test-only addition] Extra controls beyond the behaviour list**
- `test_s3_constant_negative_yield_passes`: residue below the risk-free rate gives no error.
- `test_s7_risk_decomposition_of_real_risk_still_splits`: a real covariance still splits to 100%.
- Each test asserts its fixture precondition `0 < sd <= residue_floor(mean)`, so it cannot
  silently exercise another branch.
