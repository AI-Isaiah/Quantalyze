## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest (+ pytest-xdist) |
| **Config file** | `analytics-service/pytest.ini`; `analytics-service/pyproject.toml` (mypy) |
| **Quick run command** | from `analytics-service/`: `<main-checkout venv python> -m pytest tests/test_dispersion_floor_sites.py tests/test_correlation_residue_sites.py tests/test_metrics.py tests/test_qstats_gate.py -q` |
| **Full suite command** | from `analytics-service/`: `<main-checkout venv python> -m pytest -q -n auto`, then CI's `mypy --strict --follow-imports=silent --config-file=pyproject.toml services/ routers/ models/ main.py main_worker.py main_worker_healthz.py sentry_init.py` |
| **Estimated runtime** | ~5 s quick, ~30 s full |

The venv python is the main checkout's `analytics-service/.venv/bin/python`, resolved at run time from
`git worktree list --porcelain` (`QZ_VENV_PY`), and pytest ALWAYS runs from `analytics-service/`
(a repo-root run misses cassettes and makes live broker calls).
