## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Engine → displayed number | analytics statistics (Sharpe, SQN, correlation, risk split) rendered on factsheets, the optimizer and the bridge | computed statistics; a fabricated number is an integrity defect |
| CSV upload → validator | an owner's uploaded returns are judged, and the rejection message is shown back | owner-supplied series; the message must not echo a fabricated statistic |
| Test run → PROD | phase tests must never reach a live database or broker | credentials and live data (high) |
| Release commit → public repo | CHANGELOG, VERSION and commit messages | public text; no identifiers, no CI skip token |
