**The API this plan fixes for plans 05a, 05b, 06a and 06b (they must not edit `return-stats.ts`; an API gap there is
a STOP-and-report).** All pure, no Date, no randomness:
- `DISPERSION_RESIDUE_REL` (1e-12), `residueFloor(mean)`, `dispersionIsResidue(sd, mean)`,
  `dispersionIsReal(sd, mean)`: the Python rule verbatim (floor = constant times the larger of 1 and the
  absolute mean; residue is sd at or below it; real is strictly above; a NaN on either side makes both
  false).
- `dispersion(xs, ddof)` with `ddof` 0 or 1: returns `{ n, mean, sd }` where `mean` is
  `portfolio-math-utils` `mean(xs)`, and `sd` is `stdDev(xs, ddof === 1)` EXCEPT that a residue sd
  (`dispersionIsResidue(sd, mean)`) is returned as exactly 0. A NaN sd stays NaN.
- `sharpe(xs, opts)` with `opts = { periodsPerYear, ddof, rf? }` (rf annual, default 0): `null` when
  `n < 2`, when any input is non-finite, or when `dispersion(xs, ddof).sd` is 0; otherwise
  `((mean - rf / periodsPerYear) * periodsPerYear) / (sd * Math.sqrt(periodsPerYear))`, the arithmetic
  order `src/lib/factsheet/compute.ts` uses today, so plan 06a can adopt it without moving the
  factsheet snapshot.
- `pearson(a, b)`: over the first `min(a.length, b.length)` points; `null` when that is below 2 or
  either leg's population dispersion is residue; otherwise the SUMS form `cov / Math.sqrt(varA * varB)`
  that `correlation-math.ts` `pearson` and `build-payload.ts` `pearsonCorr` use today (G11.E.5's null
  contract, kept).
- `beta(y, x)`: over equal-length arrays; `null` when `n < 2` or `x`'s population dispersion is
  residue; otherwise `cov / varX` with both sums divided by the same `n` (ddof-invariant, the form
  `factsheet/joint.ts` uses).
Each site maps `null` to the degenerate value it emits TODAY for an exactly constant input (null, 0 or
NaN), so no renderer changes (D-07).
