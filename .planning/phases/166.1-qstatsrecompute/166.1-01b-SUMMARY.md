# Phase 166.1 Plan 01b: the SQN block S8 reads the dispersion floor Summary

the R-multiple standard deviation is not residue (`dispersion_is_residue(std_r, mean_r)`). 21
identical losses of 7.7 give None, the same answer 21 identical losses of 1.0 always gave. Before
the fix they gave -4.03e16, and 37 such losses gave -5.40e16. Real dispersion (7.7 / 7.71) keeps a
finite SQN, and no other returned key moves.

### How the unedited-vs-edited comparison works

Only the edited function exists at test time. The test therefore patches
`services.analytics_runner.dispersion_is_residue` to `sd <= 0.0`, which is exactly the old
`std_r > 0` guard. It then compares every other key, patched against unpatched, on all three inputs
(7.7 x 21, 1.0 x 21, and the alternating book). The test also asserts that under the patch the
residue book's SQN has `abs > 1e15`. That check proves the patch really reproduces the old function,
so the comparison cannot be a function compared with itself. No value is hard-coded.
