## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Verdict script's `--self-test` cleanup trap referenced an out-of-scope local variable**
- **Found during:** Task 1, first manual run of `bash scripts/mutex-dead-holder-verdict.sh --self-test`
- **Issue:** The first draft declared `local scratch=$(mktemp -d)` inside `self_test()` and registered `trap 'rm -rf "${scratch}"' EXIT`. Because the EXIT trap fires at PROCESS exit — after `self_test()` has already returned and its `local` variables have gone out of scope — the trap referenced an unbound variable under `set -u`, producing `scripts/mutex-dead-holder-verdict.sh: line 1: scratch: unbound variable` and a spurious exit 1 immediately after the correct `self-test OK (3 checks)` line printed.
- **Fix:** Renamed the variable to a script-global `SELF_TEST_SCRATCH` (explicitly not `local`), so the EXIT trap can still read it after the function returns.
- **Files modified:** `scripts/mutex-dead-holder-verdict.sh`
- **Verification:** `bash scripts/mutex-dead-holder-verdict.sh --self-test` now exits 0 cleanly; re-ran the direct-invocation checks (marker present → exit 1, marker absent → exit 0) to confirm no other regression.
- **Committed in:** `c8d1557a` (part of Task 1's commit — found and fixed before that commit was made, not a separate commit)

**2. [Rule 1 - Bug] Test 4's invariant-text search missed a comment that wraps across lines**
- **Found during:** Task 3, first run of the new vitest file (before it was ever committed)
- **Issue:** The release step's "must never redden a job whose real work passed" sentence is written across two `# `-prefixed YAML comment lines in source. A plain `step.body.includes(NEVER_REDDEN_INVARIANT)` check does not match across the embedded `"\n            # "` line break, so Test 4 failed on all three workflow files even though the invariant text is genuinely present and untouched.
- **Fix:** Normalized the step body before searching — `body.replace(/\n\s*#\s*/g, " ").replace(/\s+/g, " ")` joins comment continuation lines into one space-separated string, searching the same bytes without the line-wrap noise.
- **Files modified:** `src/__tests__/mutex-dead-holder-verdict.test.ts`
- **Verification:** Re-ran the file; all 11 tests passed.
- **Committed in:** `cc931bef` (part of Task 3's commit — found and fixed before that commit was made, not a separate commit)
