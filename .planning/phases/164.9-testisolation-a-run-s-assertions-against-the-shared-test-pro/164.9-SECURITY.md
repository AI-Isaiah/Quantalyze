### T-164.9-05-05 (Repudiation) — re-mitigated, and the first mitigation is why

⚠️ Recorded because the ORIGINAL control was ineffective and a reader should not
inherit it. It read "every retry emits a log line". Review proved that vacuous:
pytest renders captured log records for FAILING tests only, so an absorbed retry
on a passing run printed nothing at all — the exact case the control existed to
make visible. **Re-mitigated** with an unconditional counter emitted at session
teardown (xdist-aware), so a retried-but-green run is distinguishable from a
clean one. The audit verified the re-mitigation, not the superseded wording.
