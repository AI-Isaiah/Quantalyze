## Shared Patterns

### Default-preserving parameter (never a global)
**Source:** `analytics-service/services/nav_twr.py` `chain_linked_twr(..., *, prev0=None)` and its test `tests/test_nav_twr.py::test_prev0_default_byte_identical`.
**Apply to:** every function that gains `floors=` / `dust_floor=` / `abs_tol=`. The default equals today's constant, so Deribit, sFOX, ccxt and CSV callers (`transforms.py`, `native_nav.py:649`, `scripts/golden_parity.py:179`) never pass it and stay byte-identical. A module-global swap or monkeypatch of `DUST_NAV_FLOOR` is process-wide state across concurrent jobs of different currencies and is forbidden.

### Present-only, non-promoting flag carry
**Source:** `analytics-service/services/analytics_runner.py` `mtm_gated_reason` carry (~1929-1931), registered in `DataQualityFlags` (~212).
**Apply to:** `native_unit` (and `unsupported_unit` if the planner uses a flag rather than the failed-stamp copy). Never in `NAV_TWR_GUARD_KEYS` / `ALLOCATED_CAPITAL_GUARD_KEYS` (the only promoters).

### Strict server-truth flag coercion before it crosses to the client
**Source:** `src/lib/factsheet/composite-read-path.ts` `singleKeyDataQuality`; `src/app/api/strategies/[id]/returns/route.ts` `is_composite`; `src/lib/queries.ts` `is_composite` (raw dqf blob stripped via the `_dqf` destructure, only the boolean ships).
**Apply to:** `returnsUnit` / `returns_unit`: `typeof === "string"` AND `^[A-Z]{2,10}$`, else absent/null. Same pattern on the Python write side (CHECK `^[A-Z]{2,10}$`), so the unit is validated at the producer, the DB and every consumer.

### Fail-loud transient/permanent disposition (derive and backfill)
**Source:** `job_worker.py` derive MT5 branch (`DispatchResult(outcome=DispatchOutcome.FAILED, error_message=..., error_kind="transient"|"permanent")`, `_stamp_strategy_analytics_failed(...)` before a permanent return) and `equity_reconstruction.py` `_fail(key, "transient"|"permanent")` over `_MT5_BACKFILL_MESSAGES`.
**Apply to:** blank currency (transient, no stamp), D-03 change (ERROR log, transient, nothing written), D-06 unsupported (permanent + curated stamp). Messages carry NO broker text, amounts, logins or servers and none of `mt5_validation._WRONG_SERVER_PHRASES` / `_AUTH_PHRASES` (substring-matched by the real classifier).

### No amounts, logins or raw broker text in logs
**Source:** every MT5 arm above (`logger.error("... (allocator=%s key=%s deals=%d material_equity=%s)", ...)`, `scrub_freeform_string`).
**Apply to:** all new log lines and `error_message`s; log the currency CODE only after it matched the bare-code regex, else "unknown".

### Catalogue-only migration verification
**Source:** `20260925120000_api_keys_account_identity.sql` `DO $verify$` and `20260920120000_api_keys_venue_account_id_grant.sql` self-verify (`has_column_privilege`, `pg_constraint ... convalidated`).
**Apply to:** the new migration and its rollback. No count-asserting `DO` block (TEST has no data).

### One conversion, one place, honest absence
**Source:** `scenario-benchmark.ts` `pairScenarioWithBtc` over `alignCoveredReturns` + `COMPARATOR_CALENDARS.btc`.
**Apply to:** `convertNativeReturnsToUsd`; composer, shared-scenario resolver, portfolio page and allocator dashboard queries all call it. No surface blends raw BTC returns with USD returns (D-22); an unpriced day is absent, never 0 or carried forward.

### USD byte-identity gate on every UI helper
**Source:** UI-SPEC "The one rule this phase adds": `returnsUnit === null` takes the same early return (`withUnit` returns the same string reference; `ReturnsUnitChip` returns `null`; `convertNativeReturnsToUsd` returns the same array reference).
**Apply to:** all surfaces A-E. Existing `FactsheetView.*`, `MetricsColumn.*`, `strategy-v2-type-scale` tests and the `build-payload` snapshot pass unedited.
