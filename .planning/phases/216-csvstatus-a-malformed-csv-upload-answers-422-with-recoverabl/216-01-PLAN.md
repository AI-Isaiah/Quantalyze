<objective>
Make a malformed CSV upload that reaches the /process-key synchronous rejection gate answer **422 with `recoverable: false`**, so the contract stops telling the caller that a retry of the same bytes can succeed. Auth and scope rejections stay 403 (`recoverable: false`), and venue blips stay 424 (`recoverable: true`). Implements the founder decision recorded in ROADMAP `### Phase 216` and 215-CONTEXT Option A ("Pin today, book fix"), with the code scope fixed in 216-CONTEXT `## Implementation Decisions`.

Purpose: `/process-key`'s public error contract stops contradicting itself for a deterministic input fault. STATUS_CONTRACT §1 puts 422 in the CALLER class with `recoverable` false, which is the class a malformed upload belongs to.

Honest scope (CONTEXT "Measured at HEAD 33264affe"): no live wizard surface reaches this arm today. The deliverable is the route contract and its pins. The ROADMAP's "the wizard stops offering Retry" clause has no live surface at HEAD, and this plan does not claim one.

Output: one new arm in `routers/process_key.py`, the Phase 215 pins updated on purpose with literals, the stale status comments corrected, the one count pin the new test sites move, and a recorded neuter-RED-restore control.

Reversibility: `costly`, because it changes the public `/process-key` error contract. The founder already settled it (ROADMAP Phase 216, 215-CONTEXT Option A, recorded in 216-CONTEXT), so this plan adds no `checkpoint:decision` and runs `autonomous: true`.
