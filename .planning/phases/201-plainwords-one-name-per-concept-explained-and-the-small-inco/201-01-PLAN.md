Design decisions this plan takes (Claude's discretion per CONTEXT; D-26 ratings recorded, no checkpoint):
- Placement: the registry lives in `src/lib` (outside `figure-gate-census`'s walk roots, so it needs no EXCLUDED row) and imports only `SIX_MONTH_WINDOW_DAYS` from `@/lib/factsheet/compute`. Reversibility: reversible.
- `FULL_RECORD_BASIS` is copied into the registry module and exported; plan 201-16 deletes the private copy in `discovery-columns.ts` and imports this one. Until then the glossary test pins the two equal. Reversibility: reversible.
- Accessibility mechanism (UI-SPEC leaves it to the planner): `Tooltip` accepts its `children` either as a node (unchanged) or as a function. Called as a function, it receives `{ "aria-describedby": string | undefined }` (the bubble id while open) and the inner wrapper span no longer carries the attribute. The wrapper spans and their depth do not change, so `Tooltip.test.tsx`'s `.parentElement!.parentElement!` locator still lands on the wrapper. Reversibility: reversible.
- Print switch: a React context in `Term.tsx`, exported as the `PlainTerms` provider. `FactsheetView` sets it under `printView` (plan 201-09); `MetricsColumn` needs no prop threading (it has no `printView` today). Reversibility: reversible.
- `Term` passes `className="inline"` to `Tooltip` so the wrapper is not `inline-flex` around running label text, and a wrapped label keeps its box (U-02).
