## Implementation Decisions

### Item 2: guarded composite headline (Quantum Drift class)
- **D-01:** When an integrity guard fires, **every stat is computed on the same post-break suffix**. This covers cumulative, CAGR, Calmar, Sharpe, Sortino, volatility, window returns and drawdown. The guards are `twr_chain_broken`, `flow_dominated_guard`, `negative_nav_guard` and `dust_nav_guard`.
  - The factsheet carries a note naming the span, along the lines of "Measured since {date}; earlier history is unreliable ({guard reason})."
  - No stat may come from a different basis than the others in the same headline.
  - This was the founder's choice (2026-10-09, "One consistent suffix"). Two alternatives were rejected: withholding every return-path stat, and blanking only the mismatched ones.
  - **Reversibility:** costly. It changes stored metrics for every guarded strategy and needs the Wave 5 recompute.
- **D-02 (orchestrator default, from the never-invent-data rule):** if the suffix is too short for a stat's own minimum, that stat is null and renders "—". It is never 0.
- **D-03:** The TS headline must stop trusting finite zeros from `metrics_json_by_basis` (`composite-read-path.ts`) where the stored value is a placeholder rather than a measurement. The read path must be able to tell the two apart.

### Item 3: flat strategy leg
- **D-04:** The factsheet shows "—" for every dispersion-based stat on a no-dispersion leg: Beta, IR, capture and alpha. `beta()` keeps returning 0 internally for the allocation math, unchanged (founder, Recommended).
- **D-05:** The KS test in `style-drift.ts` returns p=1 at D=0. This is a bug fix and needed no decision.

### Item 4: share card versus factsheet
- **D-06:** **The card equals the factsheet.** The OG card shows exactly the factsheet's stored value (founder, Recommended). The `values.length >= 30` gate in `og-metrics.ts` goes. Any minimum-history rule belongs in compute, so card and page always agree.
- **D-07:** A non-finite CAGR or max-DD "—" on the card is never coloured red (DESIGN.md). This is the 170.6 item, which moved here.

### Item 5: job finished, analytics failed
- **D-08:** The owner line reads "Analytics couldn't be computed from this data. We've logged the error." The public share note reads "Analytics are not available for this strategy yet." (founder, Recommended). Public text must reveal no internals.
- **D-09:** Eclipse now reads `complete` (STATUSBRIDGE re-sync, 2026-10-08), so this copy applies only to genuine failures. Re-measure Eclipse first, as the ROADMAP requires.
