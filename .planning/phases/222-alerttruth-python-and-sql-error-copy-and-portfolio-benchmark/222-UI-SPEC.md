# Phase 222 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase's UI surface is small and adds **no component, no layout and no new token**. It covers two things:

1. **Error copy.** These are the server-written sentences a user reads. Their wording is fixed by the founder rulings in `222-CONTEXT.md` or derived from them, as the Source column marks. Existing surfaces render them. No TS component changes for this half.
2. **The benchmark outage note.** This is the wire value `benchmark unavailable: no price source`, which must read as distinct from the stale-cache note and be **muted, not amber** (founder ruling 2026-11-25).

### Benchmark note tone contract (the ERRC-02 visual rule)

The tone gate is the **`stale` boolean**, never the note string. A renderer must not parse or compare `note` to choose a colour. The router already writes `stale: benchmark_note == BENCHMARK_NOTE_STALE`, so NO_SOURCE carries `stale: false` with no further edit.

| Wire `note` | Wire `stale` | Tone | Classes on the `<p>` (base + tone) |
|---|---|---|---|
| `benchmark unavailable: stale` (`BENCHMARK_NOTE_STALE`, unchanged) | `true` | amber, recoverable: a recent cached day exists and the next refresh can fill it | base + `text-warning bg-warning-bg border border-warning-border rounded px-2 py-1` |
| `benchmark unavailable: no price source` (`BENCHMARK_NOTE_NO_SOURCE`, **new**) | `false` | **muted**: honest absence, which the founder ruled is not amber | base + `text-text-muted` |
| `benchmark unavailable: fewer than 30 shared days` (THIN, unchanged) | `false` | muted | base + `text-text-muted` |
| `benchmark unavailable: computation failed` (ERROR, unchanged) | `false` | muted | base + `text-text-muted` |

- **Base** (every variant): `<p role="status" aria-live="polite" className="mb-4 text-small break-words first-letter:uppercase …">{note}</p>`.
- The note is rendered **verbatim as a text node**, never as markup. The wire stays lowercase, and `first-letter:uppercase` displays it as **"Benchmark unavailable: no price source"**.
- **Never red** for any benchmark note. Absence is not a permanent failure (DESIGN.md semantic-colour gates).
- **Never an icon or glyph** beside the note.
- The comparison's null figures (`benchmark_twr: null`, `correlation: null`) render the em-dash `—`, colourless (DESIGN.md Numbers Contract).
- **Source of this rule:** `git show 3ba04e9a0^:src/components/portfolio/BenchmarkComparison.tsx`, the note block (amber iff `stale`, else `text-text-muted`). This contract adopts it unchanged, so NO_SOURCE is muted by construction.

### Interaction contract: the contact-form link

- Every sentence that offers a channel contains the **exact lowercase substring `contact form`**. This is `CONTACT_FORM_LINK_TEXT` in `src/lib/contact.ts`. `ContactPointerText` links the first occurrence with `text.indexOf`, which is case-sensitive.
- A sentence may start "Use the contact form …" (capital U): the lowercase `contact form` inside it still matches.
- **Never write "Contact form" with a capital C.** It would not match and would render unlinked.
- On error-envelope and wizard surfaces the link opens in a new tab with `rel="noopener noreferrer"` and the visually hidden " (opens in a new tab)" suffix. That is existing `ContactPointerText` behaviour, unchanged.
- **Banned in every user-readable sentence** in `analytics-service` and in the `computation_error_copy` arms:
  - "contact support" (any case);
  - "support team", "email us", or any channel other than the contact form.
- Voice (DESIGN.md "Voice / microcopy"): declarative, sentence case, no exclamation, the cause first and then the remedy.
- **No TS rendering change is needed for the link.** Surfaces that already route through `ContactPointerText` link the new phrase automatically. Surfaces that do not (see Surface map) show it as plain text, which this phase accepts.
