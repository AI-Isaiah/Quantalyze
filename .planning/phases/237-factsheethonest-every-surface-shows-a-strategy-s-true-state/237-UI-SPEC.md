> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

ship:

toggle shows on the next request, plus one copy correction that CACHE-03 forces.

## Global rules (apply to every section)

- **G1. Holding never un-withholds.** A surface that holds a re-running strategy shows exactly what
  the factsheet shows for that row: the same figures, the same dashes and the same Withheld notes.
  The re-run admission is `isStoredResultReadable` / `isRecomputeOverStoredResult` in
  `src/lib/factsheet/headline-basis.ts` and `src/lib/closed-sets.ts`. It changes **whether** a
  stored result is read, never **which** figures a gate shows. A FACT-01-withheld panel stays
  withheld during a re-run, and a figure-gate dash (`gateAnnualized`) stays a dash.
- **G2. One copy source per sentence.** The Updating sentence comes from `ANALYTICS_UPDATING_LINE`.
  The Withheld panel sentences come from `headlineCoverageNote` (§1.4). Data source labels come from
  `TermsPanel`'s existing `tierLabel` map. No surface inlines a second copy.
- **G3. No live regions, no motion, no CTA.** Nothing added here toggles on the client after load.
  There is no `role="status"`, no `aria-live`, no `role="alert"`, no spinner and no reload button
  (Phase 190 Accessibility).
- **G4. No new tokens, sizes, weights or colours.** Each line adopts its host's existing note class
  (tables in Typography and Color).

## 1. FACT-01: the Withheld note replaces three panels and the same figures elsewhere

### 1.1 What is withheld (founder ruling 2026-11-23, Q1-Q3)

| Panel | Component (mount sites) | Founder answer |
|---|---|---|
| Worst 10 Drawdowns | `WorstDrawdownsTablePanel` (`MetricsColumn.tsx`, full rail §Risk and `part="detailed"` §Risk) | "Withhold panel (Recommended)" |
| EOY Returns | `EoyReturnsPanel` (full rail §Performance and `detailed` §Performance) | "Withhold both (Recommended)" |
| Calmar by Year | `CalmarByYearPanel` (`AnalyticalPanels.tsx`; full rail §Risk and `detailed` §Risk) | same |
| Style Drift **and its Kolmogorov-Smirnov line** | `StyleDriftPanel` (`BatchDPanels.tsx`; full rail §Style and `detailed` §Style) | "Withhold panel + KS (Recommended)" |

Each panel has exactly two mount sites, the full rail and `part="detailed"`. Both obey this section
identically. There is no third mount (`grep -rn '<StyleDriftPanel\|<WorstDrawdownsTablePanel\|<CalmarByYearPanel\|<EoyReturnsPanel' src`).

### 1.2 Gate per panel (one predicate, two existing scopes)

Every gate is built from `isHeadlineWithheld` (cash basis, chain-broken, headline withheld) plus the
what-if term `!leverageApplied`. This is the same predicate the strip, the rail and the D-15 dashes
use, so they cannot disagree (CONTEXT). The scope follows **what the panel draws inside a zoom**,
which is the rule plan 15 round 3 already applies to these same panels' last-year dash:

| Panel | Gate | Inside a selected range |
|---|---|---|
| Worst 10 Drawdowns | `wholeRecordWithheld` (= `!selected && useFullHistoryWithheld()`) | **Shows its own slice.** The panel reads `useWindowedView`, so inside a range it lists only that range's drawdowns. That is CONTEXT's "a zoomed window keeps its own slice". |
| EOY Returns | `fullHistoryWithheld` | **Stays withheld.** The panel has no slice: inside a range it still draws the whole record under the `Full history` scope note. |
| Calmar by Year | `fullHistoryWithheld` | **Stays withheld**, same reason. |
| Style Drift + KS | `fullHistoryWithheld` | **Stays withheld**, same reason. Here the `Full history` scope note sits on the numbered **§Style section heading** (`NumberedSections` `scopeNote`), not beside the panel title. |

**Decided** by CONTEXT ("Follow-ons of the FACT-01 ruling", 2026-11-23): "EOY Returns, Calmar by
Year and Style Drift show the whole record even inside a zoom, so they have no slice to keep and
stay withheld under a zoom; Worst 10 Drawdowns keeps its zoomed slice." The reasoning: CONTEXT's
"A zoomed window keeps its own slice" assumes the panel has a slice, and only Worst 10 does. If
EOY, Calmar or Style Drift were un-withheld inside a range, a zoom would reveal the whole-record by-year and half-vs-half
figures that the full-history view withholds. That is a one-click bypass. It would also contradict
the founder rule of 2026-10-15 for these same panels: "A zoom does not switch it off: these panels
show the whole record inside a zoom too." The gate values are decided once in `MetricsColumn` and
passed down as props, exactly as today. No panel calls `isHeadlineWithheld` itself.

### 1.3 Precedence inside each panel (first match wins)

1. **The panel has no data** (Worst 10 `rows.length === 0`, EOY `years.length === 0`, Calmar
   `rows.length === 0`, Style Drift `!sd`). The panel returns `null`, as today. A Withheld view
   adds nothing to an absent panel.
2. **Gate on, cause `failed`** (`dataQuality.headlineWithheldCause === "failed"`). The panel
   returns `null` (CONTEXT follow-on: "A failed-cause panel stays omitted as today"). The page's existing "couldn't be computed" status line is the one stated cause
   (D-14), and `headlineCoverageNote` already returns no note for this cause. A titled panel with
   no sentence would read as broken.
   - **No empty numbered section.** On this arm, outside scenario mode, Style Drift is the only
     child of §Style. The §Style mount condition (`hasStyleDrift || scenarioMode`) must then use
     the same verdict, so that no empty "Style" heading renders. The later sections renumber, the
     same as for a strategy with no Style Drift today.
3. **Gate on, any other cause.** The panel keeps its header and replaces its body with the Withheld
   note (§1.4).
4. **Gate off.** The panel is unchanged, byte for byte.

function that already owns them:

| Cause | `"panel"` slot returns |
|---|---|
| absent (unmeasured; legacy mixed-basis or malformed `headline_since`) | `{ variant: "withheld", text: FH237-PANEL-WITHHELD }` |
| `"recomputing"` | `{ variant: "withheld", text: FH237-PANEL-RECOMPUTING }` |
| `"failed"` | `null`, which is arm 2 of §1.3 |

**A held re-run does not blank a Dated row's panels** (checked against G1). `headlineVerdict` in
`src/lib/factsheet/headline-basis.ts` returns the `recomputing` cause only when the stored cash
headline gate is **not applicable** (`not_rankable`) on a pending/computing row. The factsheet
resolve stage passes `recomputeOverStoredResult` into `isStoredResultReadable`, so on a held
re-run the gate is applicable: a Dated row stays Dated, its panels keep their figures, and only a
row that was already Withheld stays Withheld. The `recomputing` arm is reached only by a caller
that does not pass the hold flag. The planner pins this with a test: a held re-run over a Dated
row renders the four panels with their tables.

The strings are in the Copywriting Contract. Tone is amber with `⚠`, because the Withheld note is
recoverable: a recompute writes `headline_since` and the figures return (164.6.6.3.3 UI-SPEC §1.4,
DESIGN.md amber gate).

- The FH237-PANEL-WITHHELD sentence keeps the headline Withheld sentence's second half verbatim
