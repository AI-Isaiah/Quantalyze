# Phase 167.1.2.2.2.1 Plan 03: Safe archive downloader Summary

**One module that downloads an untrusted OKX archive link with an empty exact-host allow-list, vetted-IP-pinned TLS, no redirects or proxy, and in-memory zip/gzip decompression under compressed, decompressed and ratio caps, without ever letting the signed URL reach a log or an exception.**

## Accomplishments

- `download_archive_csv(url) -> (csv_bytes, container, compressed_bytes)` per the interface plan 07 imports; `ARCHIVE_ALLOWED_HOSTS` ships as `frozenset()` so every download is refused with `host_not_allowed` before the resolver or the transport is touched.
- SSRF: scheme, exact host, netloc==hostname (userinfo, port), fragment, whitespace/non-ASCII refused; numeric host forms (decimal, hex, short) judged as the address they dial; ANY private, loopback, link-local, CGNAT, unspecified, multicast, IPv4-mapped-private or non-global answer (including a mixed public+private answer) is refused; connect goes to the vetted IP with `Host` and `sni_hostname`, resolver called exactly once.
- Redirects never followed, environment proxies ignored, no auth header or cookie, connect and total deadlines. 403/410 is `LinkExpired`; 404 and other 4xx are `http_status`; 5xx/408/429 and network errors propagate as transient.
- Decompression in memory only, in 1 MiB `max_length` chunks, running decompressed and ratio caps, single non-encrypted zip member, truncated/trailing/multi-member gzip refused, decompression run in `asyncio.to_thread`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] httpx.AsyncClient logged the full signed URL at INFO**
- **Found during:** Task 2 (the `caplog` no-path-or-query test)
- **Issue:** Task 1's implementation used `httpx.AsyncClient`, whose `_send_single_request` logs `HTTP Request: GET <url> "<status>"` on the `httpx` logger. That URL is the vetted-IP rewrite of the signed link, query token included, so every successful or failed fetch put the bearer token in the logs (threat T-167.1.2.2.2.1-10).
- **Fix:** `_fetch_body` now builds one `httpx.Request` and calls `transport.handle_async_request` on a bare `httpx.AsyncHTTPTransport(trust_env=False)` (or the `_transport()` seam), closing the response in `finally`. A client brings nothing this module wants: no redirects, cookies, env proxy or request log. Timeouts ride on the request `timeout` extension; headers are `Host` and `Accept-Encoding: identity`.
- **Files modified:** `analytics-service/services/okx_archive_download.py`, tests
- **Verification:** `TestNoLinkInLogs` RED (6 scenarios) then GREEN; all 108 pass.
- **Committed in:** `c8fa1136f`

**2. [Rule 2 - Missing critical] Transient failures were logged nowhere, and `raise_for_status()` embeds the signed URL**
- **Found during:** Task 2 (same log test, `server_error` scenario left no record)
- **Issue:** a 5xx needed a transient error WITHOUT the URL in its message (`HTTPStatusError.__str__` includes it), and a transient failure left no log line for operators.
- **Fix:** hand-built `httpx.HTTPStatusError("archive host answered HTTP <status> (https://<host>)")`; `download_archive_csv` logs `exc_class` and scheme/host for `httpx.HTTPError`/`TimeoutError` and re-raises. 408 and 429 are treated as transient with 5xx (not in the plan's text; a rate-limit answer must not become a permanent refusal).
- **Files modified:** `analytics-service/services/okx_archive_download.py`
- **Committed in:** `c8fa1136f`

**3. [Plan phrasing] RED-first for Tasks 2 and 3**
- Task 1's action had the module implemented in full (all checks) with only the tracer tests; Tasks 2 and 3 therefore added tests against a module that already implemented them. Their gates were proven able to fail by the four neuter proofs above plus the observed log leak, rather than by a failing-test-first commit.

**4. Bracketed IPv6 literal host** is refused as `url_shape` (netloc is not the bare hostname) rather than `private_address`; both are refusals before any request, tested explicitly.
