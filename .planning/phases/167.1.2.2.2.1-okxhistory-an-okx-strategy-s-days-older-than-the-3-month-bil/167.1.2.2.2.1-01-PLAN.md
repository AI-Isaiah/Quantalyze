**Function contract (fixed here; plan 08 calls it exactly so).**
`public.apply_okx_archive_rebuild(p_strategy_id uuid, p_rows jsonb, p_expected_gaps jsonb, p_expected_gaps_after jsonb) RETURNS jsonb`.
- `p_rows`: array of `{"date": "YYYY-MM-DD", "daily_return": <finite number>}`, 1..1000 elements, no duplicate date.
- `p_expected_gaps`: the `unrecovered_gaps` array the caller read (`[{from, to}]`, order-insensitive).
- `p_expected_gaps_after`: the caller's own computation of the narrowed gaps (order-insensitive).
- Returns `{"status": "applied" | "already_applied", "inserted": n, "ranges_added": k, "gaps_before": [...], "gaps_after": [...]}`.
- Refusals: `22023` for malformed input, a missing `strategy_analytics` row, or a row outside every stored gap; `P0001` for `gaps_changed` (compare-and-set) and `gaps_after_mismatch`. Messages are prefixed `apply_okx_archive_rebuild:` and carry dates and counts only. Never `40001` (PATTERNS Correction 7: PostgREST re-runs it without bound).

**Worktree setup.** Run `npm ci` once if `node_modules/.bin/vitest` is absent.
