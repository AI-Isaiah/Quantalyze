# Phase 167.1.2.2.2.1 Plan 07: okx_archive_rebuild job skeleton Summary

**A durable api_key-scoped `okx_archive_rebuild` worker kind whose preflight mode refuses disconnected, foreign or non-read-only keys and re-mapped bill subtypes before any archive call, requests each quarter with one apply POST on its own fresh exchange instance, and reports the account, the subtype census and only the link's scheme and host through a pinned Result shape v1.**

## Performance

- **Duration:** about 39 min (start not clocked to the second; roughly 17:17Z to 17:56Z)
- **Completed:** 2026-10-15T17:56Z
- **Tasks:** 2
- **Files modified:** 5 (2 created, 3 modified)

## Accomplishments

- Worker wiring: `dispatch()` lazy-import arm, `TIMEOUT_PER_KIND["okx_archive_rebuild"] = 15 * 60`, watchdog override `"30 minutes"`; the kind is not in `BACKFILL_KINDS` or `JOB_CHAIN_FOLLOW_ON` (pinned by a test).
- `run_okx_archive_rebuild_job` order is the D-02 guarantee: validate input, `_check_keys` (identity columns only; no credential read, no decrypt, no client for a refused key), then `_allocator_key_preflight`, then one `account/config`, one `account/subtypes`, then the quarters.
- Account check: live uid must equal `venue_account_id` of the job key AND every target key (NULL never matches); `perm` must contain `read_only`; `acctLv`, `feeType`, `settleCcy` recorded as short classes only.
- D-08 preflight census: drift against the committed table is a permanent stop; unlisted subtypes are counted by type in the result.
- Quarter step (single pass; plan 16 replaces it): one apply POST on a fresh client, last call on that instance, one attempt, closed in `finally`, at least 11 s between two applies; one status read on the preflight instance via `_okx_bills_fetch_with_backoff`; only `describe_href` scheme and host recorded.
- Result shape v1 written once via the fenced `set_compute_job_progress`; the handler never touches `compute_jobs.metadata` otherwise. A stop writes its block first, then returns FAILED with `okx_archive_rebuild: <class>` plus counts.
