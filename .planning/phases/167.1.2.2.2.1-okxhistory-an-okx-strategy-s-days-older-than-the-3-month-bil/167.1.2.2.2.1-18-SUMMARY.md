# Phase 167.1.2.2.2.1 Plan 18: UTC+8 quarter cut with whole-or-missing edge days Summary

**The OKX archive parser now accepts a quarter file cut at 00:00 UTC+8 (the real Q2 file opens at 16:00 UTC on 03-31), and every daily total stays on a whole UTC day: a quarter-edge day (03-31, 06-30, 09-30) is summed only when both neighbouring files were read, otherwise it has no total, no covered entry and no row, while the Q2 to Q3 balance seam is still chained on the shared edge day.**

- **Files modified:** 6 (plus this SUMMARY)

## Accomplishments

- `okx_archive_files.py`: `_QUARTER_CUT_UTC_OFFSET_MS` (8 hours) is subtracted from both `start_ms` and `end_ms`; `covered_days` is now the quarter's first day up to, not including, its last calendar day; `ArchiveFile` gained `head_edge_day` and `tail_edge_day`; `quarter_edge_days(files)` returns `(whole, missing)`. The `quarter_range_mismatch` detail keys and date values are unchanged, so plan 17's `last_error` tokens and tests did not move. Module docstring, stop list and the `ArchiveFile` and `longest_billless_run` docstrings amended.
- `okx_archive_classify.py`: `aggregate_archive` computes `covered` (union of file `covered_days` plus `whole`) before the row loop and guards the three summing sites (NON_EXTERNAL, REALIZED outside the live instTypes, and the final branch). The classification counters and the three classification stops still read every row. `ArchiveAggregate` carries `edge_days_whole` and `edge_days_missing`. `_adjacent_runs` joins on `tail_edge_day == head_edge_day`. The now unused `date, timedelta` import was removed.
- Fixtures: q2's last bill moved to `1782835199999` and q3's last three to `1790783999999` (same UTC day, one millisecond inside the cut).
- Tests: `TestQuarterCutAtUtcPlus8` (9 cases: tracer, four exact-millisecond bounds, both-files rule, all-legs gate, classification of edge bills x2). Seven old-behaviour pins re-pinned (three in the parse file, four `TestTracerQ3` in the reconcile file).
