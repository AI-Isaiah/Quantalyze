## Shared Patterns

### Marker query first, every PROD session
**Source:** `docs/runbooks/cron-sync-go-live.md` forms `guard`, `marker-is-prod`, `marker`; CLAUDE.md "Which database am I on?".
**Apply to:** every runbook read and write. A NULL marker refuses exactly as a mismatched one does (`IS DISTINCT FROM`). `COMMENT ON DATABASE` is the only guard on the developer CLI.

### Counts, ordinals and dates only in tracked text
**Source:** the TRADESYNC runbook's "Tracked text is counts-only" rule; memory "Public repo with .planning/ tracked".
**Apply to:** PLAN, SUMMARY, runbook, CHANGELOG, test fixtures (no PROD data in any fixture), log lines, `last_error`, job results. Archive amounts never appear in a log, an error string or a tracked file.

### Fail loud, never fail open, on a data-integrity path
**Source:** `_okx_bills_fetch_with_backoff` docstring ("a persistent 429 yields NO data, never a silently truncated one"); `combine_realized_and_funding` D-02 comment.
**Apply to:** every parse, classification, quarter-range, ccy, reconciliation and containment check. Permanent failure with a class name, never data.

### Claim-token fenced deferral
**Source:** `_check_circuit_breaker` `_defer()` + `_defer_lost_ownership` in `services/job_worker.py`.
**Apply to:** every wait in the new handler.

### Catalogue-only migration verification
**Source:** `20260911120000` / `20261010140000` / `20261020120000` verify blocks; `[164.8-DATA-DEPENDENT-MIGRATION-ESCAPE]`.
**Apply to:** the new migration. Never count rows (TEST is empty), never name `vault.*` / `net.*`.

### Test oracles are independent literals; a gate must be able to fail
**Source:** `FactsheetView.unrecovered-gap.test.tsx` header; `test_okx_bills_backoff.py` docstring (Rule 9); the `RED-UNDER-M` twins.
**Apply to:** every test and every SQL arm. Neuter, see RED, restore from a byte backup.

### Required props over optional props for honesty claims
**Source:** `SyncBadgeProps.seriesEnd`, and the payload's required `unrecoveredGaps` with `?? []` at the builder.
**Apply to:** `reconstructedRanges` on the payload type, defaulted at the builders, tolerated as `undefined` in the component for a pre-field cached payload.
