## TEST (pre-merge, read-only)

Pending: not read by the executor. The `supabase-test` read-only SQL tool was not available in the
executor's tool set, and the linked CLI points at PROD, so no TEST statement was run. The orchestrator
runs the statement below through the TEST project's read-only SQL tool and records the counts here, in
words for the marker (text not quoted). Its first expression is the marker and must name TEST. Merge
blocker if any of the three booleans below is non-zero (a TEST apply refusal blocks the PROD apply, and the
remedy is to revert the merge): `non_postgres_owner_rels`, `trig_maint_acl_non_postgres_grantor`,
`trig_maint_acl_public_entries`. The `default_acl_rows_public_by_grantor` result should show grantor
`postgres` only (RESEARCH assumption A1: no platform-admin row on TEST `public`).

```sql
SELECT json_build_object(
 'which_database', (SELECT shobj_description(oid, 'pg_database') FROM pg_database WHERE datname = current_database()),
 'server_version_num', current_setting('server_version_num'),
 'public_relations_rpvmf', (SELECT count(*) FROM pg_class c WHERE c.relnamespace='public'::regnamespace AND c.relkind IN ('r','p','v','m','f')),
 'trigger_holders', (SELECT json_build_object(
    'anon', count(*) FILTER (WHERE has_table_privilege('anon', c.oid, 'TRIGGER')),
    'authenticated', count(*) FILTER (WHERE has_table_privilege('authenticated', c.oid, 'TRIGGER')),
    'service_role', count(*) FILTER (WHERE has_table_privilege('service_role', c.oid, 'TRIGGER')))
    FROM pg_class c WHERE c.relnamespace='public'::regnamespace AND c.relkind IN ('r','p','v','m','f')),
 'maintain_holders', (SELECT CASE WHEN current_setting('server_version_num')::int >= 170000 THEN json_build_object(
    'anon', count(*) FILTER (WHERE has_table_privilege('anon', c.oid, 'MAINTAIN')),
    'authenticated', count(*) FILTER (WHERE has_table_privilege('authenticated', c.oid, 'MAINTAIN')),
    'service_role', count(*) FILTER (WHERE has_table_privilege('service_role', c.oid, 'MAINTAIN')))
    ELSE json_build_object('note','server older than 17, MAINTAIN does not exist') END
    FROM pg_class c WHERE c.relnamespace='public'::regnamespace AND c.relkind IN ('r','p','v','m','f')),
 'non_postgres_owner_rels', (SELECT count(*) FROM pg_class c WHERE c.relnamespace='public'::regnamespace AND c.relkind IN ('r','p','v','m','f') AND c.relowner <> 'postgres'::regrole),
 'trig_maint_acl_non_postgres_grantor', (SELECT count(*) FROM pg_class c CROSS JOIN LATERAL aclexplode(c.relacl) a WHERE c.relnamespace='public'::regnamespace AND c.relkind IN ('r','p','v','m','f') AND a.privilege_type IN ('TRIGGER','MAINTAIN') AND a.grantor <> 'postgres'::regrole),
 'trig_maint_acl_public_entries', (SELECT count(*) FROM pg_class c CROSS JOIN LATERAL aclexplode(c.relacl) a WHERE c.relnamespace='public'::regnamespace AND c.relkind IN ('r','p','v','m','f') AND a.privilege_type IN ('TRIGGER','MAINTAIN') AND a.grantee = 0),
 'default_acl_rows_public_by_grantor', (SELECT json_agg(row_to_json(t)) FROM (
    SELECT d.defaclrole::regrole::text AS grantor_role, d.defaclobjtype AS objtype, count(*) AS rows
    FROM pg_default_acl d WHERE d.defaclnamespace='public'::regnamespace GROUP BY 1,2 ORDER BY 1,2) t)
) AS reading;
```

## Accepted residual

Founder 2026-10-08 (D-09): the following stay, are recorded, and are not touched by this phase.

- **TRIGGER and MAINTAIN on `storage.*` and `net.*`.** The platform grants both verbs on some relations in
  those schemas to the client roles, and `postgres` cannot revoke them. RESEARCH measured, on PROD:
  `net` 2 relations, `storage` 3 of 8 relations. This phase's guarantee is schema `public` only.
- **The platform admin role's default-ACL row on `public`.** It grants `t` (TRIGGER) and `m` (MAINTAIN) to
  both client roles (BEFORE reading above), `postgres` is not a member of that role and cannot alter the row,
  and a statement naming it would abort the apply. No relation in `public` is owned by that role today, so
  the row governs no existing relation. It will still show both verbs for anon and authenticated in the AFTER
  reading, by design; a verifier must not read it as a failure of this phase. Watched by
  `TRUNCREVOKE-ADMIN-DETECTOR-01` in TODOS, whose condition (b) now names TRUNCATE, TRIGGER or MAINTAIN. The
  detector is not built here.
- **The client lock-hold is NOT closed (D-08).** Revoking TRIGGER and MAINTAIN closes the CREATE TRIGGER
  vector and VACUUM, CLUSTER, REINDEX and REFRESH MATERIALIZED VIEW as a client. It does not close the
  table-wide ACCESS EXCLUSIVE lock a holder of UPDATE, DELETE or TRUNCATE can still take on PG17. Booked as
  `TRIGGERREVOKE-LOCKHOLD-01` in TODOS.
