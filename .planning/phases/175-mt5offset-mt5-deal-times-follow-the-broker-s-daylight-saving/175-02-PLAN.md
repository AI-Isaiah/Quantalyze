<objective>
Measure the broker's server clock now, set the worker's fixed offset to match on every worker
service, re-check after the US daylight-saving end, decide the broker's rule from the two dated
readings, and write the measurement into the NAVMTM chain-move pre-flight.

Purpose: D-02 ("The founder reads the broker's server clock in the MT5 terminal today;
`MT5_SERVER_UTC_OFFSET_S` is set to match on the worker, re-checked after 2026-11-01 (US DST end),
and the measurement step is added to the NAVMTM chain-move runbook preflight (SC-3). Two readings on
trading days, one before and one after 2026-11-01, separate the US rule from a fixed +3 (a +2 reading
today already means the EU rule)"), SC-1 and SC-3. This plan does not depend on the code plans; it
runs now because the marks are already being written nightly. Exposure if it waits: under the EU
rule every nightly read since 2026-10-25 01:00Z has used a clock an hour fast; under the US rule
that starts 2026-11-01 06:00Z (NAVMTM REVIEW-3 WR-02).

Output: two dated readings and the SC-1 configuration in this plan's SUMMARY; the interim value live
on both worker services; two additive runbook edits.
</objective>
