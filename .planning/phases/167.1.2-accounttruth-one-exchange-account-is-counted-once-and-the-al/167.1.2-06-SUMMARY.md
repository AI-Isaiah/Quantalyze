## Decisions Made

- **Where the guard goes.** It sits right after `totalWeight`, before `normWeight`, and it is spelled `!(totalWeight > 0)`, so NaN takes the honest path without extra code.
- **The trusted noun.** "connected keys with no return history yet" is a module-local constant in `live-holdings-summary.ts`. Only this clause renders it, so it did not become a new shared `closed-sets` noun.
- **Branch order in the narrowing arm.** The order is manager-side first, then untrusted, then absent status, then trusted. So a manager-side untrusted key lands in `excludedManagerSide`, which is what "not the allocator's book" means.
