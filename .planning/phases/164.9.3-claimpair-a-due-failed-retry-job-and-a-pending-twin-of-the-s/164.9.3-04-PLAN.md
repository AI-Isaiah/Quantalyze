**Runner exit codes (CLI contract in `scripts/mutation-runner/run.mjs`).** `--file` is a NARROWED
DIAGNOSTIC: exit 2 = no defects (the pass signal here), 1 = a defect / MEASURE_FAIL / floor
problem, 3 = usage or environment error. It never exits 0.

**Host lane lock (LOCK)** as in plan 01: every runner invocation (it boots pg-lanes), in actions
AND inside each `<automated>` command, runs under `$LANE_LOCK` (scratchpad `lane.lock`; the executor
prefixes the command with `LANE_LOCK=<scratchpad>/lane.lock` at run time, never pastes the path).
Prologue: `: "${LANE_LOCK:?...}"`, then `mkdir "$LANE_LOCK" 2>/dev/null || { echo LANE-BUSY; exit 1; }`,
then (only after the acquire) `trap 'rmdir "$LANE_LOCK" 2>/dev/null' EXIT`. On `LANE-BUSY` wait in
a background shell and re-run; release an action's own lock before the verify; 600000 ms timeout.

**EXT** as in plan 02: `ext(){ awk -v pat="$2" -v n="$3" 'substr($0,1,length(pat))==pat{c++; if(c==n){f=1;next}} f{print} f&&/^\$\$;/{exit}' "$1"; }`.
