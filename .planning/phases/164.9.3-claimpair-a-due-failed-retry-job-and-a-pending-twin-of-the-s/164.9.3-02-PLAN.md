**Host lane lock (LOCK), LS-RUN.** As defined in plan 01's `<context>`: every lane boot and
teardown, in actions AND inside every lane-booting `<automated>` command, runs under `$LANE_LOCK`
(the scratchpad `lane.lock`; the executor prefixes each command with `LANE_LOCK=<scratchpad>/lane.lock`
at run time and never pastes the path). The LOCK prologue is `: "${LANE_LOCK:?...}"`, then
`mkdir "$LANE_LOCK" 2>/dev/null || { echo LANE-BUSY; exit 1; }`, then (only after the acquire)
`trap 'rmdir "$LANE_LOCK" 2>/dev/null' EXIT`. On `LANE-BUSY` wait in a background shell and
re-run; an action releases its own lock before the verify; run lane-booting commands with a
600000 ms Bash timeout. LS-RUN reads the DSN from the gitignored handoff file and always ends with
`run.sh down`.

**MIG.** Every command below resolves the migration by its slug:
`MIG=$(ls supabase/migrations/*_claim_pair_pre_rank_exclusion.sql)`.

**MARKERS.** The clause block is one contiguous run of lines that starts with the comment line
`-- CLAIMPAIR PRE-RANK EXCLUSION BEGIN (D-08)` and ends with `-- CLAIMPAIR PRE-RANK EXCLUSION END`
(same indentation as the surrounding predicates); the 2-arg's ported C39 block is bracketed by
`-- CLAIMPAIR C39 PORT BEGIN (from claim_compute_jobs)` and `-- CLAIMPAIR C39 PORT END`. The
markers are ordinary comments: they survive in the stored body, and the verify block's
comment-strip removes them before any anchor regex runs. `BLK` prints the first marked block of a
file inclusive: `blk(){ awk -v b="$2" -v e="$3" 'index($0,b){f=1} f{print} f&&index($0,e){exit}' "$1"; }`.

**EXT (body extractor for the D-04 diff).** `ext(){ awk -v pat="$2" -v n="$3" 'substr($0,1,length(pat))==pat{c++; if(c==n){f=1;next}} f{print} f&&/^\$\$;/{exit}' "$1"; }`

header comment naming the function never matches) through the closing `$$;`. Patterns:
`CREATE OR REPLACE FUNCTION claim_compute_jobs(` (source `20260603120000` and the new file, n=1);
