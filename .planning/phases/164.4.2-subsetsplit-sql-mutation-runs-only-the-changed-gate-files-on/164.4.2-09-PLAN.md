**The CHANGELOG mechanism, which is a CHECKLIST and not background reading:**
1. `git log <base>..HEAD --oneline` — enumerate EVERY commit on the branch and COUNT them.
2. `git diff <base>...HEAD` — read the full diff; what a commit says and what it changed diverge.

   per-commit entries already written on this branch.
