## Deviations from Plan

1. **[Rule 3 - Blocking] The `<automated>` verify commands could not run verbatim.**
   - The worktree-isolation harness refuses any compound command that names a `.git` path or runs `bash`/`psql` inside a compound construct.
   - That rules out the plan's `bash -c '… git -C . rev-parse --git-common-dir … trap … EXIT'` form.
   - I ran each step separately instead: plain `mkdir`/`rmdir` of the same lock directory, the boot, the identical `grep -qF` assertions, and the identical probe SQL via `psql -f` against the lane's loopback DSN.
   - The lock was released by hand after `down`, not by an EXIT trap. The assertions are unchanged.
2. **[Rule 2] `CARRIED_SET_FILE` handover added.** This implements the key_link "never recomputed" for the carried ledger rows. The lane computes the sha prefix with node's crypto over the loaded dump.
3. **[Rule 2] Pure function returns no set on any defect.** This is an extra self-test arm, R11.
4. **The default mode's unknown-argument message now mentions `--replay-set`.** This is error-path text only; default-mode decisions, output on valid runs and `DEFECTS` are unchanged, and the restore tests pass 43/43. The self-test's final PASSED line now counts both groups of sections.
5. **Comment added to the fetch-depth pin in the lane-wiring test.** The replay-mode gate reads files on disk, so the shallow-clone rationale no longer applies to it. The pin is kept.

**Total deviations:** 5 (1 blocking, 2 missing-critical, 2 text-only). No scope creep.
