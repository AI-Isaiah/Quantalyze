<interfaces>
- `_historical_var_cvar(returns)`:
  - sorts the non-NaN returns and sets `k = floor(0.05 n)`;
  - VaR is `ordered[min(k, n - 1)]`;
  - CVaR is `mean(ordered[: max(1, k)])`;
  - returns `(None, None)` at n == 0.

  The only stored call is in `compute_all_metrics`, on `returns`, the total record.
- The smart_* lines are `(float(_smart_r.mean()) / _smart_sharpe_divisor) * math.sqrt(252)` and its `_smart_sortino_downside` twin. `compute_all_metrics` has a `periods_per_year` parameter.
- CAGR: `_cagr_index = _last_interior_break_suffix(returns).index`. CAGR is NaN when `total_return is None or len(_cagr_index) < 2`.
- `test_metrics_parity.py` `assertMetricParity` fails on any extra key not in `golden_252d_expected.json`. So `cagr_start` / `cagr_end` must enter the golden in the same commit, and `src/__tests__/metrics-parity.test.ts` reads the same golden.
- The figure-gate.test.ts pin reads `^MIN_ANNUALIZATION_OBS = (\d+)` and `^FIGURE_DEFS_VERSION = (\d+)` from metrics.py. Leave both lines as they are.
- allocated_capital.py: `_ANNUALISATION_DAYS: float = 365.0`, `returns.std(ddof=1)`, and `np.sqrt(_ANNUALISATION_DAYS)` in the two ratios.
