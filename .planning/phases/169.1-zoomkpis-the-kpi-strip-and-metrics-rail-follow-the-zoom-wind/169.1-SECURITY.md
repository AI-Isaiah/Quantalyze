## Unregistered Flags

These are WARNINGs, not blockers. No plan threat maps to them.

1. **A composite probe reads the conventions echo for every row.**
   - `readCompositeFactsheet` reads it for every composite, the probe included (`composite-read-path.ts:411-421`).
   - So a /strategies load gains one `strategy_analytics_series` read for each composite row.
   - The code comment calls this deliberate (D-83 (a) scope). T-169-53's "a probe issues no conventions query" covers the single-key arm only.
   - The read is path-only, uses the caller's handle and stays behind the gate, so there is no disclosure. The concern is load only.
2. **A persistent conventions failure makes one strategy's public factsheet permanently uncached.**
   - Example: a stored malformed echo, which persists until the next compute.
   - Each public request then rebuilds the payload and sends one Sentry event (R-01, R-02). This repo's capture path does not de-duplicate or rate-limit them. The auditor did not measure whether the Sentry SDK does.
   - An anonymous visitor cannot cause the state. While it holds, though, repeated requests multiply DB reads and Sentry volume.
   - The existing `read_error` path has the same shape (`page.tsx:161`), so this is a known class. Low severity.
