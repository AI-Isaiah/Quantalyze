<objective>
Make /admin Compute Jobs load (SC1). The list request fails with HTTP 500 on every call because the
database function it calls raises "column reference id is ambiguous", and behind that it would return
nothing because the service-role client has no `auth.uid()` (RESEARCH root cause A). The route instead
reads the admin VIEW directly, after its existing admin gate, the way its sibling page already reads
`compute_jobs`. The table stops saying "No compute jobs found." while it is showing a load error.

Purpose: an admin sees the job queue, and a failed load reads as a failure, not as an empty queue.
Output: a rewritten route read with a rewritten test, and a one-predicate client fix with a test.
</objective>
