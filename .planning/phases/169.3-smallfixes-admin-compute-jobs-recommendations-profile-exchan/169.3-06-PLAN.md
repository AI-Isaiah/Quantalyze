1. **Autofill.** The `/profile` Exchanges "Connect exchange" dialog (`ApiKeyForm.tsx`, rendered by `AllocatorExchangeManager.tsx`) still accepted a saved site login into its API Key and API Secret inputs, with `autoComplete="off"` already on both (since `6b09f96f0`). The wizard's `ConnectKeyStep` and `MultiKeyConnectStep` use the same attribute and have the same defect.
2. **Pasted whitespace.** A Client ID or Client Secret pasted from a spreadsheet cell keeps its leading/trailing whitespace in the field on all three surfaces. The server trims (`trimCredential`), so the stored value is correct. But the field shows something other than what is sent.

The approach is fixed in **D-76** (`169.3-CONTEXT.md`, written with this plan): one client-safe helper module, `new-password` on masked credential inputs, vendor ignore attributes on every credential input, and normalization of bulk-arriving text only.

Purpose: a key field never holds a site login, and the field shows exactly the credential that is sent.
Output: `src/lib/credential-input.ts`, three wired surfaces, four new test files, neuter evidence in the SUMMARY.
