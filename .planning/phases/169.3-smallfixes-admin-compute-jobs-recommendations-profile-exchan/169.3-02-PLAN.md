<objective>
Make /recommendations internally honest (SC8) and stop recommending a user their own strategy (D-05).
Today the page sets `mandateSet` from one field, renders "set your mandate" when it is false, and
still renders the candidate list and the hard-coded "fit your mandate" header regardless, because
the engine scores allocators with no mandate on defaults (RESEARCH root cause F). It also shows no
track-record age, so a record that ended long ago reads as current.

Purpose: an allocator reads one consistent statement about whether the list reflects their mandate,
sees how current each record is, and never sees their own strategy recommended back to them.
Output: the page's single branch and age badge with an RSC test, and the engine exclusion with a pytest.
The mandate PREDICATE itself is unified in plan 169.3-04 (wave 2 of this phase, D-03; pre-split: wave 4, PR 2); this plan keeps the page's current
predicate and makes the page self-consistent around it.
</objective>
