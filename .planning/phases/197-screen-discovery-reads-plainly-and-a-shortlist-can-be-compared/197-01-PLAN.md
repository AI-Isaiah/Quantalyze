- The column map lives in a NEW module `src/components/strategy/discovery-columns.ts`, not beside `COLUMNS` as the UI-SPEC suggests: `StrategyTable.tsx` imports `StrategyGrid.tsx`, so the grid importing the map from the table would be an import cycle.
- Each sortable header button gets `aria-label` set to the map's accessible name (the UI-SPEC "Accessible name" column verbatim). Accessible-name computation over inline sr-only fragments differs between jsdom and browsers (block versus inline spacing), so the label is set explicitly; the visible label text is contained in it (WCAG 2.5.3). The two plain sparkline headers get `aria-label` "Return curve, full record" and "Underwater, full record".
- Track sits at map index 1 (U-02). On the manager mount the Status and Created columns are emitted inside the header map after index 0, so they stay directly after Strategy (170.7 D-01) and Track follows them; the Track body cell is emitted after the manager Status/Created cells so header and cell line up.
- Track months use `ONE_YEAR_DAYS` (365) from `figure-gate.ts`, not the UI-SPEC's 365.25: with 365.25 a record of exactly 365 covered days prints 11 beside figures that carry no `<1y` marker. A record of 30 or more covered days shows at least 1 (the UI-SPEC state table and the edge-probe resolution both say 30 days is a month).
- The default-mounts byte-pin fixture rows stay WITHOUT `series_end`/`series_start`, so every pinned Track cell is the em dash; recorded so plan 03 builds on the same rows.
