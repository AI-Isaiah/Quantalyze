## LOW-04 (new): the predecessor verdict keys on `frontend` only, so a red on an advisory job is masked by a docs-only successor

**Location:** `scripts/classify-changed-paths.mjs:361` (`predecessorVerdict`), together with
`PREDECESSOR_CHECK_NAME`. The relevant job is `ci.yml` `lighthouse-mobile` (`:6648`), whose step
`Run Lighthouse mobile budget …` carries no `continue-on-error`. `e2e` is the other example (its
setup steps, before the `continue-on-error` smoke step).

**Failure scenario:**

1. Code push A. Every aggregator row is green, so `frontend` concludes `success`. `lighthouse-mobile`
   reds on a budget miss, so A's CI workflow run concludes failure and Railway skips A's deploy.
2. Docs-only push B lands on A. A's `frontend` is `success`, so B takes the short path.
   `lighthouse-mobile` and `e2e` are skipped, B's suite is green, and Railway deploys A's tree.

Before WR-01, B re-ran `lighthouse-mobile`, which went red again deterministically, and Railway
skipped B as well.

**Why only LOW:** the jobs it masks are advisory by founder decision. Neither tests
`analytics-service`, which is what Railway deploys, and `python` is covered through
`test-db-drift`. The visible effect is that `main` HEAD reads green while a perf-budget red sits
one commit back, unmentioned in B's run.

**Fix (pick one, and record which):**

- (a) Accept the gap and say so. Have the `docs_only=true` reason line name the predecessor's
  suite conclusion when it differs from `frontend`.
- (b) Key the verdict on the CI workflow run's conclusion for `before`, which matches Railway's
  semantics. That is `actions/runs?head_sha=<before>&event=push`, which needs `actions: read`.
  Alternatively, require every check run on `before` to be `success`, `skipped` or `neutral`,
  plus `frontend` present.

## LOW-05 (new): the classifier self-test's in-process rows default to the PRODUCTION `gh` reader

**Location:**

- `scripts/classify-changed-paths.mjs:260`: the `fetchCheckRuns = readCheckRuns` default.
- The in-process rows that pass no seam: `:683`, `:690`, `:730` (the undeterminable loop) and `:735`.

**Failure scenario:** the "OFFLINE BY CONSTRUCTION" property holds only for the `runMainOnPush`
rows, which put a fake `gh` on PATH. The in-process rows stay offline only because each of them
returns before the lookup. Two cases break that:

- A future regression, or a contract-test neuter leg such as removing the ancestor guard, lets one
  of those rows reach the lookup.
- That row then runs the real `gh api` against a scratch SHA.

In `frontend-test`, `GITHUB_REPOSITORY` names the real repo, so the self-test makes a live network
call. It usually fails fast with no auth and reads as code, so the row's FAIL still fires. But it
is a hidden network dependency in a test that claims to have none. A hung call would also block
for up to `readCheckRuns`' 60 s timeout per row.

**Fix:** have `selfTest()` bind a default seam for in-process calls that throws
`"self-test row reached the predecessor lookup without a seam"`. For example, wrap the rows'
calls, or pass an explicit `NEVER` fetch that fails the row. Then reaching the lookup is a named
red and never a network call.

## LOW-06 (new): the contract test's 60 s arm timeout cannot preempt a hung self-test

**Location:** `src/__tests__/contracts/ci-docs-path-filter.contract.test.ts:989` (the describe-level
`{ timeout: 60_000 }`), with `spawnSync` at `:1005` and `:1144`, which pass no `timeout`.

**Failure scenario:** the 60 s budget is sound. It is about 20x the measured 3.2 s, and an overrun
is reported as a timeout red, so it does not mask a failure. But `spawnSync` is synchronous, so
vitest's timer cannot fire while the child runs. A self-test that hangs blocks the worker until
the CI job timeout, and it reads as a generic job timeout instead of "the classifier self-test
hung". LOW-05's live `gh` call in a neuter leg is the plausible way to get such a hang.

**Fix:** pass `timeout: 50_000` (and `killSignal: "SIGKILL"`) to both `spawnSync` calls. Assert on
`res.error` or `res.signal` with a message that names the hang. That turns it into a named,
bounded red.
