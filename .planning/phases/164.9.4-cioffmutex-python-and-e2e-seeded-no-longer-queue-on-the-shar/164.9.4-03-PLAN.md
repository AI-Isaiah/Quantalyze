<objective>
Expose the lane's existing loopback guards through one diagnostic seam,
`run.sh --assert-local-handoff`, so each CI job that consumes the lane handoff can assert D-04 before
it exports anything. The seam reuses `assert_local` for `API_URL` and the WR-08 probe for `DB_URL`.

Purpose: D-04 requires every URL or DSN the two jobs pass to their tests to be loopback, asserted
before the first DB-touching step, with no second guard invented. `assert_local` is internal to
`run.sh`, and the probe accepts only postgres URLs, so a seam is the one way to reuse both.

Output: `run.sh` gains a function and a dispatcher arm. The lane-wiring test gains an executed pin.
One commit.
