## Recipe

Every number below was read with these commands, READ-ONLY, against repo `AI-Isaiah/Quantalyze`.
No `gh workflow run`, no push, no database command.

**Per-step timings of one job** (`started_at` / `completed_at` of the job and of each step):
```bash
gh api repos/AI-Isaiah/Quantalyze/actions/jobs/<job_id>
```

**The pytest and Playwright summary lines of one job** (copied verbatim, timestamp prefix stripped):
```bash
gh run view --job <job_id> --log
```

**Bind a run to its SHA and COUNT that SHA's workflow runs** (CLAUDE.md, CI traps; an empty count
is a finding, never a pass):
```bash
gh api "repos/AI-Isaiah/Quantalyze/actions/runs?head_sha=<sha>" -q '.workflow_runs | length'
```

**Run-level facts** (event, head, attempt, conclusion, wall clock):
```bash
gh api repos/AI-Isaiah/Quantalyze/actions/runs/<run_id> -q '{event,head_sha,run_attempt,conclusion,run_started_at,updated_at}'
```

**Is a `main` run's tree the same as the AFTER's** (the like-with-like test of `## Which runs count`):
```bash
git diff --quiet <main_sha> <after_sha> -- analytics-service && echo analytics-service-identical
git diff --quiet <main_sha> <after_sha> -- e2e && echo e2e-identical
```

Durations are computed by a Node script (`new Date(b) - new Date(a)`, rounded to the nearest
second) over the job JSON, never by hand. The script lives in the session scratchpad and is not
committed; only its output is pasted.
