## Gap closure (2026-10-03)

**The gap, as recorded at `289cc4c40` (kept as lineage):** SC-3's e2e-seeded half read `200 passed`, `1 flaky` (`e2e/full-flow.spec.ts:84:7`), `11 skipped` in run `37039941530` against the comparand's `201 passed`. The full frontmatter entry is preserved below.

**Root cause** (debug session `.planning/debug/resolved/e2e-seeded-lane-flake.md`): three conditions, all required.
1. Data: on the lane, the crypto-sma category holds only `is_example` rows. The baseline is schema-only and the seeder writes only example rows. On shared TEST, leftover non-example rows from other specs hid the dependency.
2. Product: `StrategyTable` server-renders every row (`showExamples` starts true), then hides the example rows on mount for anonymous visitors (`hide_examples` defaults to true).
3. Test: `full-flow.spec.ts` sampled for a row once, before hydration, and wrapped its assertions in a silent `if (hasStrategies)` branch. A fast host passed vacuously, a medium host hung 60 s (the CI flake), a slow host won the race. Reproduced locally under CPU throttling: 1x vacuous 6/6, 4x hang 6/6, 8x/16x race through 6/6.

**Fix (founder decision 2026-10-02, option D):** commit `8e1e9c041` changes `e2e/full-flow.spec.ts` only. The test waits for the hydrated "Hide examples" state, unticks it, requires a visible `table tbody tr a[href^="/factsheet/"]` row, and asserts the factsheet h1 names the strategy it opened. Both silent branches are gone. No timeout raise, no added retries, no seed or product change.

**Local evidence (lane, real spec, CI=1, `--retries 0`, `--workers 1`):** 10/10 at 1x, 4x, 8x and 16x, and 30/30 at 4x (the band that hung 6/6 before the fix), every repetition reaching the last assertion. Negative probe (box left ticked) fails with "no published strategy row on /browse/crypto-sma with Hide examples off". Teardown asserted, 0 containers.

**Booked, not fixed here:** the flash of example rows for anonymous visitors on `/browse` (option A, user-facing) goes to the follow-up phase list.

**What remains:** the CI reading on the ship run (the single `human_verification` item above). Per the founder's 2026-10-03 decision, the PR ships with this item open and merges only on that reading. Override recorded in `164.9.4-CONTEXT.md` and the ROADMAP.
