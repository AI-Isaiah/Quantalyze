### SFH-04 (HIGH): a docs-only push turned `main` green over a red code commit

**Files modified:** `scripts/classify-changed-paths.mjs`, `.github/workflows/ci.yml`,
`src/__tests__/contracts/ci-docs-path-filter.contract.test.ts`
**Commit:** `9292a70ab`
**Applied fix:**
- **The rule.** `classifyPushRange` keeps `docs_only=true` only when every `frontend` check run
  on `before` completed with `success`. It reads them with `gh api
  repos/$GITHUB_REPOSITORY/commits/<before>/check-runs?check_name=frontend`. The call passes
  argv elements, with a 60 s timeout.
- **What forces the full corpus.** Red, cancelled, pending, absent, a malformed body, any lookup
  error, or a missing `GITHUB_REPOSITORY` each print the reason and run the full corpus.
- **When the API is called.** The lookup runs last. Code pushes and undeterminable ranges never
  call it, and `main()` still exits 0 on every path.
- **The workflow.** The `changed-paths` job has its own `permissions:` block with
  `contents: read` and `checks: read`. A job-level block replaces the workflow one, so
  `contents: read` is restated. `GH_TOKEN: ${{ github.token }}` is set on the `classify` step
  only. The job comment that said `contents: read` is sufficient got a dated correction.
- **Why `frontend` alone is enough.** On a push, `test-db-drift` needs `python`. A failed
  `python` skips `test-db-drift`, and the aggregator's `test-db-drift` arm reds a skip on a
  trusted event. A red `python` therefore reaches `frontend`.
- **Self-test row 17**, offline:
  - an injected seam covers red, cancelled, pending, missing, a failed re-run beside a green
    run, an API error and a malformed body;
  - a spy proves that a zero before-SHA and a code range never call the lookup;
  - `main()` runs end to end against a fake `gh` on `PATH`. The fake records its argv, which
    pins the exact endpoint. It also covers a failing `gh` and an absent `GITHUB_REPOSITORY`.
- **Contract test.** A neuter leg for the gate, and a pin on the job's two permissions and on
  `GH_TOKEN` being scoped to `classify`.

  the smuggled shape matches the old glob.
- **Wiring test.** The executed refusal matrix gains the userinfo row. That row was observed RED
  against the old glob before the fix.
