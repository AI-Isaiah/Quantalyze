services/mt5_parity_report.py
- `MAX_REPORT_BYTES: Final[int] = 32 * 1024 * 1024`
- `REPORT_KNOWN_HEADERS: Final[frozenset[str]]` = {Time, Deal, Symbol, Type, Direction, Volume, Price, Order, Commission, Fee, Swap, Profit, Balance, Comment}
- `REPORT_REQUIRED_HEADERS: Final[frozenset[str]]` = {Time, Deal, Type, Commission, Swap, Profit, Balance}
- `REPORT_TYPE_CODES: Final[Mapping[str, int]]` (case-folded text to code):
  - buy 0, sell 1, balance 2, credit 3, charge 4, correction 5, bonus 6
  - commission 7, daily commission 8, monthly commission 9, agent daily commission 10, agent monthly commission 11
  - interest 12, buy canceled 13, sell canceled 14, dividend 15, dividend franked 16, tax 17
- `REPORT_DIRECTION_CODES: Final[Mapping[str, int]]` = {in: 0, out: 1, in/out: 2, out by: 3}
- `BALANCE_CONTINUITY_ABS_TOL: Final[float] = 0.005`: half a cent, the rounding of 2-decimal money. It is a parse-integrity check, not a parity tolerance.
- Errors, all subclasses of `ReportRefused(ValueError)`: `ReportEncodingRefused`, `ReportTooLarge`, `UnknownHeader`, `MissingHeader`, `DuplicateHeader`, `RowShapeRefused`, `UnknownDealType`, `UnknownDirection`, `TradingRowIncomplete`, `MoneyCellRefused`, `TimeCellRefused`, `BalanceContinuityRefused`, `EmptyDeals`. Messages name a header, a column, a type text or a row ordinal, never a money value.
- `ParsedReport` is a frozen dataclass(slots=True) with `deals: tuple[Mapping[str, Any], ...]`, `encoding: str`, `headers: tuple[str, ...]`, `fee_column_present: bool`.
- Each deal is `{"deal": int, "time": int, "type": int, "entry": int | None, "profit": float, "swap": float, "commission": float, "fee": float, "balance": float, "position_id": None, "time_msc": None}`.
- `parse_report(data: bytes) -> ParsedReport`
- `oracle_deals_bytes(parsed: ParsedReport) -> bytes`: canonical JSON `{"oracle_version": 1, "deals": [...]}` through `services.mt5_parity_capture.seal_bytes`. This is the byte form the plan 07 RED proofs mutate.
- `load_oracle_deals(data: bytes) -> tuple[Mapping[str, Any], ...]`: the inverse; it validates every field.

services/mt5_parity_intake.py (added here; `load_worksheet` from plan 01 is unchanged)
- `class WorksheetIncomplete(ValueError)`: the message lists every missing reading id per account label.
- `class UnknownReading(ValueError)`, `class ReportBindingRefused(ValueError)`.
- `RequiredReading` is a frozen dataclass(slots=True) with `id: str`, `kind: Literal["money", "text", "instant", "sha256"]`, `provenance: frozenset[str]`, `as_of: Literal["required", "forbidden"]`, `min_count: int`, `founder_prompt: str`.
- `load_required_readings(path: Path) -> tuple[RequiredReading, ...]`. It refuses a provenance outside PROVENANCE_VALUES and a duplicate id.
- `require_complete(worksheet: Worksheet, required: tuple[RequiredReading, ...]) -> None`
- `bind_report(worksheet: Worksheet, label: str, report_bytes: bytes) -> None`: the sha256 of the bytes must equal that account's `all_history_report_sha256` reading.
