## Decisions Made

1. **The replacement asserts no cause.** The `console.warn` hint lists three candidate causes (admin-client visibility, `daily_returns` shape, series clipped to the benchmark window with <2 points). The old sentence picked one and stated it as likely fact. Naming a different one, or the same one in softer words, would have been "replacing one internal detail with a different internal detail" — the fence the brief set. So the copy states only what the arm actually knows: the factsheet has not been computed.
2. **No reassurance.** Candidate wordings beginning "Nothing has gone wrong" were rejected: this branch renders for `computation_status = 'failed'` (that is STALE-01's entire point, and V2's own fixture drives a `failed` row), so a reassurance would be false exactly where it matters.
3. **No "there is nothing for you to do".** False on the owner lane, where an owner may genuinely need to act. Since the plan forbids lane-gating, the sentence must be true for both readers.
4. **DESIGN.md tension, resolved and recorded.** DESIGN.md §Voice says "state limitations with the threshold attached … *Appears once the strategy has ~35 observations*". Attaching a threshold here requires knowing the cause. The threshold rule and the anti-misattribution fence collide, and the fence wins: a fabricated threshold is exactly the "confident, wrong" copy this phase exists to remove. The rest of the Voice rules are honored — declarative, sentence case, no adjectives standing in for numbers, no cheerful empty-state framing, no icon.
5. **Nothing was pinning the old sentence.** Before editing, `grep -rn "dev-server console" src/ e2e/ tests/ scripts/` returned exactly ONE hit — `page.tsx:420`, the render itself. `bundled benchmark window` returned zero. So unlike plan 02's `SyncBadge.staler-of-two.test.tsx:269` (a load-bearing pin on the defect, which had to be INVERTED rather than deleted), this change inverted nothing: there was no test defending the wrong sentence. That absence is itself the finding — the sentence reached PROD with no test on it at all, which is why V2b is the deliverable and not an afterthought.
