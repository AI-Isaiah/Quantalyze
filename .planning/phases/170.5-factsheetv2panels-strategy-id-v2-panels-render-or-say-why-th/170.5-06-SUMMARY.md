# Phase 170.5 Plan 06: v2 benchmark greeks wired to the factsheet's joint Summary

`getStrategyDetailV2` now carries the factsheet's own alpha, beta, correlation, IR and Treynor (plan 04's `readV2BenchmarkJoint`) and a status instead of the stored Python greeks, and a composite takes the same five figures from the factsheet builder's payload through the v2 page.

## What was done

**Task 1, commit `4d9a2b09`.** In `getStrategyDetailV2` the trust read and, only when `isComplete`, the joint read run in one `Promise.all`. A rejection becomes `{ values: nulls, status: { kind: "error" } }` after `captureToSentry(err, { tags: { stage: "v2-joint", strategy_id } })`; a non-computed strategy gets `not_computed` with no admin read. The `metrics_json` alpha/beta/information_ratio/ir/treynor_ratio/treynor mapping and its false comment are deleted; `panel7Inputs.benchmark_greeks` is `joint.values` and `benchmark_joint` is `joint.status` (both new fields optional on `StrategyV2Detail`). The `STRATEGY_V2_ANALYTICS_COLUMNS` docblock no longer lists the greek keys (dated note). `queries.test.ts` Tests 4, 4b and 6 are rewritten with dated comments: stored greeks (long names, the producer's `info_ratio`, short names) do not reach the panel; Test 6 expects `correlation: null`, `benchmark_joint` `not_computed`, and no helper call.

**Task 2, commit `2484ed012`.** `composite-joint.ts` (`server-only`): `readCompositeV2Joint(id)` calls `fetchAndBuildPayloadWithReason(id, withPublishedOnly)` and returns `v2JointFromBuildResult(result)` inside one try; any throw is status `error` with `stage: "v2-composite-joint"`. `withV2Joint(detail, joint)` spreads `panel7Inputs` and sets the two fields; everything else keeps its reference. `page.tsx` (default export only): after the `notFound()` check, a `needs_builder` status replaces the detail with `withV2Joint(result, await readCompositeV2Joint(id))` before the shell renders. `generateMetadata` is unchanged and never calls the builder.

**Task 3, commit `e1eb9503a`.** The plan-01 trust-tier test and `StrategyV2Shell.footer.test.tsx` gained the same partial `v2-joint` mock (dated comment) so their Sentry assertions count only the trust-tier path; no assertion changed. `queries.hh-1255.test.ts` got the same mock in the Task 1 commit.
