UI-SPEC names:

- **light path**: `getStrategyDetailV2` calls `readV2BenchmarkJoint` (plan 04) for every computed
  strategy, concurrently with the trust-tier read from plan 01;
- **composite builder path**: the light path cannot read a composite's series (it lives behind a

  `v2JointFromBuildResult`. The builder is imported only through its canonical specifier, which the
  phase-148 cache-isolation gate allows (rule 4b(ii)); the cached wrapper stays page-private to the
  factsheet (rule 4a). The extra cost (one uncached build) is paid only for composites.

still renders four cells from `benchmark_greeks` (now live values); that intermediate state is never
shipped alone (one PR for the phase).
