# Phase 170.2 Plan 07: Discovery table unpinned below @3xl (SC-6, first half) Summary

Below 48rem of table width the Discovery ranking table pins nothing: all nine pinned class strings carry their horizontal offset behind `@3xl:`, so on a phone the whole row scrolls inside its own region and every Return %, CAGR and Sharpe cell can be scrolled into plain view. The seeded case that proves it was RED at all five widths on HEAD and is GREEN now, on the local lane.

## What changed

- **Seed.** `seedStrategyWithHistory` takes opt-in `categorySlug`, `strategyTypes`, `supportedExchanges`. The category is resolved with the same `discovery_categories` lookup `seedBridgeCandidate` uses, before the owner is created, and spread into the insert only when set. Existing callers are byte-identical.
- **Spec.** `"/discovery — SC6-DISCOVERY unpinned"` in `e2e/layout-narrow.spec.ts`, `HAS_SEED_ENV`-gated, local viewport array V360 (360x780), V375 (375x667), V390 (390x844), V768 (768x1024), V1080 (1080x800). Seeds 3 published `crypto-sma` strategies (multi-word names, several types and exchanges) under the per-worker prefix, removes them in a `finally`. Checks collect rather than throw so one RED run names every failing contract: `assertNoReflow`, region scrolls inside and ends in the viewport, hint inside viewport and frame on one line, filter row / Sort group / callout end inside the 16 px padding (phones only), Strategy header and cells move with the row, every Return %, CAGR and Sharpe cell fully inside the region and uncovered (`elementFromPoint`) at some of scrollLeft 0/60/150/300/max.
- **Component.** Nine pinned strings: `left-0`, `left-14`, `left-[6.25rem]` became `@3xl:left-*` (rank, star and Strategy; header, data row, placeholder row; both arms of the Strategy header `stickyLeft` and of the body/placeholder ternaries). The Strategy cells' `border-r border-border` became `@3xl:border-r @3xl:border-border`. `sticky`, `top-0`, `z-*` and the opaque backgrounds stay unconditional; the non-first `stickyLeft` branch is untouched. The hint span gained `whitespace-nowrap`. A dated comment names the cause.
- **Unit tests.** Rank/Strategy header and cell assertions now require `@3xl:left-0`, `@3xl:left-14`, `@3xl:border-r` and fail on any bare `left-*` / `border-r` (dated comment `// 2026-10-09 Phase 170.2 D-05: pinning keys on the table's own width (@3xl)`). A source-reading test asserts every horizontal offset token in `StrategyTable.tsx` is `@3xl:`-gated (covers the placeholder rows the render fixtures never draw), with a floor of 12 tokens against vacuity. The `z-20` assertion is unchanged (plan 08 flips it).
