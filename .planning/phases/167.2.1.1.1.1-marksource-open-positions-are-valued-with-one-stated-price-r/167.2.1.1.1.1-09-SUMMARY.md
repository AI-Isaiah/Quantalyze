# Phase 167.2.1.1.1.1 Plan 09: Price-gap predicate and summary counter Summary

One price-gap rule now exists in TypeScript and Python behind one 16-case hand-typed fixture, and the live-holdings summary counts gap rows (`priceGap`) and builds the two UI-SPEC sentences, with no AUM figure moved.

## What was built

- **Fixture** `analytics-service/tests/fixtures/holding_price_gap_cases.json`: 16 cases, each one boolean `expected_gap` (priced spot; mark 0, -1, NaN, Infinity, -Infinity, null, absent, bool, string are gaps; quantity 0, null, -1, NaN with mark 0 are not; derivative with mark 0 is not; stable USDT at 1.0 is not). Figures are invented round numbers.
- **TS** `holdingIsPriceGap` and `HoldingPriceGapInput` in `src/lib/holding-equity.ts` (module stays import-free; header extended). Runner `src/lib/holding-price-gap.parity.test.ts` maps the fixture's `mark_price` to `mark_price_usd` and asserts 16 cases.
- **Python** `is_price_gap_holding` in `analytics-service/services/holding_equity.py` via `_finite_number`. Runner `tests/test_holding_price_gap.py` (parametrized, one-expectation, edge pins).
- **Summary** `LiveHoldingsSummary.priceGap`, counted after the `pnlMissing` branch and before `out.total`; `addTo` marks a part unavailable when `!holdingEquityIsReported(h) || holdingIsPriceGap(h)`; `priceGapSentence` and `priceGapHoldingsNote` beside `pnlMissingSentence`, same contract.
