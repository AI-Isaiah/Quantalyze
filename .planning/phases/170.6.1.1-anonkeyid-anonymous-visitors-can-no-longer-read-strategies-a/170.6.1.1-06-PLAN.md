## The pg-lane's strategies grants (W3, verified by the planner 2026-10-14)

The pg-lane builds `strategies` from fixtures, and which fixture grants what decides whether the gate
reproduces today's PROD grants:
- `scripts/pg-lane/fixtures/01-fixture-core.sql` creates `strategies` (8 columns) and grants only
  `GRANT SELECT ON strategies, profiles TO authenticated` (anon gets nothing there).
- `scripts/pg-lane/fixtures/03-fixture-compute-jobs.sql` adds the `api_key_id` column.
- `scripts/pg-lane/fixtures/10-fixture-strategies-rls-baseline.sql` runs
  `GRANT ALL ON strategies TO anon, authenticated, service_role` and documents why: production's
  `strategies` was created under Supabase's bootstrap default privileges, which
  `07-fixture-supabase-default-privileges.sql` reproduces but which are not retroactive to a table 01
  already created. Its header says apply it AFTER 01/02/03. It also adds `strategies.source` and empty
  stand-ins for `discovery_categories`, `contact_requests` and `portfolio_strategies`.
- `scripts/pg-lane/fixtures/13-fixture-csv-finalize-fold.sql` also runs `GRANT ALL ON
  public.strategies TO anon, authenticated, service_role`, but brings the csv-fold scaffold
  (`strategy_verifications`, a signup trigger) this gate does not need.
- `scripts/pg-lane/fixtures/06-fixture-portfolio-strategies.sql` adds authenticated INSERT, UPDATE,
  DELETE on strategies only.

So the apply list is `01`, `02`, `03`, `10`, then the migration LAST. Fixture 10 gives anon the table
SELECT/INSERT/UPDATE/DELETE that PROD gives it today, which is what makes SC-1's "RED without the
migration" real, and it gives authenticated and service_role the four table privileges KEEP 1 asserts.
`GRANT ALL` also hands anon TRUNCATE and TRIGGER on the lane, which PROD no longer does (Phases
TRUNCATEREVOKE and TRIGGERREVOKE); this gate asserts only the four privileges this phase moves, so
those two do not affect any arm. The gate asserts over "every non-dropped column other than
api_key_id", never a typed column list, so it reads the same on the pg-lane, the local-stack lane and
any other catalogue.
