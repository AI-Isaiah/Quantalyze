**The mechanism (Claude's discretion under D-02, decided here).** Recharts 3.10.1 (installed)
accepts a React element as `XAxis` `tick`. `CartesianAxis` clones that element with the tick's
props (`x`, `y`, `payload`, `index`, `textAnchor`, `verticalAnchor`, `tickFormatter`, `fill`, …)
and merges the element's own svg props AFTER them, so a style spread on the element keeps
overriding Recharts' `fill: stroke` exactly as the plain `tick={CHART_TICK_STYLE}` object does
today. Recharts also exports `useChartWidth()` (the chart's layout width, which is the
`recharts-surface` svg width) and `Text` (its default tick renderer). The width therefore comes
from Recharts' own layout state, not from a DOM measurement of a label.

**Why not the other levers.** XAxis `padding` would move every point inward and change the plot at
every width; hiding the last tick (`interval`) breaks D-02 ("Labels are not hidden"); a larger
`margin.right` changes desktop geometry (D-04). Anchoring only the edge label changes nothing where
a label already fits.

**Width estimate.** `CHART_TICK_STYLE` draws Geist Mono (`CHART_FONT_MONO`) at 12 px, so the C-3
estimate (`label.length * fontSize * 0.6`) is the real advance, and "the estimated box crosses" is
"the drawn box crosses". Recharts' own `preserveStartEnd` placement may already shift the last tick
inward using its own measurement; `fitTickLabel` works from whatever `x` Recharts hands it, so the
rule holds either way.

**Lint and frozen status of `src/components/charts/`.** `eslint.config.mjs` turns
`quantalyze/no-raw-font-px` and `quantalyze/no-rem-less-clamp` off for `src/components/charts/**`
(the "design-lint-exempt frozen glob" the `ExposureByClass.tsx` comment names). That glob is
lint-exempt, not byte-frozen: the byte freeze is `FROZEN_ISLANDS` in
`src/__tests__/phase-52-frozen-spine-guards.test.ts`, which under this directory holds only
`src/components/charts/TouchTooltip.tsx`. Do NOT edit `TouchTooltip.tsx` or `chart-tokens.ts`
(no token is added). `src/__tests__/display-sign-single-source.test.ts` scans this directory and
pins per-file counts for `RollingVolatilityChart.tsx`; the y-axis and tooltip formatters it counts
are not touched, so its counts must not move.

**Hydration.** The three charts render through `ResponsiveContainer`, whose server render has no
measured size, so no tick markup is emitted on the server; the anchor is still a pure function of
props and Recharts' state, never a DOM read.
