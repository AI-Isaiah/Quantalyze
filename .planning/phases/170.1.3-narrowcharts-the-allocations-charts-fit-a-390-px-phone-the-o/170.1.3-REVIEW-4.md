## Questions checked

1. **Spacing in `fitXTickValues`, both ends.** Let `W = plotRight - plotLeft`.
   - `step = ceil(last*pitch/W)` and `count - 1 = floor(last/step) <= last/step`. So the real gap
     `last/(count-1) >= step`, and because `step` is an integer, every rounded index gap is at least
     `floor(last/(count-1)) >= step`. The drawn spacing is then at least `step*W/last >= pitch`.
     This holds for every `n`, not only the swept range.
   - When `maxTicks >= 2`, `W >= 2*pitch`, so `step <= ceil(last/2) <= last` and `count >= 2`.
     Both ends are kept whenever the plot fits two labels. Only a plot narrower than two pitches
     falls back to the newest label alone, as the doc comment says.
   - The whole-list path keeps spacing `W/(n-1) > W/maxTicks >= pitch`.
   - Degenerate `W <= 0` gives `count < 2` (or a non-finite `count` that fails `count < 2` the
     safe way), so the function returns the newest value and never indexes out of range.
2. **Can the oldest label hit the second label or the left edge?** Not in this product.
   `EdgeFitXTick` clamps `x` to `[half, chartWidth - half]`. All three rolling charts use the
   default 60 px YAxis plus a 5 px margin, so `plotLeft = 65`, which is more than half a label
   (18 px at font 12). The oldest label is never moved, its left edge sits at 47 px, and the
   second label is at least one pitch (44 px or more) to the right. The function does not model a
   LEFT clamp: a caller with `plotLeft < labelW/2` would push the oldest label right by
   `labelW/2 - plotLeft` with no pitch for it. No caller does that today, so this is LOW and is not
   raised.
3. **Is the regenerated fixture still font-independent?** Yes, by construction. The tick list is
   arithmetic on `"MM-DD"` length, `chartWidth` and the plot area. The plot area comes from the
   fixed default YAxis width, not an auto width. Tick positions come from the point scale, and the
   clamp uses `estLabelWidth`. None of these reads a font. The labels are single words, so
   Recharts' `Text` never wraps them. The forced-font runs were not repeated for the new list.
   That leaves the empirical control from round 3 standing, not re-measured.
