<decisions>
## Implementation Decisions

Founder accepted all four recommended answers on 2026-10-21 ("Accept all").

### How the charts fit a phone
- **D-01 Width:** below 400 px the equity chart is exactly its card's content width. The `Math.max(400, …)` floor in `EquityChart.tsx` goes. When narrow, the x axis shows fewer ticks so labels do not collide.
- **D-02 Clipped tick labels:** edge labels anchor inward (the first label left-aligned, the last right-aligned), and the right-hand y-axis gets enough padding, so every label's box sits inside its SVG. Labels are not hidden.
- **D-03 Scope:** the /allocations Overview equity chart and the scenario composer's charts named in the evidence ("2025" on the timeline brush, "P95 +0.1%", the "10-20"/"10-19" end-date ticks). Charts on other pages are deferred.
- **D-03a Shared components (founder 2026-10-21, "Fix shared once (Recommended)"):** the composer's cut labels come from `MasterBrush`, `DistributionPanels` and `TimeSeriesChart` in `src/app/factsheet/[id]/v2/`, which the composer mounts through `ScenarioFactsheetChart` → `FactsheetBody`. They are fixed once in the shared component, with no composer-only option, so `/factsheet/[id]/v2` also stops cutting those same labels. That is the only factsheet-page change; other factsheet charts stay deferred.
- **D-04 Desktop unchanged:** proven by measuring at 1280 px before and after: the same SVG width and the same tick set.

### Claude's Discretion
- The narrow-width tick count rule, and whether label fitting reuses an existing helper.

## Existing Code Insights

### Reusable Assets
- `src/lib/chart-ticks.ts`: engine-independent tick values (Phase 169.1.1 HYDRATIONTICKS); any new tick-count rule must keep server and browser tick values identical (React #418).
- `src/app/(dashboard)/allocations/widgets/performance/EquityChart.tsx`: hand-drawn SVG; width from a ResizeObserver (`setWidth(Math.max(400, Math.floor(cr.width)))`, default 960 in jsdom), plot width `width - pad.l - pad.r`, right-axis labels drawn at `width - pad.r + 4` with `textAnchor="start"`, x labels `textAnchor="middle"`.
- `src/app/(dashboard)/allocations/components/MonteCarloBandChart.tsx`: the scenario composer's band chart (P95 label).

### Established Patterns
- Charts measure their container with a ResizeObserver; jsdom falls back to a fixed width, so a unit test can drive the width through a mocked ResizeObserver.
- Existing EquityChart test files (`EquityChart.*.test.tsx`) are the place for the RED test on the 400 px floor.

### Integration Points
