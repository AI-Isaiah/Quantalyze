## 4. The measurement

The reference implementation is `readSvgTextLayout` and `assertSvgTextInsideSvg` in `e2e/helpers/geometry.ts`, and the "equity chart fits its card" case in `e2e/layout-narrow.spec.ts`. The in-page steps below are the same rule for a browser tool that can run JavaScript.

**Rule.**

1. **Equity chart fits its card.** The equity `svg` rect lies inside the `wrapRef` content box (the svg's grandparent `div.relative.w-full`, content box = its rect minus border and padding) within 0.5 px, left and right.
2. **No label cut by its own chart.** Every non-empty `svg text` on the page's in-scope charts lies inside its bound within 0.5 px on each side. The bound is the text's own `svg` rect when that svg's `overflow` is not `visible`. For an `overflow: visible` svg the bound is the padding box of the nearest ancestor that cuts on that axis (horizontally any non-`visible` overflow; vertically only `hidden` or `clip`), or the viewport width when there is none and no vertical bound.

**In-page steps** (run in the page's console or the browser tool's JavaScript tool, after section 3):

```js
(() => {
  const round = (n) => Math.round(n * 100) / 100;
  const scope = [
    '[data-testid="overview-equity-curve"]',
    '[aria-label="Master timeline brush"]',
  ];
  const svgs = [...document.querySelectorAll("main svg, #main-content svg")].filter(
    (s) => s.getBoundingClientRect().width > 0 && s.querySelector("text"),
  );
  const offenders = [];
  let measured = 0;
  for (const svg of svgs) {
    const sr = svg.getBoundingClientRect();
    const cs = getComputedStyle(svg);
    const who = svg.getAttribute("aria-label") ?? svg.closest("[aria-label]")?.getAttribute("aria-label") ?? "svg";
    for (const t of svg.querySelectorAll("text")) {
      const s = (t.textContent ?? "").trim();
      if (!s) continue;
      const r = t.getBoundingClientRect();
      if (r.width === 0 && r.height === 0) continue;
      measured++;
      let lo = { x: sr.left, y: sr.top }, hi = { x: sr.right, y: sr.bottom };
      if (cs.overflowX === "visible") {
        lo.x = 0; hi.x = document.documentElement.clientWidth;
        for (let a = svg.parentElement; a && a !== document.documentElement; a = a.parentElement) {
          if (getComputedStyle(a).overflowX !== "visible") {
            const b = a.getBoundingClientRect(); lo.x = b.left + a.clientLeft; hi.x = lo.x + a.clientWidth; break;
          }
        }
      }
      if (cs.overflowY === "visible") {
        lo.y = null; hi.y = null;
        for (let a = svg.parentElement; a && a !== document.documentElement; a = a.parentElement) {
          const oy = getComputedStyle(a).overflowY;
          if (oy === "hidden" || oy === "clip") {
            const b = a.getBoundingClientRect(); lo.y = b.top + a.clientTop; hi.y = lo.y + a.clientHeight; break;
          }
        }
      }
      const sides = { left: lo.x - r.left, right: r.right - hi.x, top: lo.y === null ? null : lo.y - r.top, bottom: hi.y === null ? null : r.bottom - hi.y };
      for (const [side, px] of Object.entries(sides)) if (px !== null && px > 0.5) offenders.push(`${who} "${s}" ${side} ${round(px)}`);
    }
  }
  const eq = document.querySelector('[data-testid="overview-equity-curve"] svg[aria-label="Equity chart"]');
  let equity = null;
  if (eq) {
    const wrap = eq.closest("div.relative.w-full");
    const w = wrap.getBoundingClientRect(), cs = getComputedStyle(wrap), s = eq.getBoundingClientRect();
    const px = (v) => parseFloat(v) || 0;
    const content = { left: w.left + px(cs.borderLeftWidth) + px(cs.paddingLeft), right: w.right - px(cs.borderRightWidth) - px(cs.paddingRight) };
    equity = { svgWidth: round(s.width), contentWidth: round(content.right - content.left), fits: s.left >= content.left - 0.5 && s.right <= content.right + 0.5 };
  }
  return { viewport: `${innerWidth} x ${innerHeight}`, measured, equity, clippedLabelCount: offenders.length, offenders };
})();
```

`scope` in the snippet is documentation of the in-scope charts; the snippet measures every `svg` under the main content so a chart that is not in the list is also caught. Read `equity` on the Overview only; on the composer `equity` is `null`. Page 3 is read with the same snippet and recorded without gating.

If the browser tool cannot run JavaScript, take the reading from a screenshot at each viewport instead and record `clipped-label count` as the number of visibly cut labels, with each label's text in the offender column. A screenshot reading cannot prove the 0.5 px bound; say so in the table's note column.
