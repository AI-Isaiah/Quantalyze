**The rule, from UI-SPEC C-3.** `fitTickLabel(x, label, fontSize, minX, maxX, anchor)` with
`minX = 0` and `maxX = VB_W`, in the chart's viewBox user units. The viewBox charts keep every
padding (`PAD`) and every font literal, desktop and mobile arms alike; the fix is anchoring only.
`ResponsiveChartFrame` scales the viewBox with `preserveAspectRatio="xMidYMid meet"`, so a label
inside the viewBox is inside the rendered svg at any width.

**Hydration.** `useBreakpoint` picks the mobile or desktop font arm; the anchor is a pure function
of that font, the label and the viewBox coordinates, so server and browser compute the same anchor
for the same breakpoint value. Never call `getBBox` or read the DOM to decide an anchor.

never in it, so both may change; the guard still runs in verify. `MasterBrush.tsx` sits in the
`eslint.config.mjs` raw-font-px `off` block; that exemption does not license a font change here.
