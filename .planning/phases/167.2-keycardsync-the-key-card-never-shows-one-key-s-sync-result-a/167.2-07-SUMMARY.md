## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Moved the owner read out of the component body**
- **Found during:** Task 1
- **Issue:** The inline read in the `!payload` branch failed eslint `react-hooks/purity` ("Cannot call impure function during render", `Date.now`). Task 3's verify requires eslint 0.
- **Fix:** A module-level `readOwnerComputeState` (Task 1), extended into `readOwnerPendingStatus` (Task 2) and placed after the page so the lexical order check still holds. It is called only from the owner `!payload` branch.
- **Files modified:** `src/app/factsheet/[id]/v2/page.tsx`
- **Verification:** eslint 0. Task 1 verify re-run OK, and the neuter was re-run on the moved code.
- **Committed in:** `6808c4aa6`, `c892dfcb5`

**2. [Rule 2 - Missing critical] A non-array RPC answer with no error is unreadable**
- **Found during:** Task 1
- **Issue:** The plan named `{error}` and a throw. A `{ data: null, error: null }` answer would otherwise read as zero rows, an exhaustive window, and `never_started`: a state claim with no evidence.
- **Fix:** Treated as a read failure: logged, sent to Sentry, derives `unreadable`.
- **Files modified:** `src/app/factsheet/[id]/v2/page.tsx`
- **Committed in:** `6808c4aa6`

**3. [Plan detail] KCS09-RUN-UNKNOWN pinned through a derivation override**
- **Found during:** Task 2
- **Issue:** The behaviour list asks for a "running unknown kind" case. Through the page, `selectFactsheetJob` picks only `stitch_composite` and the five chain kinds, and `jobPhaseOf` gives each of them a known phase, so a real row cannot reach RUN-UNKNOWN.
- **Fix:** The test file mocks `@/lib/compute-state` with a passthrough `deriveComputeState` spy and overrides one answer for that case only. Every other case runs the real derivation. The reason is recorded in the test.
- **Committed in:** `217a6fe47`

**4. [Test harness] New test file shape**
- The count chain is a thenable `strategy_keys` builder (`countCompositeMembers` awaits the builder itself).
- `Date` is faked to a fixed `NOW_ISO` so the stall and heartbeat fixtures are deterministic.
- The owner-lane suite's own request mock has no `rpc`, so its test 6 now exercises the throw path. It stays green and unedited, as the plan's truth #3 anticipated.
