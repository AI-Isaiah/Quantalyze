<objective>
Wire the docs-only path filter end to end for ONE job, and prove it by executing the
aggregator's own shell rather than reading it. The classifier exists with its full fixture
table, the `changed-paths` job publishes its boolean, `sql-gate-lint` consults it, and the
aggregator learns the single uniform arm that turns that one legitimate skip into green
without turning any other skip into green.

Purpose: the detector is this phase's single point of trust — CONTEXT.md states the vacuity
surface exactly: "if it misclassifies a code diff as docs-only, every gate greens at once."
Building it as one thin vertical slice means the architecture is falsified or confirmed after
one commit, not after sixteen `if:` lines are already in the file. `sql-gate-lint` is the
deliberate choice of first row: it is cheap (15 s), it is a strict aggregator row, and its own
header forbids a per-row tolerance arm by name — so if the uniform arm can carry it, the "this
is not a per-row tolerance" claim is demonstrated on the hardest row rather than asserted.

Output: `scripts/classify-changed-paths.mjs`, four edits to `.github/workflows/ci.yml`, the new
contract test with the extract-and-execute harness and five scenarios, and the guard's
registration in `CONTRACT_GUARDS` and `REGISTRY.md`.
</objective>
