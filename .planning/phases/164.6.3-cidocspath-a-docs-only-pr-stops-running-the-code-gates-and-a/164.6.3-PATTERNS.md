**The extractor — copy verbatim, changing only `STEP_NAME`** (`:39-68`). ⛔ Note the throw-on-missing-anchor arm and its long failure message; that IS the calibration:

```ts
const ROOT = process.cwd();
const STEP_NAME = "Run SQL self-tests against test Supabase project";
const CI_YML = join(ROOT, ".github/workflows/ci.yml");

/** Pull a step's `run: |` body out of the workflow, dedented. */
function extractRunScript(yml: string, stepName: string): string {
  const lines = yml.split("\n");
  const start = lines.findIndex((l) => l.trim() === `- name: ${stepName}`);
  if (start === -1) {
    throw new Error(
      `ci.yml has no step named "${stepName}". ... If it was renamed, update STEP_NAME here; if it was deleted, ...`,
    );
  }
  const runIdx = lines.findIndex((l, i) => i > start && l.trim() === "run: |");
  if (runIdx === -1) throw new Error(`step "${stepName}" has no "run: |" body`);
  const indent = lines[runIdx].length - lines[runIdx].trimStart().length;
  const body: string[] = [];
  for (const line of lines.slice(runIdx + 1)) {
    if (line.trim() === "") { body.push(""); continue; }
    if (line.length - line.trimStart().length <= indent) break;
    body.push(line.slice(indent + 2));
  }
  return `${body.join("\n")}\n`;
}

const YML = readFileSync(CI_YML, "utf8");
const SCRIPT = extractRunScript(YML, STEP_NAME);
```

⭐ **For this phase `STEP_NAME = "Verify all frontend-* jobs succeeded"`** — verified to be the aggregator's only step (`ci.yml:2334`), and it is a `run: |` body, so the extractor works unmodified.

**The tempdir + `spawnSync bash` harness** (`:106-130`) — `mkdtempSync` at module scope, `afterAll(() => rmSync(workdir, { recursive: true, force: true }))`, one `runGate()` returning `{ code, out }`:

## Shared Patterns

### Anti-vacuity: how an existing test encodes "this control CAN fire"

**Source:** `src/__tests__/mutation-runner-floors.test.ts` + `scripts/mutation-runner/run.mjs`.

Four composable idioms, all present in that one file:

1. **Two floors, two layers, stated in the header** (`:1-17`) — the runner enforces the upper bound, vitest the lower:
   ```
    *   - annotated < FILES_FLOOR  → a real regression; someone deleted annotations
    *   - annotated > FILES_FLOOR  → the ratchet is stale and must be raised
   ```
   with the stale-direction message naming the fix (`:533`):
   ```ts
        : `RATCHET STALE: ${annotated.length} of ${filesTotal} gate files are now annotated but FILES_FLOOR is still ${FILES_FLOOR}. Raise FILES_FLOOR in scripts/mutation-runner/run.mjs to ${annotated.length}.`,
   ```

2. **Independent re-derivation — deliberately do NOT import the thing under test** (`:61-70`):
   ```ts
   /**
    * Independent re-derivation. These regexes are written out again on purpose —
    * importing the parser's own constants would make this test agree with the
    * parser by construction and prove nothing about the corpus.
    */
   const PROSE = /^[ \t]*--[ \t]*RED-UNDER:/;
   ```
   ⭐ Directly applicable: the contract test must re-derive the filtered/always-on partition from `ci.yml` text, **not** import a list from the classifier.

3. **A vacuity fence before every derived assertion** (`:227-228`, `:294`):
   ```ts
   expect(annotated.length, "no annotated file — every assertion below would be vacuous").toBeGreaterThan(0);
   ```

4. **Neuter → RED → restore, executed in-process:** `run.mjs` is spawned against a throwaway `fixtures/selftest` corpus (`SELFTEST_DIR`) built by `mkdtempSync`/`writeFileSync`, so a mutated subject is exercised without ever touching the real tree. ⛔ The repo's recorded trap (memory `git checkout --` destroys uncommitted work in neuter/restore harnesses) is why the mutation is applied to an **in-memory string or a tempdir copy**, never to the file on disk. The aggregator test inherits this for free: it writes `step.sh` into `mkdtempSync`.

Encoded as calibration assertions the planner should name explicitly:
- **S2** (`plan-anchor-verify=skipped` ⇒ exit 1) is the `ALWAYS_ON` list's fire-proof.
- **S8** (`docs_only=false`, `e2e-seeded=skipped` ⇒ exit 1) is the "this phase did not weaken the pre-existing arm" calibration.
- **S6** (all success ⇒ exit 0) is the harness non-vacuity control.
