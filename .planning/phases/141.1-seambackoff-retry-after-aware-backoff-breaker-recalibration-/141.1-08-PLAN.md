**Two independent, separately-sufficient causes, both confirmed:**
1. `src/instrumentation.ts:45-59` writes `path: request.path` into **`extra`** (unindexed,
   unsearchable — the file's own comment says extra is metadata-only) while `correlation_id`,
   `routePath`, `routeType`, `routerKind` go into **`tags`**. Zero `setTag` calls anywhere write
   `path`. Empirically 694/694 production events have `path=""`.
2. Even promoted to a tag, the VALUE is wrong: there is no `src/app/api/process-key` route; the
   serving route is FastAPI — `APIRouter(prefix="/process-key")` at
   `analytics-service/routers/process_key.py:59`, mounted bare at `main.py:823`. The path is
   `/process-key`; the `/api` prefix is wrong even against the service that serves it.

`correlation_id:*` is healthy (681/694 = 97.8%), as are `level:error` and
`environment:production`. The single killing term is `path:/api/process-key`.

**Class size is ONE — verified.** `src/app/api/cron/phase19-error-rollup/route.ts` (the
historical sibling with the same query, CHANGELOG `[0.24.10.0]`) was retired in Phase 106
Stage B (`ce32afbd`). Exhaustive greps: `path:/api/process-key` → exactly 1 hit
(`flag-monitor/route.ts:95`); `level:error` in non-test src/ → the same single line. The
anti-`path:` guard below is RECURRENCE PREVENTION on a class currently of size one — do not
claim a second live instance was closed; the SUMMARY must not overstate this.
