## Decisions this plan records

- **DEC-04-A The fallback still returns a hold.** On a missing RPC `acquire_terminal_xlease` returns an
  `XLeaseHold` marked `cross_process=False` whose `stop_renewing` and `release` do nothing, so
  `mt5_terminal_lease` needs no new branch.
- **DEC-04-B Relog every 900 s, never latch** (CONTEXT after research): PGRST202 also fires on a parameter-
  signature drift, so a single line per process would hide a persistent fault. The constant is
  `_MT5_XLEASE_UNAVAILABLE_RELOG_S = 900.0`, the 227 `_RENEW_UNAVAILABLE_RELOG_S` cadence.
- **DEC-04-C Error budget** `_MT5_XLEASE_ERROR_BUDGET_S = 60.0` of consecutive errors for an unbounded caller.
  A successful answer (True or False) resets it. Import-time validation gains `rpc_timeout < error_budget`.
- **DEC-04-D The predicate lives in services/db.py** (CONTEXT after research): `mt5_concurrency` and `mt5_xlease`
  are leaves and `main_worker` imports half the service. `main_worker` stays untouched (Rule 3); the twin is
  pinned by a parity test, the repo's usual shape for a duplicated predicate.
