## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bearer token → share page | the constant-time HMAC match is the only authorization |
| session cookie → share page (new, OQ-3) | read for one boolean after the match |
| share page → `/` and `/signup` links | navigation away from a URL that carries a bearer token |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-196-27 | Information disclosure | session read on the token lane (OQ-3, flagged for the phase security review) | medium | mitigate | read only after the match, one boolean, no profile or owner read, never passed to the builder, `withViewerAum(payload, false)` for everyone; static and behavioural arms; neuter evidence |
| T-196-28 | Information disclosure | token in the Referer when following the header links | high | mitigate | `next.config.ts` sends `Referrer-Policy: no-referrer` for `/factsheet-share/:path*`; a test pins it |
| T-196-29 | Information disclosure (enumeration) | ordering of the session read | medium | mitigate | rate limit and token checks run first and do not read the session; arm asserts createClient is not called on those paths |
| T-196-30 | Information disclosure (cache) | token lane reaching the public cache | high | mitigate | no next/cache import, no cache primitive, `force-dynamic`; the existing no-cache-reach arms stay and gain the new static arms |
| T-196-SC | Tampering | npm/pip/cargo installs | low | accept | no package installs in this plan |
