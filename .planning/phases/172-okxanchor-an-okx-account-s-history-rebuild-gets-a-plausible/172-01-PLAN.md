<objective>
Build the independent opening-balance check D-01 asks for, as a read-only module nothing in production calls yet, and
replace the one test of the implausible arm that cannot fail.

D-01 verbatim from CONTEXT: "Founder 2026-10-27, AskUserQuestion: 'Diagnose, then check independently (Recommended)'.
1. A read-only diagnostic run on a4 on the backfill worker (...) measures the cause (SC-1). 2. If the cause is money held
before the 89-day window, the implied opening balance (`anchor - replay_final`) is checked against an independent source
(OKX bill balances); the rebuild anchors when they agree within a stated tolerance and refuses
`anchor_skipped_implausible` when they do not. 3. If OKX cannot supply that independent source, a4 is recorded as a
correct refusal with the measured reason."

This plan builds the "independent source" of item 2 so that plan 02's probe can MEASURE it on a4 (item 1, SC-1) with the
very code plan 04 will later wire into the forced anchor. Measuring the oracle that will gate production, rather than a
look-alike, is the point: the tolerance is chosen from that measurement (CONTEXT, Claude's discretion).

Two deliberate departures from RESEARCH, recorded so they are decisions and not drift (Rule 7):
- The opening INSTANT is 00:00 UTC of the replay's FIRST ROW day, not the window start. Measured on the fixture this
  session: `_compute_daily_equity` appends a row only `if breakdown or total:`, so an 89-day window whose only trade is
  nine days back yields 10 rows starting on the trade day. The anchor offset is spread over those rows only, so the
  balance it must equal is the balance before the first row's events. A funding-to-trading transfer before that day
  then no longer causes a false disagreement, while one inside the curve still does (correctly: the uniform offset
  would misstate the rows before it).
- Non-stable currencies are priced at the CLOSE OF THE OPENING DAY (the first row's own pricing day), not the previous
  day's close (RESEARCH Pitfall 4). Agreement then bounds the level error of the first written row, which is the
  quantity that matters.

Purpose: SC-1 (the measurement instrument) and SC-2 (the check the rule uses; the OKX real-arm pin).

`test_c01_03_implausible_offset_skips_anchor`, a new OKX forced pin. Nothing is run against TEST or PROD.
