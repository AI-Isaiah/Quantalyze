## THE RPC CONTRACT (byte-identical in 253-01-PLAN.md and 253-02-PLAN.md; plan 02 calls exactly this)

Signature: `public.set_strategy_fills_reread_bound(p_strategy_id uuid, p_api_key_id uuid, p_job_id uuid, p_claim_token uuid DEFAULT NULL, p_unread_from timestamptz DEFAULT NULL, p_covers_from timestamptz DEFAULT NULL) RETURNS boolean`, `LANGUAGE plpgsql SECURITY DEFINER SET search_path = public, pg_catalog`.
- `p_unread_from`: the run's EARLIEST complete-through instant (every stopped symbol is complete through it; a failed symbol or a raised read is complete through the walk start minus 1 ms). NULL means the Binance read was complete.
- `p_covers_from`: the instant the run's walk started from (seed minus OVERLAP_WINDOW_MS). The literal string `-infinity` means the walk started at the venue reach, so every reachable instant was covered. NULL means "covered nothing known" and never clears or advances a bound.
- Returns TRUE when the call owned the write (whether or not a row changed), FALSE only for an orphan claim token.
Rules, in order:
1. `p_strategy_id` or `p_api_key_id` NULL: RAISE with ERRCODE `invalid_parameter_value` (22023), message prefixed `set_strategy_fills_reread_bound:`.
2. Fence, copied from advance_sync_cursor: when `p_claim_token` IS NOT NULL, `p_job_id` NULL raises 22023, and no `compute_jobs` row with `id = p_job_id AND status = 'running' AND claim_token = p_claim_token` returns FALSE with nothing written. A NULL token skips the fence (the WORKER_FENCE_V2 kill-switch arm).
3. `SELECT api_key_id, unread_from ... FROM strategy_fills_reread_bounds WHERE strategy_id = p_strategy_id FOR UPDATE` (row lock, so a concurrent call on the same strategy serialises; the state machine deletes, so one upsert cannot express it).
4. `covers := p_covers_from IS NOT NULL AND p_covers_from <= existing.unread_from` (inclusive).
5. Branches (R0 to R7): no row and NULL: nothing (R0). No row and a value: INSERT, `ON CONFLICT (strategy_id) DO UPDATE` setting `api_key_id = EXCLUDED.api_key_id` and `unread_from = CASE WHEN strategy_fills_reread_bounds.api_key_id = EXCLUDED.api_key_id THEN LEAST(strategy_fills_reread_bounds.unread_from, EXCLUDED.unread_from) ELSE EXCLUDED.unread_from END` (R1; the conflict arm is the race the one-in-flight index and the fence make unreachable, and LEAST is its safe direction). Row for ANOTHER key and a value: replace key and instant (R2). Row for another key and NULL: DELETE (R3). Same key, a value, covers: `unread_from := p_unread_from` (R4). Same key, a value, not covers: `unread_from := LEAST(existing, p_unread_from)` (R5). Same key, NULL, covers: DELETE (R6). Same key, NULL, not covers: keep (R7). Every write sets `updated_at = now()`.
6. RETURN TRUE.
