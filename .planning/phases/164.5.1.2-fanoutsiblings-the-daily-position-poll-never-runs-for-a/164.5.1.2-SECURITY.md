2. **Response-body disclosure — clean.** `held` is an integer counter. `strategy_errors` carries
   internal strategy ids (already present in every pre-existing envelope) plus an exception type
   and message, or the type-name-only drift string. No trade contents, no credential, no host or
   DSN.
3. **Authorization — unchanged, confirmed.** `analytics-service/main.py`, which carries the route
   wiring and the service-key middleware, has an EMPTY diff on this branch.
4. **Resource exhaustion (`SYNC-HELD-CURSOR-REFETCH-COST-01`) — real, judged adequate to ship,

   not an attacker-controlled set); every tick is hard-capped by the per-key sync timeout, so the

   a named trigger and a destination phase that structurally ends the condition; and it is not
   externally reachable — it is production's own cron acting on its own key set behind the
   service-key boundary. ⭐ Recommended for formal registration as an `accept`-disposition threat
   in a future revision, for traceability.
