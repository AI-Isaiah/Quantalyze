<objective>
Make the lane-only exclusion set impossible to grow, shrink, or swap without a red test — and make
the marker mean something, by binding each declaration to the object the file's own assertion
bodies actually query.

Purpose: plan 01 removes one file from one job. Without this plan the mechanism it introduces is an
exemption anybody can self-grant in a comment, which is the same defect class as a gate reporting
PASS having measured nothing.

Output: a SITES-not-a-count pin and two cross-checks, each shown able to fail.
</objective>
