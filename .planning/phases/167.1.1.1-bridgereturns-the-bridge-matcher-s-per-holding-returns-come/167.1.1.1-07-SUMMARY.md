# Phase 167.1.1.1 Plan 07: /compare reads a derivative as a signed return Summary

**A derivative holding on /compare now shows its long/short-signed mark-price return (cumulative return, Sharpe, max drawdown, vol on the 365 clock) with the approved caption and gap sentence, options are withheld as `option_premium`, and the "rebuilding" state and State D note no longer exist.**

## Accomplishments

- `fetchHoldingCompareItem` selects `asof, mark_price, updated_at, api_key_id, side`, routes a spot holding through `classifySpotMarks` and a derivative through `classifyDerivativeMarks`, and computes derivative metrics with `analyzeSignedReturns(returns, annualizationPeriods("crypto"))` at or above the minimum usable days (null metrics below it). `fixed_price`, `account_balance`, `no_price`, `no_direction` and `option_premium` become a withheld item; `no_price` keeps its warn and `no_direction` gets the same shape of warn (ref and row count only). The contract-error log gained the bad-side count. A side outside long/short/flat (null and missing included) throws `HoldingCompareLoadError`.
- `HoldingWithheldReason` widened with `no_direction` and `option_premium` (one doc line per reason). `holdingCompareHistoryState` and the `{ historyState: "rebuilding" }` union member are deleted; the file header and the deleted helper's doc comment were rewritten by concept, and the retired Python function is no longer named in the adapter. The spot-rule notes that lived in that doc comment (no zero-fill, no forward-fill, "daily price" never close-to-close) moved into the `fetchHoldingCompareItem` doc.
- `HoldingFactsheet`: `DERIVATIVE_NOTE` deleted; `derivativePriceBasis(n, symbol)` returns the RD caption verbatim and `DERIVATIVE_GAP_NOTE` is appended in the same `holding-factsheet-price-basis` paragraph for a derivative; `withheldNote` gained `no_direction` (State ND) and `option_premium` (State OP) with the UI-SPEC sentences verbatim. The `holding-factsheet-rebuilding` test id is kept on the note slot; State X (`NOT_SPOT_NOTE`) and spot States R, R0, R2, F, F2, N are byte-unchanged. No class, token, colour or spacing value was added; every value keeps `text-text-primary` whatever its sign.
- Tests: the adapter's derivative-rebuilding test became signed-return tests with hand-typed oracles (a 1% daily fall for 30 intervals: short = 1.01^30 - 1, long = 0.99^30 - 1 = the spot level form; vol on the 365 clock from a two-point return path), plus option-without-reading-marks, all-flat no_direction with a counts-only warn, non-positive marks as no_price, bad and missing side throwing, zero rows null (D-15), and 12 usable days ready with null metrics. The shared-fixture `fetchHoldingCompareItem` replay now runs every case (derivative cases are mapped from their hand-typed `expected`) and also asserts the withheld reason. The recorded-select assertion pins the exact column string including `side`. Component tests cover RD, RD0, RD2, ND, OP, N for a derivative, sign-neutral colour, both caption directions, and State D absent on every derivative state.
