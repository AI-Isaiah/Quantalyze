## SFH-01 (MEDIUM) - a non-positive AUM turns spot weights into 0.0 and equal weights with no name

Locations: analytics-service/routers/match.py:1006-1012 (holdings context), :1215-1228
(`_load_allocator_context`), :1246 (`portfolio_aum` becomes None), :1342 and :1355 and :1417
(`compute_holding_flags`: `weight = value / aum if aum else 0.0`).

Scenario: the AUM is now spot value PLUS signed derivative P&L (D-15, D-16). A leveraged
allocator whose derivative losses exceed its spot value, or whose only non-null contribution
is negative, gets `total_aum <= 0`. Before this phase the AUM was a sum of non-negative spot
values, so this state needed all-zero values. Now it is reachable with real money:
- weights fall back to EQUAL weights over the spot holdings (:1010, :1222-1228). A holding
  that is 90 percent of the spot book is scored as 1/N of the portfolio. That is a plausible
  value standing in for an uncomputable one, and nothing in holding_flags says so.
- `compute_holding_flags` sets `aum = None`, so every spot entry, priced and withheld, is
  persisted with `weight: 0.0` next to a nonzero `value_usd`, and the max_weight test is
  skipped silently (`aum is not None` guard). The persisted 0.0 reads as "this holding has no
  weight", not "weight undefined".

User impact: the allocator with the largest drawdown on derivatives gets no max-weight flag
at all, and the portfolio-fit axis is computed on invented weights. This breaks the locked
rule that uncomputable values are null, never 0 or a plausible number.

Fix: in `compute_holding_flags`, when `aum is None` write `weight: None` for spot entries
(the derivative entries already do), and add a `weight_basis` marker or a named
`withheld_reason`-style note (for example `aum_not_positive`) so the skipped max-weight test
is visible. For the scorer, either withhold the weights axis when `combined_aum <= 0`
(return `portfolio_aum` None and no weights, as for an empty book) or log a named WARNING
carrying the allocator id and that the equal-weight fallback was taken. Add a test:
spot 1000 USD, derivative P&L -1500 USD, expect weight None and no equal-weight fallback.
