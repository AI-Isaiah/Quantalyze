## Sampling Rate

- **After every task commit:** run the one test file the task touched (Python, or one vitest file per invocation).
- **After every plan wave:** run the analytics-service neighbours (`test_match_*`, `test_holding_*`, `test_e2_match_score_golden`, `test_status_contract_match_sim_portfolio`), the vitest files named below, `tsc --noEmit`, and mypy on the touched files.
- **Before `/gsd-verify-work`:** the full suite must be green.
- **Max feedback latency:** 30 seconds per task.
