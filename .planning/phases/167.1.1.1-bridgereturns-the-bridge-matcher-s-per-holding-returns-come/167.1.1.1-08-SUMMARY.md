# Phase 167.1.1.1 Plan 08: Derivatives named in holding_flags, ENGINE_VERSION v2.3.0 Summary

**Every derivative in the allocator's book is now named in `match_batches.holding_flags` with its P&L contribution and the reason it is out of the book (never its notional, never a weight, never max-weight tested, never in the return join), and ENGINE_VERSION moves to v2.3.0 so the first scheduled cron tick after deploy re-scores every cached batch.**

## Accomplishments

- Task 1 (tracer): `_load_holding_portfolio_context` classifies each derivative with `classify_derivative_marks` and sets `withheld_reason` by precedence `pnl_missing` (D-18), then the price rule's reason (`option_premium` D-10, `no_price`, `no_direction`, `too_few_priced_days`), then `derivative_out_of_book` (D-09). `_load_allocator_context` returns `_holdings_rows_derivative`; `_score_one_allocator` passes it as `holdings_rows_derivative=`; `compute_holding_flags` appends one entry per derivative: `{holding_ref, value_usd: None, aum_contribution_usd (as-is), weight: None, breach_reasons: [], top_candidate_*: None, flagged: False, withheld_reason}`. The docstring documents both withheld shapes. `_flag_value_usd` now raises on a derivative row (orchestrator note: the notional fallback can never reach a flag). A counts-per-reason INFO line names derivative reasons (no symbol, value or key).
- Task 2 (D-12): `ENGINE_VERSION = "v2.3.0"` with a dated cause in the comment block, `WEIGHTS_VERSION` unchanged; `test_engine_version_phase09_bump` and the feedback_engine comment moved. Both goldens were regenerated (`UPDATE_GOLDEN=1`, `REGENERATE_GOLDEN=1`) and proved by a JSON comparison against the byte backups, ignoring `engine_version`: equal, and the new value is v2.3.0 in both.
- 10 new tests in `test_match_holding_returns.py` (30 in the file): the tracer (exact entry equality, join sees only spot, 40 returns), notional never in an entry, max-weight 0.01, Deribit option, parametrised price-rule reasons (all-flat, 12 usable days, no positive mark), `pnl_missing` with `is None` and a `"aum_contribution_usd": null` JSON check, `pnl_missing` outranking `option_premium` and `no_direction`, the 40/None two-account partial, the helper refusal, and an async end-to-end through `_score_one_allocator` asserting the persisted JSON.
- Census: `holding-scope-key-census` M4 for match.py moved 5 to 6 in the same commit as the new derivative-loop f-string (reason text updated).
