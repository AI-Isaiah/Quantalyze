## Deviations from Plan

**1. [Rule 3 - Blocking] The merge-base block writes with `process.stdout.write`, not `console.log`**
- **Found during:** Task 1, the first run of the second verify command.
- **Issue:** Under an agent shell (`CLAUDECODE` / `AI_AGENT` set), vitest 4.1.10 selects a reporter that drops a passing test's console output. The test passed, but `shape-scan-base:` never reached stdout, so the plan's `grep -q` failed. With those variables unset, or with `--reporter=default`, the line printed. A probe test showed that `process.stdout.write` survives both reporters.
- **Fix:** Both the per-hit lines and the summary line use `process.stdout.write`, with a comment saying why. The assertions are unchanged, and the line still prints only after they pass.
- **Files modified:** `src/lib/return-stats.single-source.test.ts` (inside the Task 1 commit).

- The plan asks that the per-hit list agree with the context block's breakdown. This agreement is now an assertion against a committed 26-entry `BASE_EXPECTED` list, so it no longer depends on reading the output by eye.
