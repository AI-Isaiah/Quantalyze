**The information ratio (D-20 B1).** `computeScenarioBenchmark`'s IR is `(excessMean * periodsPerYear) / te`
with `excessMean = mean(diff)` and `te = computeTrackingError(p, b, periodsPerYear)`, which is

in the same arithmetic order (`mean - 0` is exact), so the move is bitwise on a noisy input. The
reported `trackingError` field stays `computeTrackingError`'s value.
