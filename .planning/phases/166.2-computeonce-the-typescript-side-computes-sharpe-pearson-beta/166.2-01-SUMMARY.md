# Phase 166.2 Plan 01: return-stats, the one TS home of dispersion ratios, and sites T1-T5 Summary

**`src/lib/return-stats.ts` computes every TS dispersion, Sharpe, Pearson and beta once, on Phase 166's residue floor pinned to the Python constant; /compare's holding Sharpe, `sampleBasisRatios`, `computeScenario`'s Sharpe and correlation matrix, and `diversificationRatio` now call it, so a compounding constant yield reads as "no ratio" instead of a Sharpe of 1e12 to 1e14.**

## The return-stats API (plans 166.2-02 to 166.2-05 read this; do not edit the module)

All pure: no Date, no randomness, no I/O. One import line (`mean`, `stdDev` from `@/lib/portfolio-math-utils`).

```ts
export const DISPERSION_RESIDUE_REL = 1e-12;
export function residueFloor(meanValue: number): number;            // 1e-12 * max(1, |mean|); NaN mean -> NaN
export function dispersionIsResidue(sd: number, meanValue: number): boolean; // sd <= floor; NaN either side -> false
export function dispersionIsReal(sd: number, meanValue: number): boolean;    // sd >  floor; NaN either side -> false
export function dispersion(xs: number[], ddof: 0 | 1): { n: number; mean: number; sd: number };
  // mean = mean(xs); sd = stdDev(xs, ddof === 1), except a residue sd is exactly 0; a NaN sd stays NaN
export function sharpe(xs: number[], opts: { periodsPerYear: number; ddof: 0 | 1; rf?: number }): number | null;
  // null when n < 2, any non-finite input, or dispersion(xs, ddof).sd === 0;
  // else ((mean - rf / N) * N) / (sd * Math.sqrt(N))   (factsheet compute.ts order; rf annual, default 0)
export function pearson(a: number[], b: number[]): number | null;
  // over the first min(a.length, b.length) points; null when that is < 2, either leg's
  // population dispersion is 0 or residue, or the denominator is not > 0 (a NaN leg);
  // else sums form cov / Math.sqrt(varA * varB)   (build-payload pearsonCorr / correlation-math pearson)
export function beta(y: number[], x: number[]): number | null;
  // THROWS RangeError when y.length !== x.length (align or slice first);
  // null when n < 2, x's population dispersion is 0 or residue, or varX is not > 0;
  // else (cov / n) / (varX / n)   (factsheet joint.ts form)
```

Arithmetic notes for adopters: `sharpe` with `rf` 0 is bitwise the old `(meanR * N) / (sqrt(sampleVar) * sqrt(N))` of `sampleBasisRatios` / `computeScenario`. `pearson` reuses `dispersion`'s mean, which sums in the same order as the old loops. `beta` uses `d * d`, measured bitwise equal to `d ** 2` in V8.

**1. [Rule 1 - Bug] T5 guard uses `dispersionIsReal`, not `dispersionIsResidue`**
- **Found during:** Task 2
- **Issue:** the plan says `diversificationRatio` returns null when `dispersionIsResidue(sigmaP, 0)`. That predicate answers false on a NaN `sigmaP`, so a NaN would have fallen through to `weightedSigma / NaN` and returned NaN, where today's `!(sigmaP > 0)` returns null.
