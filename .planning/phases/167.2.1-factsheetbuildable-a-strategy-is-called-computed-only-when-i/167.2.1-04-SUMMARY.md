## Deviations from Plan

**1. [Note] One difference from /strategies, which the plan accepts.** `/strategies` never probes an uncomputed row (D-08), so for that row a probe `read_error` cannot happen there. The owner page probes on every null payload, because it has no RLS computation-status embed to gate on. An uncomputed draft whose probe read fails therefore shows KCS12-UNREADABLE on the owner page. On the list, the same draft shows its arm note. That is the W1 mapping the plan specifies, and it never claims a factsheet exists.

**2. [Note] The probe runs after `readOwnerPendingStatus`, not in parallel.** The plan orders it that way. Running the two in parallel would save one admin round-trip on a rare owner-only path, but it would reshape the `ownerStatus` hunk. I kept the hunk minimal.

Otherwise the plan executed as written. No VERSION or CHANGELOG edit (D-12), no database command and no migration.
