## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The mutant module cannot be loaded by `await import()` under vitest**

- **Found during:** Task 1 (the durable falsifier)
- **Issue:** The plan's `<action>` prescribes `await import` of the temp-dir mutant `via pathToFileURL(...).href`. MEASURED 2026-09-13, both failures observed here before the shape was changed:
  - `await import(pathToFileURL(f).href)` → `Error: Cannot find module 'file:///…/T/mt5-minus-six-falsifier-…/mt5-mutant.mjs' imported from /…/src/__tests__/prod-prober-wiring.test.ts`
  - `new Function("url", "return import(url)")` (escaping the transform) → `TypeError: A dynamic import callback was not specified.`

  Vitest rewrites every dynamic import into its own module runner, which resolves against the Vite project graph and cannot see a file outside the repo root; escaping that transform lands in a VM context with no import callback.
- **Fix:** Write the mutant plus a two-line driver `.mjs` into the same `mkdtempSync` directory and drive it with `execFileSync(process.execPath, [driver, JSON.stringify(result)], { encoding: "utf8" })`. ⛔ The rejected alternative was writing the mutant somewhere Vite *can* resolve — that place is the working tree, and staying out of it is the whole point of this idiom. The chosen shape is also the **stronger** property: the mutant is parsed and linked by the SAME Node that runs the real arm in CI, with no bundler anywhere in the path. `execFileSync` uses no shell, so the JSON argument is one argv entry and nothing in it is interpreted.
- **Files modified:** `src/__tests__/prod-prober-wiring.test.ts`
- **Verification:** `Tests  3 passed`; both measured failure strings are recorded verbatim at the call site so the next reader does not re-derive them.
- **Committed in:** `9fb751d6` (Task 1 commit)

**2. [Rule 2 - Missing Critical] The mutant needed a size bound and an absence check, not only a difference check**

- **Found during:** Task 1
- **Issue:** The plan mandates `expect(mutant).not.toBe(original)`. That alone does not distinguish a branch-sized excision from a runaway one: if the block terminator ever matched far past the branch, the mutant would still differ and `it()` #2 would still be green.
- **Fix:** Added two further preconditions inside the mutant builder — the mutant must no longer contain the `-6` anchor, and `original.length - mutant.length` must be under 1200 (measured: 630). Also added a pinned assertion that `arms/mt5.mjs` still carries ZERO `import`/`require` statements, so a future module dependency added to the arm reveals itself HERE by name rather than as a puzzling failure inside a mutant nobody is looking at.
- **Files modified:** `src/__tests__/prod-prober-wiring.test.ts`
- **Verification:** the excised span was independently printed and read — it begins at `  if (code === -6) {` and ends at `      info: null,\n    };\n  }\n`, 630 bytes.
- **Committed in:** `9fb751d6` (Task 1 commit)
