## Decisions Made

- The memo tests' `finally` blocks call `mockClear()` instead of `mockRestore()`. On a `vi.fn` created with an implementation, restoring can drop that implementation and stop the spy from delegating for later tests in the file. Clearing only resets the counter. The tests compare counts after mount, so they were never sensitive to earlier calls.
- `vitest.config.ts` sets no `mockReset`/`restoreMocks`, so the delegating implementation survives between tests. All 47 tests in the file pass.
