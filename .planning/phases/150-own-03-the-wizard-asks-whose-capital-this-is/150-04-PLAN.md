<interfaces>
Route contracts (Plan 06's dialogs fetch these exactly):

```
PATCH /api/strategies/{id}/ownership
  body: { mark: "own_capital" | "team_review", confirm_remove_allocation?: boolean }
  200 → { ok: true, mark }
  409 → { error: "live_allocation", allocated_amount: number }   // flip to team_review while caller's positions exist, no confirm
  400 / 401 / 404 / 429 / 500 per the alias-route stack

PATCH /api/strategies/{id}/name
  body: { name: string }                                          // trimmed, 1..80 chars — reject outside, never truncate
  200 → { ok: true, name }
  400 → { error: "invalid name" } (empty) / { error: "name too long" } (>80)
  404 → wrong owner, unknown id, or published row (server-side D-17 gate)
```
Dynamic-segment idiom in this Next version (verified at src/app/api/admin/allocators/[id]/holdings/route.ts:30-32):
`export async function PATCH(req: NextRequest, { params }: { params: Promise<{ id: string }> })` then `const { id } = await params;`
