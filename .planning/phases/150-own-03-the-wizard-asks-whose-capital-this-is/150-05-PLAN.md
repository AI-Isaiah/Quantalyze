```
POST /api/portfolio-strategies/allocation
  body: { portfolio_id: string, strategy_id: string, allocated_amount: number }
  200 → { ok: true, allocated_amount }
  400 → invalid amount (not finite, <= 0, or > MAGNITUDE_CAPS.MAX_DOLLAR_VALUE_USD)

  body: { portfolio_id: string, strategy_id: string }
  200 → { ok: true }   404 → no such position
```
