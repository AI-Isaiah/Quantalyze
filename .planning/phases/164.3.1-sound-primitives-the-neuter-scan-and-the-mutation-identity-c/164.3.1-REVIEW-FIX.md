### CR-01: `END LOOP` is a branch head — the neuter walk terminates on it and the failure-branch invariant anchors on it

**Files modified:** `scripts/mutation-runner/parse.mjs`, `scripts/mutation-runner/run.mjs`, `scripts/mutation-runner/GRAMMAR.md`, `src/__tests__/sql-statement-tokenizer.test.ts`, `src/__tests__/mutation-runner-neuter.test.ts`, `src/__tests__/mutation-annotation-parser.test.ts`
**Commit:** `cbf29f95`
**Applied fix:** `END` removed from `LOOP_OPENERS`, so `END LOOP;` tokenizes like `END IF;` (`[head:false, terminated:true]`) and `neuterArm` refuses it loudly. **The reviewer's one-token fix does not close defect 2 on its own** — measured: with `END` gone, `failureBranches` anchored on the loop's own `FOR … LOOP` head, and a nested `IF … END IF;` or `BEGIN … END;` anchored on *its* opener the same way, so `IF NOT ok THEN → IF TRUE THEN` behind any closed block still returned `null`. Root cause: the backward walk treated a closed block's opener as the branch head. Fix: `blockCloserKind` / `opensBlock` / `blockOpenerIndex` step OVER a closed block (`END LOOP;`/`END IF;`/`END CASE;`/`END;`, nesting-aware) to its opener and keep walking. GRAMMAR § 3b gained the "closed block between the guard and the raise" bullet. Corpus unaffected: `--parse-only` 30/30/0 and REAL CORPUS 30 arms / 49 steps / 0 violations unchanged; `--self-test` 12/12.
**Pins added (5):** tokenizer "a block CLOSER is not a head"; neuter "CR-01: SET ROLE above a closed multi-line loop is REFUSED"; annotation-parser `it.each` over loop / nested IF / BEGIN block "R3-C02 secondary behind …".
**RED evidence (HEAD bytes, 5/5 red):**
- `END LOOP; … expected [ [ true, false, 'END LOOP' ] ] to deeply equal [ [ false, true, 'END LOOP;' ] ]`
- `neuterArm ACCEPTED a neuter that leaves "SET ROLE postgres;" executing behind a closed loop: expected true to be false` (multi-line loop; the reviewer's one-line `… LOOP NULL; END LOOP;` spelling was already refused by the same-line rule on `NULL;`, so the multi-line shape is the one that leaked)
- `the branch must begin at the GUARD …: expected '    END LOOP;' to be '  IF NOT ok THEN'`, and likewise `'    IF x THEN'`, `'    BEGIN'`
- Probe pre-fix: `identityRewriteDetail` → `null (BLIND)` for loop, nestedIf, block; post-fix `detail (refused)` for all three.
