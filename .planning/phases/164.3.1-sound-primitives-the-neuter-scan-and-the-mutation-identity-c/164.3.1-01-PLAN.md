comment spuriously refuses a legal arm (P4) and the even-parity case silently over-neuters a
statement that must survive (P5) — [MUT-I01]. Four line-local readers re-opened this class four
times; a fifth regex pass is named-refused by the ROADMAP. SC-2 requires a STATEMENT-based
classifier. Phase 164.4 backfills ~70 files against this primitive — it must be sound first.

`neuterArm` / `statementEndLine` / `failureBranches` in run.mjs; pins in

104/103 real-corpus re-measurement; full corpus run still green (30/30/0, biting 30).

dependency — `libpg-query` and `pgsql-ast-parser` were explicitly REJECTED and must not be
reintroduced; the tokenizer carries `'…'` / `"…"` / `$tag$…$tag$` / `/* */` / `--` state ACROSS

<assumption_delta_decision>
Primary noun: line → STATEMENT. Decision: **promote** — the statement (with quote / dollar-quote /
comment state carried across lines and a 1-based start/end line span) becomes the primary
representation every classifier consumes; the line becomes a coordinate detail of one statement
variant. Rationale: four line-walking readers re-opened the same defect class four times because
each carried its own partial definition of "what is code" — promoting the statement to primary
makes that definition single and mechanically shared (one tokenizer in parse.mjs), and Primitive
B's raise-line resolution (plan 05) consumes the same spans, so the promotion is load-bearing for
the next wave, not cosmetic.
</assumption_delta_decision>
