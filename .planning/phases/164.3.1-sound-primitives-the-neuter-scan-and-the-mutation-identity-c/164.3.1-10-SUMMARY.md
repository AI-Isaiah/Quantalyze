## Task 3 — the CI step's extended assertions (quoted)

Inserted after the `biting > executed` arm, before the ARMS_FLOOR regression check:

```bash
lane_line=$(grep -a -m1 -E '^lane-invocations: [0-9]+ ' "$RUNNER_LOG" || true)
if [ -z "$lane_line" ]; then
  echo "::error::MEASURE_FAIL: the run printed NO 'lane-invocations: N' line, so the runner's second, independent count of arm lanes is unknown and its own cross-check cannot be re-asserted. Either the runner stopped reporting it (164.3.1-10), or the step above was not the gate (--parse-only executes zero arms and prints no lane tally)."
  exit 1
fi
echo "$lane_line"
lane_invocations=$(echo "$lane_line" | sed -E 's|^lane-invocations: ([0-9]+) .*|\1|')
case "$lane_invocations" in ''|*[!0-9]*)
  echo "::error::MEASURE_FAIL: could not read the lane-invocation count out of '$lane_line'."; exit 1;; esac
if [ "$lane_invocations" -ne "$arms_executed" ]; then
  echo "::error::MEASURE_FAIL — this is the GATE failing, not the corpus: the verdict loop reported $arms_executed executed arm(s) but the lane runner counted $lane_invocations arm lane(s) (executed=$arms_executed lane-invocations=$lane_invocations biting=$biting). Arms were claimed that no lane ran, or lanes ran that no verdict describes. The runner's own in-process floor exits 1 on this; a log reaching this step with these numbers was not produced by one honest run of the gate."
  exit 1
fi
```
