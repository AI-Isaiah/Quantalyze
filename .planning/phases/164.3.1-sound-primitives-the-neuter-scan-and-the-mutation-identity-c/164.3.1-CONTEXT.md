<decisions>
## Implementation Decisions

### Primitive B — where the arm identity lives (open DESIGN decision per the ROADMAP goal)

- **D-01 — Primitive B identity location** **Source-location attribution.** Drop the in-query nonce entirely. Run the lane with
  `\set VERBOSITY verbose` and assert the raise's error CONTEXT/LOCATION resolves to the gate file
  and line **the runner itself wrote for this lane**. The secret is no longer transmitted to the
  server, so `current_query()` and `pg_stat_activity` have nothing to read.
- A `sql`-step trigger raising the same message text reports a DIFFERENT source location, so it
  scores NO-IDENTITY rather than RED.
- **D-02 — Criterion 3 by demonstration** **Criterion 3 is met by demonstration, not by argument:** re-run the R4-C02 `current_query()`
  trigger against the new attribution and observe NO-IDENTITY. A PASSING CONTROL is required
  alongside it — the genuine arm must still score RED (identity ok) in the same run — because an
  attribution that rejects everything also passes the forgery test.
- Rejected: *sole-survivor neuter* (would raise per-lane neuters from 0–2 to ~29, making a
  tokenizer bug silently rewrite 30 arms' semantics, and letting arms that guard each other's
  preconditions pass vacuously). Rejected: *keep the nonce and record the residual* — the hole is
  already MEASURED live and the real corpus ships `CREATE TRIGGER` `sql` steps, so that is
  closing the example while the class stays open.
- Risk to verify during planning, not assume: psql's verbose error CONTEXT must be stable and
  machine-parseable for the raise shapes the corpus actually uses. If it is not, this is a
  blocker to surface — not a silent fallback to the nonce.

### Primitive A — the neuter classifier

- **D-03 — Primitive A statement tokenizer** **One hand-rolled statement tokenizer**, in `scripts/mutation-runner/parse.mjs`, carrying
  `'...'`, `"..."`, `$tag$...$tag$`, `/* ... */` and `-- ...` state ACROSS lines, and emitting
  STATEMENTS rather than lines. No new dependency.
- `executableText`, `isBranchHead`, `neuterArm`'s forward scan and `statementEndLine` all route
  through it, so the file has ONE definition of what is code.
- Closes by construction: [R4-C01] (the seven compound lines above) and [MUT-I01] (apostrophe
  inside a `--` comment → spurious `neuter-missed`; even-parity → silent OVER-neuter).
- Rejected: *a real Postgres parser* — `libpg-query` is a native dependency in a repo with a
  banned-package supply-chain gate, and `pgsql-ast-parser` does not cover all PL/pgSQL, so it
  would need a fallback reader, reintroducing the two-readers-with-composing-blind-spots defect
  ([VAC04-C1]) this phase is closing.
- Rejected: *anchoring the two regex arms only* — the ROADMAP goal names this explicitly ("a
  fifth regex pass will not close it"), and success criterion 2 requires a statement-based
  classifier.

### Primitive D — the machine check for self-referential oracles

- **D-04 — Primitive D AST rule as vitest gate** **TypeScript-AST rule shipped as a vitest gate.** Flag an `expect(SUBJ)` whose subject resolves
  to a `const`/literal declared in the SAME block and never routed through an import from the
  system under test. Uses the TypeScript compiler already in the repo.
- **D-05 — Primitive D RED by default** **RED by default.** Measured exceptions go in an explicit allowlist, and each allowlist entry
  must carry the measurement that justifies it — an unexplained entry is itself a primitive-D
  instance.
- **D-06 — Primitive D calibration at HEAD** **Calibration is part of the deliverable (criterion 5):** the rule must flag
  `src/__tests__/lint-sql-gates.test.ts:182-186` **at HEAD, before that site is fixed**. A rule
  written after the fix and never observed firing on the real instance is unproven.
- Rejected: *standalone script + CI job* — same detector in a different wrapper, plus aggregator
  wiring; the vitest path already gates through `frontend`.
- Rejected: *regex heuristic* — a line-based reader with quote/comment blind spots is Primitive
  A's own defect; shipping one to police Primitive D would be a new instance of the family.
