<decisions>
## Implementation Decisions

### Primitive B — where the arm identity lives (open DESIGN decision per the ROADMAP goal)

- **Source-location attribution.** Drop the in-query nonce entirely. Run the lane with
  `\set VERBOSITY verbose` and assert the raise's error CONTEXT/LOCATION resolves to the gate file
  and line **the runner itself wrote for this lane**. The secret is no longer transmitted to the
  server, so `current_query()` and `pg_stat_activity` have nothing to read.
- A `sql`-step trigger raising the same message text reports a DIFFERENT source location, so it
  scores NO-IDENTITY rather than RED.
- **Criterion 3 is met by demonstration, not by argument:** re-run the R4-C02 `current_query()`
  trigger against the new attribution and observe NO-IDENTITY. A PASSING CONTROL is required
  alongside it — the genuine arm must still score RED (identity ok) in the same run — because an
  attribution that rejects everything also passes the forgery test.
- Rejected: *sole-survivor neuter* (would raise per-lane neuters from 0–2 to ~29, making a
  tokenizer bug silently rewrite 30 arms' semantics, and letting arms that guard each other's
  preconditions pass vacuously). Rejected: *keep the nonce and record the residual* — the hole is
  already MEASURED live and the real corpus ships `CREATE TRIGGER` `sql` steps, so that is
  closing the example while the class stays open.
- Risk to verify during planning, not assume: psql's verbose error CONTEXT must be stable and
  machine-parseable for the raise shapes the corpus actually uses. If it is not, this is a
  blocker to surface — not a silent fallback to the nonce.

### Primitive A — the neuter classifier

- **One hand-rolled statement tokenizer**, in `scripts/mutation-runner/parse.mjs`, carrying
  `'...'`, `"..."`, `$tag$...$tag$`, `/* ... */` and `-- ...` state ACROSS lines, and emitting
  STATEMENTS rather than lines. No new dependency.
- `executableText`, `isBranchHead`, `neuterArm`'s forward scan and `statementEndLine` all route
  through it, so the file has ONE definition of what is code.
- Closes by construction: [R4-C01] (the seven compound lines above) and [MUT-I01] (apostrophe
  inside a `--` comment → spurious `neuter-missed`; even-parity → silent OVER-neuter).
- Rejected: *a real Postgres parser* — `libpg-query` is a native dependency in a repo with a
  banned-package supply-chain gate, and `pgsql-ast-parser` does not cover all PL/pgSQL, so it
  would need a fallback reader, reintroducing the two-readers-with-composing-blind-spots defect
  ([VAC04-C1]) this phase is closing.
- Rejected: *anchoring the two regex arms only* — the ROADMAP goal names this explicitly ("a
  fifth regex pass will not close it"), and success criterion 2 requires a statement-based
  classifier.

### Primitive D — the machine check for self-referential oracles

- **TypeScript-AST rule shipped as a vitest gate.** Flag an `expect(SUBJ)` whose subject resolves
  to a `const`/literal declared in the SAME block and never routed through an import from the
  system under test. Uses the TypeScript compiler already in the repo.
- **RED by default.** Measured exceptions go in an explicit allowlist, and each allowlist entry
  must carry the measurement that justifies it — an unexplained entry is itself a primitive-D
  instance.
- **Calibration is part of the deliverable (criterion 5):** the rule must flag
  `src/__tests__/lint-sql-gates.test.ts:182-186` **at HEAD, before that site is fixed**. A rule
  written after the fix and never observed firing on the real instance is unproven.
- Rejected: *standalone script + CI job* — same detector in a different wrapper, plus aggregator
  wiring; the vitest path already gates through `frontend`.
- Rejected: *regex heuristic* — a line-based reader with quote/comment blind spots is Primitive
  A's own defect; shipping one to police Primitive D would be a new instance of the family.

### Blast radius, absurdity floors, and CI wiring  ⚠️ OVERRIDE — see Open Tension below

- **VAC-04's zero path WARNS LOUDLY and does not block until Phase 164.4 lands**, then flips to
  exit non-zero. Founder call 2026-09-01, taken to avoid wedging migration PRs while this branch
  is mid-flight. (The recommended option was to block immediately.)
- **The flip itself must be pinned by an arm.** A future promise is exactly the shape this phase
  distrusts, so the deferral is only acceptable if a machine fails when the flip does not happen.
  Planning must produce that arm, not a TODO.
- **Absurdity floors** on VAC-04 (which can otherwise report "every function is new — pass" when
  its name reader breaks) and on the mutation runner (which can report arm counts it did not
  execute), alongside VAC-08's existing one.
- **Every threshold is set by MEASUREMENT with wide separation, never by taste** — the way
  VAC-08's was picked (9/262 fires, 232/262 silent). Each floor is proven able to FIRE **and**
  proven SILENT on a legitimate finding — two-directional, because a floor that fires
  unconditionally also passes its own RED arm.
- **Regression corpus** carrying every measured instance across all four primitives (including
  the VAC-08 instances — the 253-of-262 verdict and the three-convention join) as EXECUTABLE
  arms, wired into the `frontend` aggregator's `needs:` list AND its result loop, following the
  Phase 164.3 pattern, so a failure fails the aggregate rather than passing quietly.
- **DIAGNOSTIC-FIRST is a hard requirement, not a nicety.** Every gate in this family PRINTS WHAT
  IT SAW on failure — counts, keys, samples — not only its conclusion. This is the strongest
  measured result of the 2026-08-29/30 ship: a shape diagnostic on VAC-08 surfaced two further
  ledger conventions in two CI cycles that four review rounds of reasoning had missed.

## ⚠️ Open Tension — recorded, not resolved

Success criterion 4 reads: "VAC-04 **cannot exit 0 having compared nothing**: the zero path fails
closed." The accepted blast-radius decision defers that flip until Phase 164.4 lands. A warn-only
zero path **does** exit 0 having compared nothing, so **criterion 4 is NOT met at the end of this
phase** — it is met in two steps, and the second step is in 164.4.

This is a deliberate founder call, not an oversight. Two consequences the planner and verifier
must both carry, so the gap cannot be silently absorbed:

1. The flip must be pinned by an executable arm that fails when 164.4 lands without it. A TODO
   does not satisfy this.
2. Phase verification must record criterion 4 as PARTIAL with this reason, not as passed. A
   criterion marked passed on a deferred promise is the exact "close the example, declare the
   class closed" shape this phase exists to stop.
