<objective>
Close the OPS-01 eviction mechanism and the OPS-02 ungated-gate hole in one ci.yml pass:
replace GitHub's `shared-test-db` concurrency group (which holds one pending slot globally and
evicts a queued main run when a third contender arrives — issue #616's grey-`cancelled` +
silently-skipped Railway deploy) with an external FIFO mutex (Postgres session advisory lock on
the TEST project), proven end-to-end by a tracer probe BEFORE the three CI jobs adopt it; then
wire `sql-tests` into the `frontend` aggregator so the only gate that executes deployed cron
bodies can no longer be present-and-failing with nothing gating on it.

Purpose: a merged PR always produces an honestly-reported CI verdict; a PR opened mid-run can no
longer evict a queued main-branch run (ROADMAP 158 SC-1, SC-2).
Output: `.github/workflows/mutex-probe.yml` (new) + modified `.github/workflows/ci.yml`.
</objective>
