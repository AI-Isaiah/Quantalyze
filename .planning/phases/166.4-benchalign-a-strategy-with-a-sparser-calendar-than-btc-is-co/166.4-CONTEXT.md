<code_context>
## Existing Code Insights

- Root cause (ROADMAP evidence): M1, commit `d16b2fb4c` (v0.24.9.31, #323, audit batch 5), moved alpha and beta from `qs.stats.greeks` on the unaligned pair (which reindexed BTC price levels to the strategy's dates, so it paired a Monday return with the Fri→Mon move) to `returns.align(benchmark, join="inner")`, which pairs a Monday return with BTC's Sun→Mon daily move. Phase 166's `_greeks_no_guess` reproduces M1 exactly.
- The metrics disagree today: `_r_squared` (reached through `compute_qstats_scalars`) uses `_align_benchmark_like_qs`, which rebuilds BTC prices from returns and reindexes them to the strategy's dates; correlation and `info_ratio` in `compute_all_metrics`, `_greeks_no_guess`, `_rolling_greeks` and `_rolling_correlation` use the inner join. So r² ≠ correlation².
- `_align_benchmark_like_qs` fills in three places (`fillna(0)` on the benchmark returns before cumprod, `method="bfill"` on the reindexed prices, `fillna(0)` after `pct_change`). Each is a fill that D-A forbids across a gap; research must state which of them fire on real inputs.
- Measured by the orchestrator on a 67-point weekday-only series: pre-M1 beta negative, M1/Phase 166 beta positive (a sign flip), r² identical under both.
- Not yet traced: `stitch_composite` (`run_stitch_composite_job`) and the single-key broker path.

</code_context>

<specifics>
## Specific Ideas and Open Questions for Research

- **Where BTC enters and in what shape.** The metrics receive benchmark RETURNS. D-A's formula needs a close at both endpoints. Research defines "gap" and "skip" precisely for a returns series (a missing index date; a NaN return), and traces the call sites (analytics runner, broker dailies, basis series, job worker, stitch) to see whether BTC prices are available there.
- **Which test M1 added.** Success criterion 2 says M1's test stays green; research names it by test id.
- **SC1 against SC4 on dense series.** Research measures, on a dense daily fixture, whether today's `_r_squared` already equals correlation². The qs-shaped path sets the first paired point to 0 while the inner-join path uses BTC's real return that day. If they differ, unifying r² onto the shared pair moves r² for dense series, and the plans must state which reading of "dense series stay bit-identical" holds (for example: bit-identical for alpha, beta, correlation, IR, Treynor and the rolling series; r² moves by construction because it is the metric being fixed). That choice goes to the founder, not decided silently.
- **166.3 selection.** Research checks whether `strategy_analytics` (read from `supabase/schema/baseline.sql`, never from a remote) carries any engine or version stamp 166.3 could select on; if not, `computed_at` on or after 2026-05-27 plus the sparse-calendar predicate is the selection.
