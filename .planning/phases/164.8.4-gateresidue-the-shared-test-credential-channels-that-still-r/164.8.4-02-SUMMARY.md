- **Issue:** The plan's own read_first correctly flagged that every reference must be workspace-rooted, but four pre-existing tests in `test-restore-workflow-wiring.test.ts` run extracted shell scripts via `spawnSync("bash", …)` with a hand-built `env` object that never included `GITHUB_WORKSPACE`. - **Fix:** Added `GITHUB_WORKSPACE: ROOT` (the test file's own `process.cwd()` constant) to each affected `spawnSync` call's env — matching what a real GitHub Actions runner always provides.
- **Files modified:** `src/__tests__/test-restore-workflow-wiring.test.ts`.
- **Verification:** All four tests pass; full suite 114/114.
- **Committed in:** `fb7739e6` (Task 1's commit — this was found and fixed during Task 1's own verify loop, before that task's commit).

- **Files modified:** `src/__tests__/test-restore-workflow-wiring.test.ts`.
- **Verification:** Both tests pass; full suite 114/114.
