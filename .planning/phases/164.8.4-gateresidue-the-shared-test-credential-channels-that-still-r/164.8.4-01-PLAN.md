  redaction — it guards the self-test harness's own captured output with a two-pattern grep that does
  not carry the connect-failure shapes at all. Extending it would prove one shape is DETECTED in a
  harness log.
- The substitute proves strictly more: that all six shapes are MASKED in the production definition,
  and — via the per-expression falsifier driven by `it.each` over the parsed file — that not one of
  the six is decorative. That is the property SC-1 and the anti-vacuity rule actually want.

  RATCHET (currently 27), and that script's own failure text requires an added arm to raise it in the

  regenerable only by running `--self-test` against a throwaway PostgreSQL cluster.
- ⛔ Note for the executor and the verifier: raising that ratchet to match an added arm would be the
  CORRECT direction and NOT an SC-4 violation. The point here is that no plan needs to move it, so
  none does. If any plan finds itself editing `EXPECTED_ARMS` in either script, something has gone
  wrong.

**2. RESEARCH Assumption A3 was NOT discharged, and it is moot rather than skipped.** A3 asks a
planner to re-read the global wrapper's current environment scrubber before finalizing the sentinel,
because the guard's trigger condition might need adjusting. The guard shipped in Plan 04 requires
explicit INTENT and does not attempt provenance detection at all, so no behaviour of that scrubber
can change its trigger. The CONTEXT decision also forbids editing the wrapper. A3 therefore cannot
change any plan in this set.

**3. Area 4's derivation is a separate script, not an inline `run:` block** (RESEARCH Open Question

carries a `--self-check`; an inline block can only be exercised by extracting and spawning it. The
repo already prefers small named scripts with their own coverage. Recorded in Plan 05.

**4. The Plan 04 guard has NO `CI` escape hatch**, on a measurement rather than on taste: no CI job
that runs vitest carries both live-DB variables. An escape hatch would be inert today and an
unearned exemption tomorrow, which SC-4 forbids. Recorded in full in Plan 04's measured baseline.
