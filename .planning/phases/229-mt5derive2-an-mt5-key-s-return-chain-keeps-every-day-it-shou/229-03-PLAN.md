<objective>
A timed MT5 key that stores no writer basis never composes silently on the legacy roll (MT5D-07). Founder ruling 2026-11-24 (CONTEXT "Timed MT5 key with no writer basis"): block it, like the holed-key precedent, with a counts-only log line naming the branch that returned no basis.

The writer alone knows the branch and that the key is timed; the compose sees neither. So the writer stores a closed reason token in the `key_inputs` payload (`writer_basis_withheld`) whenever a timed MT5 key reaches the store gate without a basis, and the compose reads the token at its three read sites and raises the existing blocking `key_inputs_mismatch` through the caller-supplied `degrade_reasons` list. No migration: `allocator_equity_derived.payload` is jsonb, and the field is additive and present-only.

Measured on PROD 2026-11-24 by the orchestrator: all 11 MT5 `key_inputs` rows carry a writer basis, so this moves no live key today.

Output: the token on `_NativeKeyUsd`, the store-gate write, the sibling reader, the three read sites, the reason row, and their tests.
</objective>
