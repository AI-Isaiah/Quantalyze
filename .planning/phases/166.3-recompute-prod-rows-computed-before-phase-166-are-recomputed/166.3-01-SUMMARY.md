**Root cause (reproduced locally by the orchestrator):** not Phase 166. It is the M1 alignment change, commit `d16b2fb4c` (v0.24.9.31, #323). M1 pairs each return of a sparse-calendar strategy with BTC's overlapping daily move (Sun→Mon, via an inner join). Before M1, quantstats paired it with the BTC move over the same holding interval (Fri→Mon). R1 was last computed before M1 deployed, so its stored beta was the pre-M1 value, and the recompute replaced it with the M1-era value. Phase 166's `_greeks_no_guess` is bit-identical to M1.

**R1's state now:** R1 carries the M1-era beta. It must be recomputed again after the fix. It is a private row, so no reader sees it.
