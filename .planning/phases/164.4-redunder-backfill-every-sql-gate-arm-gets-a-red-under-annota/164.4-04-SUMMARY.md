## Decisions Made

See `key-decisions` in the frontmatter. The two most consequential for later batches:

- **A gate file that PARKS its fixtures** (`status = 'draft'`) **and un-parks one arm at a time is
  cheap to annotate.** A predicate mutation only reaches the cohort published at that tick, so
  almost every arm here took a single-step `edit` with no `neuter`. A gate that seeds everything
  live would need far more neuters. Worth checking before estimating a batch.
- **`neuter` is per-RAISE, not per-arm.** `raiseStatementIndex` finds the FIRST innermost carrier,
  so naming an arm suppresses ONE of its raises. Sections whose arm raises twice (composite B, G, H;
  staleness A, C, D, F, H) cannot be fully suppressed, which constrains which sub-case arms are
  reachable. Five neuters were needed and all five name single-raise arms.
