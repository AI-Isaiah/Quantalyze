**2. [Rule 3 - Blocking] The verify's sorted-names comparison depends on the locale**
- **Found during:** Task 2 verify
- **Issue:** The first verify run failed on the `sort "$S/names"` comparison, and only there. The expected string is in byte order (`CHANGELOG.md VERSION package.json …`), but this host's `en_US.UTF-8` `sort` folds case (`CHANGELOG.md package.json … VERSION`). The inspected clone held exactly the six paths, a bot author and committer, and a green staleness gate.
- **Fix:** Re-ran the identical command under `LC_ALL=C`, the collation its expected string is written in. It passed. The script was not changed. Plan 04/09 authors should know the verify string assumes C collation. GitHub's ubuntu runners use C.UTF-8 by default, which sorts the same way.
- **Files modified:** none.
