| `redump-dump` → `redump-pr` | an artifact of exactly three files, uploaded only when `changed == 'true'`, kept for 1 day | the dump, the carried-migrations marker and the schema-validated `measured.json` |

## Residuals (low, recorded)

- **Bot-branch ownership is narrowed by CR-02.** D-24 declared an unconditional refusal on a foreign commit. The shipped behaviour refuses only while an OPEN PR heads the bot branch. Otherwise it resets under the lease with a `::notice::` naming the short shas. IN-05 records the reopen-in-window race.
- **Surfaces added in the review rounds, with no T-id; each fails closed:**
  - the anonymous open-PR lookup (`openBotPrsCurlArgv` / `anonOpenBotPrs`);
  - the anonymous `main` listing fetch (`anonMainMigrationListing`);
  - the D-30 repository setting.
- **Carried from REVIEW round 4:** WR-11, IN-01 (the read-only ghcr token remains in the docker config), IN-02 (setup-node receives the job token through its default input; the action is SHA-pinned and GitHub-owned), IN-06 through IN-10.
- **The dump step's CLI output may print the project ref.** It is a `vars` value and not a credential; the existing `apply` job has the same exposure.
