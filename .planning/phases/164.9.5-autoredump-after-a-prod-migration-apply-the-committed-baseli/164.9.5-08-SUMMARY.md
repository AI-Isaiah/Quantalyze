# Phase 164.9.5 Plan 08: bot-branch check and the one bot PR Summary

**`--check-bot-branch` refuses to force-push over a human commit on `automation/baseline-redump` and names the PR that commit sits on (or states that no PR points at it), from one anonymous `git ls-remote`. It hands the push a lease on the tip it judged. `--open-or-edit-pr` creates or edits the single bot PR, never merges it, and refuses on ambiguity, skip tokens and any gh failure. The D-10 no-op notice now reports the bot branch and its PR.**

## Accomplishments

- `findPullRefsForSha(lsRemoteText, sha)` returns the PR numbers, in numeric ascending order, whose `refs/pull/<n>/head` is exactly the sha. `/merge` refs and other refs are ignored.
- `--check-bot-branch --remote <name>` runs ONE `git ls-remote <remote> refs/heads/automation/baseline-redump 'refs/pull/*/head'` with the credential helper reset and the terminal prompt disabled:
  - When the branch is absent, it prints `baseline-redump bot-branch: absent` and `lease=`.
  - When it is present, it fetches the bot branch and `main` into `refs/remotes/<remote>/…`, requires the fetched tip to equal the listed tip, and runs `git log --format=%H%x09%an%x09%ae <remote>/main..<remote>/<bot>`.
  - If every author is the bot, it prints `baseline-redump bot-branch: present tip=<sha8> prs=<#n,…|none>` and `lease=<sha>`.
  - Otherwise it REFUSES. The `::error::` names the branch, `<k> of <n> commit(s) over main` and the short shas. It then names the PR(s) whose head is the tip, or states `No pull request's head points at tip <sha8>, so the commit was pushed after the branch's pull requests closed.` Author names, emails and commit messages are never printed.
- `--gate-dump`'s no-op notice keeps its leading text and appends `; bot branch absent`, `; bot branch at <sha8>; pull request(s) #n point at it (not closed automatically)` or `; bot branch at <sha8>; no pull request points at it`. A failed lookup prints `::warning::baseline-redump: bot-PR status not measured (git ls-remote exit <n>)`, and the run still prints `changed=false` and exits 0.
- `buildPrArgv` returns only `pr create --base main --head automation/baseline-redump …` or `pr edit <n> …`.
- `openOrEditPr` works in this order:
  1. It reads both files.
  2. It re-runs `judgeSkipTokens` over the title and body.
  3. It requires `GH_TOKEN` and a valid `GITHUB_REPOSITORY`.
  4. It lists open PRs on the bot branch and dispatches 0 → create, 1 → edit, 2+ → refuse.
  5. It emits `pr_number` and prints the URL.
- The self-test went from 172 to 198 assertions (205 with `--with-gitleaks`). The scratch fixture now carries a local bare `origin`.

## Deviations from Plan

**1. [Rule 2 - Missing critical] The fetched tip must equal the ls-remote tip.** The plan's lease is the ls-remote sha, while the author check runs over what `fetch` brought in. If the branch moved between the two calls, the lease would name commits nobody judged. A mismatch is now MEASURE_FAIL, with an arm driven by an injected `lsRemote`. Commit `ab459c89d`.

**2. [Rule 2 - Missing critical] `--remote` is validated as a plain remote name.** `parseFlags` only rejects values starting with `--`, and the value is the first positional of `git ls-remote`/`git fetch`. It has an arm. Commit `ab459c89d`.

**3. [Rule 2 - Missing critical] `--open-or-edit-pr` requires `GH_TOKEN` and a valid `GITHUB_REPOSITORY`, with no fallback.** A local `gh` keyring login plus the `DEFAULT_REPO` fallback that compose uses would otherwise let a local run open a real PR. It has an arm. Commit `51e2bd6f0`.

**4. `buildPrArgv` takes `title` rather than `titleFile`.** `gh pr create` has no title-file flag, so the caller reads the file and passes one validated line. The plan's parameter name was `titleFile`. The behaviour it specified is unchanged.

**5. [Rule 3 - Blocking] node_modules was symlinked instead of `npm ci`**, per the standing constraints. The link was removed before every commit.

**Total deviations:** 5 (3 missing-critical hardenings, 1 interface adjustment, 1 environment). **Impact:** stricter than the plan, and no refusal was loosened.
