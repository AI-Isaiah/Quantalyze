**1. [Rule 3 - Blocking] Path-sorting verify ran under `LC_ALL=C`.**
- **Found during:** Task 3.
- **Issue:** on macOS the `en_US.UTF-8` `sort` ignores case, so the verify's `sort "$S/names"` produced `CHANGELOG.md package.json … VERSION`. The expected string is byte-ordered, so the check failed even though the commit carried exactly the right six paths.
- **Fix:** re-ran the unchanged verify with `LC_ALL=C` exported. The script is unchanged.
- **Verification:** the verify then exited 0.

**2. [Rule 2 - Missing critical] compose checks `marker_sha256` against the in-dir marker.**
- **Found during:** Task 1.
- **Issue:** compose checked the artifact dump's hash but not the marker's, so a marker swapped inside the artifact would go unchecked.
- **Fix:** added one hash comparison next to the existing dump-hash check.
- **Committed in:** `9dd69e65c`.

**3. [Rule 1 - Bug] `refuseWriterDefects` said "nothing was staged" at a call site where six paths are staged.**
- **Found during:** Task 2.
