# Phase 164.8.2 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

⭐ **The register was authored at PLAN time and the branch moved a long way after it.** Six review
rounds rewrote the very files the mitigations live in — `assert_public_sql_dsn_free` was renamed
`refuse_credential_in_published_sql` and widened from one credential class to six, the artifact's
channel loop went from a glob to a by-name allowlist with a four-arm guard, `EXPECTED_ARMS` moved
26 → 27. **Every row below was therefore verified against HEAD (`7db3e77f`), never against the
plan's description of itself** — a mitigation that was true when written and has since been
refactored away is exactly the gap this audit exists to find.
