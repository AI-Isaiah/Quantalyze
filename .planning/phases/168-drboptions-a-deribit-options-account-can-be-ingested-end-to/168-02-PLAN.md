<objective>
Pin, one test per site, that `assignment` behaves like `delivery` on every basis wherever the
option book is read (D-07, D-04), decide the two remaining vocabulary sites (`_SIBLING_TYPES`,
`_SHAPE_FIELDS`), and bring every prose description of the option book events in line with the
code so the vocabulary cannot fork again.

Purpose: plan 01 swapped the six literal sites to `_OPTION_BOOK_EVENT_TYPES` in the same commit as
the classification. Without a per-site test, a later edit could revert one site silently and bring
back the mark-to-market double count or an un-zeroed assigned short. This plan makes each site
fail loudly on its own.

No migration is needed: this is pure Python and docs under `analytics-service/`.

Output: per-site tests and a smoothed end-to-end test, the two vocabulary decisions with their
tests, and the prose updates.
</objective>
