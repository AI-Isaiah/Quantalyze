## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (listed below).
- **After every plan wave:** waves 1-3 (PR-A): full mutation run, `lint-sql-gates`, the census vitests, `schema:functions:check`. Waves 4-7 (PR-B): full `test_cron_router.py`, the two new pytest files, `npx tsc --noEmit`, `npx vitest run src/components/strategy src/lib "src/app/factsheet/[id]"`.
- **Before `/gsd-verify-work`:** full suite green; plans 17 and 21 readings recorded.
- **Exit codes:** every task command that pipes a test tool or the typecheck into `tail` starts with `set -o pipefail` (after a leading `cd`, so the command stays grounded), or captures the output to a file first, so the tool's own status decides.
- **Max feedback latency:** 60 s for task-level commands, except the full mutation run in plans 03 and 04.
