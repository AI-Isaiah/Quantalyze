# Phase 170.1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This is a **copy phase**. Most of the contract is copy: exact strings, label vocabularies and a title list. The visual part is small. It covers the four elements the copy changes bring with them: the wizard status line on `/strategies` (D-07), the "vs current book" suffix on scenario KPI deltas (D-11), the empty chart subtitle (D-11), and the removal of `/referral` and its sidebar link (D-02). No new tokens, components, colours or fonts are introduced.

**Sources.** Locked decisions D-01..D-12 come from `170.1-CONTEXT.md`. Tone, voices and tokens come from `DESIGN.md`. Every enum value below was read from `supabase/schema/baseline.sql` CHECK constraints or the TypeScript closed sets at HEAD `d43b4e967` (v0.132.1.1) on 2026-10-15. A row marked **[discretion]** is Claude's choice inside the CONTEXT discretion areas or under DESIGN.md. Everything else is locked.

**Strings marked LOCKED are copied verbatim from CONTEXT.md.** Executors copy them byte for byte, including the ASCII apostrophes and the em dash (U+2014).
