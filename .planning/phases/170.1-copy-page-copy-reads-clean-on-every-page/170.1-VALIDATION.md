---

## Sampling Rate

- **After every task commit:** the test file(s) the task changes.
- **After every plan wave:** `npm run typecheck` plus `npx vitest run` over the touched directories, plus the pytest line when the CSV plan is in the wave.
- **Before `/gsd-verify-work`:** full lint, typecheck, vitest and pytest green.
- **Max feedback latency:** ~60 seconds per task.

Every new test carries a negative control: neuter the change, see RED, restore from a byte backup (never `git checkout`/`restore`/`stash` on uncommitted work).
