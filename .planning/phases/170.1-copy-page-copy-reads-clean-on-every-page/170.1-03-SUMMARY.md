# Phase 170.1 Plan 03: No "vs None", KPI deltas name their baseline Summary

**Charts with no comparator series print an empty subtitle and a vs-free aria-label, and every scenario KPI delta reads "{signed delta} vs current book" with an R-4 aria-label and a "Current book: {value}" title.**

## What changed

**Task 1.** `subtitleFor(cfg, cmpName, hasCmp)` returns `""` first when `hasCmp` is false; the call site passes `!!cmp.cumulative`, the test `ariaLabel` already used. `ariaLabel` returns `{title}: {strategy}` for both branches when `hasCmp` is false. The subtitle `<p>` stays rendered. New `TimeSeriesChart.no-comparator.test.tsx` (5 cases): `cumulative` on the picker's "None" (empty subtitle, no "vs None", vs-free aria-label); every comparator chart without a static subtitle; a `comparatorAsPrimary` chart (aria-label `{title}: {strategy}`, no "None comparator"); positive control (`vs BTC-USD`); and the hasCmp edge (a named comparator, `name: "BTC-USD"`, with `cumulative: null` renders an EMPTY subtitle and a vs-free aria-label, so the gate is the series and not the name).

**Behavior change (recorded as required).** Before this plan, a chart whose comparator block had a name but no series printed "vs {name}" with no comparator line drawn. It now prints an empty subtitle, which matches what the chart draws.

**Task 2.** The delta line is `div.mt-1.flex.flex-wrap.items-baseline.gap-x-1.font-mono.text-xs.tabular-nums` holding a `whitespace-nowrap` figure span (carrying `deltaPillClass`) and a `whitespace-nowrap text-text-muted` "vs current book" span. aria-label is `{label} delta vs current book: {delta} ({sign})`; title is `Current book: {live}`. The dash case keeps the suffix. No raw px added (`TimeSeriesChart.tsx` raw `text-[Npx]` count 5 before and after).

## Rule 7 note (surfaced difference)

UI-SPEC marked the aria-label shape `{label} vs current book: ...` as discretion; the founder-confirmed R-4 reads `... delta vs current book: ...`. R-4 was used. Every old selector ended in a colon (`^="Sharpe delta:"`, `^="Max DD 12m delta:"`, `^="YTD TWR delta:"`, `*="delta:"`) and so had to move; all were re-pointed, none deleted:
- `KpiStrip.scenario.test.tsx`: 14 selector lines (one is a comment), plus the `Live: ` title matcher and header comment.
- `KpiStrip.test.tsx`: 1 selector, 1 exact aria-label, 5 title strings and 1 comment (`Live: ` to `Current book: `).
- `display-sign-census-misses.test.tsx`: 4 selectors and 4 exact aria-labels.
- Pins that read `className` or `textContent` off the aria-label element were re-pointed to the figure span (`children[0]`), because that element now also holds the suffix and no longer carries the tone class. This includes the 4 colour pins in `display-sign-census-misses.test.tsx`, 3 muted + 3 toned pins and the `+0.31` text pin in `KpiStrip.scenario.test.tsx`, and 3 text + 2 class pins in `KpiStrip.test.tsx`.
- Census after: `grep -arlE '\^="[^"]* delta:"|\*="delta:"' src e2e` prints nothing.
