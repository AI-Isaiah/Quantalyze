```python
def _usable_closes(btc_closes: pd.Series) -> dict[pd.Timestamp, float]:
    """The closes that can price a return, keyed by their UTC calendar day."""
    out: dict[pd.Timestamp, float] = {}
    for ts, close in btc_closes.items():
        try:
            value = float(close)
        except (TypeError, ValueError):
            continue
        if not math.isfinite(value) or value <= 0:
            continue
        out[pd.Timestamp(ts).normalize()] = value
    return out
```

## Shared Patterns

### Absent, never filled (D-02)
Source: `analytics-service/services/native_to_usd.py:83-97` (`_usable_closes`: finite and positive only) and the module docstring "a day whose USD return cannot be formed ... is ABSENT ... never 0, carried forward or interpolated". Apply to all four writers, the matching conversion, the MTD, and the `usdView`. A native-balance forward-fill across quiet days is legitimate; a PRICE fill is not.

### One price source, two runtimes
Source: `get_btc_closes` (`benchmark.py:326`) and `readBtcCloses` (`benchmark-source.ts:305`), `BTC_CLOSES_SOURCE = "benchmark_prices only"`. No new query, never the bundled `BTC_DAILY` fixture, never `get_benchmark_returns` (170.2 re-windows it).

### Convert candidates, then correlate
Source: `routers/portfolio.py:2195-2201` (also `routers/simulator.py:350`, `routers/match.py:1104`): `_usd = UsdSeriesConverter(get_btc_closes)` once per request, `await _usd.convert(series_by_id, native_units_by_id(rows))`, an unconvertible id is a missing series.

### Single scalar out of a private blob
Source: `three_month:metrics_json->three_month`, `series_end:returns_series->-1->>date`, `cumulative_method:data_quality_flags->>cumulative_method`. One enumerated key, a negative pin on the bare column, a positive pin on the alias.

### Unit gate is one value
Source: `payload.returnsUnit` / `parseReturnsUnit` (`src/lib/factsheet/returns-unit.ts`), `parse_native_unit` (`native_to_usd.py:60-70`, `fullmatch`). Malformed reads as USD, never as label text; a unit is a parameter, never a literal.

### Migration discipline
Header with deploy order and rollback order; catalogue-only checks (`information_schema`, `has_column_privilege`); no data-reading `DO` block; down file; separate PR for the GRANT; marker query first for any PROD read (`SELECT shobj_description(oid,'pg_database') ...`).
