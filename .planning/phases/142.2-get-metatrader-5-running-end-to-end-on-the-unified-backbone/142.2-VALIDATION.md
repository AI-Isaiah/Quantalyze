## Oracle Independence

> The failure this catches: assertions that read their expected value out of the module under test.
> ⚠️ Live precedent on this codebase: **three money bugs survived six review passes** behind
> self-referential oracles. This section is not boilerplate here.

- [x] No test imports a **constant** from the module it tests — expected values are **literals** in
      the test. *Evidence:* plan 03's seven per-return-path verdict tests hand-type every expected
      string and import **nothing** from `SERIES_COMPLETENESS_VALUES`; plan 06's gate suite and
      plan 07's two 12-row route tables are likewise hand-typed.
- [x] No assertion compares a value to itself via a re-export, fixture, or table under test.
      *Evidence:* plan 07 chose to **duplicate the two route tables by hand** rather than share one
      — "two hand-typed tables that agree are evidence the routes are in lockstep; one shared table
      is only evidence a constant equals itself".
- [x] Table/registry sizes are pinned to a **literal count**, not to `len(THE_TABLE)`. *Evidence:*
      `wizardErrors.invariant.test.ts` pins the emitting-site count at the literal **12** per route
      (**not 14** — see correction (a)); `wizardErrors.test.ts`'s two hand-typed table-size guards
      moved 57 → **61** with the reasoning re-run over all four new entries **before** the number
      moved. ⚠️ Standing conflict, recorded not resolved: `DEF-142.1-08` in `TODOS.md` argues the
      opposite for `TIMEOUT_PER_KIND`; that conflict deserves its own decision, and this phase did
      not take it.
- [x] Any fake/double is pinned against the real contract it stands in for. *Evidence:* plan 06's
      `installGateSupabaseMock` serves a null verdict as an **absent row** (what the double always
      did, and what production coerces identically) rather than inventing a null-column row shape;
      `audit-fanout-integration.test.ts`'s mock now spreads the **real module** rather than
      hand-writing a second copy of the predicate this phase consolidated. Plan 05's SC-5/SC-6
      mutations were run **through the real producer**, not a mock.
- [x] **The D-15 economic fixture asserts an ECONOMIC INVARIANT.** *Evidence:*
      `test_funding_only_series_is_understated_and_never_certified` builds **two combiner calls with
      different inputs** and asserts `cumulative(gapped) < cumulative(truth) − 0.05` (bound
      hand-typed; designed understatement **8.77 pp**), compounding computed in the test from first
      principles `(1+r).prod()−1` — **not** via `compute_all_metrics` — so a shared compounding bug
      cannot cancel out of both sides. An anti-vacuity floor pins that the truth book shows material
      return, so the inequality cannot be satisfied by two near-zero series. The verdict-string
      assertion is a **second, separate** half, never the whole test.
      ⚠️ It also pins the **premise** that makes this the dangerous case: the gapped series is dense,
      has ≥2 interpretable rows (so `job_worker.py:4340` does not fire) and reports
      `computation_status_hint == "complete"` — it looks perfectly publishable.
- [x] The gate's verdict allow-list is pinned as **literals in the test**, not imported from
      `strategyGate.ts`. *Evidence:* SC-1's TS half — widening the allow-list reddened the

      demands. `strategyGate.invariant.test.ts` reads the `SERIES_TRUSTED_FOR_DAILY_BRANCH` **Set
      initializer from source text** (keyed off the constant's *name*, which fails loud if the
      constant is renamed or deleted) — it does not import the value.
