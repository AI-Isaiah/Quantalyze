<objective>
Close `SHARE-QA-07` (ROADMAP SC2). Rewrite `scrubSentryEvent` in `src/instrumentation.ts` so that no event shape can make it throw, a share token is never delivered, and the report is never lost. Every read and every write is guarded. A string is written only when `scrubSharePath` changed it (D-06), and each write is verified by reading it back (D-07). A slot that cannot be cleaned makes its holder be replaced at the nearest writable parent by an empty value of the same shape (D-08). When the escalation reaches the event root, a minimal replacement event carrying a fixed marker message is returned instead of `null` (D-08), and a transaction replacement keeps `type: "transaction"`.

Purpose: in `@sentry/core` 11.11.0 a `beforeSend` that throws is caught by `safeCallback` and the event is DROPPED (`callback_error`), so today a frozen object anywhere in the walked subtree silently loses the error report. That happens even when no token is present, because every string is assigned unconditionally. Returning the event unscrubbed would ship a live capability token, and returning `null` would lose the report; this plan does neither.

Output: guarded helpers and a replacement-event builder in `instrumentation.ts`; a nested `[209 SC2]` describe in `instrumentation.test.ts` that runs the REGISTERED hooks; a corrected contract comment; neuter-to-RED proofs in the SUMMARY (SC5).
</objective>
