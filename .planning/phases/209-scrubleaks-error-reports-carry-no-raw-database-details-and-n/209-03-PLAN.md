<objective>
Close `170.3-OG-MALFORMED-ID` and `170.3-OG-P3-STATUS-VACUOUS` (ROADMAP SC3). The signed-out OG route checks `isUuid(id)` before its published-only read. A malformed id is then treated as not-found: no read, the generic card, the long cache, no failure log, no `shouldCaptureNow` call and no capture. It can no longer spend the one-per-minute `og-factsheet:read` Sentry slot and mask a real read failure. The public-access test's P3 is rewritten so its status assertion can actually fail.

Purpose: since 170.3 the route is public. A non-uuid id reached `.eq("id", id)`, PostgREST answered 22P02, and the failure path ran on every hit: it logged, sent `no-store`, and spent the throttle slot. A malformed hit once a minute could hide a real timeout or column drift from Sentry.

Output: one guard plus one import in `route.tsx`; P3 and P5 changed on purpose and P6/P7 added in `route.public-access.test.tsx`; neuter-to-RED proofs in the SUMMARY (SC5).
</objective>
