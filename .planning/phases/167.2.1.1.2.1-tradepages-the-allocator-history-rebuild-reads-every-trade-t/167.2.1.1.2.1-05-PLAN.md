Facts measured at HEAD 6796b4f34 (cite by symbol):
- `_fetch_and_price_window(exchange, venue, supabase, start_date, end_date, *, require_anchor)` reads trades,
  transfers, OHLCV and the anchor and persists nothing, EXCEPT `_cache_coingecko_prices`, which upserts into
  `token_price_history` on a BadSymbol fallback and swallows any exception from that write (logged, logging is off in the
  probe). `_read_cached_prices` and `_read_account_keys` are selects.
- `_crawl_account_key` stamps a rate limit on `api_keys` through `_stamp_429`; `_crawl_whole_account` opens siblings
  through `_allocator_key_preflight`, whose circuit-breaker arm can write. The probe calls neither.
- `_read_account_keys(supabase, allocator_id, job_api_key_id)` selects every `api_keys` row of the user with the
  account columns (no `created_at`, no credentials) and refuses `account_state_unreadable` when the job key is absent.
- `_select_account_crawl_keys(account_keys, job_api_key_id)` returns `(selected, zero_contribution)` or raises
  `ForcedRebuildRefusedError(reason)`; `_account_rebuild_window(selected, end_date)` returns `(start, window_days)`;
  `_sum_account_rows(per_account_rows)` returns `(summed_rows, days_incomplete)`.
- `services/db.py` `db_execute` runs a synchronous query in a thread pool; `rows(resp)` reads `.data`.
- ccxt's okx raw method `private_get_trade_fills_history(params)` answers `{"code": ..., "data": [...]}` with a string
  `ts` per row (the strategy sync calls it).
- `scripts/bybit_upnl_probe.py` exports `sig3`, `classify_failure`, `FAILURE_CLASSES`, `validate_record`-style
  validators and `EXIT_*`; it is run as `railway ssh "cd /app && python -m scripts.bybit_upnl_probe"`.
