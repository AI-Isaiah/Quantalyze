    The emitted fragment: no `BEGIN;`/`COMMIT;`; one `DO` block with a dollar-quote tag unique to this script
    (distinct from `$restore$`); every name schema-qualified (`public.system_settings`, because the restore's
    `search_path` is `pg_catalog` at that point); the marker read via `shobj_description` on the current database

    by the caller through two environment variables the restore will set to its own `RESTORE_EXPECT_MARKER_RE` /
    `RESTORE_REFUSE_MARKER_RE` values; quotes are doubled with the `sed "s/'/''/g"` idiom. The emitter never
    connects to a database and writes no file (D-28).

    Add a second read-only mode `--print-sink` (D-17): it applies the SAME loopback charset check to
    `NORMALIZE_SINK` and prints the sink alone on one line to stdout, exit 0; on a non-loopback sink it exits
    non-zero with the same named refusal and prints nothing to stdout. It never connects and writes no file.
    Plan 05's restore self-test arms read their expected value from this mode, so no second hand-typed copy of
    the sink exists anywhere. The sink is not a secret (it is a loopback discard address), so printing it is safe;
