# Phase 164.9.1 Plan 08: the holdings sync route answers 409 for a disconnected key Summary

**`POST /api/allocator/holdings/sync` now maps the RPC error `{code: "P0001", message: "api_key_disconnected"}`, which M2 restored, to HTTP 409 with `NO_STORE_HEADERS` and the fixed sentence "This API key is disconnected. Reconnect it before syncing holdings." Before this, it fell through to the generic 500 ("Could not start sync. Try again in a moment."), which invites a retry that can never succeed. Any other `P0001` still reaches the logged 500. The route's comments now describe M2's in-flight prefetch instead of the handler M2 removed.**
