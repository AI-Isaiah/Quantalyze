## The false positive this wave nearly shipped

⛔ **MEASURED 2026-09-12, on committed PROD text carrying no credential at all.** The first spelling of the walk inherited `derivedLiteralLength`'s rule — sum every literal in the range — which is sound for a range that IS one value expression and wrong for anything else. `reconcile_dropped_enqueue_sweep` contains

```sql
(cj.status = 'failed_final' AND cj.last_error LIKE 'orphaned_running_reaped:%')
```

Two unrelated literals in a **boolean** expression. Summed, they read 37 characters, `fromConcat` was true, the digit guard was therefore skipped, and the committed manifest produced a `cron-secret-in-command` finding — the rotation remedy, hourly, on no evidence. The self-test caught it (`and NONE of them trips a hygiene rule (reconcile_dropped_enqueue_sweep: [long-token-anywhere])`).

`||` is now the only join, a comma never joins, and both directions are pinned by the `|| is the ONLY join` case. **Lever L6 reproduces it**, so that case is not decoration.

## Accepted residual, PINNED rather than hidden

A value that is **BOTH `||`-split AND left inside an UNBALANCED header argument list** is not named by the derived measure. The reason is structural, not principled: `fixture_unbalanced_headers_job` is a RED row whose header value must DERIVE ≥ `HEADERS_LITERAL_MAX` (`run.mjs` asserts it, because that length is load-bearing for the unparseable-region skip), and red rows must isolate one rule — so reporting the derived measure there would make it fire two.

It is a **downgrade, never a false green**: the row still reports `header-unparseable`, which is in `UNJUDGEABLE_RULE_IDS` and routes to `measure-fail` at exit 1. The **whole-token** spelling of the same credential after the same stray `(` is still named, because the literal producer deliberately does not exclude unparseable regions (164.8.5-REVIEW F2). The gap is exactly "split AND unbalanced", it is carried by `bypass_split_after_unparseable_job` with an `expect_not`, and `headerRegions`' docstring now records the three-way split (literal producer: no exclusion; comment producer: never asks; derived measure: excluded) in place of its stale prediction that "the token rule a later plan adds must exclude it too".
