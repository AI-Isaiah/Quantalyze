<objective>
Chain the archive-fills read from `sync_trades`, so a future OKX strategy's history older than `fills-history`'s reach is completed without an operator (CONTEXT "Trigger and scope", Claude's discretion recorded for the founder: chained from `sync_trades` like `derive_broker_dailies`; Addendum "Cooldown, not a marker table": anchor below the floor, earliest stored fill more than 2 days after the anchor, no `fills_apply` job in 14 days, `fills_calibrate` not counted; "Empty but clean read" counts as answered).

Purpose: SC-5's PROD backfill runs "through the product's own path" (`enqueue_compute_job` of `sync_trades`, as Phase 255 did). This seam is that path. It is also the only shape that keeps future OKX strategies complete with no human in the loop, which is why CONTEXT records it as the recommendation.

Output: `services/okx_archive_fills_chain.py`, a one-hunk seam in `run_sync_trades_job`, and `tests/test_okx_archive_fills_chain.py`. This plan does not depend on the job module: the mode literal `fills_apply` is defined here as `FILLS_APPLY_MODE`, and plan 07 pins it equal to the job's own mode set by a test.

Deviation from RESEARCH and PATTERNS, recorded at planning time: they gate the seam on the cursor-advance inputs, which include `phase1_failed` and `phase1_read_refused`. The ROADMAP's Phase 255 result shows the three PROD OKX strategies' daily read refused on every sync (`daily_pnl_non_usd_okx`) while the fills read is clean, so that gate would never fire for the strategies SC-5 names. The gate here reads the fills read only, which is what the archive reconcile depends on.

Scratch: set `SCRATCH` to the executing session's scratchpad path in EVERY shell call. Interpreter: `analytics-service/.venv/bin/python` (3.12). Phase base: `git merge-base HEAD origin/main`, computed at run time (`9f0fb9e6a` when planned).
