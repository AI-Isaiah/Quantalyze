Facts read from `parse_archive_csv` (cite by symbol):
- Each data row becomes `row = dict(zip(header, cells))`; then `row["billId"] = _strip_bill_id(row["billId"])`; then `raw_rows.append((line, row, tuple(row.values()), int(ts_text)))`. The in-file dedupe compares that tuple (`earlier == cell_tuple`), so anything stripped BEFORE the tuple changes dedupe; anything stripped at `ArchiveRow(...)` construction does not.
- `ArchiveRow` is a frozen dataclass constructed only in `parse_archive_csv` (no test constructs it), so trailing defaulted fields break no call site. Its `==` drives `duplicate_bill_conflict` across files in `aggregate_archive` and `verify_bal_chain` (`kept[0] != row`): widening the fields widens that equality, which is correct for one bill seen in two files.
- Quarter cut: `[day(start) - 8 h, day(end_exclusive) - 8 h)` in epoch ms (`_QUARTER_CUT_UTC_OFFSET_MS`).
