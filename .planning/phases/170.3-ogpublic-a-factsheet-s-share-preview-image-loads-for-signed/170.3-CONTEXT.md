<decisions>
## Implementation Decisions

### Public access
- **D-01:** add exactly `/api/og/factsheet` to `PUBLIC_ROUTES`, not `/api/og`. Only the route
  that exists becomes public, and a future OG route has to opt in. The proxy's existing match
  (`path === route || path.startsWith(route + "/")`) covers `/api/og/factsheet/<id>`.
- **D-02:** for an unpublished or unknown ID, a signed-out request gets today's generic card with
  a 200, the same as a signed-in request. The route already reads through `withPublishedOnly`, so
  no strategy data reaches an anonymous caller for a row that is not published. No 404.
- **D-03:** proof is a proxy-level test showing that a signed-out `GET /api/og/factsheet/<id>` is
  not redirected while another non-public `/api/*` path still is, plus a route test showing that an
  unpublished ID renders the generic card and carries none of the row's name, description or
  figures.

### Description
- **D-04:** shorten at the last word boundary at or under 140 characters, then append "…". A
  description of 140 characters or fewer is shown unchanged, with no ellipsis.
- **D-05:** a single word longer than 140 characters is hard-cut at 140 and given "…".
- **D-06:** collapse line breaks and runs of whitespace to single spaces, and trim, before
  measuring and cutting.

### Claude's Discretion
- Where the shortening helper lives (inline in the route or a small shared util), following the
  codebase's existing text helpers if one fits.
- The exact ellipsis rule against the 140 budget (whether "…" counts toward it), provided the
  rendered text never ends mid-word except under D-05.

</decisions>
