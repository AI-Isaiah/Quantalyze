## Focus-area findings

- **Runner-private lane only.** The python job reaches no shared TEST or PROD credential: no `secrets.*`, no `TEST_SUPABASE_DB_URL` in the job; the only DB values are the lane's loopback URL and key, gated by `--assert-local-handoff`. Unchanged by this phase.
- **No secret printed.** New helpers emit fixed messages and module names; gate failures print child pytest stdout, which for the offline selection (`partition_columns`) carries no DB values.
- **Coverage floor not weakened.** Argument string pinned to the exact D-06 literal, so a suffix, reorder or `--cov-fail-under=0` fails the pin.
- **No test silently skipped by grouping.** The hook only adds a marker; `--dist loadgroup` reschedules, it does not filter. No skip/deselect/xfail introduced; no test function removed.
- **Removed subprocess timeouts cannot exceed the job bound.** The python job carries `timeout-minutes: 90` (job level, unchanged). Rendezvous helpers keep a 30 s `asyncio.timeout_at` never-reached ceiling that fails loud. Six child `subprocess.run` calls lost their `timeout=`; a hung child is stopped by the 90-minute job timeout (cost: a hang burns up to 90 minutes before failing, not an unbounded hang). Local `make test` has no wall bound; same as before for the pytest process itself.
