   would silently end that property.

   is possible from the poll.**

   `const admittedAtMs = Date.now();` and above the try, so no `recordSeamFailure` path is reachable
   from a short-circuit — retrying into an open breaker cannot extend it.
4. **TRAP-4 untripped.** Pinned by `140.3-10`; **verify that pin still exists and is a table scan**,
   because this phase gave `keys/sync` codes and that is the change that could have woken it.

target.** Confirm this phase did not "improve" it.
