<objective>
Stop the admin match routes flattening every upstream failure to a bodyless 500, then render the
`424` as what it is: **the caller's venue failed, and it is named.**

Purpose: obligations `TS-19` then `TS-18`, in that order — TS-19 is a hard prerequisite because
**TS-18 has nothing to render until the status survives the route.**

## The flattening is broader than B-12 states — verified at source

Neither admin route has an `AnalyticsUpstreamError` arm at all (`grep -n "AnalyticsUpstreamError"` →
0 hits in both). Only `CircuitOpenError` (→ 503 + `Retry-After`) and `AnalyticsTimeoutError` (→ 504)
are branched. The terminal arm is **unconditional**:

```
console.error("[api/admin/match/recompute] error:", err);
return NextResponse.json({ error: GENERIC_COPY }, { status: 500, headers: NO_STORE_HEADERS });
```

**Every other upstream status — including a 424 — becomes a bodyless 500 with "Please try again".**
That is two failures at once: the status is lost, and a venue's outage is reported to an admin as
**our** 500.

## Why the 424 is now real, and why it was not before

`grep -rn "424" --include='*.tsx' src` → **no consumer branches on it anywhere.** It has never been
emitted. Plan `140.3-06` changed that: all seven `VenueTransientHTTPException` sites now answer 424.
This plan is the render half.

**The venue name is safe to display, by contract.** `analytics-service/services/error_contract.py`'s
`_validate` **refuses a 424 that names a *service* dependency**, so `body.detail.dependency` on a 424
can only be a venue slug — the two vocabularies cannot collide. **Verify that predicate still holds
first-hand before rendering the field**; it is TS-18's whole premise and it is a Python-side guarantee
being consumed from TypeScript.

⚠️ **`424` has no in-repo render analog** — this is one of the five items PATTERNS records as having no
analog. The nearest guidance is `STATUS_CONTRACT.md` §6 O-1 and TS-18's own wording:
*"Binance isn't responding right now — your key is fine."* Follow DESIGN.md's voice rules for the
actual sentence.
</objective>
