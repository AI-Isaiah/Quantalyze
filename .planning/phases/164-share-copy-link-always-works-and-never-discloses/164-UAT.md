## Defects found and fixed during this pass

Both were found by driving the browser. Neither was reachable by any test in
this phase, and neither appeared in the code review.

- **UAT-01 (blocking, fixed in `4db23fe3b`) — every `GET /strategies` threw.**
  `isPublishedStatus` was declared in `ShareableLink.tsx` (`"use client"`), and
  `strategies/page.tsx` is a SERVER component that CALLS it at `:186` to compute
  the `published` prop. Measured: three requests, three
  `Attempted to call isPublishedStatus() from the server` throws. The line was
  added by this phase. `page.share-affordance.test.tsx` makes the same call and
  passes, because jsdom does not enforce the RSC boundary — the test could not
  have caught it. Fixed by moving both pure functions to
  `src/lib/share-affordance.ts` (no directive) with `ShareableLink` re-exporting,
  so the one-predicate drift pin still holds.

- **UAT-02 (blocking, fixed in `4db23fe3b`) — the pending factsheet promised a
  link it could not mint.** `page.tsx`'s still-computing early return rendered
  `OwnerUnpublishedNotice` alone. That notice ends "You can create a private
  share link…" and the page had ZERO clickable elements. The block's own comment
  says the pending state "is when an owner is MOST likely to share the URL".
  Fixed with `OwnerUnpublishedPanel` — notice and controls driven by one
  `shareLive` state, because adding only a mint button would have manufactured
  the mirror-image false claim ("…until you revoke it", with no revoke control).
