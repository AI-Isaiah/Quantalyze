## The two arms added after plan-check, and why

- **Arm 17 — unresolvable-class tripwire.** The derived census resolves dependents through a
  `refclassid` WHITELIST. A non-public dependent of a public operator, opclass, collation or
  text-search object would escape it. The excluded classes are now pinned as a MEASURED empty
  set on the live database, and arm 17 gives that pin a subject (a public operator overlay).
  The whitelist is closed by measurement, not assumption.
- **Arm 18 — default-ACL carrier.** MEASURED on shared TEST 2026-09-08: `pg_default_acl` holds
  **6** rows whose `defaclnamespace` is `public`. Without a carrier branch the closure could not
  resolve that class, fell through to `pg_describe_object` text, and would have ABORTED the
  first real preflight naming an object the dump does restore (12 `ALTER DEFAULT PRIVILEGES`
  statements). Resolved by CARRIER, never by an exclusion list — an exclusion would also hide a
  default ACL in a NON-public schema referencing public, which is a genuine survivor.
  ⚠️ The dump QUOTES the schema identifier. A grep written unquoted matches ZERO and reads as
  "the dump omits these grants entirely". That mistake was made and corrected during planning.
