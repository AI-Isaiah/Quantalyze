**Seams (env, every DB read/write goes through them, defaults are the real path):** `RESTORE_DB_URL` (the SESSION-mode DSN; absent ⇒ `::error::` naming `RESTORE_DB_URL` + exit 1, never a skip — the newest credential-assert shape, lines 102-121 of .github/workflows/migration-drift-check.yml), `BASELINE_FILE` (default `supabase/schema/baseline.sql`), `BASELINE_DOC` (default `supabase/schema/BASELINE.md`), `MIGRATIONS_DIR` (default `supabase/migrations`), `FRESHNESS_TS_CMD` (default: `git log -1 --format=%ct -- <path>`; prints an epoch), `RESTORE_EXPECT_MARKER_RE` (default: case-insensitive, `test` as a whole word), `RESTORE_REFUSE_MARKER_RE` (default: case-insensitive `prod`), `RESTORE_OUT_DIR` (where census files are written; default a mktemp dir), `RESTORE_REQUIRE_MUTEX` (default `1`). `RESTORE_DB_URL` is NEVER echoed; psql stderr may be printed (it names SQL objects, not credentials).

**`--run` ordering — refusals first, all before the first write, each its own `::error::` line and exit 1:**
