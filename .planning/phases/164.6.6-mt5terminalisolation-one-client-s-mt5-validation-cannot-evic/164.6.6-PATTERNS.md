### §2 Committed remote-source discipline (T-134-03 / D-05)

**Source:** `analytics-service/services/mt5_client.py::_REMOTE_TERMINAL_RECYCLE_SRC` and
`Mt5Client.recycle_terminal_process`.
**Apply to:** the scrub verb, and any instance verb option (d) would need.

- One module-level assignment of a plain string literal. Not an f-string, not `.format`, and no
  brace anywhere. Contrast `_REMOTE_MATERIALIZE_SRC`, which IS an f-string and is the older
  shape. Do not copy it.
- The only run-time value crosses as an INT argument (`exit_wait_ms`), never as text.
- The far side returns `json.dumps(dict(...))` of ints, int lists and class names only. The
  image PATH is never returned ("the image PATH is never returned: it names the prefix").
- Per-item failures are COUNTED, never raised (`open_errors`, `terminate_errors`, `pid_errors`
  via `failure_name(exc)` = `type(exc).__name__`).
- The budget is internal: `budget_ms = 3 * exit_wait_ms`, `remaining_ms()`, and `unprocessed`
  counts work the budget skipped.

Call-site shape (`Mt5Client.recycle_terminal_process`):
```python
        self._assert_live("terminal_recycle")
        conn = getattr(self._mt5, "_MetaTrader5__conn", None)
        if conn is None:
            raise Mt5ClientError(
                0, "MT5 rpyc transport is not reachable for the terminal recycle"
            )

        exit_wait_ms = min(
            _TERMINAL_EXIT_WAIT_MS,
            int(self._request_timeout_s * 1000) // _TERMINAL_EXIT_WAIT_DIVISOR,
        )

        def _remote_call() -> str:
            conn.execute(_REMOTE_TERMINAL_RECYCLE_SRC)
            return cast(
                str,
                conn.namespace[_REMOTE_TERMINAL_RECYCLE_FN](exit_wait_ms),
            )

        payload = self._guarded_read(_remote_call, stage="terminal_recycle")
        try:
            counts = json.loads(payload)
            matched = _recycle_int(counts["matched"])
            terminated = _recycle_int(counts["terminated"])
            exited = _recycle_int(counts["exited"])
        except (TypeError, ValueError, KeyError):
            raise Mt5ClientError(
                0, "MT5 terminal recycle returned a malformed verdict"
            ) from None
        diagnostics = _parse_recycle_diagnostics(counts)
        logger.warning(
            "Mt5Client.recycle_terminal_process: terminate crossed — matched=%d ..."
```
Copy: `_assert_live(<stage>)` as the FIRST statement (D-36), the `_MetaTrader5__conn` seam with
typed raise, `_guarded_read(..., stage=...)` for scrubbing and timing, essential counts parsed
strictly and diagnostics tolerantly (a `_parse_*_diagnostics` that cannot raise), and the
counts LOGGED BEFORE any follow-up call (SFH-06). The log carries counts and codes only, never a
path, host, port or account.

### §3 The scrub cannot relaunch itself; the credentialed relaunch lives in orchestration

**Source:** `Mt5Client.initialize_with_credentials` (the house-credential relaunch) and
`tests/test_mt5_client_contract.py::test_TERMINAL_RECYCLE_the_verb_structurally_cannot_accept_a_credential`.

- The scrub verb's signature is pinned to `["self"]`, copying the recycle's signature pin. It
  is credential-free.
- Deleting `accounts.dat` also deletes the saved house login (RESEARCH Pitfall 2). A bare
  `initialize()` then comes back `-6`. So the scrub verb either does not relaunch, or records
  its relaunch as expected-`-6`, never as a failure.
- The relaunch is a SEPARATE call made by `mt5_relogin`, inside the SAME lease:
  `client.initialize_with_credentials(login, password, server)` with the house triple from
  `read_env_mt5_credentials()`. That method already carries the by-value redaction on both
  failure arms:
```python
        self._assert_live("initialize_credentialed")
        try:
            inited = self._timed(
                "initialize_credentialed",
                lambda: self._mt5.initialize(
                    login=login,
                    password=password,
                    server=server,
                    timeout=self._ipc_timeouts_ms["initialize"],
                ),
            )
        except Mt5ClientError:
            raise
        except Mt5SessionAbandoned:
            raise
        except Exception as exc:  # noqa: BLE001 — never let raw transport text escape
            raise Mt5ClientError(
                0, _redact_credential_values(str(exc), login, password, server)
            ) from None
        if not inited:
            self._raise_last(credentials=(login, password, server))
```
⛔ Never add a credential parameter to the scrub verb to "save a round trip". The
signature-derived redaction gate (`test_CREDENTIAL_REDACTION_every_credentialed_verb_routes_through_the_shared_redactor`)
would then need the scrub in its drive set, and the committed source would be one edit away
from carrying a credential.

### §5 Log and row hygiene (public repo)

**Source:** `mt5_session_episodes` module docstring "WHAT MAY NEVER REACH A ROW", `ATTRIBUTION_LIMIT`,
and `emit_mt5_stage_event`'s closed allow-list.
**Apply to:** every new log line and every new row.

- No login, password, broker server, gateway host, port or terminal key, and no free text from
  `last_error()`. Names, codes and counts only.
- A handover row is keyed by `api_key_id` (a UUID) or the literal `"house"`. Never read
  `account_info()` to learn the displaced account (the ATTRIBUTION_LIMIT comment forbids that
  extra read, and it would put an account number in memory and in logs).
- ⛔ Do not widen `emit_mt5_stage_event`'s field allow-list to carry `api_key_id`.
- Stdlib logger under the `quantalyze.analytics.` prefix, never a module-scope structlog proxy:
  `logger = logging.getLogger("quantalyze.analytics.mt5_session_episodes")`.

### Scrub verb — `analytics-service/services/mt5_client.py` (service verb, file-I/O on gateway)

Remote body skeleton to mirror (structure only):
```python
_REMOTE_TERMINAL_RECYCLE_FN = "_qz_recycle_terminal_process"
_REMOTE_TERMINAL_RECYCLE_SRC = """
def _qz_recycle_terminal_process(exit_wait_ms):
    import ctypes
    import json
    import time
    ...
    def failure_name(exc):

    budget_ms = 3 * exit_wait_ms
```

- Verdict dict fields are parsed like `_parse_recycle_diagnostics`: essential counts strictly,
  the rest tolerantly to `"unparsed"`, class names via `_RECYCLE_CLASS_NAME_RE`.

### Scrub contract tests — `analytics-service/tests/test_mt5_client_contract.py` (test)

**Analog:** `_install_recycle_double`, `_recycle_verdict`, `_FakeWin32`, and the
`test_TERMINAL_RECYCLE_*` family in the same file.

Harness to clone (`_install_recycle_double`): wrap `conn.execute` so the REAL committed source
is exec'd (proving it compiles and binds the name), then swap the bound function for a
recording stub:
```python
def _install_recycle_double(conn, *, returns=None, raises=None):
    record: dict = {"sources": [], "calls": []}
    real_execute = conn.execute

    def _execute(src):
        record["sources"].append(src)
        real_execute(src)
        assert _RECYCLE_FN_NAME in conn.namespace, (...)

        def _stub(*args):
            record["calls"].append(args)
            record["order"] = record.get("order", []) + ["remote"]
            if raises is not None:
                raise raises
            return returns

        dict.__setitem__(conn.namespace, _RECYCLE_FN_NAME, _stub)

    conn.execute = _execute
    return record
```
Tests to mirror one-for-one as `test_TERMINAL_SCRUB_*`:
- `..._a_live_session_sends_the_committed_source_then_relaunches`: asserts
  `record["sources"] == [<constant>]`, `record["calls"] == [(<int>,)]`, the ordering, and
  `fake.login_calls == []`. For the scrub, assert `fake.initialize_kwargs` carries NO
  credential keys (the credentialed relaunch is the orchestrator's job).
- `..._the_remote_source_is_a_committed_literal_with_no_interpolation`: an AST walk over

Adapter (unbounded, batch):
```python

        port_raw = os.getenv("MT5_GATEWAY_PORT")
        if not host or not port_raw:
            raise RuntimeError(
                "MT5 gateway not configured: MT5_GATEWAY_HOST / MT5_GATEWAY_PORT "
```

Rules:
- Both sites switch to ONE shared validation-endpoint reader. Copy the reader pattern from
  `mt5_relogin.read_env_gateway_endpoint` (per-call `os.getenv`, strip, int-parse), but each site
  keeps its OWN misconfiguration disposition (`service_error 500 MT5_GATEWAY_UNCONFIGURED` in the
  router, `RuntimeError` in the adapter). The reader is shared; the disposition is not.
- Build the key with `mt5_terminal_key(host, port)`, not a third hand-spelled `f"{host}:{port}"`
  (the `mt5_terminal_key` docstring: "never a second hand-spelled f-string"). Both sites
  hand-spell it today. Switching them is in scope because they are edited anyway.
- A second terminal is a second KEY in the one registry (Pitfall 4). Lease verb, wait bounds,
  deadlines (`_MT5_VALIDATE_DEADLINE_S`, `_MT5_PROBE_TIMEOUT_S`) are unchanged.
- The env names (for example `MT5_VALIDATION_GATEWAY_HOST` / `_PORT`) are `[ASSUMED]` (RESEARCH A10).
  Decide the fallback when unset: fall back to the job terminal (a silent return to today's
  eviction) or fail loud. Given U1, fail loud is the default recommendation, and that choice
  goes in CONTEXT.md.
- ⚠️ Coverage bill (RESEARCH option (b) row): `mt5_session_monitor`, the boot heal, the
  `ipc_fault` recycle and the prod-prober MT5 arm all key on the single
  `MT5_GATEWAY_HOST`/`PORT` pair via `read_env_gateway_endpoint`. A validation terminal is dark
  to all of them unless the plan extends each. Name it as scope or as a routed deferral.
