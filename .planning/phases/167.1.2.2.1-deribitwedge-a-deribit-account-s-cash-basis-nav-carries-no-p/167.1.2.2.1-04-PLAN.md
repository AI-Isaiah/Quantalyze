<objective>
Work item (B), compose half: an emptied account composes as zero capital instead of refusing the allocator's book (SC-3, founder D-01, D-02 as amended by D-04), RED first.

Purpose: the compose refuses any non-positive reconstructed level. With the writer fixed, an emptied stretch reconstructs to a level of exactly or nearly zero, and float noise then decides whether the whole book refuses. The founder's rule is that a level below 1% of the prior peak is zero capital with no return, and the book continues on re-deposit.
Output: the forward classification pass in `replay_key_equity`, and one new test file.

Downstream needs no code (RESEARCH 3.3, verified): `portfolio_returns` weights by the previous day's level, and a day on which every key is empty is already omitted and counted. The TS reader already accepts gapped returns (RESEARCH 3.4). No TypeScript change is planned; a Python contract test pins the payload shape instead.
Known semantic caveat, recorded and not fixed here (RESEARCH 3.4): the factsheet CAGR annualizes over the calendar span, so a book empty for long stretches reads a diluted CAGR. Plan 07 records it in the CHANGELOG notes.
</objective>
