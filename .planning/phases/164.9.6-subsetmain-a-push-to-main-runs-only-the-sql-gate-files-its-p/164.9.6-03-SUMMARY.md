# Phase 164.9.6 Plan 03: push-to-main SUBSET wiring and the scope-reason line Summary

A push to `refs/heads/main` whose derivation says `subset` now mutates exactly that list, and the assert step accepts it. A SUBSET on any other event is refused twice: by the mutate step, which runs FULL with a warning, and by the assert step, which MEASURE_FAILs and names the event and the ref. Every corpus run now prints one `scope-reason:` line directly after `scope:`, and CI fails a log that lacks one, has two, or has a blank one.

## What changed

**ci.yml `changed-paths`**
- The `sql_gate_subset` step gets `PUSH_BEFORE_SHA` and `PUSH_FORCED` through `env:`, using the same `github.event.*` expressions as `classify`. It gets no GH_TOKEN.
- The job outputs `sql_gate_reason`.
- A dated CORRECTED note was added to the DECISION D paragraph. The old sentence is kept as lineage.

**ci.yml `sql-mutation` mutate step**
- `SQL_GATE_REASON` was added to `env:`.
- The condition is now one line:
  `if [ "${GITHUB_EVENT_NAME:-}" = "pull_request" ] || { [ "${GITHUB_EVENT_NAME:-}" = "push" ] && [ "${GITHUB_REF:-}" = "refs/heads/main" ]; }; then`
- A general guard sits after the SUBSET block. Any non-empty, non-`full` mode that reaches it prints a `::warning::` naming the mode, event and ref, then rewrites and exports `SQL_GATE_REASON` as `the mutate step refused sql_gate_mode=<mode> on a <event> event (<ref>); the full corpus runs. Derivation said: <reason>`.
- The FULL command, `status=$?`, `cat` and `exit $status` are byte-identical to before.
- A dated `MODE IDENTITY, EXTENDED 2026-10-03` paragraph was added.

**ci.yml `sql-mutation` assert step**
- The step reads `ref_name` beside `event_name`.
- `subset_allowed` is true only on `pull_request`, or on `push` with `refs/heads/main`. The arm (2) message names the event and the ref.
- The D-12 block comes after arm (2) and before the floors read. A grep exit above 1, a count of 0, a count above 1, or a reason that is blank once whitespace is stripped each MEASURE_FAIL. It then echoes the line, and never parses it for names.
- The closing SUBSET echo now names the event and ref, and says ARMS_FLOOR "is compared by the nightly full-corpus run and by every FULL run". The static-bound error now reads "A full-corpus run cannot reach the floor".
- `timeout-minutes: 20` is unchanged (measured: exactly one `^    timeout-minutes: 20$` in the job).

**run.mjs**
- Adds the exported pure `scopeReasonLine({ subsetFallback, reason } = {})`. Every character in 0x00-0x1F, plus 0x7F, collapses to a space and the result is trimmed. Precedence is: the runner's fallback (it also carries the derivation's reason, or "none supplied"), then a non-blank reason, then `no derivation reason supplied (a direct invocation)`. There is no numeric constant, since run.mjs is threshold-bearing.
- `runCorpus` takes a `scopeReason` option. It logs `reasonLine` on the line directly after `log(scopeLine);` and returns it as `scopeReasonLine`.
- The CLI passes `process.env.SQL_GATE_REASON`. The argv contract is unchanged, and the header's CLI CONTRACT block has a dated D-12 line.
- The SUBSET ARMS_FLOOR note and static-bound defect now carry the new tails.

## Deviations from Plan

1. **The Task 1 / Task 2 split in ci.yml.** The D-12 assertion block was first drafted alongside the Task 1 edits. Committed there, it would have turned every count-recheck arm red until Task 2 added the fixture lines, so it was held back and landed in the Task 2 GREEN commit. The Task 1 commit is green on its own.
2. **[Rule 1] The refusal-reason quoting.** The plan's template quotes `'<event>'` inside the reason string. actionlint's shellcheck flags that (SC2089/SC2090) because the variable is exported. The quotes were dropped from the REASON only. The `::warning::` and the assert-step messages keep `'<event>'`.
3. **[Rule 2] Extra executed arms** beyond `<behavior>`: exit-status propagation on both mutate branches, and a PR control row inside the calibration.
4. **The `runCorpus` D-12 arm** was added to the existing `164.4.2-07 (D-D)` describe block, so it could reuse its stub lane. The plan named only the unit and source-pin blocks.
