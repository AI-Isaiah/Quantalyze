## Falsifiability Ledger

> **Coverage answers "is it verified?". This answers "CAN the verification FAIL?"**

**Rules — binding, and violated at least once in every prior phase of this milestone:**
- The mutation is a **semantic** edit to **PRODUCTION source** — a value, a boundary, a branch
  direction. **Never a syntax error, never a type error, never an edit to a test.** `tsc --noEmit`
  must exit 0 *under* the mutation, or the mutation is inadmissible and must be substituted.
- **Observed means run.** "The test covers it" is not evidence. Paste the failing assertion.
- A skipped mutation is recorded **skipped**, never **caught**.
- ⭐ **Prefer the SECOND member of a class.** 140.4 found nine acceptance criteria that passed on an
  untouched tree or failed on correct code; the whole phase existed because 140 shipped instance
  fixes that read as class fixes.
- **Revert every mutation before committing** and prove `git status --porcelain` is clean.
  ⚠️ **Never `git checkout --` a file holding uncommitted work** — 140.4's fix round destroyed 15
  uncommitted edits that way.

## Oracle Independence

> The failure this catches: assertions that read their expected value out of the module under test,
> so the test passes for any implementation.

- [ ] No test imports a **constant** from the module it tests — expected values are **literals**
- [ ] No assertion compares a value to itself via a re-export, fixture, or table under test
- [ ] Registry/roster sizes pinned to a **literal count**, never `len(THE_TABLE)`
- [ ] Any fake/double pinned against the real contract it stands in for

⚠️ **Phase-specific hazards, all measured:**
1. ⭐ **`sentry-capture.ts`'s false claim is defended by a grep that is LITERALLY TRUE** — zero
   `captureException` — while the sentence it supports is false (**107 sites** via
   `captureToSentry`). **A true grep supporting a false claim is this phase's purest specimen.** No
   plan may accept a grep as a receipt (CONTEXT §3).
2. **DEF-16-2 is live inside the mechanism this phase schedules:** widening `ci.yml:1633` to
   `src/**` + `tests/**` reddens a clean tree **today**, on one hit — and that hit is **a comment**
   (`ResponsiveChartFrame.test.tsx:6`). Comment-strip before counting.
3. ⭐ **No plan may cite "881 citations."** Three predicates produced three answers (817 / 846 / 391).
   **Every count in this phase publishes its predicate or is not a count.**
4. **Do not "correct" the registry's "six seam files" to eight** — the measured truth is **nineteen**,
   and `seam-log-coverage.test.ts:177` still says eight. Correcting to eight replaces one false
   integer with another.
5. **The wire table and the client rosters are NOT disjoint** — two overlaps
   (`KNOWN_KICKOFF_CODES` ∩ = `{RATE_LIMITED}`, `KNOWN_FINALIZE_CODES` ∩ = `{SEAM_MISCONFIGURED}`).
   Assert **agreement**, not disjointness. Three docblocks currently assert the false version.
