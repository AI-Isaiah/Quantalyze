## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Guarded `COMMENT ON FUNCTION public.latest_cron_success(TEXT)` against a missing target on the pg-lane**
- **Found during:** Task 1 (migration authoring, pg-lane sanity apply)
- **Issue:** `COMMENT ON FUNCTION` resolves its target at parse time; the pg-lane's fixture 33 only stands in for the `cron_runs` table, not the `latest_cron_success` function, so the unguarded statement aborted the migration apply on the lane.
- **Fix:** Wrapped the statement in `DO $latest_cron_success_comment$ ... IF EXISTS (SELECT 1 FROM pg_proc WHERE proname='latest_cron_success') THEN COMMENT ON FUNCTION ... END IF; END $$;`
- **Files modified:** supabase/migrations/20260918120000_prod_prober_cadence.sql
- **Verification:** pg-lane apply succeeds cleanly; migration's own self-verification block passes
- **Committed in:** d1d6ca63 (Task 1 commit)

**2. [Rule 3 - Blocking] Bumped `SELF_TEST_SCENARIOS` pin in `prod-prober-wiring.test.ts`**
- **Found during:** Task 2 (prober contact-write self-test scenario)
- **Issue:** `prod-prober-wiring.test.ts` carries a deliberate-edit pin (`expect(SELF_TEST_SCENARIOS).toBe(82)`) that goes stale the moment the prober's own count moves. Not in the plan's `files_modified` list but required for the suite to stay green.

- **Files modified:** src/__tests__/prod-prober-wiring.test.ts

**3. [Rule 3 - Blocking] Renamed gate arms G/S to G1/S1**
- **Found during:** Task 3 (mutation runner corpus-wide invariant check)
- **Issue:** `sectionOfIdentity()`'s `-SUFFIX` collapse rule only fires when a DIGIT precedes the suffix. Bare identities "G"/"S" left a bare "SETUP" raise as its own un-twinned top-level section, failing the corpus-wide every-SECTION-has-a-twin invariant.
- **Fix:** Renamed arms to G1/S1 (matching this repo's existing V1/U1/U2/C1 convention) and scoped the setup block to S1 alone as "S1-SETUP", which correctly collapses into section S1.
- **Files modified:** supabase/tests/test_prod_prober_cadence.sql
- **Verification:** `node scripts/mutation-runner/run.mjs --file supabase/tests/test_prod_prober_cadence.sql` reports `sections 2 / judged 2 / annotated 2 / waived 0 / biting 2` (correct — was 3 un-twinned sections before the fix)
- **Committed in:** 16e962ad (Task 3 commit)
