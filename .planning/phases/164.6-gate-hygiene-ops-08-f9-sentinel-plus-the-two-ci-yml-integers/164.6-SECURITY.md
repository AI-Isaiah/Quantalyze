# Phase 164.6 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| client → route handler | an authenticated owner triggers csv-finalize or an allocator holdings sync | request body (untrusted) |
| route → PostgREST RPC | the route re-issues an RPC once after a 40001 | RPC arguments |
| route (service-role admin client) → `compute_jobs` | the marker retraction rewrites job metadata with BYPASSRLS privileges | job metadata |
| pg_cron tick (definer, table owner) → `public.cron_runs` | the fan-outs write failure rows by ownership (no FORCE RLS) | counts + failed strategy ids |
| `cron_runs` readers → `failed_targets` | admin SELECT policy and service_role policy; anon/authenticated hold grants but no admitting policy | strategy ids |
| CI gate configuration → merge | floors and sentinel integers decide whether a weakened gate can merge | integers |
| public runbook → operator paste | runbook query output may be pasted into the public repo | counts only |
| repo → PROD database | `supabase/migrations/**` auto-applies to TEST then PROD on merge, no human stop | DDL |
