## ⛔ FINDING — RESEARCH.md and PATTERNS.md are WRONG about the second site. Measured 2026-09-17.

Both documents state that the companion function `enqueue_ledger_composite_refresh()` "has no
status conjunct at all" and is therefore not a second site. **It has one.** Measured with
`grep -n` over the source migration: the literal appears at two line numbers, not one.

supabase/migrations/20260911130000_ledger_fanout_grantees_and_dormancy.sql:611 — `AND s.status IN ('published', 'pending_review')`

That is the single-key fan-out, and it is the one this phase widens.

supabase/migrations/20260911130000_ledger_fanout_grantees_and_dormancy.sql:1059 — `AND s.status IN ('published', 'pending_review')`

That is `enqueue_ledger_composite_refresh()`, and it is NOT widened here.

**Three consequences, all load-bearing:**

1. **The migration widens ONE function.** Because it re-bases only
   `enqueue_ledger_refresh_for_strategies` from that function's own snapshot, the new migration
   file contains the literal exactly ONCE — which is what makes `occurrences: 1` correct for every
   new twin. There is one `prod-body-ack:` line, not two, and it is one for the right reason.
2. **The composite gate's own precondition must NOT be widened**, despite RESEARCH.md, PATTERNS.md
   and VALIDATION.md all instructing otherwise. That precondition guards arm H, the composite
   function's global burst cap, and it mirrors the conjunct of the function it guards — which stays
   at two values. Widening it would make it fail loud on a foreign `private` composite that the
   composite function would in fact REFUSE: an over-strict precondition, i.e. a false abort. Plan 03
   annotates that file instead of editing its literal.
3. **The composite function's own `private` blindness is a real, separate finding** and is booked in
   plan 03. It is not fixed here: `enqueue_ledger_composite_refresh` has no registered cron row at
   all, and widening it would make the deribit composite a candidate the moment one were ever
   registered — silently reversing the exclusion CONTEXT.md locks (D-01 stays; the composite is NOT
   reported as fixed by this phase).
