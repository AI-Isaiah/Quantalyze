`supabase/schema/functions/` holds the canonical current body of every function in this project.
Measured 2026-09-17, THREE of those bodies carry the two-value lifecycle literal:
`enqueue_ledger_refresh_for_strategies` (widened by this phase),
`enqueue_ledger_composite_refresh`, and `enqueue_poll_positions_for_all_strategies`.

RESEARCH.md and PATTERNS.md both state that the composite function "has no status conjunct at all"
and then instruct — as does VALIDATION.md's obligation table — that the composite GATE's
foreign-candidate precondition be widened in lockstep. That instruction is built on the wrong
premise and must not be followed: the precondition mirrors the conjunct of the function it guards,

candidate the guarded function would refuse anyway. Task 1 annotates the file instead.
