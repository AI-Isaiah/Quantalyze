## What changed

### `src/components/ui/LiveRegion.tsx` (new, coverage-law **ROW 1**)

```tsx
export function LiveRegion({ message, assertive = false }: LiveRegionProps) {
  return (
    <p
      role={assertive ? "alert" : "status"}
      aria-live={assertive ? "assertive" : "polite"}
      className="sr-only"
    >
      {message}
    </p>
  );
}
```

`className` is a hard-coded literal with **no override prop**, on purpose: the moment this primitive can
carry a visible style, adopting it stops being a no-op and becomes an unreviewed design change at every
adoption site at once. The docblock states the four non-obvious things a future "simplification" would
delete — that it implements DESIGN-05 rather than deciding it; that it is an extraction of the
`CardShell` idiom; why it is `sr-only`; and why the region renders **before** its message arrives (a
region mounted at the same moment as its text is frequently missed by assistive tech).

Corroborating measurement, comment-stripped:
`grep -vE '^\s*(//|\*|/\*)' … | grep -cE 'text-|bg-|border-|px-|py-|mt-|font-'` → **0** visual tokens.

### ⚠️ An unplanned consequence, and how it was resolved

Announcing *the same sentence the surface already renders* puts that sentence in the DOM **twice**.
`getByText` implicitly asserts uniqueness, so **11 pre-existing assertions across the three test files
broke** — all with `Found multiple elements with the text: …`.

I did **not** relax them to `getAllByText`. Each file gained one documented helper:

```ts
function visibleAndAnnounced(text: string): HTMLElement[] {
  const nodes = screen.getAllByText(text);
  expect(nodes, `"${text}" must appear exactly twice — the visible card + the sr-only LiveRegion`)
    .toHaveLength(2);
  return nodes;
}
```

This is **strictly stronger** than the `getByText(…).toBeInTheDocument()` it replaces: the exact count
pins the visible copy *and* the announcement together, so it fails if either is dropped or if a third
copy appears. It is why M96 reddens **five** cases rather than two.

**Zero `it(` blocks were removed** from any of the three test files (measured:
`git diff -U0 … | grep '^-' | grep -c 'it('` → **0**). No existing case was weakened.
