strictly per panel, because these panels validate independently and one panel's wait must never
render under another's.

else. A composite can contain a serialized venue, so the same 120 000 ms silent spinner D-05
forbids exists here — and this step already carries the per-panel discipline (`retryAfterSeconds`
is per panel for exactly this reason, `PanelState:296-303`), so the wait must follow it.

Output: per-panel abort, elapsed, card, cancelled state and client deadline, with the step-level
Continue path untouched.
