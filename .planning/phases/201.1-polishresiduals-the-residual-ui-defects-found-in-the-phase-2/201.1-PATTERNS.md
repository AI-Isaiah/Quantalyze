## Shared Patterns

### Real flex-basis on the flexible item of a `flex-wrap` row
**Source:** RESEARCH Pattern 1. **Apply to:** `AllocatorExchangeManager.tsx` (D-01), `ScenarioFooter.tsx` (D-06). `flex-1` is `flex: 1 1 0%`, counted as 0px by line breaking; give it a basis equal to the smallest acceptable width (12.5rem, 14rem) with `min-w-0` kept.

### The one UI date helper
**Source:** `src/lib/utils.ts` `formatDay` / `formatMonth` / `formatDayTime`. **Apply to:** CoverageTimeline, CompareEquityOverlay ticks and tooltip. Never add `toLocaleDateString`/`Intl`/month arrays (rule C fails them).

### Expected strings are literals, not helper output
**Apply to:** all date-asserting tests. Write NBSP via `\u00a0` escapes or a test-local `nb()`; building the expectation with `formatDay` is a tautology.

### Reflow and layout gates
**Source:** `assertNoReflow`, `assertTargetSizes`, `assertChildrenInside` in `e2e/helpers/reflow.ts` and `layout-narrow.spec.ts`. **Apply to:** D-01, D-06, D-02b e2e additions. First assert the target element is visible with the expected content, then measure (vacuity guard).

### Every new gate seen RED
Neuter on a byte copy, observe RED, restore with `cp` (never `git checkout/stash`). Applies to: cap test, LABEL_W oracle, helper code-point pin, census form (red and green fixtures), `basis` e2e rows, jsdom rerender test, footer wrap test.

### Golden bake
**Source:** `ci.yml` `workflow_dispatch` input `bake_svg_goldens`; README in `e2e/svg-chart-parity.spec.ts-snapshots/`. Never local `--update-snapshots` (host font hinting false-reds CI). Name any desktop/2560 golden that changes as a recorded exception (label-string mechanism).
